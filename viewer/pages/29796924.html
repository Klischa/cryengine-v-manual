Overview

This page covers the properties and options available for AI Entities in CRYENGINE.

Please note that some older options such as AIAlertness and AISpawner are now performed via Flow Graph, so check the available Flow Graph nodes for more options, if you can't find it here.

The main Entity new users will want to use is the Legacy Entities → AI → Characters → Human entity, which is the base character included in the CRYENGINE SDK.

AIWave

Used with AITerritory entity to create and control enemy waves for combat, see AI Territories and Waves for more information.

DamageTestEnt

With this entity you can test hit zones of the character model.

DummyPlayer

Flyer

Flyer is a simple flying entity, which can serve as a starting point for more sophisticated flying entities. Details on How to Create a Simple Flying Entity are available.

Human Entity Reference

The Human entity is used for AI characters. For reference, this entity used to be called "Grunt". The Entity has property options like Sight, Accuracy and Faction, so that designers can create custom enemy or friendly characters.

An AI Human entity has built in AI behaviors (via the ModularBehaviorTree), meaning they can be placed into the level with relatively little behavioral scripting and still function.

Basic functions like weapon firing are built into the entity scripts. Advanced behavioral scripting can be set up using Flow Graph.
