← ContentsUsing Area Solid with Audio EntitiesEN
  1. Create a Box as an AreaSolid object.
  2. Now place an "AudioAreaAmbience" entity from the "Audio" group under the Create Object tab, and place the ambience sound entity near the AreaSolid Object.
  3. Select the ambience sound entity. Then, AudioAreaAmbience Properties can be displayed on the right panel as shown in the image below. Now fill the PlayTrigger and RtpcDistance properties.

  4. Select the AreaSolid entity in the level, and then under the Properties tab click Pick button in the Target Tools field of the Area section. Now select the Audio Area Ambiance entity that has been placed near to the AreaSolid to attach the ambience sound entity to the Solid object as a target.
  5. Try to modify the AreaSolid object with the Designer tool as explained above. If users want to visualize the sound to see how it works, they can type s_DrawAudioDebug = abcdefvw in the console. When approaching an open space in the AreaSolid Object, users will be able to see the red ball as follows.
  6. Every time the AreaSolid object is modified with the Designer Object, polygons consisting of the area solid will be transferred to the Engine side and users will be able to make sure that the interaction between the sound object and the AreaSolid object as a result of the modification.
