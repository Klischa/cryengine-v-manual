Overview

Trigger entities are used to activate events in a level. The triggers entities can be found in Create Object → Legacy Entities → Triggers.

Area Trigger

The Area Trigger is activated when the player enters an area.

First, create an area shape. Then, select the area trigger entity with the PICK function.

Cinematic Trigger

The Cinematic Trigger is used if the player looks at a certain spot.

Proximity Trigger

The Proximitry Trigger is used when certain entities enter a box.
