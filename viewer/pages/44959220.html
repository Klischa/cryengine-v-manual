CRYENGINE provides a cutting edge rendering system that has proven to be capable of delivering some of the visually most stunning games, like Ryse: Son of Rome or Crysis 3.

The rendering system features a linear HDR pipeline, Physically Based Shading (PBS), Dynamic Lighting, High Quality Post Processing and Anti-aliasing, all heavily optimized to run efficiently on current-generation platforms.
