Overview

The editor supports typed properties where the type is derived from special prefixes in the property name. For a complete list of supported prefixes, refer to the s_paramTypes array defined in Objects/EntityScript.cpp in the Editor solution. This array maps prefixes to variable types.

The following is the list of prefixes supported by CryENGINE 3.0.0:
