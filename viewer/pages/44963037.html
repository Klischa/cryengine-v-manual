Overview

This article gives an overview of the content within the Sample Assets package available with CRYENGINE 3.6.

You can download this package for free via the DLC page on the CRYENGINE Store Page. We will continue to update the package with additional sample assets to show how to work with the latest CRYENGINE tech!
