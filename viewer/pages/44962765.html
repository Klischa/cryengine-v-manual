Release Highlights

CRYENGINE 5.5.1 while being a minor release does bring some worthwhile fixes and updates to the Engine.

Accessing CRYENGINE 5.5.1 and Sandbox Editor Source Code

Engine versions are now available through the CRYENGINE Launcher.

  1. Log into the CRYENGINE Launcher
  2. Go to LIBRARY -> My Engines where your currently installed and available Engines are listed. From there Engines can be updated (installed).

Sandbox Editor source code is only available via Github: https://github.com/CRYTEK/CRYENGINE
