Overview

CRYENGINE provides links and tools to various asset creation packages and version control programs. To simplify the setup process, it is recommended to use the CryToolsInstaller, which can be accessed through the CRYENGINE Launcher during Engine installation or through the CRYENGINE Launcher menu option Library → My Engines (expand the menu) Dependencies → Tools and Plugins.
