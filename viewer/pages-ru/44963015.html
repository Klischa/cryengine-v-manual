Редактор

  • Новый: (Flowgraph) Вывод названия режима огня оружия (строка) из узла WeaponSensor.
  • Новый: (Редактор слоев) Дополнительные кнопки управления слоями, позволяющие легко включать/отключать слои (CE-3960).
  • Новый: Добавлена функция «Преобразовать в GameVolume», позволяющая конвертировать фигуры (объемы воды) в GameVolumes (CE-1739).
  • Исправлено: (LODGen) Сбой при нажатии кнопки «Создать цепочку LOD» (CE-2928).

  • Исправлено: (Ландшафт) Флажок «Синхронизировать радиус для всех типов» в редакторе ландшафта не синхронизирует радиусы сразу (CE-4289).
  • Исправлено: (Particle Editor) Включение и отключение эффектов корректно обновляет излучатели. Отменено предыдущее изменение, сохранившее контейнеры с отключенными эффектами. Отключение и повторное включение всех дополнительных эффектов теперь корректно перезапускает существующие излучатели. Исправлена небольшая ошибка обновления с прикрепленной геометрией.
  • Исправлено: (Flowgraph) Исправлено перемещение поля комментария вниз при отмене и импорте (CE-4608).
  • Исправлено: вход в игровой режим после создания нового уровня с включенной AI/физикой приводит к сбою (CE-4705).
  • Исправлено: Сбросить ткань на переключателях игровых режимов (CE-2952).
  • Исправлено: Редактор Flowgraph и ModularBehaviorTree больше не переопределяет метод HyperGraphs CanConnectPorts (CE-4614).
  • Исправлено: Утечка памяти при загрузке уровня (CE-4447).
  • Исправлено: Исправлена ошибка, из-за которой значок объекта области ветра исчезал, когда он не активен (CE-2720).
  • Исправлено: диалоговое окно файла GeomCache, указывающее на неправильное расположение папки.
  • Исправлено: значение TOD может быть установлено на минус (включена проверка диапазона CTimelineCtrl) (CE-4401).
  • Исправлено: Функции сохранения в редакторе транспортных средств.
  • Исправлено: объект комментария теперь также показывает, связан ли он с другим объектом (CE-3926).
  • Исправлено: Сделана «перезагрузка геометрии», заново физикализирующая все (CE-73).
  • Оптимизированный: (FlashUI) переработаны флэш-узлы UI.
  • Оптимизированный: изменен скрипт GameVolume, теперь цвета по умолчанию не являются фиолетовыми. Увеличена плотность тумана по умолчанию. Добавлен текст описания к параметру AwakeAreaWhenMoving.
  • Оптимизированный: унифицированные настройки по умолчанию для цвета тумана, плотности и множителя для рек, WaterVolumes и GameVolumes.
  • Оптимизированный: сужена форма стрелки для узла потока Debug:draw:direction (CE-4480).

  • Оптимизированный: хранилище отладочных имен ATL теперь присутствует только в нерелизных сборках.

  • Оптимизированный: добавлены краткие описания в заголовки CryAudioCommon, небольшие изменения и исправления для существующих документов.
  • Оптимизированный: обновлен путь к библиотеке для Wwise v2014.1, сборка 5158.
