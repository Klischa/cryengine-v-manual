Обзор

Реализация актера игрока имеет возможность взаимодействовать с сущностями с помощью нажатия клавиши (по умолчанию «F»). Сущности, с которыми можно взаимодействовать, будут включать специальный значок на экране внутри игры, чтобы информировать игрока.

MakeUsable(NewEntity)

function NewEntity:IsUsable(userId)
  -- code implementation
  return index;
end

function NewEntity:OnUsed(userId, index)
  -- code implementation
end

Реализация IsUsable

Функция IsUsable вызывается, когда игрок направляет перекрестие на объект. Функция определит, может ли объект использоваться игроком, который его запросил. Функция принимает только один параметр, который содержит EntityId игрока, который пытается использовать объект.

Функция может вернуть 0 в случае, если игроку запрещено использовать сущность. Возвращая 0, UI не будет отображать значок "USE" над объектом.

В случае, если сущность действительно может быть использована, должно быть возвращено положительное значение. Значение будет сохранено и позже использовано при вызове функции OnUsed.

Реализация OnUsed

Функция OnUsed вызывается, когда игрок нажимает клавишу «Использовать» (по умолчанию «F»). Первый параметр — это EntityId игрока, запросившего использование объекта. Второй параметр передается с тем же значением, которое возвращает IsUsable.
