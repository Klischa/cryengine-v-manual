Обзор

Интеграция Scaleform 4 является дополнительной и отдельной от Scaleform 3.

Ниже показано, как выбрать между Scaleform 3 и Scaleform 4 в сборке Engine, полученной с помощью средства запуска CRYENGINE, а также скопировать необходимые двоичные файлы в пользовательскую сборку Engine (т. е. созданную с использованием исходного кода, полученного из GitHub), чтобы включить на них Scaleform.

Кроме того, на этой странице также объясняется, как включить в ваш проект новые узлы Scaleform Schematyc (экспериментальные) и сгенерированные компоненты для Scaleform 3 или 4.

Добавление схемы Scaleform в ваш проект

Чтобы включить в свой проект узлы Scaleform Schematyc (экспериментальные) и сгенерированные компоненты, вам необходимо добавить следующее определение плагина в файл .cryproject:

{ "guid": "", "type": "EType::Native", "path": "CryScaleformSchematyc" }

Добавление Scaleform Schematyc в ваш проект

Выбор Scaleform 3 или 4

Масштабная форма 3

По умолчанию Engine загрузит Scaleform 3, если:

  • Он встроен в двоичный файл CrySystem или;
  • он доступен через CryScaleformHelper.dll находящийся в двоичной папке (т.е. бин/win_x64) и нет определения плагина для CryScaleform в твоем .cryproject файл.

Масштабная форма 4

Сначала убедитесь, что следующие файлы DLL находятся в вашей двоичной папке (т. е. бин/win_x64):

  • CryScaleform.dll
  • CryScaleformDX11.dll
  • CryScaleformDX12.dll
  • CryScaleformVulkan.dll

Тогда в твоем .cryproject файл, добавьте следующее определение плагина:

{ "guid": "", "type": "EType::Native", "path": "CryScaleform" }

Загрузка Scaleform 4

Использование Scaleform с пользовательской сборкой движка

Скопируйте следующие библиотеки DLL из двоичного каталога модуля запуска (т. е. сборки двигателя, полученной с помощью средства запуска CE) в двоичный каталог вашей пользовательской сборки двигателя:

  • CryScaleformHelper.dll
  • CryScaleform.dll
  • CryScaleformDX11.dll
  • CryScaleformDX12.dll
  • CryScaleformVulkan.dll

Для совместимости версия вашего пользовательского движка должна совпадать с движком запуска.

Бинарный каталог Engine — это мусорное ведро/win_x64 папка вашего проекта.
