PushGameScope

Помещает область на вершину стека. 

GameStatistics.PushGameScope(scopeID)

PopGameScope

Удаляет область видимости из вершины стека. 

GameStatistics.PopGameScope( [checkScopeId] )

CurrentScope

Возвращает ID текущей области действия, -1, если стек пуст. 

GameStatistics.CurrentScope()

AddGameElement

Добавляет игровой элемент в указанную область. 

GameStatistics.AddGameElement( scopeID, elementID, locatorID, locatorValue [, table])

RemoveGameElement

Удаляет элемент из указанной области, если параметры данных совпадают. 

GameStatistics.RemoveGameElement( scopeID, elementID, locatorID, locatorValue )
