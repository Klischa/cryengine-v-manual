Конвертировать видео

Чтобы воспроизвести видео с помощью Scaleform, вам необходимо преобразовать видеофайл в формат .usm.

Видео Scaleform SDK поставляется с инструментом ScaleformVideoEncoder.exe, который позволяет конвертировать файлы .avi в формат .usm.

Загрузка видео в CRYENGINE

Есть два способа загрузить видео в CRYENGINE:

1. Загрузите usm напрямую

Простой способ отображения видео: напрямую загрузите файл usm через экземпляр IFlashPlayer.

IFlashPlayer* pFlashPlayer = gEnv->pSystem->CreateFlashPlayerInstance();
bool bRes = pFlashPlayer->Load("myvideo.usm");

Теперь вы можете визуализировать видео, как любой другой файл GFX.

pFlashPlayer->Advance(fDeltaTime);
pFlashPlayer->Render();
2. Вставьте объект «связанное видео» в свой Flash-ресурс.

Другой способ — поместить объект «связанное видео» в файл Flash, загрузить файл .usm с объектом NetStream и прикрепить его к объекту связанного видео.

Чтобы добавить видеообъект в свой Flash-ресурс, щелкните правой кнопкой мыши библиотеку и выберите «Новое видео...» в контекстном меню.

Поместите видеообъект на сцену и задайте имя экземпляра, например. "MyVideo". Затем добавьте следующее ActionScript код в вашем fla-файле:

// enable gfx extensions
_global.gfxExtensions = true;

// create new NetStream object with an NetConnection object
var NetC = new NetConnection();
NetC.connect(null);
ns = new NetStream(NetC);

// attach NetStream to the linked video object on stage
MyVideo.attachVideo(ns);

// play the video
onLoad = function()
{
  ns.play("myvideo.usm");
}

Если вы хотите получить информацию о состоянии видео, например. для отправки уведомлений через fscommand в ваш код C++ вы можете добавить функцию "onStatus" в свой ActionScript:

// listening to video events
ns.onStatus = function (infoObject)
{
    if (infoObject.level == "status")
    {
    if(infoObject.code == "NetStream.Play.Start")
      fsCommand("onVideoStart");
    else if (infoObject.code == "NetStream.Play.Stop")
      fsCommand("onVideoStop");
    }
    else if (infoObject.level == "error")
    {
        if (infoObject.code == "NetStream.Play.StreamNotFound")
      fsCommand("onVideoNotFound");
    }
}
