Обзор

Чешуйчатая форма GFx — это внешнее промежуточное программное обеспечение, обеспечивающее отображение элементов Flash на экране, таких как пользовательский интерфейс, HUD, текстуры на основе файлов Flash и т. д.

Flash-файлы должны обрабатываться GFxExporter перед использованием в CRYENGINE. Чешуйчатая форма GFx файлы используют GFX расширение для своих файлов. Ниже приведен пример short, как нарисовать базовый элемент Flash как HUD:

Открыть Game.h искать m_pGameAudio и добавьте ниже:

IFlashPlayer* m_pFlashPlayer;

При необходимости вы можете добавить IFlashPlayer заголовок:

#include "IFlashPlayer.h"

IFlashPlayer — это интерфейс, который предоставляет все функции для управления Flash-плеером внутри окна просмотра игры.

Откройте Game.cpp. Добавьте в конструктор инициализацию указателя флеш-плеера.

m_pFlashPlayer(NULL)

В CGame::Init функция создает экземпляр Flash player после m_pGameAudio был инициализирован.

if(!m_pFlashPlayer)
{
  m_pFlashPlayer = gEnv->pSystem->CreateFlashPlayerInstance();
  bool bResult = m_pFlashPlayer->Load("Libs\\UI\\YOURFILE.gfx");
  CryLogAlways("Loading Libs\\UI\\YOURFILE.gfx: %s", bResult ? "Done" : "Error");
  m_pFlashPlayer->SetViewport(0, 0, m_pFlashPlayer->GetWidth(), m_pFlashPlayer->GetHeight(), 1);
}

YOURFILE является заполнителем для вашего GFX файл, который должен находиться в корень\GameSDK\Libs\UI.

Экземпляр Flash player создается CrySystem. Вы можете получить доступ CrySystem через глобальную переменную gEnv.

Теперь вы можете визуализировать Flash-файл внутри CGame::OnPostUpdate функция.

if (m_pFlashPlayer)
{
  m_pFlashPlayer->Advance(fDeltaTime);
  m_pFlashPlayer->Render();
}

заранее синхронизирует игру с Flash-файлами. С заранее вы можете визуализировать анимированные Flash-файлы.

Вам нужно пройти уровень, прежде чем вы сможете увидеть результат, поскольку функции обновления игры не вызываются из главного меню.

Существуют различные CVar, которые могут управлять средой Flash:

  • sys_flash = включает/выключает Flash-рендеринг.
  • sys_flash_info = включает профилирование Flash и отображает различную информацию.
  • sys_flash_log_options = включает регистрацию нескольких аспектов, связанных с Flash (загрузка Flash, выполнение скрипта действий Flash и т. д.).

Вызов ActionScript в Lua

В ActionScript, позвоните:

fscommand("MyCommand")

который будет обрабатываться на C++ с помощью FSCommandHandler (IFSCommandHandler интерфейс). Поэтому, если у вас есть собственный класс (например, HUD Manager), который загружает ваши файлы Flash, вам необходимо зарегистрировать свой класс как FSCommandHandler для команд Flash через IFlashPlayer указатель с:

pFlashPlayer->SetFSCommandHandler(this);

(конечно, вы также можете иметь более одного обработчика команд, например, один для MENU и один для HUD)

После этого вы получите все команды, вызванные из Flash, в методе вашего класса на основе IFSCommandHandler интерфейс:

void MyHUDManager::HandleFSCommand( const char *szCommand,const char *strArgs, void* pUserData )
{
   if(!strcmp(szCommand, "MyCommand"))
   {
       CryLogAlways("Flash command received...");
   }
}

Если вы получили команду Flash, все, что вам нужно сделать, это вызвать метод сценария Lua (см. ScriptHelpers.h файл или напрямую использовать сам ScriptSystem (gEnv->pScriptSystem)).

Чтобы использовать его по-другому, вам нужно реализовать ScriptBind для вашего (например) класса менеджера HUD, чтобы иметь возможность обмениваться данными между Lua и C++ (взгляните на ScriptBind_Game.h ScriptBind_Game.cpp файлы для простого примера).

Из этих методов ScriptBind вы можете просто вызвать метод Flash через IFlashPlayer указатель с:

pFlashPlayer->Invoke0("FlashMethod"); // 0 arguments
