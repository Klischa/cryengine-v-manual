Обзор

Игра Sydewinder разработана на C#, а некоторые аспекты игры созданы с помощью редактора Sandbox.

Sydewinder использует файл одного уровня с именем каньон.крик. Этот уровень позволяет просматривать все 3D-модели и эффекты частиц, которые используются в игре. Кроме того, он содержит маркеры, помогающие позиционировать такие объекты, как камера и главное меню.

Игрой управляет компания SydewinderApp класс. В каждом кадре он проверяет глобальный статус, создает новые волны, обновляет позиции и очищает неиспользуемые элементы.

GamePool Класс содержит ссылки на все доступные сущности и позволяет игровому циклу очищать сущности, которые больше не требуются.

Бассейн игровых объектов

GamePool поддерживает все объекты типа DestroyableBase и унаследованные от него классы. Основная цель — отслеживать вновь созданные объекты и очищать их позже, когда они больше не нужны. Класс упрощает доступ к процедурам обновления, представленным в DestroyableBase класс.

В основе этого класса лежит _gameObjects словарь и несколько вспомогательных коллекций.

public static class GamePool
{
  private static Dictionary<uint, DestroyableBase> _gameObjects = new Dictionary<uint, DestroyableBase>();
  //...
}

Позвонив в static AddObjectToPool метод и предоставление DestroyableBase объект в качестве аргумента, регистрируемый объект будет обновляться для каждого цикла.

GamePool.AddObjectToPool(gameObject);

Вы можете удалить объект, который может быть выполнен в текущем цикле, отложив его выполнение. Чтобы объект был отложен, вам необходимо предоставить Entity ID объекта FlagForPurge метод.

GamePool.FlagForPurge(entityId);

OnUpdate

OnUpdate метод является основным методом для любой игры и будет вызывает каждый кадр компонентов сущности для обновить свой статус. Чтобы воспользоваться OnUpdate метод, от которого класс должен наследовать EntityComponent. Как только класс наследует от EntityComponent они могут override базу OnUpdate метод для получения вызовов обновления. В Sydewinder основной цикл игрового процесса обрабатывается в OnUpdate метод SydewinderApp класс, который можно найти в файле SydewinderApp.cs.

public class SydewinderApp : EntityComponent
{
  protected override void OnUpdate(float frameTime)
  {
    base.OnUpdate(frameTime);
    Update();
  }
 
  private void Update()
  {
    // Check game status.
    // ...
 
    // Spawn and update environment.
    // ...
 
    // Update player direction and speed.
    // ...
 
    // Update position of game objects including player.
    // ...
 
    // Spawn enemies.
    // ..
  }
}

FrameTime

Каждая сущность обновляется каждый кадр. Поскольку не все устройства одинаковы, может случиться так, что игра работает с другой частотой кадров (количество кадров, отображаемых в секунду), чем на устройстве, на котором она разработана. Чтобы гарантировать, что игровой процесс остается практически одинаковым на всех устройствах, frameTime можно использовать. Стоимость frameTime — это время, необходимое для обновления предыдущего кадра. OnUpdate метод EntityComponent автоматически получает frameTime каждый раз, когда его вызывают. Еще один способ получить frameTime состоит в том, чтобы получить значение FrameTime.Delta. FrameTime class — это класс static, который обновляется в начале каждого кадра, что упрощает доступ к frameTime из любого места кода.

Распространенным вариантом использования frameTime является перемещение объекта, что, вероятно, всегда должно происходить независимо от частоты кадров.

public void Move(Vector3 direction, float speed)
{
  var position = Entity.Position;
  // Normalize the direction before applying the speed to it.
  direction = direction.Normalized * speed;
  // Multiply the direction-vector by the frametime.
  // This makes it independent of the game's framerate.
  position += direction * FrameTime.Delta; 
  Entity.Position = position;
}


Статус игры

static State переменная указывает, находится ли игра в данный момент в режиме игры или нет. Это может измениться, когда открыто главное меню или игра поставлена ​​на паузу. Когда State не равен GameState.Running, тот Update метод немедленно вернется, поэтому новые объекты не создаются, а существующий объект не перемещается дальше.

// Check Game Status
// Ensures physics won't kick in while paused.
if (State == GameState.Paused)
{
  GamePool.UpdatePoolForPausedGame();
}
 
if (State != GameState.Running)
{
  return;
}

UpdatePoolForPauseGame Метод гарантирует, что объекты, на которые влияет физика, остаются в том же положении, устанавливая Velocity чтобы Vector3.Zero каждый кадр.

Обновить плеер

UpdateSpeed метод Player класс обрабатывает ввод пользователя в каждом кадре. После оценки входных данных он рассчитает скорость игрока. Он также проверяет скорость, поэтому игрок не может вылететь за пределы уровня.

Дополнительную информацию об оценке ввода с клавиатуры см. Вход и игровой контроллер статья. 

// Check Key input and update player speed.
if (Playership.Entity.Exists)
{
  Playership.CheckCoolDown();
  Playership.UpdateSpeed();    
}

Обновить другие игровые объекты

Каждый кадр UpdatePool метод называется. GamePool перебирает все зарегистрированные объекты, такие как объекты среды (Tunnel и Door классы) и вражеские сущности, чтобы обновить свои позиции.

// Update position of game objects including player.
GamePool.UpdatePool();

Создать врага

Игрок летит через бесконечный туннель, и будут появляться большие волны врагов, чтобы сделать игру более интересной. сложный.

Чтобы добиться точного времени появления в 3 секунды, FrameTime будет добавлен в _spawnTimer переменная. При превышении продолжительности появления таймер сбрасывается на 0, и случайная волна вражеских кораблей располагается за границей экрана, чтобы они не появлялись сразу на экране. В следующем цикле обновления корабли противника переместятся в видимую часть экрана.

// Add frame time and check if greater than or equal timer.
_spawnTimer += FrameTime.Current;
if(_spawnTimer >= SPAWN_EVERY_SECONDS)
{        
  // Reset spawn timer.
  _spawnTimer = 0;
    
  var waveType = Random.Next(3);
  var enemyType = Random.Next(3);

  // Increase speed for each difficulty level.
  var waveSpeed = new Vector3(0f, -11f - (HUD.Stage * 2), 0f);
  var spawnPoint = _spawnPoint;

  switch((WaveType)waveType)
  {
  case WaveType.VerticalLine:
    spawnPoint.z = 79;
    Enemy.SpawnWave(spawnPoint, enemyType, WaveType.VerticalLine, waveSpeed);
    break;
  case WaveType.HorizontalLine:
    var waveOffset = Random.Next(3);
    spawnPoint.z = 72 + waveOffset;
    Enemy.SpawnWave(spawnPoint, enemyType, WaveType.HorizontalLine, waveSpeed);
    spawnPoint.z = 64 + waveOffset;
    Enemy.SpawnWave(spawnPoint, enemyType, WaveType.HorizontalLine, waveSpeed);
    break;
  case WaveType.Diagonal:
    spawnPoint.z = 79;
    Enemy.SpawnWave(spawnPoint, enemyType, WaveType.Diagonal, waveSpeed);
    break;
  }
}
