Обзор

Панель «Компоненты» содержит все доступные компоненты, которые можно применить к объекту. В этой статье подробно описаны индивидуальные настройки каждого из Компонентов.

Когда эти Компоненты сущности применяются к сущности, в свойствах этой сущности появляется новый подраздел:

Его можно удалить из объекта, нажав кнопку в правом верхнем углу и выбрав Удалить.

Трансформация

Многие компоненты имеют настройку Transform. Это позволяет смещать их положение и ориентацию относительно объекта, к которому они прикреплены, при этом следуя за ним.

AI Наблюдаемый

Наблюдаемый компонент регистрирует объект в VisionMap и делает его «видимым» другими объектами, зарегистрированными как «Наблюдатели».

AI Слушатель

Компонент Listener регистрирует объект в AuditionMap и позволяет ему воспринимать звуковые стимулы. Компонент уведомляется, когда слышны какие-либо интересные стимулы.

Фракции, которые стоит слушать

Обрабатываться будут только звуковые стимулы, исходные сущности которых принадлежат этим фракциям.

Шкала расстояния прослушивания

Дополнительная шкала, которую можно применять для увеличения или уменьшения расстояния прослушивания.

Расположение ушей

Коллекция мест, которая определит, находится ли сущность в пределах слышимости звуковых раздражителей. Может также использоваться для направления лучей в эти места для определения падения звуковых препятствий и т.п.

AI Форма разметки навигации

Компонент Navigation Markup Shape используется для создания фигур разметки, позволяющих «помечать» треугольники в NavMesh различными аннотациями (типами областей и флагами). Аннотации можно установить в Скрипты/AI/Navigation.xml файл конфигурации.

AI Навигационный агент

Компонент «Агент навигации» дает возможность перемещаться в пространстве, находя пути к нужным пунктам назначения, следуя за ними, а также стараясь избегать столкновений с другими агентами.

AI Фракция

AI Обложка пользователя

Компонент «Пользователь обложки» работает совместно с системой перемещения и предоставляет возможность использовать обложки для объекта. Обложки — это созданные пользователем объекты (Cover Surface), помещенные в Sandbox.

AI Дерево поведения

Компонент, обеспечивающий возможность запуска дерева поведения для объекта. Дерево поведения автоматически запускается после запуска игры и останавливается после ее завершения.

Имя дерева поведения

Аудио

Окружающая среда

Прикрепите это к области (форме, рамке, телу, сфере и т. д.), чтобы назначить эту среду области.

Слушатель

Функции аналогичны микрофону; вы слушаете мировое аудио с позиции слушателя. Наиболее известное применение — прикрепление к камерам.

Триггер

Barebone Audio Trigger, который обрабатывает аудио триггеры, созданные в редакторе элементов управления звуком.

Дополнительные сведения о поведении Play/Stop см. эта страница.

Камеры

Камера

Это камера в мире, с помощью которой можно визуализировать уровень. Имейте в виду, что одновременно может быть активной только одна камера.

Объекты с компонентами камеры будут отображаться в Камера меню в Перспектива область просмотра (под Объект камеры).


Камера масштаба комнаты VR

Предоставьте новый Entity Component, который позволяет легко создавать камеру Roomscale VR. Это работает довольно просто: все, что пользователю нужно сделать, это перетащить компонент в свою сущность Schematyc, и он активируется сам по себе. Кроме того, компонент автоматизирует асинхронное внедрение камеры, эффективно получая координаты гарнитуры как можно позже, чтобы избежать ненужной задержки.

Отладка

Отладка

Компонент Debug Draw можно использовать для рисования текста отладки; текст будет нарисован в мировой позиции родительского объекта. Этот компонент может быть полезен для обозначения или выделения определенных объектов в мире.

Эффекты

наклейка

Компонент Decal проецирует текстуру на геометрию и ландшафт. Типичным вариантом использования наклейки могут быть, например, брызги крови.

Объем тумана

Компонент «Объем тумана» добавляет область тумана вокруг положения компонента. Это можно использовать для создания локальных областей тумана вместо глобального тумана с помощью редактора среды.

Излучатель частиц

Компонент Particle Emitter может испускать частицы в позиции родительского объекта.

Дождь

Этот компонент — единственный способ добиться дождя на вашем уровне. Он создает дождь в радиусе вокруг объекта, к которому вы прикрепляете этот компонент.

Водная рябь

Позволяет создавать рябь на поверхности воды. Это особенно полезно для кат-сцен, когда нефизизированные сущности движутся по водоему.

Геометрия

Расширенная анимация

Компонент Advanced Animations можно использовать для воспроизведения сложных настроек анимации. Это можно использовать для управления анимацией игрока или NPC в игре.

Перегонная сетка

Компонент Alembic Mesh позволяет вам добавить Геометрические кэши сущности.

Анимированная сетка

Компонент Animated Mesh воспроизводит анимацию для анимированной сетки. Обычно это используется для базовой геометрии с одной простой анимацией, например веером.

сетка

Компонент Mesh добавляет к объекту геометрию static, которую можно физически реализовать с помощью компонента Rigid-body.

Свет

Зонд окружающей среды

С помощью компонентов Environment Probes у вас есть возможность размещать кубические карты по всему уровню. Это очень полезно, особенно с отражающими материалами, поскольку автоматически присваивает кубическую карту всему, что находится в пределах ее радиуса.

Точечный свет

Точечный свет добавляет к объекту источник света, который излучает свет во всех направлениях; в реальном мире он ведет себя как лампочка.

Проектор Свет

Компонент Projector Light добавляет свет к объекту, который проецирует/излучает свет в определенном направлении на основе текстуры проекции. Типичное использование для фонарика в качестве примера.

Площадь

Коробочный коллайдер

Добавляет только физическую часть коробки к физике (без StatObj). Он по-прежнему использует слот сущности.

Капсульный коллайдер

Контроллер персонажа

Создает физику живого существа (PE_LIVING) для объекта. В качестве альтернативы рассмотрите возможность использования Sample Rigidbody Actor.

Максимальный угол подъема

Цилиндрический коллайдер

Добавляет в физику только часть физического цилиндра (без StatObj). Он по-прежнему использует слот сущности.

RigidBody

Физически воплощает объект в виде твердого тела или static (в зависимости от типа). Добавляет компоненты сетки и примитивные компоненты коллайдера как части. Обратите внимание, что эти компоненты сами по себе не будут физически реализовывать объект, они могут только добавлять части к объекту, который физически реализован другими способами, например компонентом RigidBody.

Параметры плавучести

Образец твердого тела Actor

Физически оформляет объект как PE_WALKING_RIGID, что является предлагаемой заменой PE_LIVING. Он имеет то же самое движение основной геометрии, основанное на развертке, настраиваемый набор лучей выборки земли (в отличие от PE_LIVING, фиксированного в центре), и он является производным от PE_RIGID, что означает, что он может плавно взаимодействовать с другими физическими объектами (исходные PE_LIVINGs моделируются независимо от обычных физических объектов, и поэтому их взаимодействия не такие мгновенные и отзывчивые). Естественно, он использует все геометрии, которые были добавлены к объекту, так же, как это сделал бы RigidBody (cgf, физические коллайдеры).

Сферический коллайдер

Добавляет к физике только часть физической сферы (без StatObj). Он по-прежнему использует слот сущности.

подруливающее устройство

Простой компонент, который может ускорять объект, применяя постоянный импульс на каждый кадр (который генерирует силу, ускоряющую объект).

VR Взаимодействие

Создает физические объекты рук и позволяет удерживать другие физические объекты с помощью контроллеров VR, физически ограничивая их «руками».

Физика транспортных средств

Физически олицетворяет объект как PE_WHEELEDVEHICLE (колесное транспортное средство на основе твердого тела)

Физическое ограничение

Внутреннее разрушаемое соединение

Создает внутреннее разрывное соединение между частями физического объекта. Соединение может либо соединять две части, либо одну часть с «землей» (соединительные части определяются автоматически путем проверки пересечений). Когда сущность получает импульсы (от столкновений или других источников), она пересчитывает внутренние силы между суставами и разрушает те, чьи пределы нарушены. Сломанные соединения могут дополнительно создавать динамическое ограничение между сломанными частями вместо их полного разъединения. Если нарушенным ограничением было скручивание, вокруг оси z соединения создается ограничение «шарнир» (1 DOF), в противном случае — ограничение изгиба (2 DOF).

Части, которые отделяются от основного объекта, всегда физически оформляются как жесткие объекты (PE_RIGID).

Динамическое ограничение

Линейное ограничение

Ограничивает перемещение объекта линией относительно другого объекта. Другой объект передается функции ConstrainToEntity или это может быть «мир», если используется ConstrainToPoint. Вращение также можно полностью отключить.

Ограничение плоскости

Ограничивает перемещение объекта плоскостью, относительно другого объекта. Другой объект передается функции ConstrainToEntity или это может быть «мир», если используется ConstrainToPoint. Вращение также может быть дополнительно ограничено.

Точечное ограничение

Создает ограничение «точка-точка» между двумя объектами. Другой объект передается функции ConstrainToEntity или это может быть «мир», если используется ConstrainToPoint. Вращение может быть ограничено в двух измерениях: как вращение вокруг оси ограничения и как изгиб этой оси в кадре одного объекта относительно кадра другого объекта.
