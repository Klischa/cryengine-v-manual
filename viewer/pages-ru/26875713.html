CRYENGINE Учебники по коду

В этом разделе представлены простые концепции архитектуры ядра. Наряду с исходным кодом движка и игры мы также предоставляем API с использованием Doxygen, чтобы помочь пользователям понять кодовую базу.

Ссылка API охватывает многие системы движка и предоставляет описание и список функций общих классов. В этом разделе действуйте осторожно, поскольку в состав CRYENGINE входит сложная кодовая база.

В технической документации у нас есть несколько путей для программистов, которые позволяют вам экспериментировать как с C#, так и с C++. Вы можете найти все: от подготовки сборки для Steam до программирования всей игры Sydewinder на C#.

Для получения дополнительной информации по темам, затронутым в этом Быстрый старт руководство и во всем редакторе см. CRYENGINE Руководство.
