Обзор

Ниже приведены некоторые важные изменения кода и данных, о которых вам следует знать при переходе на будущие выпуски CRYENGINE.

Прекращение поддержки Visual Studio 2012 и 2013 гг.

После CRYENGINE 5.1 мы больше не будем поддерживать Visual Studio 2012 и 2013. Пожалуйста, обновите свои проекты до Visual Studio 2015, поскольку предыдущие версии будут полностью удалены в последующих выпусках Engine. Пожалуйста, обратитесь к Visual Studio Поддерживаемые версии для получения дополнительной информации.

При сборке для Windows с помощью набора инструментов VS2012 или VS2013: в настоящее время для использования сторонней библиотеки Oculus требуется использование набора инструментов VS2015. Если вы планируете использовать VS2012 или VS2013 с CRYENGINE 5.1 (и вы согласны с отсутствием поддержки Oculus), удалите библиотеку Oculus из файла спецификации WAF для вашего проекта и удалите ее как зависимость от CryRenderD3D11 и CrySystem.
Мы планируем автоматизировать эту часть настройки, если в следующей версии Engine не будет использоваться набор инструментов VS2015.
