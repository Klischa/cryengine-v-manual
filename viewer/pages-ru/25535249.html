Обзор

Добавление узлов в граф можно выполнить несколькими разными способами, в зависимости от того, добавлен ли узел сущности или узла. На график можно добавить любую сущность на уровне, кроме кистей и порталов.

Узлы сущностей всегда работают с конкретным экземпляром сущности на уровне.

Узлы компонентов независимы от сущностей и используют сущности в качестве цели для выполнения определенных действий. Цель узла можно переназначать и изменять так часто, как это необходимо.

Узлы сущностей

Чтобы добавить узел сущности, выберите сущность и откройте график. Затем откройте контекстное меню графика, щелкнув правой кнопкой мыши на основной панели редактирования графика.

Выбрать Добавить выбранный объект чтобы вставить узел объекта в положение указателя мыши.

Рис1: Выбор объекта в редакторе Flow Graph.

Эта процедура работает только в том случае, если объект был выбран в окне просмотра «Перспектива». Опция контекстного меню, Добавить объект по умолчанию для графика, добавляет узел сущности, который уже был создан в Flow Graph.

Узлы компонентов

Узлы компонентов можно добавлять в граф, и для них не требуется какой-либо выбранный объект. Есть три способа добавить эти узлы:

  • Щелкните правой кнопкой мыши контекстное меню в окне редактирования графика.
  • Компоненты меню, и вы можете использовать Ключевое слово поиска в этом меню, чтобы найти свой компонент.
  • QuickSearchNode (Ярлык: вопрос).

В приведенном ниже примере описан процесс добавления сущности (Сущность: EntityPos) с помощью контекстного меню.

Чтобы добавить новый узел компонента:

  1. Щелкните правой кнопкой мыши главную панель редактирования и выберите Добавить узел.
  2. Выберите узел из списка подпапок.
  3. Выбрать Сущность чтобы открыть папку с узлами компонентов, связанных с объектами, а затем выберите EntityPos.

Удаление узлов

Чтобы удалить узел, щелкните его правой кнопкой мыши и выберите Удалить. Вы также можете удалить его с помощью Удалить ключ.

Перемещение и расположение узлов

Узлы можно перемещать, перетаскивая их на главную панель редактирования. Несколько узлов можно выбрать, удерживая кнопку Ctrl и щелкните все узлы, которые необходимо выбрать.

В качестве альтернативы можно использовать мышь, чтобы обвести рамкой все узлы, которые необходимо выбрать. Ссылки между выбранными узлами будут перемещаться при перемещении узлов, и их расположение будет автоматически изменено.

Копирование узлов

Чтобы скопировать один или несколько узлов, выберите узлы, которые необходимо скопировать, и щелкните правой кнопкой мыши любой из них. узел, а затем выберите Копировать . Все узлы, включая соединительные звенья, будут скопированы в буфер обмена.

Узлы можно вставить из буфера обмена в график, выбрав Вставить в контекстном меню.

Ярлыки: Удерживать Ctrl+С чтобы скопировать выбранные узлы и использовать Ctrl+В чтобы вставить их. Использование Ctrl+Сдвиг+В чтобы вставить узлы вместе со ссылками.
