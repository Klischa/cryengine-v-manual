Обзор

В этом руководстве объясняется, как настроить редактор (или игру) для захвата видео с CryENGINE, которое будет выводиться в виде отдельных кадров, а при необходимости также может выводить звук (в стерео или объемном звуке 5.1) в формате .wav. Этот материал позже можно будет скомпоновать с помощью любого программного обеспечения для редактирования видео.

Подготовка

Процесс захвата видеоматериалов требует ввода в консоль некоторых команд, чтобы запустить оба медиапотока.

Чтобы ускорить процесс, вы можете создать файлы конфигурации, которые будут выполнять все необходимые команды одновременно. Таким образом, вы сможете довольно быстро запустить и остановить процесс. Чтобы начать запись, вам необходимо настроить несколько вещей, которые будут обсуждаться ниже.

Настройки видео

Размер кадра

Высота и ширина захваченных кадров в редакторе обычно устанавливаются точно по размеру визуализированного окна перспективы. Вы можете легко изменить размер вида, изменив масштаб окна перспективы или щелкнув правой кнопкой мыши в правом верхнем углу окна просмотра перспективы, где отображается размер кадра.

Недавно в процесс захвата были внесены некоторые изменения, и теперь вы можете захватывать изображения с более высоким качеством, чем визуализированные, с помощью Sandbox и Launcher.

Переменные консоли, которые теперь используются вместе с кадрами захвата:

  • r_CustomResHeight=Н
  • r_CustomResWidth=М

Где N обозначает желаемую высоту кадра, а M — желаемую ширину кадра в пикселях.

Следующие несколько команд, о которых вам также следует знать:

  • r_CustomResMaxSize=4096
  • r_CustomResPreview=1

r_customresmaxsize Команда определяет максимальное разрешение, с которым движок будет отображать кадры.
r_customrespreview Команда включает и отключает предварительный просмотр рендеринга с пользовательским разрешением в окне просмотра, где 0 = нет предварительного просмотра, 1 = масштабируется в соответствии с окном просмотра, 2 = пользовательское разрешение обрезается до окна просмотра.

Кадров в секунду

Все захваченные кадры являются полными кадрами, также называемыми прогрессивными кадрами.

Определите необходимое количество кадров в секунду. Стандартное видео NTSC имеет частоту примерно 30 кадров в секунду, что является хорошим компромиссом между качеством и размером файла.

Видео высокого качества может иметь частоту до 60 кадров в секунду — разница в качестве при более высоких значениях едва заметна, но все равно будет занимать много файлового пространства. Движение не будет выглядеть плавным при частоте менее 24 кадров в секунду (киностандарт).

Фиксированный временной шаг

Чтобы принудительно установить фиксированную частоту кадров определенной скорости, используйте команду: t_fixedstep Н.

Где N указывает шаг по времени, который рассчитывается следующим образом: шаг по времени = 1 секунда / количество кадров.

Пример: 1 секунда / 30 кадров = 0,033333333.

0,0166666667 будет равно 60 кадрам в секунду. Если вы хотите записать видео со стандартной скоростью PAL (25 кадров в секунду), используйте значение 0,04.

Выбор формата файла

Захваченные изображения могут быть в нескольких различных форматах файлов. Хорошим выбором для среднего качества является формат .jpeg, тогда как .tga или .bmp лучше подходят для более высокого качества, а HDR — для изображений с высоким качеством динамического диапазона.

Формат файла захвата

Используйте консольную команду: capture_file_format Н

Чтобы выбрать нужный формат, N следует заменить на jpg, bmp, tga или hdr.

Местоположение файла

Записанные кадры будут храниться либо в папке по умолчанию под названием «CaptureOutput», расположенной в корневой папке, либо в пользовательской папке, определяемой с помощью следующей команды: capture_folder Н

Чтобы выбрать правильную папку, N следует заменить именем вашей папки (например, scene12_take1).

Имейте в виду, что когда вы начинаете запись, захваченные кадры будут помещены в текущую определенную папку, перезаписывая все существующие файлы с тем же именем.

Для каждой новой записи вам следует либо создать новую папку, либо переместить существующие файлы в другую папку, чтобы не потерять какую-либо работу.

Начало и окончание записи

Когда все настроено, можно запустить запись командой: capture_frames Н

Установите N на 1, чтобы начать запись, и на 0, чтобы остановить.

Настройки звука

Прежде всего, решите, нужен ли вам звук в формате стерео или объемного звука 5.1. Вам нужно будет изменить настройки звука в панели управления Windows. Перейдите в раздел «Звуки и аудиоустройства», выберите вкладку «Громкость», нажмите кнопку «Дополнительно» и выберите устройство вывода.

Деактивация звуковой системы

После загрузки нужного уровня вам необходимо будет деактивировать звуковую систему, прежде чем вы сможете перенаправить вывод звука в файл. Чтобы отключить его, используйте команду: #Sound.DeactivateAudioDevice()

Теперь вывод звука будет перенаправлен в корневую папку и сохранен в виде файла .wav. Звук не будет воспроизводиться в реальном времени, а будет точно привязан к заданному временному шагу. После повторной активации звука вы ничего не услышите, пока long не запишете его.

Для записи звука используйте команду: s_OutputConfig Н

N должно быть установлено на 3, чтобы активировать запись файла .wav не в реальном времени, или на 0, чтобы переключить его обратно на настройки по умолчанию (автоопределение).

Повторная активация звуковой системы

Для сброса звуковой системы используйте следующую команду: #Sound.ActivateAudioDevice()

Теперь в корневой папке игры будет создан файл .wav. Файл будет продолжать запись до тех пор, пока запись не будет отключена следующей комбинацией команд:

  • #Sound.DeactivateAudioDevice()
  • s_OutputConfig 0
  • #Sound.ActivateAudioDevice()
Несмотря на то, что вся звуковая система сбрасывается с помощью приведенных выше команд, некоторые звуки не перезапускаются до тех пор, пока они не будут правильно активированы снова. Это особенно относится к зацикленным звукам.
Чтобы воспроизводить правильные звуки, рекомендуется сначала начать запись видео и звука, а затем войти в любую область, которая запускает зацикленные звуки для записи.

Создание файлов конфигурации

Чтобы сделать несколько записей с одинаковыми настройками, может быть удобно создать файл конфигурации, содержащий параметры, необходимые для записи, чтобы гарантировать, что все захваченные файлы имеют один и тот же формат.

Файл конфигурации настроек может выглядеть так:

sys_spec = 4

Fixed_time_step 0.0333333333

Capture_file_format jpg

Capture_folder myrecording

r_width 1280
r_height 800

Команда sys_spec = 4 устанавливает очень высокие настройки графики игры, чтобы получить наилучший вид.

Чтобы ускорить процесс запуска и остановки записи, удобно создать два файла конфигурации: один для запуска и один для остановки видео.

Чтобы начать запись, вам понадобится файл конфигурации, который выглядит примерно так:

#Sound.DeactivateAudioDevice()

s_OutputConfig 3

#Sound.ActivateAudioDevice()

Capture_frames 1

Чтобы остановить запись, вам понадобится файл конфигурации, который выглядит примерно так:

Capture_frames 0

#Sound.DeactivateAudioDevice()

s_OutputConfig 0

#Sound.ActivateAudioDevice()

Выполнение файлов конфигурации

Чтобы активировать файл конфигурации, откройте консоль и введите: Руководитель Н

Где N — имя файла конфигурации.
