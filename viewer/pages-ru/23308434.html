Описание

Теги, специфичные для FragmentID (также известный как фрагтеги) являются теги которые вы можете назначить только фрагменты с конкретным fragmentID.

Они существуют, потому что множество тегов не обязательно должны быть доступны для всех фрагментов. Например, у вас может быть «хит» FragmentID, объединяющий все фрагменты, содержащие анимацию реакции на удар. Фактический тип попадания (например, «выстрел в голову», «взрыв», ...) затем будет закодировано в тегах. Но эти теги полезны только в контексте этого «хита» fragmentID. В этом случае мы бы сделали эти теги специфичными для FragmentID. На самом деле, большинство ваших тегов могут быть такими.

Еще одна причина, по которой список глобальных тегов должен быть небольшим, — это производительность. Несмотря на то, что система оптимизировала хранение тегов и обеспечивает быстрый поиск тегов, чем больше у вас глобальных тегов, тем больше памяти они занимают и тем больше времени потребуется для такого поиска.

Создание и редактирование фрагтегов

Вы создаете список фрагтегов, создавая новый определение тега в Mannequin Редактор определений тегов.

Затем вы назначаете это новое определение тега FragmentID (или FragmentIDs) в Mannequin FragmentID Редактор.

Каждый fragmentID может иметь только один определение тега, содержащее его фрагтеги, но для более сложных случаев вы можете включить (импортировать) другие файлы определения тега иерархически из этого основного определения тега. См. раздел «Формат файла» на странице Файл определения тега (xxxTags.xml) статья.

Хранение

Фрагтеги хранятся в отдельных файлы определения тегов. Они связаны с Файл определения fragmentID как определения субтегов.
