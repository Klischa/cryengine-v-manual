Ниже приведен сборник советов и рекомендаций, которые помогут устранить распространенные проблемы, возникающие при загрузке/установке программы запуска CRYENGINE.

По вопросам, не описанным в разделах ниже, обращайтесь к команде CRYENGINE через ее или Поддержка каналы с полным описанием возникших проблем.

Перед устранением неполадок убедитесь, что все инструкции по установке соблюдены правильно.

Некоторые из приведенных ниже решений по устранению неполадок предполагают внесение изменений в операционную систему, поэтому их должны выполнять только опытные пользователи, осознающие связанные с этим риски.


Пользователям может потребоваться открыть «скрытые папки», если перечисленные ниже папки не могут быть найдены.

Медленная скорость загрузки

Чтобы улучшить скорость загрузки:

  1. Откройте программу запуска и исполняемый файл Engine для брандмауэра.
  2. Внесите в белый список программу запуска и модуль установленного антивирусного программного обеспечения.
  3. Очистите и сбросьте кэш DNS согласно следующим инструкциям:
DNS

  • Для получения дополнительной информации о Cisco OpenDNS, обратитесь к руководству Cisco здесь.
  • Для получения дополнительной информации о DNS от Cloudflare, обратитесь к документации Cloudflare. здесь.
