Обзор

В этом уроке мы добавим функцию «бега» персонажу игрока, который был создан в первой части этой серии (Создание игрока с использованием C++).

К концу этого урока ваш игровой персонаж будет иметь две разные скорости передвижения: ходьбу и бег, которые вы сможете настроить непосредственно в CRYENGINE.

Вы будете опираться на Игрок.cpp и Player.h файлы построены в Создание игрока с использованием C++ учебник.

Предварительные условия

  • CRYENGINE 5,7 LTS
  • Visual Studio (2017, 2019 или 2020 работают нормально) или любой другой IDE или редактор кода по вашему выбору.

Начало работы

Оптимизация проекта

Прежде чем начать, рекомендуется оптимизировать проект с помощью форвардной декларации. Это не обязательно, но может помочь улучшить производительность вашего проекта и избежать ошибок в дальнейшем.

  1. Открыть Game.sln, который можно найти в папке решения основного каталога вашего проекта:

    Файл Game.sln в папке решений.

    яЕсли вы не сгенерировали решение или не уверены в местоположении Game.sln файл, выполните первые шаги Создание игрока с использованием C++ учебник.

  2. Копировать все Компонент #include линии внутри Player.hи вставьте их под существующий #include на вершине Player.cpp:

    Компонент #include строк

    Попытка построить решение на этом этапе потерпит неудачу, поскольку классы компонентов больше не будут распознаваться.

  3. Внутри Player.h, в верх, создайте namespace для компонентов и под этим типом их классов в фигурных скобках:

    Классы компонентов

Добавление спринта

Добавление PlayerState

  1. Под namespace вы только что создали в Player.h, добавьте перечислитель и назовите его <EPlayerState>:

    enum class EPlayerState

    Обратите внимание, что "class"был добавлен между enum и EPlayerState так как чтобы не загрязнять область применения.

  2. Под этим определите и назовите состояния игрока:

    {
Walking,
Sprinting
};


    Счетчик EPlayerState готов.

  3. В нижней части private класс внутри Player.h, объявить EPlayerState и добавьте переменную-член:

    EPlayerState m_currentPlayerState;

  4. Под существующим float переменные-члены в private class, создайте еще два — один для ходьбы и один для спринта:

    float m_walkSpeed; 
float m_runSpeed;

    Класс private с три новые переменные-члены

  5. В public класс Player.h, рзаменить существующий AddMember строка для "m_movementSpeed" с AddMember для "m_walkspeed":

    desc.AddMember(&CPlayerComponent::m_walkSpeed, 'pws', "playerwalkspeed", "Player Walk Speed", "Sets the Player Walk Speed", ZERO);

    Заменена строка m_movementSpeed.

  6. Скопируйте m_walkSpeed AddMember линия тебе просто создатьЭд и вставьте его сразу ниже. Изменить это чтобы у вас был AddMember линия для "m_runSpeed":

    desc.AddMember(&CPlayerComponent::m_runSpeed, 'prs', "playerrunspeed", "Player Run Speed", "Sets the Player Run Speed", ZERO);

    Завершено AddMember строки для двух новых переменных-членов

    Поскольку m_walkSpeed теперь это скорость ходьбы по умолчанию, которую вы хотите изменить, вам нужно заменить m_movementSpeedвозможность модификации. Вы все равно будете использовать m_movementSpeed, но вам больше не понадобится возможность изменять его значения.

Добавление ввода

Далее вам необходимо определить, какие входные данные будут использоваться для спринта и как они используются.

  1. Под InitializeInput внутри Player.cpp, скопируйте и вставьте существующий RegisterAction и BindAction строку и заменить имя входа, а также eKI для ключа, который вы хотите использовать:

    m_pInputComponent->RegisterAction("player", "sprint", [this](int         activationMode, float value) {m_movementDelta.x = -value; });
m_pInputComponent->BindAction("player", "sprint", eAID_KeyboardMouse, eKI_LShift);

    Имя входа было изменено на «спринт», а поле eKI установлен на LShift (Левый сдвиг)
  2. Удалить "m_movementDelta.x = -value;" изнутри lambda о новом спринте RegisterAction строку и переместите фигурные скобки под ней:

    Как должна выглядеть реструктурированная линия

  3. Внутри этих фигурных скобок добавьте следующее if заявление:

    if (activationMode == (int)eAAM_OnPress) 
{ 
m_currentPlayerState = EPlayerState::Sprinting;  
}

    Эта строка означает «если eAAM_OnPress (вход) нажат, игрок побежит».

    Реструктурированная строка с оператором if

  4. Адд следующее else if утверждение чуть ниже предыдущих строк: 

    else if (activationMode == eAAM_OnRelease) 
{ 
m_currentPlayerState = EPlayerState::Walking; 
}

    Эта строка означает «если eAAM_OnPress (вход) не нажат, игрок будет ходить».

    Завершено RegisterAction и BindAction строка с операторами «if»/«else if»

Основная функциональность

Наконец, вы должны определить основную логику, которая будет переместить персонажа игрока.

  1. В нижней части Player.cpp, создайте новую пустую строку под Normalize. Здесь вы добавите логику для спринта:

    float playerMoveSpeed = m_currentPlayerState == EPlayerState::Sprinting ? m_runSpeed : m_walkSpeed;

    Добавляем логику спринта

    Эта строка означает, что playerMoveSpeed равен currentPlayerState, то есть бег или ходьба, в зависимости от введенных данных, а скорость движения игрока будет меняться в соответствии с текущим состоянием игрока. Знак вопроса после EPlayerState это тернарный оператор, который функционирует как if заявление. Это if Оператор определяет, какое состояние игрока будет служить скоростью его перемещения.

  2. В конце самой последней строки, под только что добавленной строкой, измените "m_movementSpeed" сразу после «* velocity *” к имени переменной-члена состояния игрока "playerMoveSpeed":

Тон последний спринт логика

Пресса Ctrl + Shift + С спасти всех вкладки и построить решение. После сборки запустите его в CRYENGINE 5.7 LTS.

Тестирование персонажа

Как только решение будет создано, вы сможете протестировать своего игрового персонажа в редакторе Sandbox.

  1. Откройте уровень, который вы создали в Создание игрока с использованием C++ учебники выберите ранее размещенный Сущность игрока.

    Если у вас еще нет объекта Player, перетащите на сцену пустой объект и добавить CPlayerComponent к этому.

  2. С сущностью игрока выбран, откройте панель «Свойства» и прокрутите вниз до CPlayerComponent свойства, где вы сможете настроить скорость ходьбы и бега персонажа.


    CPlayerComponent Свойства компонента сущности

    Средняя скорость ходьбы может составлять от 2-5, где обычно бегает 5-8. Настройте эти значения и найдите скорость, подходящую для вашей игры.

  3. Когда эти переменные установлены для вашей сущности игрока CPlayerComponent свойства, теперь вы можете нажать Ctrl + Г и проверить свой характер.
