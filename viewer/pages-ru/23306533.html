Обзор

CRYENGINE поставляется с системой локализации, которая позволяет локализовать текст для UI. Локализация Система документирована в Руководстве по созданию активов.

Помимо локализации строк, также можно использовать разные наборы шрифтов и глифов для каждого языка.

Базовая структура папок

Локализация строк

Переводы строк UI хранятся в XML-листах Excel. В нем просто хранятся метки (ключи) и перевод.

Таблица перевода

Таблицы перевода для каждого языка должны храниться в: Localization\<Language>\text_ui*.xml для его обработки в местоположениях по умолчанию, используемых движком.

Для перевода UI в таблицах должен быть столбец "KEY", "ORIGINAL TEXT" и "TRANSLATED TEXT".

Передача локализованной строки во время выполнения

Метка также переводится, если она передается в виде строки в динамическое текстовое поле с помощью: Code\FlowGraph\LUA

  <UIElement name="MyElement">

    <GFx file=" MyElement.gfx" layer="2" alpha="1" >
      <Constraints>
        <Align mode="fullscreen" />
      </Constraints>
    </GFx>

    <variables>
      <variable name=" MyTextbox " varname="_root.TextLayer.TextBox.text"/>
    </variables>

  </UIElement>

IFlashUIPtr pFlashUI = GetIFlashUIPtr();
if( NULL != pFlashUI )
{
   IUIElement* pElement = pFlashUI->GetUIElement("MyElement");
   if( NULL != pElement)

   }
}

Библиотеки шрифтов и наборы глифов

Рекомендуется использовать один библиотека шрифтов для всех флэш-ресурсов. Одна из причин — экономия памяти, поскольку вы не хотите встраивать каждый шрифт в каждый флэш-файл. Этот метод также позволяет встраивать разные наборы глифов для разных языков.

Это также гарантирует, что ваш дизайн будет единообразным для всех ресурсов UI, а вносить изменения станет еще проще, поскольку достаточно изменить только один файл для каждого языка, чтобы переключить шрифт для всего UI.

Настройка библиотеки шрифтов

Библиотека шрифтов — это файл GFX, который экспортирует символы Action Script, описывающие шрифт, и содержит связанные данные глифов для отображения шрифта в игре.
Когда динамический текст создается пользователем, глифы будут загружены Scaleform из этого исходного файла.

Можно настроить библиотеку шрифтов с более чем одним шрифтом (с разными именами экспорта Action Script), но в примере GameSDK мы используем только один.

В примере проекта GameSDK мы используем библиотеку HUD_Font_LocFont.gfx файл. Флеш-файл, использованный для создания этого GFX в SDK, можно скачать здесь в качестве образца: HUD_Font_LocFont.fla. Однако вы можете создать свою собственную, если предпочитаете создать библиотеку шрифтов с нуля.

Для каждого отдельного шрифта, который вы хотите использовать, создайте новые символы шрифта и установите стиль шрифта в библиотеке (Щелкните правой кнопкой мыши -> Новый шрифт.).

Перейдите в свойства шрифта, чтобы настроить параметры экспорта.
Обязательно установите оба флажка экспорта и установите для идентификатора уникальное имя. Это имя будет использоваться во флеш-файлах с использованием этого шрифта.
Для общего доступа URL должно быть установлено имя окончательного файла GFX (с расширением .SWF).

После того, как вы настроите все шрифты, которые хотите использовать в UI, вам следует создать локализованные копии библиотеки шрифтов для каждого языка, который вы хотите поддерживать.
Самый оптимизированный и эффективный способ сделать это — выбрать поднабор глифов, который можно использовать на каком-то языке, и экспортировать этот набор глифов только для этого конкретного языка. Это экономит место на диске и в памяти, поскольку будут доступны только необходимые глифы.

В диалоговом окне параметров шрифта вы можете установить группы шрифтов для встраивания глифов. Глифы будут обработаны с использованием заданного шрифта и стилей OS.

После завершения настройки шрифтов в библиотеке шрифтов для языка опубликуйте флэш-файл в формате .SWF.
Это должно привести к HUD_Font_LocFont.swf файл для этого конкретного языка.

Теперь используйте gfxexport инструмент для преобразования библиотеки шрифтов в формат Scaleform GFX.

gfxexport.exe -c -i DDS -rescale hi HUD_Font_LocFont.swf

Обязательно скопируйте полученный GFX в файл ресурсов, локализованный для каждого языка (чтобы в конечном итоге он оказался в Localization/<language>_xml.pak для этого языка для сценария сборки ресурса по умолчанию вы должны сохранить его как Localization/<language/HUD_Font_LocFont.gfx)

Эти шаги следует повторить для каждого языка, который вы хотите поддерживать в своем проекте, которому требуются отдельные наборы глифов для шрифтов. Альтернативно вы можете создать только одну (большую) библиотеку шрифтов и повторно использовать ее для каждого языка.

Во время выполнения вам необходимо перезагрузить элементы UI после переключения на другой язык, чтобы новые глифы вступили в силу.

Импортируйте шрифты в любой Flash-ресурс.

Наконец, вам нужно импортировать экспортированные шрифты из библиотеки шрифтов в ваши флэш-ресурсы.
Вам необходимо настроить шрифт в библиотеке флэш-файла и пометить его для импорта, как показано здесь.
Введите тот же идентификатор для шрифта, который вы экспортировали в файл библиотеки шрифтов GFX, и установите импорт URL в файл GFX.

При создании флэш-файла вы можете использовать импортированный символ шрифта в библиотеке вместо ссылки на шрифт OS.
Во время выполнения этот шрифт будет загружен из библиотеки шрифтов.

Экспортируйте свои флэш-ресурсы с помощью следующей команды:

gfxexport.exe -c -i DDS -share_images -rescale hi -strip_font_shapes *.swf

Чтобы использовать шрифты в текстовых полях, просто выберите их в раскрывающемся списке шрифтов.
Обратите внимание: * на шрифте означает, что шрифт находится в библиотеке шрифтов.

Если вы используете метки перевода для текстовых полей static, вам необходимо сделать их динамическими! В противном случае перевод не работает.
