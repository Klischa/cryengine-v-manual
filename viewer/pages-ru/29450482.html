Обзор

Стандартная библиотека Universal Query System (UQS) (StdLib) представляет собой набор типов элементов, функций, генераторов и оценщиков, которые предназначены для использования в качестве справочника по реализации пользовательских элементов, но также могут использоваться в вашей игре «из коробки».

Это библиотека static, и ее необходимо связать с исполняемым файлом вашей игры.

Технически говоря, StdLib находится на том же слое, что и пользовательские типы предметов, функции и т. д. в вашей игре.

Чтобы сделать содержимое StdLib доступным для регистрации в ядре UQS, достаточно одного вызова метода:

UQS::StdLib::CStdLibRegistration::InstantiateAllFactoriesForRegistration();

Содержание StdLib

На момент написания StdLib в настоящее время предоставляет следующие элементы, которые зарегистрированы с префиксом «std::»:

  • Типы предметов:
    • станд::EntityId
    • станд::int
    • станд::bool
    • станд::float
    • станд::Pos3
    • станд::Ofs3
    • станд::Dir3
    • станд::NavigationAgentTypeID
  • Функции:
    • std::Pos3 std::Pos3AddOfs3 ( std::Pos3 pos, std::Ofs3 ofs )
    • std::Pos3 std::PosFromEntity ( std::EntityId entityId )
  • Генераторы:
    • std::Pos3[] std::PointsOnPureGrid (центр std::Pos3, размер std::float, интервал std::float)
    • std::Pos3[] std::PointsOnNavMesh ( std::Pos3 Pivot, std::Ofs3 localAABBMins, std::Ofs3 localAABBMaxs, std::NavigationAgentTypeID navigationAgentTypeID )
  • InstantEvaluators:
    • std::TestMinDistance ( std::Pos3 pos1, std::Pos3 pos2, std::float minRequiredDistance )
    • std::TestMaxDistance ( std::Pos3 pos1, std::Pos3 pos2, std::float maxAllowedDistance )
    • std::TestLocationInNavMesh ( std::Pos3 locationToTest, std::NavigationAgentTypeID navigationAgentTypeID )
    • std::ScoreDistance ( std::Pos3 pos1, std::Pos3 pos2, std::float distanceThreshold )
    • std::ScoreDistanceInverse ( std::Pos3 pos1, std::Pos3 pos2, std::float distanceThreshold )
    • станд::ScoreRandom ()
  • DeferredEvaluators:
    • std::TestRaycast ( std::Pos3 from, std::Pos3 to, bool raycastShallSucceed )
станд::TestRaycast

Уведомление о станд::TestRaycast оценщик: базовый raycaster использует Renderer для регулирования количества raycasts на кадр и поэтому не будет работать на выделенном сервере! (Читайте: сбой при нулевом указателе!)

Кроме того, все параметры для тестирования конкретных типов объектов и флагов для пересечений Ray <-> World жестко запрограммированы. Из-за этих ограничений не рекомендуется использовать этот Deferred Evaluator в производственной среде — вам следует рассматривать его как образец для вашей собственной реализации.
