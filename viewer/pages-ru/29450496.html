Обзор

Мониторинг элементов — это дополнительная функция, которая работает вместе с текущим запросом. Его цель — обнаружить изменения в пространстве рассуждений, которые могут привести к его искажению и, следовательно, вызвать сбои или непредсказуемое поведение.

Пример

Рассмотрим запрос, который оценивает треугольники навигационной сетки: может быть установлен пользовательский монитор элементов, чтобы определять, когда определенные области навигационной сетки восстанавливаются во время выполнения. Если какой-либо из треугольников (элементов) будет затронут регенерацией, монитор элементов может сообщить о повреждении, и тогда весь запрос завершится с ошибкой.

Установка и срок службы Item-Monitors

Мониторы элементов обычно устанавливаются специальным генератором элементов текущего запроса. Они будут сохраняться как минимум в течение long, пока выполняется этот конкретный запрос. Однако в случае цепочек запросов мониторы элементов будут сохраняться еще дольше, а именно до тех пор, пока не будет обработан самый последний дочерний запрос. Это делается для того, чтобы элементы более ранних запросов в цепочке не могли стать поврежденными (остаться незамеченными) к тому времени, когда они будут использованы в качестве входных параметров более поздним запросом в цепочке.

С помощью этого метода вы можете добавить в запрос столько мониторов элементов, сколько захотите:

UQS::Core::IQueryManager::AddItemMonitorToQuery(const CQueryID& queryID, UQS::Client::ItemMonitorUniquePtr&& pItemMonitorToInstall);

Обычно это делается в генераторе. Вот отрывок из одного из генераторов StdLib:

UQS::Client::IGenerator::EUpdateStatus CGenerator_PointsOnNavMesh::DoUpdate(const SUpdateContext& updateContext, client::CItemListProxy_Writable<Vec3>& itemListToPopulate)
{
    // ...
    std::unique_ptr<CItemMonitor_NavMeshChangesInAABB> pItemMonitorNavMeshChanges(new CItemMonitor_NavMeshChangesInAABB(m_params.navigationAgentTypeID));
    // ...
    UQS::Core::IHubPlugin::GetHub().GetQueryManager().AddItemMonitorToQuery(updateContext.queryID, std::move(pItemMonitorNavMeshChanges));
    // ...
}
