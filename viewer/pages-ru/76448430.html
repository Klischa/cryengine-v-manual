Обзор

Учетная запись в плагине GamePlatform представляет собой абстракцию учетной записи платформы, которой она принадлежит, что позволяет идентифицировать действия, нацеленные на определенные учетные записи платформы (например, локального пользователя, друзей или учетные записи подобранных пользователей).

С технической стороны Учетная запись содержит уникальный идентификатор, основанный на базовых идентификационных данных, предоставленных платформой (например: Steam ID на платформе Steam). Он также содержит уникальный идентификатор службы платформы, которому принадлежит учетная запись платформы.

Учетную запись одной платформы нельзя использовать на другой платформе, поскольку они зависят от платформы.

Функции обслуживания учетной записи

Функции и события обслуживания учетной записи позволяют получить информацию, относящуюся к любой учетной записи на платформе. Например, вы можете получить аватары и псевдонимы пользователей, получить список друзей локального пользователя и заблокированных пользователей на платформе, а также получать уведомления, когда другой пользователь на платформе меняет свой псевдоним и т. д.

IsFriendWith

Проверяет, находится ли указанная учетная запись платформы в списке друзей локальной учетной записи.

GetAccountInfo

Получает сведения об указанной учетной записи на платформе.

GetAvatar

Получает текстуру аватара указанной учетной записи ID указанного размера.

Некоторые платформы имеют только один размер аватаров (например, Discord), в то время как другие по умолчанию предоставляют только малый размер. Чтобы получить средние и большие размеры, вам нужно использовать RequestUserInformation функцию и дождитесь OnAvatarImageLoaded событие.

GetBlockedAccounts

Получает список учетных записей, заблокированных локальной учетной записью.

GetFriendAccounts

Получает список учетных записей «друзей», связанных с локальной учетной записью.

GetLocalAccount

Получает идентификатор локальной учетной записи на платформе.

RequestUserInformation

Запрашивает информацию о пользователе (никнейм, аватар) с удаленного сервера для указанного аккаунта на указанной платформе.

Слушайте тот OnPersonaStateChanged и OnAvatarImageLoaded события для перемен.

События обслуживания учетной записи

OnAccountAdded

Запускается при добавлении учетной записи во внутренний реестр (например, когда в локальную учетную запись был добавлен друг).

OnAccountRemoved

Вызывается при удалении учетной записи (например, был удален друг).

OnAvatarImageLoaded

Запускается, когда служба платформы предоставила запрошенное изображение аватара.

OnPersonaStateChanged

Запускается, когда персональные данные пользователя (имя, статус друга/заблокирован, разрешения, такие как отправка сообщений/приглашений, голосовой чат и т. д.) изменились.
