Обзор

Character Tool может вызвать Анимационные мероприятия для «Шаги и Фоли», который позволяет изменять звук в зависимости от типа персонажа или поверхности при использовании одной и той же анимации.
Статья Аудио и Character Tool являются необходимыми знаниями для следующего урока.

Используя Анимационные мероприятия в CharacterTools вы сможете добиться:

  • Шаги и Фоли на основе персонажей.
  • анимация синхронизирована с шагами и Фоули.
  • Шаги, основанные на материалах.

Техническая деталь

Настройка FXLibs Footsteps

Для включения символов Foleys и Footsteps требуются записи «CharacterSounds» внутри скрипта Entity Lua.

Следующий пример взят из файла player.lua, который можно найти в разделе <Game folder>\GameSDK\Assets и в этом *.pak,
в Scripts\Entities\actor\.

После указания библиотеки эффектов шагов эту запись необходимо создать в MaterialEffects.xml таблица под <Game folder>\Assets\gamedata.pak. В этом файле *.pak файл MaterialEffects.xml можно найти по адресу Libs\MaterialEffects.

Файлы MaterialEffects находятся в gamedata.pak.

MaterialEffects.xml открыт в Excel

Соответствующий эффект (в зависимости от материала) определяет фактический триггер аудиосистемы для воспроизведения. Это делается в Библиотека эффектов хранится под
<Game folder>\Assets\gamedata.pak и в этом файле *.pak в Libs\MaterialEffects\FXLibs.

В качестве примера: footsteps_player:metal_thick будет искать эффект metal_thick в foosteps_player.xml, который находится в FXLibs.

Рис2: Footsteps_player.xml

В этом случае триггер аудиосистемы «Play_c_player_fts» воспроизводится для каждого материала, но при установленном переключателе аудиосистемы на основе SurfaceType — это соответствующим образом меняет звук.

Настройка шагов в Character Tool

Для правильного расчета времени в каждой анимации теперь требуется запись «шаг». Это достигается в Character Tool и сохраняется в файле анимевентс.

Следующий пример взят из <Game folder>\Animations.pak и внутри этого *.pak-файла, в animations\human\male\events.animevents.

Нажав double на временную шкалу, можно создать новую Анимационное мероприятие это сработает, когда анимация достигнет определенной точки.

Для каждого Анимационное мероприятие можно выбирать между различными типами. Чтобы вызвать шаги, мы выбираем «шаг» в раскрывающемся меню «Анимационные события».
Каждый Анимационное мероприятие также может быть сопоставлен с конкретной костью. Нажав на значок кости, можно открыть раскрывающееся меню со списком выбора:

Для Footsteps особенно важно правильно нанести на карту кости. Это связано с тем, что частицы также можно запускать через FXLibs.

При звуке шагов учитывается параметр аудиосистемы character_speed. Этот параметр предлагает модификацию звука в зависимости, например, от скорости объекта в игровом мире.

Настройка Фоли в Character Tool

Символьные Фолеи не нужно прогонять по таблице MaterialEffects.xml, поскольку они не зависят от материала. Однако для них требуется библиотека эффектов, определяющая триггеры аудиосистемы для различных действий Фоли внутри foley_player XML в разделе <Game folder>\Assets\gamedata.pak и внутри этого файла *.pak в Libs\MaterialEffects\FXLibs.

Персонажи Фоли в foley_player.xml

Чтобы получить доступ к указанной FXLib, мы выбираем Фоли из раскрывающегося меню созданного анимационного события.

В примере снимка экрана ниже поле в крайнем правом углу используется для определения того, какое действие Фоли (crouch_off) надо играть.

Использование Foley FXLibs может быть полезно, если/когда вы используете несколько персонажей, поскольку оно позволяет изменять звук на основе персонажа и при использовании одной и той же анимации.

CVar и советы

  • Поскольку шаги и Фоли зависят от анимации, сотрудничество между отделами звука и анимации команды разработчиков игры должно быть тесным.
  • Данные, хранящиеся в файле анимевентс, ссылаются на имя анимации. Таким образом, определение соглашения об именах, структуры папок анимации и даже анимаций-заполнителей на ранних этапах производственного цикла помогает оставаться в курсе огромного количества ресурсов.
  • Animevents работает как файл *xml, поэтому его можно открыть в любом текстовом редакторе. Это может быть полезно с помощью функции копирования/вставки, а также проверки соглашения об именах и общих целей отладки.
  • Добавление записей «Шаги» и «Фоли» в анимацию передвижения (например, _RELAXED) покроет большинство уже рассмотренных случаев. После этого аддитивную анимацию можно заполнить записями Footstep и Foley.
  • mfx_DebugVisual = Включает визуальную отладку системы MaterialEffects.
