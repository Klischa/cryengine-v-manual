Обзор

Сетевое планирование контролирует доставку сетевых данных на основе этих приоритетов + доступного места в пакете.

Определение типов планирования

Типы планирования определяются внутри XML, который загружается во время запуска двигателя. Этот файл должен иметь такой путь: Game/Scripts/Network/Scheduler.xml

Вот пример типа:

<Group name="auth" priority="15" latency="2">

Это определяет тип с именем auth. Его базовый приоритет равен 15. Задержка должна составлять 2 секунды, что означает, что сообщение может находиться в очереди в течение 2 секунд, прежде чем его приоритет будет искусственно повышен, чтобы попытаться принудительно отправить его в сеть.

Сопоставление классов объектов и типов планирования задается внутри другого файла XML. Этот файл должен иметь такой путь: Game/Scripts/Network/EntityScheduler.xml

Приоритетное значение

Планирование в сети определяется приоритетами. 16 – 0, причем 16 – наивысший показатель (читай – самый важный). Значения приоритета являются экспоненциальными. Приоритет 1 в два раза важнее приоритета 0, приоритет 2 в два раза важнее приоритета 1 и т. д.

Настройка приоритета

Обратите внимание, что приоритет является базовым. Его можно настроить с помощью ряда дополнительных значений.

Вот несколько примеров.

normalDistance="nnn" close="ccc" far="fff"
  • nnn — расстояние, к которому применяется базовый приоритет.
Foi="aaa" front="fff" back="bbb"
  • aaa = угол падения на камеру (внутри угла применяется усиление приоритета передней части – применяется уменьшение приоритета внешней задней части).
  • fff = максимальный уровень приоритета для повышения.
  • bbb = максимальная величина снижения приоритета.
Drawn="n"
  • Если n == 1, то после всех остальных соображений, если средство визуализации решило, что объект следует отбросить, его приоритет снижается до 0.

Пульс

Можно определить набор импульсов программатора. Это полезно для временного повышения приоритета сетевого обновления игрового объекта изнутри кода из-за изменения внутреннего состояния.

Вот пример:

<Pulse name="bump" bump="3" decayTime="2">
  • Bump повышает приоритет (в этом примере на 3), который сеть медленно снижает (в этом примере более 2 секунд).

См. CGameObject::Пульс() функция для получения дополнительной информации.
