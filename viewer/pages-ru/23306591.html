Обзор

Entity System предоставляет простой механизм переключения состояний для Script Entity.

Каждое государство состоит из:

  • Имя (строка).
  • Таблица Lua внутри таблицы сущностей, идентифицируемая именем состояния.
  • Функция OnEndState (необязательно).
  • Функция OnBeginState (необязательно).
  • Множество дополнительных функций обратного вызова (все необязательно). Список доступных функций c. ф. Обратные вызовы сценариев Entity System

Все состояния объектов должны быть заявил сначала в основной таблице сущности, иначе система Entity Script не узнает о них. Вот как в третьем примере будут объявлены «Открыто», «Закрыто», «Уничтожено»:

AdvancedDoor =
{
    Client = {},
    Server = {},
    PropertiesInstance = ...
    Properties = ...
    States = {"Opened","Closed","Destroyed"},
}

Состояния объектов могут находиться либо на сервере, либо на клиенте (или на обоих). Определение состояния «Открыто» на стороне сервера с помощью двух функций «OnBeginState()» и «OnUpdate()» будет выглядеть следующим образом:

AdvancedDoor.Server.Opened =
{
  OnBeginState = function( self )
    if(self.Properties.bUsePortal==1)then
      System.ActivatePortal(self:GetWorldPos(),1,self.id);
    end;
    self.bUpdate=1;
    self.lasttime=0;
    AI.ModifySmartObjectStates( self.id, "Open-Closed" );
    self:Play(1);
   end,
 
  OnUpdate = function(self, dt)
    self:OnUpdate();
  end,
}

Первоначально организация находится в нет состояния состояние вообще. Чтобы перевести сущность в состояние, вы должны использовать один из функции обратного вызова сущности (не путайте с сущностью государствофункции обратного вызова здесь) и вызвать его GotoState() метод:

function AdvancedDoor:OnReset()
    self:GotoState("Opened");
end

С этого момента сущность находится в состоянии «Открыто», и события также будут направляться в это состояние.

Переход из текущего состояния в любое другое состояние также можно осуществить с помощью GotoState() метод:

function AdvancedDoor.Server:OnHit(hit)
    ...
    if(self:IsDead())then
        self:GotoState("Destroyed");
    end
end

Запрос состояния, в котором в данный момент находится объект, можно выполнить с помощью GetState() метод:

if (self:GetState()=="Opened") then ...

if (self:GetState()~="Opened") then ...
