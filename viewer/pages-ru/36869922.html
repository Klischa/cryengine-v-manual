Обзор

Эта функция позволяет использовать инструмент «Физика» в Sandbox для создания тряпичных объектов, когда симуляция не запущена. Поддерживаются коллизии и дополнительные ограничения. Затем позу можно использовать в качестве начального состояния для Имитировать объекты функцию или сохранить как физическое состояние напрямую.

Поддерживаются два режима IK: один минимизирует только изменение кинетической энергии, а другой представляет собой сочетание минимизации энергии и сохранения позы.

Поскольку инструмент «Физика» полностью используется в PhysDebugger, эта функция доступна и там.


Режимы

Есть два разных режима:

Режим по умолчанию

Измеряет влияние каждого угла поворота на скорость каждого тела, используя векторные суммы, что делает оценку точной.

Жесткий режим

В режиме «Жесткий» каждое вращение взвешивается, предполагая, что его дочерние элементы неподвижны, поэтому поза имеет тенденцию больше сохраняться.

Существует команда, которую можно добавить на панели инструментов для жесткого режима, которая называется Используйте жесткий режим IK. Дополнительные сведения о настройке панелей инструментов см. Настройка ToolBars.

Использование

Чтобы изобразить мертвое тело:

  1. Добавьте мертвое тело на уровень из Создать объект -> Устаревшие объекты -> Физика -> DeadBody (возможно, при желании добавьте немного геометрии, чтобы он падал)

  2. Включи Режим инструмента «Физика»

    Эта панель инструментов не отображается по умолчанию
  3. Включите нужный режим (режим по умолчанию или жесткий) с помощью CVar. ed_PhysToolIKStiffMode. Для режима по умолчанию установите это значение 0, для жесткого режима установите значение 1.
  4. Переместить труп вокруг
    • Использование Ctrl + LMB чтобы перетащить труп и зафиксировать ориентацию перетаскиваемой части.
  5. Каждое движение автоматически сохраняется как физическое состояние, как если бы Получить физическое состояние были использованы.
  6. Выберите Имитировать объекты если рэгдолл не спит и вы хотите его смоделировать дальше. Как только рэгдолл перейдет в состояние покоя, он сохранит свое состояние.

Столкновения и ограничения

Конечности рэгдолла будут двигаться, если он столкнется с местностью или объектами.

Также можно добавить ограничения, чтобы рэгдолл не перемещал определенную часть своего тела.

Использование Шифт + LMB создать точечные ограничения или Shift + Ctrl + LMB для "полный" ограничения (положение и вращение). Shift + Alt + LMB создает ограничение Alignment для выравнивания кости по поверхности, на которую указывает нормаль грани наибольшей ограничивающей рамки. Обычное использование этого ограничения может заключаться в выравнивании ступни по земле под ней. Это ограничение работает только на конечных костях.

Холдинг Сдвиг в то время как перетаскивание отменит перетаскивание, как только произойдет любое столкновение (обратите внимание, что Сдвиг придется нажать после тот LMB, поскольку в противном случае LMB создаст ограничение вместо входа в режим перетаскивания). Это может быть полезно, если вы хотите, чтобы тряпичная кукла просто коснулась чего-то, не пытаясь приспособиться к столкновению, отталкивая кости назад/в сторону и т. д.
