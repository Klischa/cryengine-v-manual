Обзор

Это руководство проведет вас через начальные шаги по настройке звука из FMOD Studio для работы с CRYENGINE с использованием аудиосистемы CRYENGINE.

Первые шаги с FMOD Studio в CRYENGINE

Настройка студии FMOD в CRYENGINE

Включите промежуточное программное обеспечение FMOD в CRYENGINE. Консоль установив s_ImplName CVar для CryAudioImplFmod. В качестве альтернативы добавьте следующую строку в файл system.cfg или user.cfg (расположенный в корневой папке CRYENGINE):
s_ImplName = CryAudioImplFmod

FMOD Местоположение студийного проекта и Soundbank

При использовании FMOD Studio с CRYENGINE вы можете найти конкретные данные FMOD Studio в следующих местах:

  • `Звуковые банки:
    <папка проекта>/активы/аудио/фмод

    В версии 5.5 местоположение Soundbanks изменилось на \<папка проекта>\<папка ресурсов проекта>\audio\fmod\assets, где <папка ресурсов проекта> относится к папке ресурсов, установленной в файле .cryproject проекта.

  • FMOD Проект студии:
    <папка проекта>/активы/аудио/fmod_project


Вы можете выбрать другой путь для своего проекта FMOD Studio, перейдя в раздел Редактировать -> Настройки в Редактор управления звуком. Затем вы можете ввести желаемый путь или найти папку с помощью Обзор кнопка:

По умолчанию CRYENGINE проверяет эти папки на наличие всех элементов управления студии и звуковых банков FMOD и отображает эти файлы в Редактор управления звуком.

Проект Fmod Studio и звуковые банки

При отправке игры убедитесь, что в папку с игрой включены только звуковые банки, поскольку они содержат все данные из проекта студии FMOD.

Проверка поддерживаемой версии FMOD Studio

Прежде чем настраивать проект FMOD Studio, убедитесь, что вы используете правильную версию FMOD Studio с CRYENGINE. CRYENGINE всегда обновляется для поддержки последней версии FMOD Studio.

Чтобы убедиться, что вы используете правильную версию, откройте файл Консоль в CRYENGINE, а затем установите s_DrawDebug до ненулевого значения. Теперь вы можете увидеть (в верхнем левом углу) текущую версию FMOD Studio, которая поддерживается аудиосистемой в вашей сборке CRYENGINE.

Вы можете загрузить последнюю версию FMOD Studio с сайта здесь.

Создание настройки звука для CRYENGINE в FMOD Studio

Обучение Fmod Studio

Если вы новичок в FMOD Studio, рекомендуем вам прочитать руководство по FMOD Studio. Вы также можете посетить страницу поддержки FMOD. здесь.

Создание звукового события в FMOD Studio

В FMOD Studio вы можете импортировать аудио в Редактор событий перетащив файл или используя Импорт вариант (Файл->Импортировать аудиофайлы).
После того как вы импортируете аудиофайл в формате *.wav, FMOD Studio создаст для него новое звуковое событие.

Для каждого звукового события в FMOD Studio вы можете настроить несколько настроек в Колода область ниже Хронология раздел. В области «Дека» вы можете изменить настройки, включая громкость, высоту тона, фильтрацию низких/высоких частот и расположение звука.

Создание звукового банка в FMOD Studio

Чтобы интегрировать новое событие в вашу игру, вам необходимо создать звуковой банк в FMOD Studio, который можно будет загрузить с помощью CRYENGINE.

В FMOD Studio выберите Банк вкладку в редакторе событий, а затем щелкните правой кнопкой мыши, чтобы создать новый банк.

Теперь вы можете заполнить Soundbank созданным вами аудиоконтентом. На вкладке «Событие» щелкните правой кнопкой мыши звуковое событие (возможно выбрать несколько событий) и выберите Назначить банку (см. ниже). Вы также можете назначить звуковые события непосредственно новому банку.

Убедитесь, что звуковые банки расположены в указанном ниже месте, чтобы их могли обнаружить Редактор управления звуком:

  • <ProjectFolder>/assets/audio/fmod
Потоковые ресурсы

Если вы хотите использовать потоковую передачу, перейдите на Настройки -> Сборка и выберите Создавайте метаданные, непотоковые и потоковые активы для отдельных банков.:

В результате будут построены следующие банки:

  • <имя банка>.bank (содержит метаданные)
  • <имя банка>.assets.bank (содержит непередаваемые активы)
  • <имя банка>.streams.bank (содержит потоковые активы)

.банк файл необходимо предварительно загрузить с помощью запроса на предварительную загрузку ACE, чтобы можно было воспроизводить потоковые ресурсы,

.streams.bank не отображается в ACE, поскольку доступ к нему будет осуществляться автоматически по требованию.
Автоматическое создание звуковых банков

Вы можете настроить FMOD Studio для автоматического создания звуковых банков в правильном месте, изменив каталоги банков в Правка -> Настройки -> Сборка.

Теперь, когда вы создали настройку в Fmod Studio, Редактор управления звуком сможет распознавать элементы управления Studio FMOD и звуковые банки. Вы можете открыть CRYENGINE и выбрать Редактор управления звуком под Инструменты меню.

Подключение элементов управления Fmod Studio к аудиосистеме CRYENGINE

Теперь Редактор управления звуком перечисляет все элементы управления Studio FMOD, содержащиеся в вашем проекте FMOD Studio, и созданных вами звуковых банках.

Теперь вы можете подключить их к аудиосистеме, чтобы интегрировать их в свой уровень в CRYENGINE. Вам необходимо создать новую папку в редакторе элементов управления звуком, выбрав значок +Добавить кнопку и выберите Папка из раскрывающегося списка.

После создания папки вы можете просто перетащить элементы управления Studio FMOD в новую папку на стороне элементов управления аудиосистемой. CRYENGINE автоматически создаст соответствующие элементы управления подключенной аудиосистемы и назовет их в честь их аналогов в Studio FMOD.


Вы увидите, что созданы два типа элементов управления аудиосистемой: триггер и предварительная загрузка. Триггер будет использоваться для вызова события FMOD Studio в вашей игре, а предварительная загрузка будет использоваться для загрузки звуковых банков студии FMOC, чтобы все данные, связанные с событием, были включены в память.

Звуковые банки Fmod Studio

Для воспроизведения звука на вашем уровне CRYENGINE требуется загрузка звукового банка студии FMOD, содержащего данные ваших событий. Поэтому обязательно подключите звуковые банки FMOD Studio к предварительным загрузкам аудиосистемы и обновляйте их при добавлении нового контента в FMOD Studio.

В разделе «Предварительная загрузка аудиосистемы» убедитесь, что Автозагрузка флажок активирован и оставьте Контекст на Глобальный на данный момент. Вы можете прочитать больше об использовании контекстов в редакторе элементов управления звуком. здесь.

Размещение триггера аудиосистемы в игре

Если вы выполнили вышеуказанные шаги, теперь вы можете выбрать триггер аудиосистемы в редакторе и воспроизвести его на аудиообъекте. Вы можете предварительно прослушать триггеры вашей аудиосистемы в редакторе управления звуком, щелкнув его правой кнопкой мыши и выбрав Выполнить триггер.
Чтобы слушать свой звук в игре, вам необходимо разместить на уровне звуковой объект, который запускает звуковой триггер во время игры.

Для каждого уровня рекомендуется сначала создать специальный аудиослой, содержащий ваши аудиоданные. Чтобы включить это, выберите Инструменты-> Редактор уровней-> Level Explorer, а затем выбрать Файл-> Новый слой чтобы создать новый слой и переименовать его в Audio.

Поскольку в качестве аудиослоя выбран long, все объекты, которые вы размещаете на уровне, будут включены в этот слой. Теперь вернитесь к Создать объект, и выберите Аудио-триггер субъект в Аудио вкладку и поместите объект на уровень.

Лучшие практики

Рекомендуется называть аудиообъекты сокращениями, чтобы улучшить читаемость в больших проектах. Для аудио-триггера вы можете использовать аббревиатуру ATS. Таким образом, звук бездействия лягушки можно было бы назвать ATS_frog_idle в точке аудио-триггера на уровне.

Если вы правильно выполнили вышеуказанные шаги, теперь вы можете выбрать созданный вами триггер аудиосистемы в Свойства вкладка «Триггер аудио». Он будет воспроизведен, как только будет включен объект Audio Trigger Spot.

Использование StopTrigger

Если StopTrigger выполняется, а StopTriggerName остается пустым, CRYENGINE автоматически останавливает воспроизведение события FMOD Studio. Это важно помнить, поскольку поведение одинаково во всех местах в CRYENGINE, где можно использовать StopTrigger.

Если вы хотите заглушить звук, вам нужно создать модуляцию AHDSR для громкости в FMOD Studio и добавить StopTrigger в Редактор управления звуком. Модуляция AHDSR также используется для создания постепенного появления.

Когда вы выбираете соединение в окне «Подключенные элементы управления», вы можете выбрать, следует ли запускать или останавливать звук, используя кнопку Действие раскрывающийся вариант.

Для получения дополнительной информации ознакомьтесь с функциональностью Audio Trigger Spot в сочетании с FMOD Studio. здесь.
