Выпущено 4 июля 2014 г.

Редактор

  • Новый: добавлен флаг для отключения динамических объемов воды на выбранных объектах редактора.
  • Новый: добавить реализацию SHAllocator, которая использует malloc/free из Sandbox (который может быть #определен как что-то другое).
  • Новый: Flowgraph Узлы отрисовки отладки: Debug:Draw:Direction, Debug:Draw:Cone, Debug:Draw:Cylinder, Debug:Draw:Line, Debug:Draw:Sphere, Debug:Draw:AABB, Debug:Draw:PlanarDisc, Debug:Draw:EntityTag, Debug:Draw:EntityTagAdvanced.
  • Исправлено: Обновление системы FlowGraph в последний раз прямо перед сбросом систем во время выгрузки уровня, чтобы гарантировать выполнение ожидающих запросов.
  • Исправлено: #define USE_MEM_ALLOCATOR, чтобы исправить несоответствие распределителя между Sandbox и PRT. Это может привести к сбою во время создания поверхности местности.
  • Исправлено: Диалоговое окно «Слой» не устанавливает новый слой (исправление 2674).
  • Исправлено: UI Макет не сохранен (CE-3684) (исправление 2685).
  • Исправлено: Поддержка всех возможных расширений в диалоговом окне «Экспорт файлов» (даже тех, которые не обязательно совместимы) (CE-3704).
  • Исправлено: пометить редактор как не поддерживающий DPI в манифесте (CE-3729), чтобы предотвратить сбой при размере шрифта Windows, отличном от 100% (по умолчанию) (исправление 2685).
  • Исправлено: Редактор игнорирует флаг DPI Aware из Manifest Tool после чистой сборки, также принудительно встраивает файл XML с поддержкой DPI.
  • Исправлено: Панель «Растительность»: изменена кодировка .bmp, которую MFC BarTool не удалось загрузить, поскольку она поддерживает только индексированные растровые изображения.
  • Исправлено: Удаление транспортного средства с уровня, открытого в VE, приводит к сбою редактора (CE-3446).
  • Исправлено: Разрешить отмену режима создания при запуске инструмента ландшафта (CE-2257), иначе инструмент просто не откроется.
  • Исправлено: Обновлены сценарии Boid, теперь их минимальное количество равно 0, чтобы предотвратить сбой при использовании -1 или меньше (CE-3750). Удалены мертвые параметры. Добавлены разделители для ясности структуры.
  • Исправлено: Параметр активации Боида не сработал (CE-3801).
  • Исправлено: Бесконечный цикл кода при связывании цели камеры с камерой.
  • Исправлено: Сбой при создании нового уровня при выборе «Рассчитать доступность неба над местностью» (CE-3450).
  • Оптимизированный: удалить устаревшие виды Z и ModelPreview из параметров видового экрана (CE-328).
  • Оптимизированный: Удаление неподдерживаемого кода ленты UI.
  • Оптимизированный: Удален устаревший параметр «AffectThisAreaOnly» из объектов Light (CE-1650).
  • Оптимизированный: кнопка «Выключить все звуки» перемещена из InfoBar в меню «Звук» (исправление 2674).
  • Оптимизированный: Удалить последние ссылки на рекордер AVI.
  • Оптимизированный: Удалить AICheckInBox (используйте ProxyTrigger), Удалить DelayTrigger (используйте узел Time:Delay FG), Удалить MultipleTrigger. Удалены визуальные эффекты ограничивающей рамки из AreaTrigger, так как они бесполезны.

Аудио

  • Новый: к AudioSystem добавлена базовая обработка AudioEnvironment (реверберация).
  • Исправлено: Восстановлен звук типа ATL в системе частиц, для чего базовый аудиопрокси перемещен в аудиосистему и оптимизирована обработка с некоторыми незначительными исправлениями кода.
  • Исправлено: Исправлена ошибка, из-за которой аудиообъекты не освобождались должным образом, также добавлена переменная CVar для установки размера пула аудиособытий, исправлена утечка AudioProxies, когда они не возвращались обратно в пул, предварительное исправление утечки аудиопрокси.
  • Исправлено: Исправлена утечка идентификаторов и описаний аудиообъектов.
  • Исправлено: Исправлена пересылка имен AudioObject на Wwise.
  • Исправлено: Исправлена ошибка настройки вложенной области.
  • Исправлено: При смене папки с игрой сломался звук (исправление 2685).
  • Исправлено: Сбой при доступе к висячему указателю AudioSystem при выходе из системы.
  • Исправлено: Сбой в AudioProxy при доступе к висячему указателю AudioSystem.
  • Исправлено: OnFarToNear не срабатывает на узле AudioAreaEntity FG при появлении внутри области (исправление 2674).
  • Оптимизированный: SoundProxy переименован в EntityAudioProxy и теперь может использовать AudioProxy.
  • Оптимизированный: ACB: обновлен внешний вид панели фильтров и свойств соединения.

Двигатель

  • Новый: Возможность обнаружения устройства HMD (CE-3603).
  • Исправлено: Декодер кэша Geom все еще использовал инструкцию SSE4.1 на PC (сбой на старых процессорах AMD) (исправление 2674).
  • Исправлено: Кэш Geom: необходимо остановить потоковую передачу при сбросе, иначе будут загружены кэши Geom с расстоянием потоковой передачи = 0. Потоковая передача будет запущена снова по логике обновления кадров, если расстояние> 0.
  • Исправлено: Кэш Geom: исправлена взаимоблокировка на AbortAndWait (происходит при настройке размера буфера во время воспроизведения кэша Geom).
  • Исправлено: обновлены файлы ресурсов для улучшения совместимости с Visual Studio Express.
  • Исправлено: отключена потоковая передача текстур из Skybox_highQ, чтобы предотвратить размытие текстур (CE-3613).
  • Исправлено: предварительное кэширование материала CGA для независимых объектов static, прикрепленных к суставам.
  • Исправлено: Исправлена загрузка профиля CrySystem.
  • Исправлено: (Физика) UnprojectionNeeded не учитывает радиус компонента z (CE-3636).
  • Исправлено: (Физика) Сбой при отправке запроса raycast с недопустимым физическим стримером (CE-3742).
  • Исправлено: (Физика) Некоторые исправления ограничений.
  • Исправлено: (Действие) Регистрация события игрового объекта с неверным именем (CE-3606).
  • Исправлено: (Действие) sv_LoadAllLayersForResList перенесен из игры в игровую среду (CE-3683).
  • Исправлено: (Сеть) Правильно отформатируйте идентификатор сеанса.
  • Исправлено: (Scaleform) Возможный сбой при воспроизведении фильма (из-за проблемы с глобальным порядком инициализации).
  • Исправлено: Теперь правильная обработка логических значений в сериализации ScriptProperty.
  • Оптимизированный: Переместить привязки сценария GameToken в отдельный файл.
  • Оптимизированный: переименуйте CGameTokenScriptBind в CScriptBind_GameToken для согласованности со всеми другими привязками скриптов.
  • Оптимизированный: Обновлено для использования DirectX SDK, июнь 2010 г.
  • Оптимизированный: расширенный интерфейс, позволяющий выполнять больше локальных операций в контейнере.

Рендеринг

  • Исправлено: Установите для параметра «Свечение в генераторе шейдера Diffuse Alpha» значение «скрыто», так как оно не требуется. Если обнаружена диффузная альфа, маска применяется автоматически и из-за отложенного затенения ее нельзя отменить (CE-1526).
  • Исправлено: Неправильное использование идентификатора потока для рекурсивной спин-блокировки.
  • Исправлено: Исправлена неправильная обработка отключения/повторного подключения дисплея (CE-3549).
  • Оптимизированный: Удалить зависимость от d3dx9 и d3d10.

CryDesigner

  • Новый: Реализована первая полная версия инструмента «Токарный станок».
  • Исправлено: курсор, показывающий перемещение, вращение или масштаб, обновляется в зависимости от того, находится ли курсор в объекте или манипуляторе гизмо или нет (CE-3443).
  • Исправлено: добавлено сообщение eNotify_OnEndUndoRedo для лучшей обработки операций отмены/повтора.
  • Оптимизированный: удален инструмент «Отсоединить». Вместо этого отсоединить грани можно, удерживая клавишу Shift и перемещая грани с помощью инструмента перемещения.
  • Оптимизированный: существующий инструмент лестницы разделен на инструмент лестницы и инструмент StairProfile.
  • Оптимизированный: Улучшен метод создания лестниц.
  • Оптимизированный: клавиша выбора нескольких ребер/вершин/граней изменена с Ctrl на Shift.
  • Оптимизированный: удалена кнопка LoopCut.

Частицы

  • Новый: добавлен ParticleParams.fSortBoundsScale для настройки BB, используемого для сортировки; 0 => сортировка по происхождению (CE-2649).
  • Исправлено: Частицы геометрии с подсетками снова создают случайную подсетку, а не полную сетку, как задумано.
  • Исправлено: Частицы, обращенные к воде, на водных объемах: исправлен запрос pe_status_area путем восстановления удаленного кода, проверяющего сдерживание ящика внутри области; снова возвращает 1 для сдерживания, -1 для пересечения, что позволяет оптимизировать тесты. PhysEnv для границ static теперь запрашивает все объемы воды. Убрано бесполезное смещение ATTACH_BUFFER_DIST (CE-3756).
  • Исправлено: Редкий сбой с прикрепленными частицами, когда GetRandomPos выбирает пустую часть в конце списка. Пустые части теперь автоматически обрезаются, удалена функция TrimParts().
  • Оптимизированный: Проведён рефакторинг SPhysEnviron struct для ясности и эффективности: некоторые элементы переименованы, удалены неиспользуемые аргументы и код. Объединение запросов силовой и водной плоскости в одну функцию. ENV_WATER теперь необходимо явно передавать в области запроса; теперь включается только при необходимости.

Инструменты

  • Исправлено: RC Диалоговое окно ImageCompiler (CryTif) имело неверный макет, когда панель задач находилась вверху или сбоку экрана (CE-3697).
  • Исправлено: Сбой в CrySCompileServer при обработке пустого сообщения об ошибке.
  • Исправлено: someStr изменен на someStr.c_str() в выводе журнала для экспортера Max.
  • Оптимизированный: Переместить файлы статоскопа в каталог пользователя, а не в корневой каталог.

Анимация и персонажи

  • Новый: добавлена поддержка костных ссылок с 16-битными индексами костей.
  • Исправлено: Формат индекса вершин перемещён на typedef, чтобы можно было использовать 32-битные индексы вершин.
  • Исправлено: Убрано жестко заданное значение DivBy4 в ca_AttachmentCullingRation (вместо этого мы добавили правильное значение в файл конфигурации). Это влияет на расстояние обзора персонажа.
  • Исправлено: активируйте сетку рендеринга и фрагменты сетки символов только после того, как в основном потоке произошло переназначение костей.
  • Исправлено: спекулятивное исправление неработающего предварительного кэширования файлов CHR без вложений.
  • Исправлено: Рекурсивная функция getChildren() в скрипте приводит к сбою 3ds Max, когда иерархия объектов/костей имеет глубину > ~250 костей. Исправлено, сделав getChildren() нерекурсивным.

Активы

  • Новый: Перезапечены нормали MH60 Blackhawk с 2-кратным разрешением. Изменен материал/текстуры.
  • Исправлено: Многочисленные обновления ресурсов в библиотеке образцов ресурсов. Большинство зданий и разного реквизита были обновлены для PBS в базовой форме. Другой реквизит WIP.
