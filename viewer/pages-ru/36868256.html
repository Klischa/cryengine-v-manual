Обзор

Категория «Аудио» отвечает за запуск аудиофайлов в эффектах частиц. Эту функцию можно использовать несколько раз в одном компоненте, и она позволяет использовать сложную аудиологику в эффектах частиц.

Следующие опции доступны в разделе Аудио категория:

Элементы управления параметрами в реальном времени (RTPC)

Содержит настройки управления параметрами в реальном времени (RTPC) для аудиосистемы CRYENGINE. RTPC — это атрибуты звука, которые могут управлять определенными аспектами звука, такими как высота тона, громкость, срез фильтра и т. д. Для получения дополнительной информации о RTPC посетите сайт CRYENGINE. Аудио документация.

Триггер

Эта функция позволяет каждой частице в этом компоненте запускать звуковое событие.

GPU Поддержка

Поскольку между частицами GPU и хостом нет связи, звуковые события не поддерживаются для частиц GPU.
