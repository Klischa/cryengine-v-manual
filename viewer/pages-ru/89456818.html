Как обрабатываются события UI

Открыв функцию из Flash UI, вы теперь можете приказать Flash UI что-то сделать. Следующий вопрос — как обрабатывать такие события, как нажатия кнопок, чтобы Flash UI мог сообщить вашему проекту, что что-то произошло.

В этом разделе вы узнаете, как добавить кнопку во Flash UI, активировать курсор при открытии UI и распознавать в своем игровом проекте нажатие кнопки. С помощью событий Flash UI вы можете обрабатывать простые события, такие как нажатие кнопки, а также обрабатывать такие данные, как ввод текста из элемента управления UI и фактическую логику внутри вашего игрового проекта.

Экспонирование события из Flash

Масштабная форма 3

  1. Начните с создания нового символа в библиотеке Flash-проекта. Мы назовем этот символ «BasicButton» и изменим его тип на кнопку.

    Новый символ


    Установите тип «Кнопка».

  2. Появится новое окно с содержимым вашего символа; здесь нарисуйте простой прямоугольник, используя Инструмент «Прямоугольник» (R).

    Нарисуйте простой прямоугольник

  3. Теперь вы можете вернуться в свою сцену и из своей библиотеки поместить в сцену экземпляр нового символа BasicButton.

    Поместите экземпляр BasicButton в свою сцену.

  4. Назовите этот экземпляр символа BasicButton «btnTest». Вот как на эту кнопку будет ссылаться ActionScript.

    Назовите символ btnTest.


  5. Затем откройте окно «Действия», нажав F9 или перейдя в меню «Окно → Действия»; добавьте следующий код после существующего кода в Сцене 1 → Слой 1: Кадр 1:

    btnTest.onPress = function () {
    fscommand("button", "btnTest");
};


    Добавьте код в Сцену → Слой 1: Кадр 1.

  6. Теперь, когда вы определили свою функцию, скомпилируйте файл GFx через экспортер, как показано на рисунке. Глава 2. Flash и Gfx, а затем добавьте следующие изменения в файл UI Elements XML, чтобы предоставить событие визуальному сценарию:

         <events>
      <event name="OnButtonPress" fscommand="button" desc="Activated when user clicks the button">
        <param name="ButtonName" desc="Name of the button" type="string" />
      </event>
    </events>


    Предоставление события визуальному сценарию
