Выравнивание

Назначение разных подматериалов разным полигонам

С помощью параметров «Подматериал» вы можете назначить один подматериал одному полигону объекта Designer, а второй (или третий, четвертый и т. д.) другому полигону. Для этого:

  1. Выберите объект дизайнера
  2. Назначьте ему мультиматериал (Свойства -> Общие -> Материал)
  3. Вернитесь в Designer Tool и активируйте. Расширенное -> Сопоставление UV
  4. Нажмите Выбрать и выберите полигон(ы), подматериал которого вы хотите изменить.
  5. Под Дополнительно -> Дополнительные материалы, выберите нужный субматериал (первый всегда будет назначен всем полигонам по умолчанию)
  6. Нажмите Назначить

Чтобы узнать, как работает редактор карт UV, см. эта страница.

Группа сглаживания

Группа сглаживания создает группы полигонов с плавной заливкой, в отличие от плоской заливки по умолчанию.

Форма объекта останется прежней; изменится только затенение, так что полигоны в одной группе будут выглядеть гладкими.

При выборе инструмента вы получаете панель с различными кнопками для управления группами сглаживания.

Как это работает

1. Выделите полигоны, щелкнув Полигон в Выбор раздел и щелкните по полигонам, которые вы хотите выделить на объекте Designer. Удерживать Ctrl чтобы выбрать более одного полигона:


2. Нажмите Добавить SG чтобы добавить выбранные полигоны в качестве группы сглаживания. При нажатии этой кнопки выбранные полигоны будут сглажены. После этого вы увидите, что края выглядят более гладкими:
