Обзор

На панели «Настройки уровня» глобальные настройки например анимация океана, положение и размер луны и несколько настроек ветра для уровня можно установить. В дополнение к этим общим настройкам здесь можно найти вкладку «Настройки среды», которую можно использовать для отслеживания и изменения эффектов среды.

Некоторые из этих override настроек в Environment Editor.

Панель настроек уровня можно найти в разделе Инструменты → Редактор уровней → Настройки уровня. Он состоит из двух разных вкладок:

Вкладка «Предустановки среды»

Вкладка «Настройки среды» используется для управления списком ресурсов среды, которые были добавлены на уровень. Установка актива среды по умолчанию, перетащив его во видовой экран из браузера ресурсов или выбрав Установить по умолчанию для этого уровня Опция в контекстном меню добавляет выбранный ресурс в список пресетов.

Несмотря на то, что в список предустановок можно добавить несколько ресурсов среды, в окне просмотра одновременно может отображаться только один.

На вкладке «Настройки среды» есть три основных поля:

1. Предустановка по умолчанию

Отображает ресурсы среды, представленные на уровне. Выбор объекта окружающей среды на Предустановка по умолчанию list устанавливает этот актив по умолчанию. Этот список включает в себя все ресурсы окружающей среды, представленные на уровне; однако одновременно только один актив может быть установлен по умолчанию. Выбор другого актива также приведет к изменению параметров среды и отображению результата на видовом экране.

2. Раскрывающееся меню предустановок.

Пользователи могут добавлять/удалять ресурсы среды, щелкнув или щелкнув правой кнопкой мыши значок Раскрывающееся меню пресетов значок и выбирая либо Вставить или Добавить в зависимости от того, где в списке должен быть размещен новый актив среды. Это добавляет новое поле в Пресеты список позволяя пользователям выбирать из существующих ресурсов среды, нажав на значок Обзор кнопка.

3. Список пресетов

Чтобы выбрать существующий актив среды, щелкните правой кнопкой мыши новое поле и выберите Выберите ресурс... или щелкните значок обзора рядом с полем имени. Также можно редактировать выбранный ресурс среды, нажав кнопку редактирования.

Чтобы удалить активы из списка, щелкните правой кнопкой мыши и выберите Удалить все в раскрывающемся меню «Предустановки».
