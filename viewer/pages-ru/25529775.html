← Содержание Использование GameSDK с Custom Engine RU

В этой статье подробно описываются шаги, необходимые для успешной компиляции и запуска Пример проекта gamesdk с собственным движком, клонированным из GIT. Примечание. Мы не будем перемещать исходный код gamesdk, а будем ссылаться на ресурсы, расположенные во внешней папке проекта. В дополнение к шаги, необходимые для проектов C++ вам нужно будет:

  1. Загрузите CRYENGINE GameSDK Пример проекта через лаунчер CRYENGINE, т.е. из «Библиотека/Мои активы» Примечание. Если вы ранее не загружали пример проекта CRYENGINE GameSDK, вам придется сначала сделать это. Его можно бесплатно загрузить с сайта CRYENGINE. База данных активов. Вы можете легко найти путь к ресурсу, выбрав «Показать в проводнике» в раскрывающемся списке образцов.
  2. Перейдите в только что загруженную папку примера проекта GameSDK и измените файл project.cfg. "engine_version=локальный"
  3. Поскольку мы создаем GameSDK, используя настройки WAF по умолчанию, вам также потребуется изменить настройки project.cfg. "sys_dll_game=CryGameSDK"
  4. Запустите cry_waf.exe из папки пользовательского движка и создайте game_sdk проект. Откройте сгенерированное решение и скомпилируйте [GameSDK] Профиль x64
  5. Добавьте следующее свойство проекта Visual Studio в свой Отладка/аргументы команды -projectroot "path_to_gamesdk_sample_downloaded_from_asset_database"
  6. Добавить "r_width=1280", и"r_height=720" к system.cfg

Теперь вы можете запустить свой игровой проект, используя собственный движок из Visual Studio или файла Game.bat. Чтобы загрузить тип карты "+карта леса" во внутриигровую консоль.
