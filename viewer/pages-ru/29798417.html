Заготовка template предназначена для тех ситуаций, когда вы хотите начать проект с нуля. Этот template включает в себя только счетчик FPS и базовую настройку CryEnginePlugin который можно использовать в качестве отправной точки для инициализации вашего проекта. Однако, если вы не знакомы с программированием на C# в CRYENGINE, мы рекомендуем сначала начать с другого из доступных шаблонов.

Связанный контент:

  • Справочник по C# API
  • Программирование на С#

FPS-Счетчик

Счетчик FPS отображается с помощью CryEngine.UI. Холст устанавливается CreateUI метод. Текст компонент добавляется на холст и размещается в правильном положении. В OnUpdate методе подсчитывается количество прошедших кадров, и каждую секунду оно записывается в Текст компонента, и счетчик сбрасывается на 0. OnUpdate метод вызывается каждый кадр GameFramework, что достигается вызовом RegisterForUpdate в конструкторе Игра класс.

CreateUI и DestroyUI подписаны на событие перезагрузки двигателя. Это необходимо для очистки UI при перезагрузке плагинов C#, например, когда ресурс C# был отредактирован.
