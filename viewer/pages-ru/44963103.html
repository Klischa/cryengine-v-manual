Обзор

В папке вашего проекта будет файл типа Cryengine project — расширение имени файла для этих типов файлов — *.cryproject.

Когда вы щелкаете правой кнопкой мыши (как показано ниже) по такому файлу, вы получаете ряд опций, с помощью которых вы можете легко выполнять различные действия в отношении вашего проекта.

Вы можете не увидеть точный формат (как показано выше) вашего проекта Game.cry. Причина этого в том, что у вас установлена ​​более старая версия CryVersionSelector. Чтобы исправить это, вам необходимо установить CryVersionSelector для версии Engine (5.4, 5.3, 5.2), которую использует ваш проект. Для получения дополнительной информации об установке CryVersionSelector см. раздел FAQ внизу этой страницы.

Доступные параметры делают следующее.

Добавление консольных переменных и консольных команд

Файлы *.cryproject можно использовать для установки определенных консольных переменных и консольных команд для вашего проекта. Для этого вам нужно открыть файл *.cryproject с помощью текстового редактора, например Блокнота. Файлы *.cryproject — это простые файлы JSON, которые описывают различные настройки проекта. Файл CryProject по умолчанию будет выглядеть так:

{
    "console_variables": [
        { "name": "sys_target_platforms", "value": "pc,ps4,xboxone,linux" },
        { "name": "r_displayinfo", "value": "1" }
    ],
    "console_commands": [
        { "name": "map", "value": "example" }
    ],
    "content": {
        "assets": [ "Assets" ],
        "code": [ "Code" ]
    },
    "info": {
        "name": "Game"
    },
    "require": {
        "engine": "engine-5.4",
        "plugins": [
            { "path": "CryDefaultEntities", "type": "EPluginType::Native" },
            { "path": "CrySensorSystem", "type": "EPluginType::Native" },
            { "path": "CryPerceptionSystem", "type": "EPluginType::Native" },
            { "path": "bin/Game.dll", "type": "EPluginType::Managed" }
        ]
    },
    "type": "",
    "version": 1
}

Чтобы добавить консольную команду в проект, ее необходимо добавить в файл console_commands список. Например, GameLauncher можно заставить загружать карту при запуске, добавив map команда.

"console_commands": [
  { "name": "map", "value": "example" },
]

Консольные переменные добавляются в console_variables список. Например, displayinfo можно установить с помощью r_displayinfo переменная.

"console_variables": [
  { "name": "r_displayinfo", "value": "1" },
]

Всегда делайте резервную копию, прежде чем вносить изменения вручную. Механизм может прочитать файл, только если он содержит действительный JSON. Если JSON недействителен, проект нельзя будет запустить, пока он не будет исправлен.

FAQ

Отсутствующие или неверные параметры при щелчке правой кнопкой мыши по файлу *.cryproject.

Это может произойти, если установлена более старая версия CryVersionSelector. Чтобы установить правильную версию CryVersionSelector, перейдите в корневую папку вашего движка (по умолчанию она находится в C:\Program Files (x86)\Crytek\CRYENGINE Launcher\Crytek). Оттуда идите в Инструменты\CryVersionSelector. Там либо запустите Install.bat или откройте командное окно и запустите cryselect.exe установить или в Powershell ./cryselect.exe установить.

Не удалось сгенерировать решение для GameSDK.

Создать решение для GameSDK невозможно, поскольку GameSDK скомпилирован в движке. Чтобы настроить код GameSDK, вам необходимо получить исходный код движка с сайта Гитхаб.

Игра выглядит иначе, если она запущена в редакторе GameLauncher, а не в редакторе Sandbox.

Прежде чем запускать игру в GameLauncher, убедитесь, что вы экспортировали уровни в движок редактора Sandbox. Это можно сделать в редакторе Sandbox, перейдя в Открыть -> Экспорт в движок.

GameLauncher показывает только черный экран

Это может произойти потому, что GameLauncher не может загрузить проект. Есть несколько способов заставить GameLauncher загрузить проект. Самый простой способ — щелкнуть правой кнопкой мыши файл *.cryproject в вашем проекте и выбрать Запустить игру. Другой способ — указать проект для загрузки в system.cfg двигателя. Это делается добавлением строки sys_project=вашпроект.cryproject к system.cfg. Последний способ запуска GameLauncher — добавить проект для загрузки в аргументы при запуске, например. GameLauncher.exe -проект Game.cryproject.

Другой причиной черного экрана может быть то, что не загружается карта. Вы можете использовать карта команду в консоли, чтобы убедиться, что ваша игра загружается правильно
