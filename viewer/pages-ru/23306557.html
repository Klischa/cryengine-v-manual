Новая реализация

CryENGINE уже предоставляет несколько базовых реализаций GameRules, в том числе Одиночная игра и DeathMatch. На основе этих GameRules можно использовать их основные функции.

Чтобы реализовать захват флагов GameRules, мы будем производными от TeamDeathMatch GameRules. Нам нужно написать следующие строки в начале нашей реализации GameRules.

Script.ReloadScript("scripts/gamerules/teamdeathmatch.lua");
CaptureTheFlags = new(TeamDeathMatch);

Оценка

Чтобы обновить результаты на основе флагов, которые были зафиксированы всеми командами, мы можем создать функцию, которая будет вызываться в заранее определенный период времени. Этот период времени определяется переменной CaptureTheFlags.TICK_TIME.

function CaptureTheFlags.Server.InGame:OnTick()
    CaptureTheFlags.Server.UpdateScores(self);
end

function CaptureTheFlags.Server:UpdateScores()
    for i,flagId in pairs(self.Server.FlagIds) do
        local teamId = self.game:GetTeam(flagId);

        if (teamId) then
            self:SetTeamScore(teamId, self:GetTeamScore(teamId) + 1);
        end
    end
end

Регистрация в системе GameRules

Во время запуска игры будет проанализирован каждый файл в каталоге скриптов GameRules. Добавление следующей строки позволит GameRules зарегистрироваться.

GameRules.RegisterGameRules("CaptureTheFlags", "GameRules");

Первый параметр должен совпадать как с именем GameRules, так и с именем файла, исключая расширение .lua. Второй параметр будет использовать стандартный класс C++ GameRules, который обрабатывает большую часть низкоуровневой части GameRules, например сетевую синхронизацию и создание игроков.

GameRules теперь можно просто запустить, набрав sv_gamerules CaptureTheFlags в консоли сервера или в лаунчере игры.

GameRulesModulesManager

CryENGINE использует 'GameRulesModulesManager' для анализа файла XML, содержащего определения каждого из правил игры во время выполнения. Файл XML находится по адресу Game/Scripts/GameRules/GameModes.xml и содержит имя каждого игрового режима, его псевдонимы, каталоги расположения уровней, путь к определенному файлу XML, который определяет поведение игрового режима, и, наконец, конкретный HUD, если требуется.

Пример записи:

<GameMode name='DeathMatch'>
  <Alias name='DM' />
  <Alias name='DeathMatch' />
  <LevelLocation path='Multiplayer/' />
  <Rules path='Scripts/GameRules/DeathMatch.xml' />
  <DefaultHudState name="mp_dm" />
</GameMode>
