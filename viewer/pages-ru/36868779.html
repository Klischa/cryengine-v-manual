Обзор

CRYENGINE предлагает уникальный система частиц разработанный чтобы обеспечить большую гибкость для пользователя и оптимальное использование современных CPU и архитектур памяти. Для достижения этой цели серверная часть моделирования частиц реализует ориентированный на данные дизайн, в котором структура памяти оптимизирована для векторизованной обработки.

Что касается внешнего интерфейса, система частиц представляет собой модульный подход к настройке, который позволяет более гибко разрабатывать эффекты частиц, которые можно настроить для взаимодействия с остальной частью движка посредством передачи атрибутов.

Система частиц обеспечивает плавное переключение между конвейерами частиц на основе GPU и CPU. Конвейер частиц на основе GPU реализует подмножество функций частиц CPU, предлагая при этом гораздо более высокую скорость для эффектов массивных частиц, таких как эффекты жидкости и фрактальное движение.

CRYENGINE Система частиц предлагает широкий спектр функций. Сочетание этих функций гарантирует, что пользователи смогут создавать уникальные эффекты частиц.

Эти особенности тесно связаны с Particle Editor и их не следует путать с Вкладка «Частицы» (устаревшая версия Particle Editor) особенности.
