Обзор

Интеграция Scaleform в CRYENGINE — это гибкое и производительное решение, использующее технологию Autodesk Scaleform для предоставления инструментов и возможностей для визуализации функциональных пользовательских интерфейсов для ваших проектов.

С момента выпуска CRYENGINE 5.7 LTS реализация обеспечивает поддержку Scaleform 3 и Scaleform 4. Включение Scaleform 3 задумано как запасной вариант для пользователей, полагающихся на функциональность, которая, возможно, будет изменена в Scaleform 4, чтобы они могли беспрепятственно продолжать разработку своих проектов.

Scaleform 4 поддерживает Actionscript 2.0, а также Actionscript 3.0. Это означает, что вы можете использовать любое программное обеспечение Adobe Flash или анимацию, поддерживающее ActionScript 2.0 или 3.0, для создания ресурсов Scaleform GFX. Хотя рабочий процесс остался неизменным, существуют различия в отношении существующих сейчас инструментов и других технических элементов, которые требуют разделения создания активов Scaleform 3 и Scaleform 4.

Цели

Целью этого руководства является то, чтобы вы начали использовать реализации Scaleform 3 и/или 4, поставляемые с CRYENGINE V.

  • Там, где это применимо, инструкции для Scaleform 3 и 4 представлены отдельно в каждой главе.
  • При использовании этого руководства для Scaleform 3 рекомендуется использовать версии CRYENGINE от 5.0 до 5.6.7. и Adobe Flash CS6.
  • Тем временем аспекты Scaleform 4 в этом руководстве рекомендуются для CRYENGINE версии 5.7 LTS. Вам также необходимо включить Scaleform 4 для вашей сборки Engine; увидеть Включение Scaleform 4 для проектов и пользовательских сборок движка для получения дополнительной информации.

В этом руководстве вы также будете выполнять части XML и визуальные сценарии для достижения базовой функциональности; Что касается визуального написания сценариев, вы можете выбирать между инструкциями, предоставленными для Flow Graph и Schematyc (экспериментальная версия) в соответствующих главах. Однако не рекомендуется смешивать подходы Flow Graph и Schematyc (экспериментальный), поскольку это может привести к трудноразрешимым проблемам.

Вы также узнаете, как:

  • Создайте новый проект Flash для использования Scaleform.
  • Конвертируйте файлы SWF в файлы GFx.
  • Создайте необходимые изображения DDS.
  • Предоставляйте функции и события UI визуальным сценариям.
  • Вызов и обработка функций UI в Flow Graph.
  • Проверьте свой UI в игре.
