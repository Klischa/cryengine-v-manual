Обзор


Объединить все узлы вариант в Экспорт геометрии Панель 3ds Max компилирует всю геометрию из разных узлов в один узел. Он поддерживается только для геометрии без оболочки (геометрия static).

Когда эта опция включена, компилятор ресурсов объединяет сетки нескольких узлов вашей сцены в один узел в файле CGF.

Однако файл CGF по-прежнему может содержать более одного узла, но каждый из них может содержать один или несколько бывших узлов вашей сцены DCC.

Процесс объединения всех узлов

Объединить все узлы По сути, этот параметр является оптимизацией рендеринга, поскольку он уменьшает количество вызовов отрисовки. Основные изменения, как описано ниже, являются следствием процесса слияния. Однако Объединить все узлы Опция не предназначена для изменения поворотов сетки.

Компилятор ресурсов создает единую объединенную сетку для всех узлов на одном уровне детализации. В частности, объединенный файл CGF содержит один единственный узел, который объединяет все сетки LOD0 в вашей сцене. Аналогично, также будет узел для LOD1, LOD2 и т. д.

В файле CGF узел, который объединяет все сетки LOD0, является родительским узлом для всех остальных узлов (включая узлы LOD и другие вспомогательные узлы). Когда компилятор ресурсов объединяет две сетки, он преобразует вершины обеих сеток в мировое пространство. Несмотря на то, что вершины физических прокси преобразуются, их узлы не объединяются.
