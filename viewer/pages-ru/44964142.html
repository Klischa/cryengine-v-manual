Обзор

Эта функция может быть полезна для мгновенной трассировки лучей быстро движущихся объектов. Обычно прокси физики будет на один кадр опережать геометрию рендеринга из-за многопоточности, что означает, что наведение на прокси рендеринга может промахнуться. Кроме того, pe_status_pos гарантированно вернет те же координаты, которые были установлены предыдущим pe_params_pos, даже если команда была поставлена в очередь и еще не была полностью выполнена.

Эта функция дополнительно сохраняет второй набор координат объекта верхнего уровня (pos+quat), который синхронизируется с основным набором при отправке зарегистрированного события poststep (в основном потоке), то есть он синхронизируется с основными координатами CEntity. Мировые запросы (RWI, PWI, GEA) могут дополнительно выполнять тесты с использованием этих координат. Кроме того, pe_params_pos запросы изменяют их мгновенно, и pe_status_pos при желании можно прочитать их вместо основных координат (это означает, что SetParams(pe_params_pos); GetStatus(pe_status_pos); вернет обновленную позицию, даже если SetParams стоял в очереди).

Использование

Чтобы включить буферизацию double для определенного объекта, pe_params_pos.doubleBuffCords должен быть установлен.

Для скелетов персонажей он должен быть установлен для обоих CЖивой хозяин и сам персонаж.

Чтобы использовать эти координаты в RWI, PWI и GEA, ent_use_sync_coords должен быть установлен в типы объектов. Чтобы использовать их в pe_status_pos, status_use_sync_coords должен быть установлен во флагах. По умолчанию синхронизация координат не включена и не используется.
