Классы:

IUndoManager (Код\Sandbox\EditorInterface\IUndoManager.h) Хранит список команд отмены и предоставляет все операции, необходимые для манипуляций с этим списком. В настоящее время существует только один экземпляр, доступ к которому можно получить через GetIEditor()->GetIUndoManager().
CUndo (Код\Sandbox\EditorInterface\IUndoObject.h) Это вспомогательный класс для простого использования экземпляра GetIEditor()->GetIUndoManager().
IUndoObject (Код\Sandbox\EditorInterface\IUndoObject.h) Интерфейс, который необходимо реализовать для отдельных шагов отмены.

Пожалуйста, обратитесь к CUndoVariableChange (Код\Sandbox\EditorQt\Controls\PropertyItem.cpp).

Важно: когда вы реализуете свой собственный IUndoObject, функция IUndoObject::Undo(bool bUndo) принимает логический аргумент - каждый объект отмены должен запомнить свое исходное состояние и новое состояние, т.е. в случае реализации CUndoVariableChange у него есть переменные TSmartPtr<IVariable> m_undo и TSmartPtr<IVariable> m_redo для хранения старого и нового состояния - Переменная m_undo заполняется текущими данными m_var (то есть до изменения m_var) в конструкторе CUndoVariableChange. Переменная m_redo должна быть заполнена после изменения значения, поэтому она заполняется при первом вызове функции IUndoObject::Undo(bool bUndo) - когда она вызывается в первый раз, bUndo имеет значение true, поэтому теперь вы заполняете переменную m_redo текущими данными m_var (то есть после того, как m_var изменяется извне).

Использование

Чтобы начать запись команды отмены, вам необходимо сначала вызвать функцию IUndoManager::Begin().
Чтобы записать шаг отмены, вам нужно вызвать IUndoManager::RecordUndo(pMyCommand). Вы можете вызывать эту функцию несколько раз, если хотите сгруппировать больше команд.
Чтобы завершить запись, вам нужно вызвать IUndoManager::Accept("Desc") или IUndoManager::Cancel(), если вы хотите отменить команды.
Для всех этих функций существует вспомогательный класс. CUndo который вызывает начало/принятие/отмену в своем конструкторе/деструкторе, а также предоставляет функцию для записи.
