Документация по конкретной платформе

Для разработки на определенных платформах разработчик MUST должен быть зарегистрирован у поставщика платформы, например Sony или Microsoft. Кроме того, доступ к некоторой документации CRYENGINE разрешен только одобренным разработчикам.

Регистрация в качестве сертифицированного разработчика

Чтобы стать сертифицированным разработчиком на PlayStation или Xbox, вам необходимо зарегистрироваться в Sony или Microsoft. Для регистрации перейдите по ссылкам ниже;

PlayStation

Xbox

После регистрации

PlayStation

  1. После регистрации вы MUST подтвердите свою лицензию на консоль с помощью Сони
  2. Затем Crytek свяжется с вами и попросит указать ваши имена пользователей GitHub и CRYENGINE.
  3. Crytek предоставит вам доступ к соответствующему репозиторию PlayStation из GitHub и предоставит вам доступ к документации CRYENGINE PlayStation.

Xbox

Вы MUST свяжитесь с Crytek по адресу contact@cryengine.com со следующей информацией;

  1. Ваш регион
  2. Название вашей компании или имя человека, зарегистрированного в Microsoft.
  3. Адрес электронной почты, который использовался при регистрации в качестве разработчика в Microsoft.
  4. Имя вашей учетной записи GitHub
  5. Ваше имя пользователя CRYENGINE
  6. Crytek предоставит вам доступ к соответствующему репозиторию Xbox через GitHub и предоставит вам доступ к документации Xbox CRYENGINE.
