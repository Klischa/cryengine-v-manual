Обзор

В этом уроке мы покажем вам процесс настройки физического взаимодействия между свисающими листьями ивы и любым другим физическим объектом на уровне (например, игроком). Для этого мы будем использовать наш Деформация объединенной сетки система в CRYENGINE.

Деформация объединенной сетки Ткань — это улучшенная и оптимизированная система по сравнению с сущностью ткани. С помощью этой системы можно настроить активы с поведением ткани в виде кистей и объектов растительности. В отличие от обычного тканевые сущности в CRYENGINE объединенная сетчатая деформирующая ткань одновременно содержит геометрию static и геометрию деформируемой ткани.

Этот метод отлично подходит для подвешивания растительности, такой как болотный мох или листья ивы. Но мы также можем представить себе и другие цели, например, шесты (static) с флагами (деформируемые) или белье (деформируемое), висящие между двумя шестами (static).

Предварительная информация

  • В отличие от учебной части 3ds Max, нам нужно создать специальную иерархию экспорта с группами, такими как пустые узлы преобразования. Это самая сложная часть этого урока Maya.

    Рис.2: Частично свернутое иерархическое дерево сцены Maya.
  • Для экспорта из Maya вам понадобится специальная родительская группа под названием <asset_name>_helper (См. Рис2 выше).
  • Геометрии деформации объединенной сетки должны соответствовать следующему соглашению об именах: "гибкий##" (## — это бегущие числа).
  • Цвет вершины (зеленый) используется для описания того, насколько ваши вершины затронуты расчетами деформации объединенной сетки.
  • Сохраняйте топологию ткани неравномерной, а не равномерно расположенной четырехугольниками, чтобы избежать быстрого урегулирования.
  • Пользовательские свойства необходимо настроить, чтобы движок распознавал сетку как ткань (см. таблицу UDP ниже).
  • SPU будет вычислять узлы одновременно в нескольких потоках. Для обеспечения дружелюбия с SPU можно использовать до десяти узлов на каждый объект.
  • Не используйте слишком много разных идентификаторов материалов для узлов ткани вашего объекта. Узлы ткани объединяются в один большой объект в движке, тогда как каждый материал ID получает свой собственный объединенный объект. Поэтому старайтесь иметь как можно меньше предметов из одной ткани.
  • Хотя бы одна вершина окрашена черный (RGB = 0 0 0) должен быть в каждом узле геометрии ткани/листа, чтобы предотвратить отделение деформирующих частей объединенной сетки от ветвей. Если вы видите сильно растянутые полигоны поверх объединенной сетки, деформирующей объекты растительности, значит, вы пропустили закрашивание некоторых вершин черным цветом.

Геометрия

Чтобы напомнить вам о важных аспектах создания объединенная деформация сетки растительность для CRYENGINE:

Ключ к объединенная деформация сетки из Maya экспортированы следующие элементы:

  • Иерархия экспорта настроена правильно. См. Рис.1 и Рис.2 в начале этого урока.
  • Узлы деформируемой группы должны быть названы гибкий##_group, например, bendable01_group или bendable02_groupи т. д. Имена фактического узла полисетки, который должен оставаться дочерним по отношению к сгибаемым группам, могут выбираться свободно.
  • UDP для объединенной деформации сетки установлены для гибкий##_group узлы.
  • Примените окраску вершин, по крайней мере, одну вершину, окрашенную в черный цвет, для каждой части полисетки, чтобы она оставалась на месте.
  • 3ds Max и Maya требуют другого подхода для настройки рабочего экспортируемого файла. объединенная деформация сетки актив.

Нашей геометрией для этого урока будет ива. Благодаря своим свисающим листьям этот тип дерева идеально подходит для демонстрации тканевой физики на объекте static. Чтобы эта функция работала, нам нужно смоделировать следующую геометрию:

  • Статический ствол ивы
  • Деформируемые кусочки листовой полисетки
  • Прокси-сетка столкновений

И поместите три верхних типа геометрии в правильно настроенную иерархию экспорта.

    б: Если да, вы увидите макет UV и выберите UV в редакторе UV. Щелкните правой кнопкой мыши и перетащите UV вправо, чтобы перейти в режим выбора UV.
  5. Нажмите и перетащите прямоугольник, чтобы выбрать все UV.

    Рис.16: Режим выбора UV
  6. Теперь иди в UV Редактор меню: Полигоны->Копировать UV в UV Set->map1 чтобы скопировать и вставить выбранные UV-развертки по умолчанию карта1 UV установлен.

    Рис.17: Копирование и вставка UV-разверток.
  7. Повторите шаги со 2 по 5 для остальных непустых наборов UV. Удалите скопированные или пустые наборы UV с помощью UV Редактор наборов (если таковые остались).
    Этот процесс довольно раздражает и должен выполняться с помощью сценария. Возможно, вы можете попросить своего технического художника выполнить эту задачу.

Листья нужно разбросать по веткам ствола дерева. Вы можете комбинировать геометрии (не забудьте удалить историю) или просто объединить их в сгибаемую группу. Но не переусердствуйте с использованием узлов группы сгибаемых элементов. Максимум десяти должно быть достаточно, и вы не получите снижения производительности из-за узкого места SPU.

Дальнейшие ловушки

  • Избегайте неуникальных имен в Maya.
  • Несколько наборов UV: скопируйте и вставьте все UV в один набор UV (по умолчанию). карта1) и удалите остальные наборы UV.
  • Проверьте иерархию экспорта и ее именование.
  • Назовите узел группы в честь cryExportNode_<CE_ASSET_FILE> как <YOUR_ASSET_NAME>_helper, поскольку нам нужно добавить более одного узла группы.
  • Избегайте давать одно и то же имя <PREFIX>_helper узел и любой <PREFIX>_group узел вашей экспортной иерархии, например willow_tree_helper и willow_tree_group.
