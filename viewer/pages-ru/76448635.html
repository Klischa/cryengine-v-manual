Обзор

Абстракция Rich Presence пытается унифицировать функциональность представления статуса локальных пользователей другим клиентам на платформе.

Реализация и соответствующие параметры Rich Presence различаются на каждой платформе с точки зрения того, какие и как данные отображаются другим клиентам. По этой причине в настоящее время только Discord имеет полную функциональность Rich Presence, поскольку он предоставляет больше всего возможностей. Другие платформы будут использовать интерфейс статуса (или заголовков данных) для предоставления базовой информации о присутствии.

Богатые функции службы присутствия

GetRichPresence

Получает подробные данные о присутствии локального пользователя на указанной платформе.

SetRichPresence

Устанавливает расширенные данные о присутствии для локального пользователя на указанной платформе.

SetStatus

Устанавливает строку состояния для локального пользователя на указанной платформе.

  • Строка статуса — это отображаемый текст, который показывает, что пользователь в данный момент делает в игре. Например, игра на определенной карте и т. д. На каждой платформе это реализуется по-разному.
  • Чтобы получить статус, используйте GetRichPresence и прочитайте вывод «заголовок».
  • На большинстве, если не на всех платформах, установка строки состояния для локального пользователя не происходит мгновенно, и другим пользователям на платформе требуется до 3 минут, чтобы она стала видимой.
  • Слишком частое выполнение этого приведет к тому, что некоторые вызовы будут игнорироваться. Как правило, выполняйте эту функцию не чаще, чем каждые 3 минуты по мере необходимости. Если текст, который вы хотите отобразить, не изменился, нет необходимости задавать его снова.
