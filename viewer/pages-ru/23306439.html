Обзор

CFacialEffector

Эффектор (также известный как выражение) представляет собой действие, которое может выполнить лицо — это может быть простая цель морфинга, вращение кости или сочетание более простых выражений.

Выражения могут применяться в различной степени, от -1 до 1. Значение 1 указывает, что выражение применяется полностью (Пример: в случае целевого выражения морфинга морф полностью применяется к сетке). Значение 0 указывает, что выражение отключено. -1 означает, что применяется противоположное выражение (цель морфинга вычитается из модели).

В случае составных выражений объект CFacialEffCtrl сопоставляет входное значение со значением, которое должно быть передано каждому дочернему выражению.

CFacialEffCtrl

Этот класс используется составными экземплярами CFacialEffector для управления субэффектором. Он отвечает за получение входного значения и вычисление значения для передачи дочернему элементу управления. Этим расчетом можно управлять либо с помощью линейного отображения, либо с помощью сплайна.

CFacialEffectorsLibrary

Этот класс представляет библиотеку лицевых эффекторов (или выражений). Обычно это читается из файла *.FXL. Каждая модель обращается к определенной библиотеке выражений, которую она использует для отображения текущего состояния последовательностей анимации.

Лицевая анимация предназначена для работы с любой библиотекой выражений. Это означает, что должна быть возможность настраивать выражения для конкретного персонажа и использовать для него лицевую анимацию, даже если они были созданы с использованием другого персонажа/библиотеки.

CFacialModel

Этот класс хранит информацию, относящуюся к конкретной модели, используемой в лицевой анимации. Каждая модель персонажа, содержащая морфы, также создает принадлежащий ей экземпляр CFacialModel. Этот класс используется системой лицевой анимации для получения информации о том, какие морфы содержит персонаж.

Это также класс, ответственный за окончательные расчеты того, какие морфы должны отображаться (см. CFaceState), и применение их к экземпляру персонажа. Это реализовано в методе ApplyFaceStateToCharacter().

CFacialInstance

Это класс, который чаще всего используется в коде игры. Это позволяет клиентскому коду управлять лицевой анимацией одного персонажа. В частности, методы PlaySequence() и StopSequence() позволяют запускать и останавливать последовательности лицевой анимации.

Внутренне CFacialInstance делегирует большинство аспектов воспроизведения последовательностей CFacialAnimationContext, который содержит список воспроизводимых в данный момент последовательностей. В существующей реализации CFacialInstance фактически запускает только один экземпляр последовательности в CFacialAnimationContext.

Интерфейс воспроизведения последовательности CFacialInstance содержит несколько слоев последовательности. Каждый слой может воспроизводить одну последовательность или быть неактивным. Каждый слой имеет свой приоритет, и только слой с наивысшим приоритетом с активной последовательностью фактически передается в CFacialAnimationContext для отображения на персонаже.

Различные уровни в системе анимации предназначены для отражения различных целей, для которых часто используется система анимации. Например, существует слой, зарезервированный для анимации, воспроизводимой через граф анимации (список доступных слоев см. в перечислении EFacialSequenceLayer). Хотя это имеет тот недостаток, что оно кодирует знания о системах более высокого уровня в коде анимации лица, это упрощает использование системы и позволяет множеству клиентских систем управлять одновременно воспроизводимыми последовательностями в коде анимации лица.

Обновление экземпляра лица состоит из двух частей. UpdatePlayingSequences() — это метод, который увеличивает время воспроизводимых в данный момент последовательностей и деактивирует их, если они закончились. Это следует вызывать в каждом кадре, даже если символ не виден. Этот метод делает две основные вещи: во-первых, он вызывает UpdatePlayingSequences() для экземпляра контекста, чтобы обновить состояние воспроизводимой в данный момент последовательности. Затем он обновляет все слои экземпляра и гарантирует, что анимация с наивысшим приоритетом воспроизводится в CFacialAnimationContext.

Update() — это метод, который оценивает текущее состояние воспроизводимых последовательностей и применяет воспроизводимые выражения к модели персонажа. Для этого он использует экземпляр CFaceState для представления желаемого состояния лица. Он передает этот экземпляр в CFacialAnimationContext, который оценивает все сплайны в последовательности в текущий момент времени и сохраняет нужные значения в состоянии грани.

Состояние лица затем передается модели лица, которая применяет все желаемые выражения к модели персонажа. Обычно это включает в себя рекурсивную оценку составных выражений до тех пор, пока не будут достигнуты основные цели морфинга и повороты костей.

CFacialAnimation

Этот класс является основным классом менеджера системы лицевой анимации. Существует единственный экземпляр, созданный как часть класса CharacterManager, поэтому он доступен глобально через экземпляр ISystem.

Его основные обязанности — предоставление методов создания и сериализации библиотек выражений и последовательностей. Кэширование также выполняется объектом. Он также управляет наборами джойстиков, хотя они используются только в редакторе.

Обратите внимание, что этот объект не управляет экземплярами лиц — они управляются экземпляром персонажа, который они представляют.

CFacialSentence

Этот класс принадлежит CFacialAnimSequence и представляет набор фонем, которые определяют синхронизацию губ для данного звука. По сути, он содержит набор фонем и время их начала и окончания.

Во время выполнения CFacialAnimSequence::Update() этому классу передается CFaceState, а затем он добавляет выражения к состоянию лица для отображения текущей синхронизации губ. Обычно он добавляет два выражения — одно для фонемы, которая в данный момент активна, и одно для следующей, выполняя плавное плавное затухание между ними. Эти выражения затем применяются к модели лица вместе с выражениями из остальных сплайнов последовательности.

CFacialAnimChannel

Этот класс представляет одно из анимированных выражений в последовательности. Последовательность содержит набор каналов, каждый из которых описывает, как данное выражение изменяется с течением времени, с помощью сплайна.

CFacialAnimSequence

Этот класс представляет последовательность лицевой анимации. Обычно этот класс сериализуется в файле *.FSQ, но экземпляром CFacialAnimation также могут быть созданы пустые. Он содержит набор CFacialAnimChannels и набор звуковых записей, каждая из которых может содержать CFacialSentence.

Метод Animate() отвечает за оценку всех частей последовательности и обновление экземпляра CFaceState для их представления. Этот метод сначала перебирает все каналы последовательности и вычисляет текущее значение сплайна. Затем он добавляет связанное выражение к состоянию лица с этим значением. Оставшийся шаг — пройтись по всем экземплярам CFacialSentence и вызвать для них Animate().

CFaceState

Этот класс используется для обозначения желаемого состояния модели лица. Он используется для хранения состояния, которое рассчитывается CFacialAnimationContext, а затем считывается CFacialModel и применяется к сетке.

Объект содержит список лицевых эффекторов. Каждое из них должно быть простым выражением — любые составные выражения, которые необходимо применить, сначала разбиваются на целевые объекты морфинга или выражения вращения костей.

CFacialAnimationContext

Этот класс не является частью внешнего интерфейса системы. Он используется внутри CFacialInstance для управления воспроизведением последовательностей.

Член Update() отвечает за вычисление желаемого состояния лица на основе всех воспроизводимых последовательностей в текущий момент времени. Он работает, сначала вызывая Animate() для всех текущих последовательностей, чтобы выяснить, какие выражения и с какой интенсивностью следует воспроизводить. Затем он рекурсивно разбивает сложные выражения на подвыражения на основе кривых в экземплярах CFacialEffCtrl, связанных с каждым подвыражением.

UpdatePlayingSequences() отвечает за обновление времени воспроизводимых в данный момент последовательностей. Он просто добавляет разницу во времени к текущему времени каждой воспроизводимой последовательности, а затем удаляет из списка все завершенные последовательности.
