Обзор

CVars, используемые реализацией ADX2 CRYENGINE, описаны ниже.

CVars

s_Adx2CuePoolSize

  • Устанавливает количество предварительно выделенных экземпляров вызова.
  • Использование: s_Adx2CuePoolSize [0/...]
  • Значения по умолчанию:
    PC: 256 | XboxOne: 256 | PS4: 256 |Мак: 256 | Линукс: 256 | iOS: 256 | Андроид: 256

s_Adx2MaxVirtualVoices

  • Указывает максимальное количество голосов, для которых голосовое управление выполняется одновременно.
  • Использование: s_Adx2MaxVirtualVoices [0/...]
  • Значения по умолчанию:
    PC: 16

s_AdxMaxVoiceLimitGroups

  • Указывает максимальное количество групп ограничения голоса, которые можно создать.
  • Использование: s_AdxMaxVoiceLimitGroups [0/...]
  • Значения по умолчанию:
    PC: 16

s_Adx2MaxCategories

  • Указывает максимальное количество категорий, которые можно создать.
  • Использование: s_Adx2MaxCategories [0/...]
  • Значения по умолчанию
    PC: 16

s_Adx2CategoriesPerPlayback

  • Указывает количество категорий, на которые можно ссылаться при воспроизведении.
  • Использование: s_Adx2CategoriesPerPlayback [0/...]
  • Значения по умолчанию:
    PC: 4

s_Adx2MaxTracks

  • Указывает общее количество дорожек в последовательности, которые могут воспроизводиться одновременно.
  • Использование: s_Adx2MaxTracks [0/...]
  • Значения по умолчанию:
    PC: 32

s_Adx2MaxFaders

  • Определяет максимальное количество фейдеров, используемых в библиотеке Atom.
  • Использование: s_Adx2MaxFaders [0/...]
  • Значения по умолчанию:
    PC: 4

s_Adx2NumVoices

  • Определяет количество голосов.
  • Использование: s_Adx2NumVoices [0/...]
  • Значения по умолчанию:
    PC: 8

s_Adx2MaxChannels

  • Указывает максимальное количество каналов, которые может обрабатывать DSP.
  • Использование: s_Adx2MaxChannels [0/...]
  • Значения по умолчанию:
    PC: 2

s_Adx2MaxSamplingRate

  • Указывает максимальную частоту дискретизации, которую может обрабатывать DSP.\
  • Использование: s_Adx2MaxSamplingRate [0/...]\п
  • Значения по умолчанию:
    PC: 48000

s_Adx2NumBuses

  • Указывает количество автобусов.
  • Использование: s_Adx2NumBuses [0/...]
  • Значения по умолчанию:
    PC: 8

s_Adx2OutputChannels

  • Определяет количество выходных каналов.
  • Использование: s_Adx2OutputChannels [0/...]
  • Значения по умолчанию:
    PC: 6

s_Adx2OutputSamplingRate

  • Определяет частоту дискретизации.
  • Использование: s_Adx2OutputSamplingRate [0/...]
  • Значения по умолчанию:
    PC: 48000

s_Adx2MaxStreams

  • Указывает мгновенное максимальное количество потоковой передачи.
  • Использование: s_Adx2MaxStreams [0/...]
  • Значения по умолчанию:
    PC: 8

s_Adx2MaxFiles

  • Указывает максимальное количество файлов, открываемых одновременно.
  • Использование: s_Adx2MaxFiles [0/...]
  • Значения по умолчанию:
    PC: 32

s_Adx2VoiceAllocationMethod

  • Указывает метод, используемый, когда игрок AtomEx распределяет голоса.
  • Использование: s_Adx2VoiceAllocationMethod [0/1]
    0: Распределение голоса выполняется один раз.
    1: Распределение голоса выполняется столько раз, сколько необходимо.
  • Значения по умолчанию:
    PC: 0

s_Adx2MaxPitch

  • Определяет верхний предел изменения высоты звука, применяемого в библиотеке Atom.
  • Использование: s_Adx2MaxPitch [0/...]
  • Значения по умолчанию:
    PC: 2400

s_Adx2VelocityTrackingThreshold

  • Объект должен изменить свою скорость как минимум на эту величину, чтобы выдать сигнал. absolute_velocity запрос обновления параметров аудиосистемы.
  • Использование: s_Adx2VelocityTrackingThreshold [0/...]
  • Значения по умолчанию:
    PC: 0,1 (10 см/с)

s_Adx2PositionUpdateThresholdMultiplier

  • Расстояние объекта до слушателя умножается на это значение, чтобы определить порог обновления положения.
  • Использование: s_Adx2PositionUpdateThresholdMultiplier [0/...]
  • Значения по умолчанию:
    PC: 0,02

s_Adx2MaxVelocity

  • Максимальная скорость, которая будет нормализована до 1,0 элемента управления AISCA. absolute_velocity.
  • Например, если для этого значения установлено значение 100, а скорость объекта равна 20, соответствующее значение элемента AISAC-Control будет равно 0,2.
  • Использование: s_Adx2MaxVelocity [0/...]
  • Значения по умолчанию:
    PC: 100

s_Adx2DebugListFilter

  • Определяет, какие списки отображать, когда фильтрация списков включена в отладочной схеме аудиосистемы.

Эта CVar работает только в профилях и отладочных сборках.

  • Использование: s_Adx2DebugListFilter [0ab...] (флаги можно комбинировать)
     0: Ничего не рисовать.
    a: Нарисуйте экземпляры реплик.
    б: Нарисуйте значения GameVariable.
    c: Нарисовать значения категорий.
  • Значения по умолчанию:
    PC: abc
