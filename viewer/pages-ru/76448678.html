Требования

  • Винда 10 х64.

  • Раздор.
  • Действующее игровое приложение (с действительным идентификатором приложения), разработанное через портал разработчиков Discord.
  • Хотя Windows 11 x64 может работать, официально она не поддерживается.

  • Обязательно скопируйте discord_game_sdk.dll из игры Discord SDK в папку двоичного вывода вашего проекта CRYENGINE (по умолчанию: мусорное ведро/win_x64 для сборок профиля). Поскольку плагин Discord CryGamePlatform динамически ссылается на этот DLL, этот DLL должен находиться где-то, где приложение сможет его найти (например, в двоичной папке).

  • По умолчанию discord_game_sdk.dll файл можно найти в папке Код/SDK/discord-game-sdk/lib/x86_64/ папка вашего проекта CRYENGINE.

Настройка конфигурации

По умолчанию реализация Discord не загружается, если вы запускаете проект через редактор Sandbox. Чтобы включить реализацию в редакторе Sandbox:

  • Установите discord_editor_support CVar для 1.
  • Объявить discord_appid, идентификатор вашего игрового приложения, созданного через портал разработчиков Discord.

Их можно поместить в один из файлов .cfg по умолчанию (system.cfg, game.cfg или user.cfg) или встроен в ваш .cryproject файл.

Пример

Вот пример CVar и идентификатора приложения, объявленных в проекте шаблона First Shooter:

  "console_commands": { },
  "console_variables": {
    "cl_DefaultNearPlane": "0.05",
    "sys_target_platforms": "pc,ps4,xboxone,linux",
        "discord_appid": "931611096516476130",
        "discord_editor_support": "1"
  }

Дополнительную информацию о настройке собственного приложения Discord для использования с игрой см. Документация портала разработчиков Discord.
