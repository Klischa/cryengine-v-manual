Обзор

В этом уроке мы рассмотрим процесс создания бьющихся стеклянных панелей с помощью 3ds Max. Мы рассмотрим настройку материала ID для различных типов стекла, а также необходимые шаги по настройке вашей сцены, чтобы успешно экспортировать ваш ресурс для CRYENGINE и получить желаемый результат. Разрушаемость актива зависит от типов поверхности, которые мы назначаем в CRYENGINE.



Рис1: Внутриигровой снимок разбитых стекол, полученный с помощью технологии Breakable Glass.

Речь идет о шейдере Breakable Glass Shader, который используется для создания динамичного и физически точного разрушения стеклянных объектов при сохранении низких затрат на производительность.

Предварительные требования для этого урока

Прежде чем продолжить изучение этого руководства, убедитесь, что вы прочитали и поняли следующее;

  • Установка инструментов 3ds Max
  • Базовая настройка и экспорт активов — 3ds Max
  • CRYENGINE Экспортер в 3ds Max
  • Справочник по измерениям — (настройка единиц измерения DCC)

Полезная информация

Чтобы избежать каких-либо проблем, необходимо учитывать несколько ограничений:

  • Бьющимся стеклянным панелям нужна толщина, причем не просто в виде двух многоугольников, обращенных противоположными сторонами, а в виде фактической геометрии толщины. Это также способ контролировать толщину/тонкость вашей стеклянной панели. Пожалуйста, создайте стеклянные панели, используя простые коробки.
  • Кривизна стекла нет поддерживается, поэтому держите панели плоскими. Установите для них небьющееся стекло или измените модель так, чтобы она не включала изогнутое бьющееся стекло.
  • Шейдер берет на себя всю работу по разрушению, поэтому нет необходимости создавать мозаику вашей геометрии. На самом деле рекомендуется сделать это как можно проще.
  • CRYENGINE поддерживает 4 различных типа поверхности бьющегося стекла, которые можно использовать. Просто назначьте уникальный тип поверхности каждому материалу стекла ID, если вы хотите, чтобы ваша модель содержала разные типы стекла. Мы вернемся к этому в части CRYENGINE руководства.
  • Не назначайте материал стекла ID какой-либо другой части вашего актива, которая не должна быть бьющимся стеклом.



Рис.2: Каркас стеклянных панелей внутри 3ds Max.

Первоначальная настройка 3ds Max

Как и в случае с любым другим ресурсом, предназначенным для экспорта в CRYENGINE, нам сначала нужно создать новую папку в структуре папок движка. Здесь вы будете сохранять любые файлы, связанные с вашим активом.

  • <Project Folder>\Assets\Objects\tutorials\breakable_glass\Bus_stop

Поскольку это не урок по моделированию, мы будем использовать уже созданную модель автобусной остановки, поскольку она включает в себя несколько различных вариантов использования шейдера бьющегося стекла. Итак, для начала сохраните файл *.max в новой папке, которую вы только что создали.

Материал

Предполагая, что у вас есть базовое представление о том, как работает редактор материалов 3ds Max, мы теперь настроим материал для нашего актива. Начните с создания нового материала Multi/Sub-Object с 8 подматериалами и назовите их соответствующим образом. В этом примере мы назовем это bus_stop.

Для этого актива у нас есть 8 SubIDs с подробным описанием различных частей актива.

  • 1 x прокси ID (для геометрии коллизий основных структур)
  • 1 х металлический ID (для основной конструкции)
  • 3 разных идентификатора стекла (потому что нам нужны некоторые вариации: «ребристые» верхние и задние бьющиеся стеклянные панели, изогнутые небьющиеся панели, рекламные панели из прозрачного стекла)
  • 1 х обивка сиденья (пластик)
  • 2 текстуры прокрутки (реклама ID: прокрутка текста, прокрутка рекламы)
Несколько стекол SubIDs необходимы, поскольку нам нужно определить разные типы поверхности для каждой из этих стеклянных панелей. А поскольку для каждого SubID можно назначить только один тип поверхности, поэтому мы разделили их.



Рис. 3: Полная настройка материала для актива автобусной остановки с 8 SubIDs.

ID1: Настройка прокси ID (основная физическая геометрия)

Хорошей практикой является использование вашего первого материала ID в качестве прокси-материала физики (он используется для обнаружения попаданий, физики и т. д.). Также стоит отметить, что для работы наших стеклянных панелей не требуется физический прокси (поскольку мы будем физизировать видимую сетку), но мы рассмотрим это позже.

Теперь необходимо изменить несколько настроек, чтобы правильно настроить CRYENGINE:

Для прокси SubID... (это для металлоконструкции остановки):

  1. В разделе «Основные параметры шейдера» выберите Крайтек Шейдер из раскрывающегося меню. (Это стандартная настройка для любого материала, предназначенного для использования в CRYENGINE)
  2. Отметьте Физически вариант.
  3. Во втором раскрывающемся меню выберите Физический прокси (NoDraw)
  4. Для этого материала вы также можете изменить диффузный цвет на ярко-красный и уменьшить непрозрачность до 50, чтобы было легче визуализировать вашу прокси-сетку.



Рис.4: Настройка прокси-сервера ID в 3ds Max

ID2: Настройка рекламного бьющегося стекла ID

Для нашего второго материала ID мы создадим первый материал стекла и назовем его. Стекло. Это рекламные панели сбоку от модели автобусной остановки. Это будут образцы из прозрачного стекла. Это настраивается аналогично прокси-материалу (включающему физику), за исключением того, что мы выбираем По умолчанию во втором раскрывающемся меню.

Для стакана SubID:

  1. В разделе «Основные параметры шейдера» выберите Крайтек Шейдер из раскрывающегося меню.
  2. Отметьте Физически вариант.
  3. Во втором раскрывающемся меню выберите По умолчанию

Вот важный шаг, который контролирует бьющееся стекло. Мы не создаем отдельный прокси для бьющегося стекла,Это физикализация видимой сетки, поскольку нам нужна точная связь 1 к 1 между видимой сеткой и физической системой.



Рис5: Первая установка бьющегося стекла ID (реклама) в 3ds Max

ID3: Настройка основного бьющегося стекла

Для этого конкретного актива нам нужен еще один материал Glass для наших основных стеклянных панелей, и мы будем использовать набор текстур для создания эффекта. Мы создадим это для нашего третьего материала ID и назовем его Glass_Ribbed. Настройка для него идентична Стекло ID2, однако вы можете загружать в него свои текстуры, хотя это можно сделать и позже в редакторе CRYENGINE.

Этот конкретный материал также использует альфа-канал своей диффузной текстуры для создания альфа-проверенных теней.

Для основного бьющегося стекла SubID:

  1. В разделе «Основные параметры шейдера» выберите Крайтек Шейдер из раскрывающегося меню.
  2. Отметьте Физически вариант.
  3. Во втором раскрывающемся меню выберите По умолчанию



Рис.6: Второй материал бьющегося стекла ID (основные панели) в 3ds Max.

ID4,5,6,7: (Стандартная настройка)

Следующий набор SubID представляет собой базовую настройку для стандартных материалов. Во всех них должен быть установлен шейдер Crytek, и в раскрывающемся списке выберите значение по умолчанию. Эти идентификаторы не требуют какой-либо настройки физикализации, поскольку их настройка столкновений будет обрабатываться основным физическим прокси: (SubID 1)

  • ID4 — Обивка сиденья
  • ID5 - Тест прокрутки (расписание автобуса)
  • ID6 — прокручиваемый рекламный щит
  • ID7 - Металл (основная конструкция остановки)



Рис.7: Настройка материала для ID 4,5,6,7 (нефизизированный SubIDs)

ID8: Установка небьющегося стекла

ID8 Последний SubID для этого материала. Это изогнутое стекло, которое мы хотим разместить на передней части автобусной остановки. Установка такая же, как у ID 4,5,6,7, но требует особого упоминания, так как это будет стекло, но небьющееся.

Этот не должен быть физикализировано, поскольку, как упоминалось ранее, мы не можем использовать бьющееся стекло на изогнутых поверхностях!

Экспортируйте материал

Это довольно просто:

  1. Убедитесь, что на самом высоком уровне в редакторе материалов выбран правильный материал.
  2. В экспортере CRYENGINE нажмите кнопку Создать материал кнопка. Сохраните это в ту же папку, где мы сохраним наш актив.
  • <YOUR_PROJECT_FOLDER\Assets\Objects\tutorials\breakable_glass\Bus_stop\bus_stop.mtl
Убедитесь, что имя материала в 3ds Max совпадает с именем файла *.mtl, который вы создаете. В противном случае объект не сможет найти материал в CRYENGINE!



Рис.8: Материал, выбранный на верхнем уровне, готов к экспорту.

Настройка объекта

Переходя к настройке геометрии, необходимо упомянуть несколько особенностей стеклянного объекта:

  • Прежде всего, каждая бьющаяся стеклянная панель должна быть отдельным узлом в 3ds Max.
  • Как упоминалось ранее, эти стеклянные панели не требуют физического прокси, поскольку SubID физический, движок будет использовать сетку рендеринга для создания трещин.
  • Все панели Glass должны быть связаны с экспортом в родительский узел (сетку автобусной остановки), который затем связан с вспомогательным манекеном. Обязательно выровняйте их опорные точки по этому узлу, а также сбросьте XForm, чтобы избежать проблем, связанных с преобразованием.
  • Рекомендуется предусмотреть отверстия для стекла в прокси-сетке вашего актива, чтобы обеспечить точное обнаружение попаданий. (вы хотите ударить по стеклу, а не по прокси-серверу фреймов.
  • Как упоминалось ранее, убедитесь, что каждый из ваших стеклянных объектов представляет собой замкнутую сетку и не содержит ненужной геометрии или тесселяции. (Простая коробка)

Как только мы убедимся, что наш актив соответствует упомянутым выше правилам, мы можем продолжить и логически назвать панели, чтобы было легче устранять неполадки на случай, если что-то пойдет не так.

Также убедитесь, что bus_stop К нашей геометрии применяется мульти/подобъектный материал, стеклянным панелям назначаются правильные ID, и никакая другая часть геометрии, кроме панелей, не использует какой-либо хрупкий стеклянный материал ID.



Рис9: Настройка иерархии

Обратите внимание, что прокси-сервер смещен только для целей предварительного просмотра! Обычно оно должно совпадать с расположением вашей сетки рендеринга.

Настройка прокси

Для основной прокси-сетки (металлическая остановка) см. картинку вышемы разделили сетку на несколько узлов, а не на одну большую сетку. Причина этого в том, что чем проще физический прокси, тем лучше он будет работать (внутри физической системы). Обратите внимание, как он состоит из нескольких простых коробок.

Еще раз убедитесь, что все прокси имеют опорные точки, выровненные по корню. В противном случае ваши прокси будут находиться в разных местах. (Используйте p_draw_helpers= 1 для визуализации физической геометрии в движке).

Все прокси должны быть связаны с родительским объектом (видимой сеткой), который затем связан с вспомогательным манекеном. На рисунке выше показана схема расположения в 3ds Max.

LOD Настройка

Чтобы следовать правилам создания ресурсов для CRYENGINE, мы сделали LOD для автобусной остановки. Это упрощенная модель исходной сетки (LOD 0).
Опять же, LOD должен быть связан с родительским объектом (видимой сеткой), который затем связан с вспомогательным манекеном.

Хорошее эмпирическое правило, которого мы придерживаемся здесь, в Crytek, — уменьшать количество полигонов примерно на 50% для каждого шага LOD.

Экспортируйте геометрию

Теперь мы готовы экспортировать нашу геометрию в движок. В экспортере CRYENGINE:

  1. Добавьте корневой узел актива в список экспорта. В нашем случае это пустышка под названием "Bus_stop".
  2. Выбрать Геометрия (*.cgf) из раскрывающегося списка «Формат экспорта»
  3. Нажмите кнопку Экспорт узлов кнопка

CRYENGINE Настройка

Мы завершили настройку 3ds Max части руководства. Ниже, мы настроим материалы для нашего бьющегося стекла с помощью редактора материалов CRYENGINE. В этой части урока будет рассмотрена настройка материалов стекла внутри CRYENGINE, чтобы они функционировали по назначению. Хотя это простой процесс, его очень важно пройти, иначе бьющееся стекло не получится.

Твот две настройки, которые нам нужно будет изменить, чтобы материалы стекла работали правильно:

Первый — это шейдер, который отвечает за обработку материала средством рендеринга, предоставляя вам доступ к различным параметрам, управляющим внешним видом стеклянных поверхностей в CRYENGINE.

После того, как вы открыли сцену, выберите материал автобусной остановки в Material Editor и измените Шейдер чтобы Стекло для Стекло и Glass_Ribbed суб-ID.

Для Glass_unbreakable sub-ID мы установим Шейдер чтобы Иллюм. Причина в том, что мы стремимся добиться вида толстого непрозрачного стекла, поэтому дополнительные элементы управления, предлагаемые шейдером стекла, не приносят никакой пользы в данном конкретном случае.

Рис. 10: Скриншот отдельных частей материала Glass ID внутри CRYENGINE.

Второй параметр, который необходимо изменить, — это тип поверхности. Это позволит стеклу разбиться, а также нанести соответствующие наклейки при попадании пуль на поверхность, а также на частицы, образовавшиеся в результате удара.

Как упоминалось в предыдущей части урока, необходимо назначить уникальные типы поверхности каждому из наших стеклянных подматериалов, чтобы они правильно работали вместе.

В CRYENGINE доступны следующие типы стеклянных поверхностей:

  • Glass_breakable_safetyglass_large
  • Glass_breakable_safetyglass_small
  • Glass_breakable_thin_large
  • Glass_breakable_thin_small
  • Glass_unbreakable

Разница между _large и _small заключается в количестве деталей, которые могут иметь фрагменты стекла. _small типы поверхностей имеют более высокую тесселяцию и более высокую детализацию в фрагментах, и их следует использовать в местах, где игрок может подойти очень близко к активу, в то время как _large они дешевле и их следует использовать для более удаленных объектов.

Защитное стекло и Тонкий работают аналогичным образом, с той ключевой разницей, что Защитное стекло сохраняет текстуры, нанесенные на материал после разрушения. Это важно для достижения желаемого результата для нашего подматериала Glass_ribbed.

Glass_unbreakable используется в тех случаях, когда нет необходимости или желания разбивать стекло, но все же требуется правильное нанесение ударных наклеек и частиц.

Теперь мы можем продолжить настройку наших материалов с правильными типами поверхности.

Для подгруппы «Стекло» ID (ID 2) измените тип поверхности на Glass_breakable_thin_small.

Теперь выберите Glass_Ribbed (ID 3) и назначьте ему Glass_breakable_safetyglass_small и, наконец, для Glass_unbreakable (ID 8) измените его на Glass_unbreakable.
Рис. 11: Снимок экрана с материалом Glass, настроенным с правильным шейдером и типом поверхности.

Если вы правильно настроили шейдер и тип поверхности, теперь в вашей сцене должны быть полностью разрушаемые стеклянные панели.
