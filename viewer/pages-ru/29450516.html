Обзор

Чтобы создать новую связь между двумя узлами, щелкните любой выходной порт и перетащите его на нужный входной порт. При перемещении узлов ссылка автоматически настраивается.

Чтобы удалить ссылку, щелкните ее правой кнопкой мыши и выберите Удалить. Вы также можете щелкнуть входной порт и перетащить ссылку из порта. Когда ссылка будет перенесена на фоновую панель, она будет удалена.

Контекстное меню ссылки

Каждая ссылка имеет контекстное меню, которое можно открыть, щелкнув правой кнопкой мыши по дескриптору в середине ссылки.

Выделение ссылок

Ссылки на вход и выход выделены, чтобы упростить отладку сложных графиков. Вы также можете навести указатель мыши на порты ввода/вывода, чтобы выделить ссылки. Вы можете просмотреть тип ссылок, подключенных к узлу, по цвету. Когда вы выбираете узел, входные ссылки выделяются красным, а выходные — синим.

Несколько входов на одном порту

Обычно входному порту не может быть назначено несколько ссылок. Вспомогательный узел может действовать как мост для подключения нескольких каналов к входному порту. Например, Логика:Любая узел может взять несколько ссылок и перенаправить их на выходной порт.

Каждый раз, когда входной сигнал поступает на один из входных портов, срабатывает выходной порт. Логика:Любая node также является лучшим способом построения конструкции цикла.
