Отладка многоуровневой очереди перехода

Вы можете включить отладочную информацию на экране, чтобы увидеть, какие анимации поставлены в очередь и воспроизводятся, а также информацию о примененных модификаторах позы и IK. См. Слои анимации для получения дополнительной информации о системе.


Пример вывода.

Показать для каждой сущности

Вы можете отобразить очередь перехода для всех экземпляров персонажей указанного объекта.

es_debuganim <имя объекта> [0 | 1]

Примеры...

es_debuganim чувак 1

Включите отладку для игрока (при условии, что сущность игрока называется «чувак»).

es_debuganim npc_flanker_01 0

Отключите отладку для объекта с именем npc_flanker_01.

Показать по CharacterInstance

Вы можете показать очередь перехода для всех экземпляров персонажей или для тех, которые имеют определенное имя модели.

ca_debugtext [<подстрока-имя-модели> | 1 | 0]

  • Если указано 1, отображаются все экземпляры символов.
  • Если указан 0, текст отладки отключается.
  • Если указана <modelname-substring>, отображается информация для всех экземпляров персонажей, имя модели которых содержит указанную строку.
Примеры...

ca_debugtext игрок

Показать информацию обо всех экземплярах персонажей, в названии модели которых есть слово «игрок».

ca_debugtext 0

Отключите всю информацию о очереди перехода.

Интерпретация вывода

Каждая анимация в очереди перехода отображается в виде пары строк, подобных следующей. Детали описаны ниже.

AnimInAFIFO 02: t:1043 _stand_tac_idle_scar_3p_01 ATime:0,84 (1,17 с/1,40 с) ASpd:1,00 Флаг:00000042 (----------I-K----) TTime:0,20 TWght:1,00 seg:00 inmem:1

(Попробуйте)UseAimIK: 1 AimIKBlend: 1,00 AimIKInfluence: 1,00 (Попробуйте)UseLookIK: 0 LookIKBlend: 0,00 LookIKInfluence: 0,00

MoveSpeed: 4.49 заблокировано: 1

Класс PM: AnimationPoseModifier_OperatorQueue, имя: неизвестно.

...

LayerBlendWeight: 1.00

...

ADIK Bip01 RHand2RiflePos_IKTarget: 0,24 Bip01 RHand2Aim_IKTarget: 1,00 Bip01 LHand2Aim_IKTarget: 0,00

Цвет текста

  • Если анимация еще не активна, она будет черной или зеленой.
  • Когда анимация активна, она имеет красный или желтый цвет.

Или подробно:

  • Красный канал = вес анимации.
  • Зеленый канал = (layerIndex > 0)
  • Альфа-канал = (Вес + 1)*0,5.

AnimInAFIFO Строка (одна на анимацию)

AnimInAFIFO 02: t:1043 _stand_tac_idle_scar_3p_01 ATime:0,84 (1,17 с/1,40 с) ASpd:1,00 Флаг:00000042 (----------I-K----) TTime:0,20 TWght:1,00 seg:00 inmem:1

Прицелиться/Смотри – линия IK

(Попробуйте)UseAimIK: 1 AimIKBlend: 1,00 AimIKInfluence: 1,00 (Попробуйте)UseLookIK: 0 LookIKBlend: 0,00 LookIKInfluence: 0,00

Строки параметров (только для пространств смешивания)

MoveSpeed: 4.500000 заблокировано: 1
TravelAngle: 0.000000 заблокировано: 0

PoseModifier Линии (если работают)

Класс PM: AnimationPoseModifier_OperatorQueue, имя: неизвестно.

Отображает, какие модификаторы позы работают на этом слое. Отображается класс, а также имя (если доступно).

Линия LayerBlendWeight (не на слое 0)

LayerBlendWeight: 1.00

Вес этого слоя (0,00 – 1,00).

ADIK Строки (только если применяется анимация IK)

ADIK Bip01 RHand2RiflePos_IKTarget: 0,24 Bip01 RHand2Aim_IKTarget: 1,00 Bip01 LHand2Aim_IKTarget: 0,00

Отображает список целей IK с анимацией и их текущий вес. Для получения более подробной информации о положении/повороте вы можете использовать отдельный параметр «ca_debugadiktargets 1».

CommandBuffer Отладка

На самом низком уровне система анимации выполняет список простых команд для создания окончательной позы скелета.

Например, это команды «выбрать анимацию x в момент времени t и добавить к позе результат с весом w». Или «очистить позу».


Пример вывода.

Вы можете включить отображение отладочной информации на экране, чтобы увидеть, что помещается в буфер команд (для всех символов), используя следующую команду:

ca_debugcommandbuffer [0 | 1]

Уровень предупреждения

Вы можете контролировать, когда система анимации выдает предупреждения, используя квар ca_animWarningLevel:

ca_animWarningLevel [0 | 1 | 2 | 3]
