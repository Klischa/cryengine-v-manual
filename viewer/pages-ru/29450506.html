Это бета-функция

Эта функция Schematyc все еще находится в стадии бета-тестирования и может постоянно меняться. Мы рекомендуем вам использовать его в тестовых проектах и ​​оставить нам свои отзывы.

Однако, DO NOT используйте его в производстве, где он создает зависимости! Всегда создавайте резервные копии своих проектов, чтобы иметь возможность вернуться к предыдущей версии.

Обзор

В CRYENGINE 5.4 мы добавили предварительную поддержку Schematyc.

Чтобы включить поддержку Schematyc через универсальную систему запросов (UQS), для следующего макроса C++ необходимо установить значение 1:

UQS_SCHEMATYC_SUPPORT

Это можно сделать через CMake, используя следующий OPTION:

OPTION_UQS_SCHEMATYC_SUPPORT

Обязательно перекомпилируйте полный код (все проекты UQS, предоставленные движком, а также код вашей игры), чтобы обеспечить согласованность файлов заголовков, библиотек и DLL.

Существует компонент Schematyc, который позволяет пользователю запускать определенный запрос и обрабатывать полученные элементы после завершения запроса.

Функции

UQS::BeginQuery

Это подготавливает компонент Schematyc к запуску нового запроса.

UQS::AddParam

Добавляет параметр к параметрам времени выполнения запроса. Эта функция доступна в разных версиях для разных типов данных. Если для запроса требуется более одного параметра времени выполнения, эту функцию необходимо связать в цепочку для всех параметров времени выполнения.

UQS::StartQuery

Фактически запускает запрос, который был настроен до сих пор через UQS::BeginQuery и различные UQS::AddParam звонки.

UQS::GetResult

Позволяет получить все результирующие элементы после успешного завершения определенного запроса. Эта функция доступна в разных версиях для разных типов данных. Вам следует использовать функцию с типом данных, который соответствует типу данных элементов, сгенерированных запросом.

Равный

Сравнивает два QueryIDs на равенство.

Сигналы

UQS::QueryFinished

Запускается, когда запрос завершился без каких-либо проблем во время выполнения.

UQS::QueryException

Запускается, когда во время выполнения запроса возникла проблема.

Типы данных

QueryID

Уникальный ID текущего запроса.
