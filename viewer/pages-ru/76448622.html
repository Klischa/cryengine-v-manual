Обзор

Абстракция сети пытается унифицировать основные сетевые функции между различными платформами. Сюда входит отправка и получение файлов между пользователями, маркировка пользователей, находящихся в многопользовательском режиме, а также проверка, вошел ли пользователь в систему и имеет ли доступ к многопользовательским сервисам на платформе.

Поскольку функциональные возможности различаются на разных платформах, для облегчения абстракции требуются некоторые специфичные для платформы функции.

Функции сетевых служб

CloseSession

Закрывает сетевой сеанс, открытый с помощью SendPacket между локальным пользователем и указанной учетной записью.

FilterText

Цензурирует/фильтрует указанный текст на платформе. Вывод ограничен один раз за кадр.

Это полезно для цензуры чата; некоторые платформы требуют цензурировать чаты в зависимости от региона или рейтинга игры.

Выход может не срабатывать в одном и том же кадре.

GetAuthToken

Получает токен авторизации, используемый для веб-служб на указанной платформе.

IsLoggedIn

Проверяет, зарегистрирована ли платформа и доступен ли доступ к бэкэнду.

IsPacketAvailable

Проверяет, доступен ли пакет данных через сеть платформы, и если да, возвращает размер данных.

Эти данные также являются двоичными. Это означает, что если вы читаете данные как строку, вы можете пропустить часть данных (двоичный файл может содержать двоичный ноль, который для строк означает просто конец строки).

ReadPacket

Пытается прочитать полезную нагрузку следующего пакета. Результатом этой функции будет идентификатор исходной учетной записи, прочитанные данные (может быть строкой или двоичным буфером, в зависимости от того, используется ли C++ API/Flow Graph или Schematyc) и количество байтов, прочитанных из пакета.

Весь пакет, возможно, придется прочитать несколько раз, пока общее количество прочитанных байтов не станет равным размеру пакета (полученному с помощью IsPacketAvailable).

SendPacket

Отправляет пакет данных на указанную учетную запись через сеть платформы.

Это функция счетчика ReadPacket; только отправленные пакеты могут быть прочитаны. Один пользователь отправит данные через SendPacket другому, который затем сможет проверить наличие IsPacketAvailable, а затем прочитать данные с помощью ReadPacket.

События сетевых служб

OnCheckMultiplayerAccess

Запускается, когда запрос на проверку многопользовательского доступа получает ответ.

OnGetSteamAuthTicketResponse

Запускается, когда запрос токена аутентификации Steam получает ответ.
