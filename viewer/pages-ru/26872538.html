UI Быстрый старт

В этом кратком руководстве UI мы научимся создавать базового персонажа и применять анимацию.! Изучив эти шаги и выполнив задачу, вы можете перейти к более сложным темам, таким как Blendspaces или Mannequin для функциональности плеера.

UI Обзор

Система UI — это ваш доступ к HUD и меню, которые вы создаете для своей игры. По умолчанию мы используем Scaleform для создания UI и выполняем его через Adobe Flash. В обзоре вы найдете темы о локализации шрифтов и текста для различных регионов, в которых вы будете обслуживать свою игру.

  • Система локализации
  • Локализация текстур
  • TrueType Рендеринг шрифтов
  • UI Динамические текстуры
