← Содержание Справочник по C# API RU

Этот справочник содержит документацию обо всех функциях и свойствах основного проекта C# Framework. Функции в этом проекте обеспечивают доступ высокого уровня к среднему уровню API CryCommon.

Этот справочник по API предназначен только для CRYENGINE C# API. Для получения дополнительной информации о C# API см. Документация Microsoft .NET.
