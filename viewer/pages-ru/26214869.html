Обзор

Этот документ призван помочь пользователям использовать редактор транспортных средств для создания работающих внутриигровых транспортных средств и настройки таких свойств транспортных средств, как движение, эффекты и боеприпасы.

Начиная с файла ресурсов, пользователи могут создавать рабочие внутриигровые транспортные средства без вмешательства в программирование или создание сценариев.

Многие описания элементов можно найти в Scripts/Entities/Vehicles/def_vehicle.xml файл, поэтому обязательно прочтите его для получения дополнительной информации.

Редактирование автомобиля

Выберите любой объект транспортного средства на уровне. Откройте редактор транспортных средств через Вид -> Открыть панель просмотра -> Редактор транспортных средств. В редакторе нажмите Открыть выбранное.

Создание нового автомобиля

Чтобы начать с почти пустого автомобиля, перетащите значок DefaultVehicle на свой уровень. Вы увидите, что он состоит только из объекта-заполнителя по умолчанию.

Во многих случаях может быть быстрее использовать в качестве старта уже существующее транспортное средство, например используйте 4-колесное транспортное средство в качестве основы для создания другого 4-колесного транспортного средства.

Первое использование Транспортное средство -> Сохранить как из строки меню. Выбранное вами имя файла определяет имя класса сущности нового транспортного средства.

Чтобы сделать новый класс объекта доступным, вам следует перезапустить редактор, иначе вы все равно будете работать со старым (существующим) классом транспортных средств.

Компоненты редактора транспортных средств

  • Панель движения содержит все свойства, связанные с движением. Он используется для выбора MovementType и настройки его свойств.
  • Структурная панель показывает древовидное представление структуры транспортного средства. Часто он состоит из основной части (шасси или корпуса) и дополнительных частей, таких как башни и вооружение. Также здесь редактируются компоненты Seats и Damage.
  • Панель эффектов используется для выбора и настройки эффектов частиц. На данный момент сюда входят частицы выхлопа и эффекты урона.

Редактирование параметров движения

Панель «Движение» предлагает поле для выбора типа движения. Каждый тип имеет свой определенный набор свойств. Подсказки дают short объяснение каждого свойства.

Нажмите Сохранить после редактирования переключитесь в игровой режим и протестируйте свой автомобиль.

Некоторые типы движения не будут работать сразу, например типы «StdWheeled» и «Танк», для которых сначала необходимо добавить колеса (см. «Редактирование структуры»).

Редактирование структуры

Панель структуры показывает древовидное представление структуры транспортного средства. Корнем является само транспортное средство.

Детали обозначаются в древовидном представлении небольшими серыми прямоугольниками. Добавить детали к автомобилю или к другим деталям можно с помощью контекстного меню. Обратите внимание, что вам нужно создавать только части для вещей, которые должны иметь определенные способности и, следовательно, свойства для настройки.

Примеры:

  • Турели/Пушки/Навесное оружие
  • Колеса/гусеницы
  • Массовые коробки
  • Фары
  • ...

Деталь всегда перемещается относительно своего родителя. Итак, если вы хотите создать танкоподобную машину, вам сначала нужно прикрепить к машине деталь башни и сделать ее способной вращаться влево/вправо с помощью yawLimits собственность.

Теперь добавьте еще одну часть, на этот раз к башне, назовите ее «пушка» и дайте ей возможность вращаться вверх/вниз с помощью pitchLimits собственность.

Классы деталей

Каждой части присвоен свой класс. Классы деталей используются для обеспечения специальных функций и могут иметь дополнительные свойства. В настоящее время используются следующие классы:

Общие свойства деталей

Мастер колес

Для упрощения настройки общих свойств колеса доступно диалоговое окно Wheel Master.

  • Щелкните правой кнопкой мыши любое из колес, затем выберите «Редактировать мастер колес», чтобы открыть диалоговое окно.
  • Используйте флажки, чтобы выбрать, какие свойства колес вы хотите обновить (сохраняются только активные).
  • Выберите, к каким колесам следует применить новые настройки.
  • Нажмите «Применить к колесам».

Выбор только нужных свойств (и нужных колес) позволяет вам сохранить другие настройки (которые могут различаться для разных колес), которые вы не хотите перезаписывать.

Например, диалоговое окно ниже используется для обновления minFriction и maxFriction колес 1 и 2.

MassBox Редактирование

При желании блоки масс можно использовать для получения симметричного распределения массы (в отличие от распределения, которое в противном случае автоматически рассчитывается в соответствии с сеткой).

Это позволяет легко настраивать центр тяжести и инерцию, что весьма важно, например, для автомобилей. поведение колесных транспортных средств.


Помощники

Помощники — это небольшие объекты, определяющие положение и направление в координатном пространстве транспортного средства (или его части). В древовидном представлении они обозначаются маленькими прямоугольниками с буквой «H».

В главном окне они отображаются в виде маленьких желтых прямоугольников. Они отображаются только в том случае, если на панели деталей установлен флажок «Помощники по транспортным средствам».

Помощники используются везде, где требуется указанное пользователем положение/направление, например. для позиций сиденья и обзора, позиций оружия, расположения эффектов и т. д.

Вы можете добавить помощников к деталям с помощью контекстного меню. Помощники всегда будут двигаться вместе с той частью, к которой они прикреплены.

Сиденья

Древовидное представление также используется для редактирования мест. Сиденье можно установить как в сам автомобиль, так и в одну из его частей. Это полезно, например. сиденья наводчика, которые должны двигаться вместе с башней танка.

Общие свойства седла

  • имя может быть любым по вашему выбору, он используется в основном для идентификации пользователя.
  • isDriver определяет, может ли игрок на этом месте управлять транспортным средством.
  • Вспомогательные поля определяют позиции, которые используются для входа, сидения, просмотра и выхода из места:
    • enterHelper это позиция, которую парни AI попытаются занять, когда захотят занять это место.
    • exitHelper является необязательным и необходим только в том случае, если позиция выхода должна отличаться от позиции входа.
    • sitHelper это место, где размещается модель игрока, когда он сидит на сиденье.
  • просмотры Массив содержит доступные виды, которые игрок имеет на этом месте. По умолчанию есть GhostPit и Третье лицо:
    • Для Призрачная яма вид, позиция просмотра по умолчанию находится на высоте 0,6 м над sitHelper. Если вам нужно изменить это положение (например, для внутренней части резервуаров или для общей настройки), укажите имя помощника в параметрах представления. Камера будет размещена в позиции этого помощника (см., например, «Джип»). canRotate флажок разрешает/запрещает вращение вида.
    • Для Третье лицо вид, можно указать камеру расстояние от автомобиля и опционально heightOffset, при желании. canRotate флажок разрешает/запрещает вращение вида.
  • AimPart это необязательная часть, за которой будет следовать вид с этого места (от 3-го лица). Используется, например. для танковых пушек или станковых орудий. AI использует его для определения направления обзора пассажиров AI.
  • ActionParts — это список частей, на которые будут перенаправлены действия, вводимые пользователем. В настоящее время это необходимо для каждой части, которая должна, например. вращаться, когда пользователь перемещает мышь, или должен получать ввод с клавиатуры с этого сиденья (например, фары хотят получать ключ активации, когда сиденье водителя нажимает его). Вы можете добавить ActionParts, щелкнув правой кнопкой мыши элемент свойства.

Оружие

Оружие добавляется на место с помощью контекстного меню. Пассажир этого места будет оператором оружия. класс Свойство определяет тип оружия и содержит список устанавливаемого на транспортное средство вооружения.

Помощники Массив определяет один или несколько помощников для указания огневой позиции(й). Огневая позиция меняется в списке помощников при каждом последовательном выстреле, что можно использовать для такого оружия, как системы залпового огня.

Вы можете добавить помощников, щелкнув правой кнопкой мыши элемент свойства. Помощники, которые вы здесь указываете, конечно, должны быть прикреплены к соответствующей части, с которой вы хотите, чтобы оружие перемещалось, например. танковая пушка.

В настоящее время поддерживается основное оружие, вторичное появится позже. Вы можете иметь несколько основных видов оружия на одном месте! Оружие будет стрелять последовательно (например, поочередно из левой и правой ракетной установки на вертолете).

Хотя этого эффекта также можно достичь с помощью помощников, некоторые виды оружия позволяют системе повреждений наносить урон (и уничтожать) независимо друг от друга.

Все дальнейшие свойства оружия определяются сущностью Weapon и типом боеприпасов. [Следует: Установка боекомплекта для машины].

Компоненты урона

Компонент повреждения указывается именем, количеством очков урона, которое он может получить, и ограничивающей рамкой, выровненной по оси:

Всякий раз, когда транспортное средство подвергается удару, компонент(ы), ограничивающая рамка(ы) которого включает положение удара, получает повреждение. Когда повреждение компонента приближается к максимальному, может сработать предопределенный DamageBehaviors (например, эффект частиц, звук, изменение обращения или, наконец, взрыв).

Примеры использования:

  • Запустите эффект дыма, когда двигатель поврежден, например. 50%
  • Назначьте низкий порог повреждения топливному баку и инициируйте взрыв автомобиля при его уничтожении.
  • Измените поведение движения при разрушении шины (при условии, что код поддерживает это).
    Работа с компонентами в редакторе аналогична работе с деталями: щелкните правой кнопкой мыши автомобиль в древовидном представлении, чтобы добавить компонент (чтобы увидеть их, убедитесь, что флажок «Компоненты» установлен). Компонент обладает следующими свойствами:
  • имя: можно свободно выбрать для идентификации компонента.
  • damageMax: максимальное количество очков жизни, которое может получить компонент.
  • minBound, maxBound: минимальная и максимальная позиции ограничивающей рамки. Значение 0,0,0 для обеих границ означает, что используется вся ограничивающая рамка транспортного средства.
  • useBoundsFromParts: когда этот параметр активен, bbox компонента рассчитывается из частей, принадлежащих этому компоненту (см. компонент имущество в частях).
  • DamageBehaviors: Произвольное количество DamageBehaviors.
    Когда компонент выбран в древовидном представлении, его ограничивающая рамка отображается в редакторе. По умолчанию используется ограничивающая рамка транспортного средства. Используйте редактор для перемещения и масштабирования bbox. Если вы хотите использовать ограничивающую рамку частей, принадлежащих компоненту (например, для колеса), выберите useBoundsFromParts флаг. (Примечание: в этом случае в настоящее время bbox не отображается, надеюсь, это скоро исправят)

Чтобы что-то произошло при получении компонента повреждения, нужно добавить DamageBehaviors к компоненту. Щелкните правой кнопкой мыши на DamageBehaviors элемент собственности для этого. На данный момент доступны следующие классы DamageBehaviors (wip):

  • Уничтожить: уничтожает транспортное средство (только уничтожение, без дальнейшего эффекта).
  • Эффект: порождает эффект частиц. Указанное здесь имя должно быть доступно в DamageEffects список на панели «Частицы» (см. ниже).
  • Импульс: подает импульс автомобилю. Сумма рандомизирована между forceMin и forceMax.
  • MovementNotification: передает событие повреждения движению, обычно используется с компонентами двигателя. Влияние события повреждения зависит от кода движения. Например, колесные транспортные средства в настоящее время теряют мощность двигателя по мере увеличения повреждений двигателя.
  • Раковина: Изменяет плавучесть, например. заставить лодки тонуть до определенной степени.
    Эти DamageBehavior классы имеют следующие общие свойства:
  • damageRatioMin: минимальный коэффициент урона перед срабатыванием этого поведения (по умолчанию 1, 100% урона).
  • damageRatioMax: максимальный коэффициент урона, до которого срабатывает данное поведение (по умолчанию 0, т.е. нет максимума).

Редактирование эффектов

Частицы выхлопных газов

Это предназначено для создания выхлопов, реактивных турбин и т.п. Помощники Массив используется для указания одного или нескольких помощников, в чьих позициях будет создаваться эффект.

Поддерживаются три эффекта выхлопа:

  • Запуск двигателя.
  • Остановка двигателя.
  • Двигатель работает.

Если на вашем уровне есть сущность ParticleEffect, вы можете щелкнуть правой кнопкой мыши по ней. эффект items, чтобы получить имя эффекта от объекта, не вводя его вручную.

Используйте функцию «Запуск/остановка двигателя», если вы хотите добиться особого эффекта (например, большого плотного облака выхлопных газов) для этих событий.

Эффект EngineRunning обычно будет непрерывным и отображается как long, поскольку текущий статус транспортного средства соответствует ограничениям, заданным параметрами EngineRunning.

Используйте их, чтобы изменить внешний вид в зависимости от текущей скорости и мощности (т. е. нагрузки двигателя). В настоящее время SizeScale и CountScale доступны для динамической настройки, при необходимости можно добавить другие.

Эффекты урона

Здесь вы можете настроить эффекты частиц для использования системой повреждения компонентов. Вы можете добавить эффект, щелкнув правой кнопкой мыши категорию «DamageEffects». Удаление возможно, щелкнув правой кнопкой мыши элемент DamageEffect, который нужно удалить.
