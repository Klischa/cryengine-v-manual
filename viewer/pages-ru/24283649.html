Обзор

Менеджер карт действий предоставляет высокоуровневый интерфейс для управления элементами управления вводом внутри игры. Система карт действий реализована в CryAction и может использоваться непосредственно любым кодом внутри CryAction или GameDLL.

Инициализация

Менеджер карт действий инициализируется во время инициализации CryAction.

Мы упростили процесс инициализации, переместив большую часть кода в сам диспетчер карт действий, поэтому игре достаточно указать путь для defaultProfile.xml (путь по умолчанию — Game/Libs/Config/defaultProfile.xml).

Это можно сделать, просто передав путь менеджеру следующим образом:

IActionMapManager* pActionMapManager = m_pFramework->GetIActionMapManager();
if (pActionMapManager)
{
  pActionMapManager->InitActionMaps(filename);
}

Примечание. При инициализации ActionMapManager очистит все существующие инициализированные карты, фильтры и макеты контроллеров.

ActionMapManager События

Если у вас есть другие системы, которым необходимо знать о событиях карты действий, вы можете подписаться на события ActionMapManager через IActionMapEventListener. На данный момент доступны следующие события:

  • eActionMapManagerEvent_ActionMapsInitialized — ActionMapManager успешно инициализировал заданные определения карты действий.
  • eActionMapManagerEvent_DefaultActionEntityChanged — объект действия по умолчанию изменен (менеджер автоматически назначит новые карты действий этому объекту)
  • eActionMapManagerEvent_FilterStatusChanged – существующий фильтр включен/отключен.
  • eActionMapManagerEvent_ActionMapStatusChanged — существующая карта действий включена/отключена.

Получение действий во время выполнения

Включение/отключение карт действий

Необходимо включить каждую карту действий, поскольку имеется возможность получать действия. Можно включить или отключить отдельную карту действий в любой момент во время выполнения.

Следующий код:

pActionMapMan->EnableActionMap("default", true);
Слушатель

Чтобы получать Действия, необходимо реализовать интерфейс IActionListener в классе.
