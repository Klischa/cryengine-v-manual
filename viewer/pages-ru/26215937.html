Обзор

По сути, это руководство посвящено исправлению импортированной камеры FBX из CRYENGINE Track View. Импортированная камера изначально неправильно наводится по правильным осям. Мы должны исправить это в ходе выполнения этого урока. Наконец, мы также должны сопоставить значение FOV и другие настройки камеры с видом камеры CRYENGINE.

Импортируйте объекты сцены и камеру FBX.

Из предыдущего урока вы экспортировали анимированную камеру и объекты сцены в два отдельных файла FBX.

  1. Запустите 3dsMax с пустой сцены или «Сбросьте», если ваш 3dsMax уже открыт.
  2. Получите объекты сцены FBX, выполнив MAX -> Импорт -> Импорт. Перейдите к файлу FBX с (неанимированными) объектами сцены и нажмите «Открыть» в диалоговом окне «Обзор файлов».

    (img01: объекты сцены FBX импортированы в 3dsMax)

  3. Скомпонуйте объекты сцены CRYENGINE в открытом окне просмотра, чтобы убедиться, что все они правильно импортированы в 3dsMax (кроме ландшафта CRYENGINE, если вы не добавили объект Area на свой уровень).
    Объекты вашей сцены, вероятно, плавают над плоскостью XY. Вы можете добавить объект плоскости 3dsMax в качестве замены ландшафта.

    У танка «Абрамс» после импорта отсутствуют гусеницы. Это связано с тем, что танк «Абрамс» (субстанция «Машина») состоит из двух сущностей: *.CGA (корпус танка) и *.CHR (гусеницы танка).

  4. Теперь нам нужно импортировать анимацию камеры из второго файла FBX. Выполните шаг 2, чтобы импортировать анимацию камеры FBX.

    Обычно ваш файл, экспортированный из Track View редактора Sandbox, содержит "MasterCamera" и любой дополнительный объект камеры, созданный вами в CRYENGINE.

    Вы получите одну камеру с именем «MasterCamera», преобразования которой выглядят неправильно, и вторую. помощник узел с именем «Camera1», который также содержит данные вашей анимации. Мы исправим только трансформацию "MasterCamera". Это основная цель, которую мы должны достичь в ходе изучения этого урока:

    Повторное выравнивание импортированной камеры FBX в 3dsMax в соответствии с камерой CRYENGINE.

Повторно выровняйте импортированную камеру CRYENGINE.

В этом разделе мы добавим Список ротации контроллер с двумя контроллерами Euler_XYZ, один из которых уже содержит импортированную анимацию, а второй добавляет смещение вращения на 90° к "MasterCamera" к его локальным осям.

  1. Выберите камеру с именем «MasteraCamera».
  2. Замените контроллер вращения по умолчанию «Euler_XYZ» на контроллер «Rotation_List». Но не удаляйте старый «Эйлер XYZ», который автоматически включается в «Список ротации». Он содержит импортированную анимацию камеры FBX.

    (img04: Замените стандартный контроллер Эйлера XYZ более универсальным контроллером «Список вращения»)
  3. Добавьте новый «Euler_XYZ» в «Доступный» субконтроллер «Rotation_List».

    (img05: добавьте новый «Эйлер XYZ» в «Список ротации»)
  4. Мы переименовали сгруппированные субконтроллеры вращения, чтобы вы могли лучше понять, для чего нужен контроллер:

    (img06: Завершена настройка контроллера «Список ротации» перед добавлением корректирующего вращения)
  5. Прежде чем смещать вращение камеры, убедитесь, что вашим активным контроллером вращения является контроллер «Offset_Rot».

    (img07: Установите «Offset_Rot» в качестве активного контроллера вращения)
  6. Наконец, мы можем добавить вращение смещения, необходимое для фиксации ориентации «MasterCamera». Пожалуйста, внимательно выполняйте каждый шаг, чтобы избежать ошибок:

    1. Выберите «MasterCamera» в окне просмотра в перспективе, если это еще не сделано.

    2. Переключите инструмент вращения, нажав "Э"ключ

      Обратите внимание, чтобы быть в LOCAL пространство/система координат при добавлении смещения вращения камеры

    4. Теперь мы поворачиваем наш «MasterCamera» на угол 90°, чтобы переориентировать его, пока не получим перспективу камеры, для которой требуется только коррекция в FOV/линзе и разрешении рендеринга. Нам пришлось вращать локальные X и Y с шагом +/- 90°.

      (img09: Исправлена ориентация камеры)

Распространенные ловушки:

  1. Вы переключаетесь на локальную систему координат. BEFORE вы находитесь в инструменте «Поворот» («Э«ключ»).
  2. Помните: 3dsMax хранит информацию о каждом инструменте перемещения/поворота/масштабирования ("Вт", "Э", "Р"ключ) свою собственную систему координат он трансформирует. Таким образом, ваш инструмент перемещения может использовать систему координат экрана, но инструмент вращения находится в системе локальных координат, а инструмент масштабирования преобразуется в систему координат мира.
  3. При выполнении смещения вращения активируйте неправильный субконтроллер вашего «Списка поворотов».
  4. Применить вращение смещения непосредственно к исходным данным анимации -> Не использовался контроллер «Список поворотов» и инкапсулировать исходные данные анимации и корректирующее смещение вращения в отдельные субконтроллеры TWO.
  5. Фиксируется только первый кадр анимации вашей камеры: переместите ползунок времени к последнему кадру и проверьте результаты на глаз! См. iii.

Сопоставление настроек камеры 3dsMax с камерой CRYENGINE

Теперь пришло время настроить "MasterCamera" в 3dsMax, чтобы он соответствовал окну просмотра камеры CRYENGINE. Помните FOV/FPS/Разрешение камеры в редакторе Sandbox, которое мы создали?

  1. У вас должны быть открыты сцены CRYENGINE и 3dsMax. Это значительно упрощает понимание того, какие изменения к чему приводят.

    (изображение 10: Подготовьте CRYENGINE и 3dsMax для работы на двух мониторах. Ниже мы можем видеть готовые и подобранные камеры)

  2. Выбрав «MasterCamera», перейдите на панель изменения 3dsMax, чтобы увидеть параметры камеры, которые мы должны изменить.

    Чтобы правильно установить угол FOV для камеры 3dsMax, вы должны знать, что угол FOV, который вы устанавливаете в CRYENGINE, измеряется. вертикально. Имейте в виду, что вам также необходимо знать выходное разрешение камеры или, по крайней мере, соотношение сторон, чтобы обеспечить правильное соответствие камеры как в CRYENGINE, так и в вашем целевом 3D-приложении (Maya, 3dsMax, Cinema4d, Blender и т. д.).


    (img11: Измените эти настройки камеры 3dsMax)

  3. Нам также необходимо изменить выходное разрешение камеры на то, которое вы установили еще в CRYENGINE: в нашем случае это 640 x 480.

    (img12: рендеринг изображения камеры 3dsMax)
  4. Вам также следует убедиться, что 3dsMax имеет частоту 30 кадров в секунду, поскольку наша анимация в CRYENGINE составляла 240 кадров long. Последняя опция, которую вам следует активировать:
    всякий раз, когда у вас задействована настоящая камера, вам действительно хочется, чтобы кадры камеры совпадали:

    (изображение 13: Safe Frame включено)
  5. С этими настройками камеры ваш результат должен соответствовать тому, что вы создали в CRYENGINE.

    (img14: Готовые и подобранные камеры в 3dsMax и CRYENGINE)

Функция MAXScript для преобразования FOV

Вот функция, которую вы можете использовать для преобразования камеры CRYENGINE FOV в любую FOV, используемую другими 3D-программами:

function ceFn_convertFOV argWidth argHeight argVerticalFOV =
(
  clearListener()
  
  -- convert user input parameters to float values
  fVertFOVAngleDeg = argVerticalFOV as float
  fWidth = argWidth as float
  fHeight = argHeight  as float
  
  aspectRatio = undefined
  fHorFOVAngleDeg = undefined
  iConversionCase = 1
  
  -- FOV conversion calculations
  try
  ( 
    -- calculate aspect ratio by given pixel width and height of the camera resolution
    aspectRatio =  fWidth / fHeight
    format "\nAspect ratio: %\n" aspectRatio
    
    case (iConversionCase) of 
    (
      1: -- case 1: convert vertical to horizontal FOV
      (
        fDistance1 = fHeight / (2.0 * tan(fVertFOVAngleDeg / 2.0))
        format "\nDistance: %\n" fDistance1
        
        res1 = 2.0 * atan (fWidth / (2.0 * fDistance1))
        format "\nconverted horizontal FOV: % \n" res1
          
        fHorFOVAngleDeg = res1
      
        -- case 2: convert horizontal back to vertical FOV for testing the correctness
        fDistance2 = fWidth / (2.0 * tan(fHorFOVAngleDeg / 2.0))
        format "\nDistance: %\n" fDistance2
          
        res2 = 2.0 * ( atan ( fHeight / (2.0 * fDistance2) ))
        format "\nconverted vertical FOV: % \n" res2
      
        -- case 3: convert vertical FOV to diagonal FOV
        fDistance3 = fHeight / (2.0 * tan(fVertFOVAngleDeg / 2.0))
        format "\nDistance: %\n" fDistance3
        
        fDiagonal = sqrt( (pow fWidth 2) + (pow fHeight 2) )
        
        res3 = 2.0 * ( atan (( fDiagonal / (2.0 * fDistance3) )) )
        format "\nconverted diagonal FOV: % " res3
      )
    )
  )
  catch
  (
    messageBox "Exception thrown by ceFn_convertFOV()"
  )
)
-- example function call for a resolution of 640 x 480 pixels and a vertical FOV of 60° as used by CRYENGINE Sandbox Editor
ceFn_convertFOV 640 480 60
