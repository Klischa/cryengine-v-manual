← Содержание EaaS 3.6.15 RU

Выпущено 16 января 2015 г.

Обязательно ознакомьтесь с Руководство по выпуску проектов на основе EaaS (3.6) — DEPRECATED статья, в которой содержится информация о том, как настроить игру EaaS для компиляции в режиме «Релиз».

Редактор

  • Исправлено: маловероятно разыменование нулевого указателя при переключении в игровой режим (CE-5258).

Двигатель

  • Новый: (Сборка) Добавлена конфигурация сборки выпуска для EaaS (которая не идентична «обычной» версии с точки зрения компоновки).
  • Новый: (CrySystem) Позволяет коду игры указывать список загружаемых pak-файлов (вместо жесткого кодирования в CrySystem) для использования EaaS.
  • Исправлено: (RC, CryCommonTools) RC игнорирует файлы, находящиеся внутри подпапки, имя которой начинается с . (точка).

Рендерер

  • Исправлено: не пропускайте отложенную генерацию теней, если еще есть пользовательские или облачные тени, которые нужно отрисовать (CE-5168).
  • Исправлено: перекрытие значений трафарета с помощью каскадного смешивания и пользовательских карт теней.
  • Исправлено: использовать зональное освещение для солнца только тогда, когда включена поддержка зонального освещения. Фиксированные площадные светильники с плиточным затенением.
  • Исправлено: генерация скорости gbuffer при включенной тесселяции (исправляет проблемы с размытием персонажей при движении) (CE-3335).
  • Исправлено: Множитель солнечного блика в стандартном пути затенения (исправляет невозможность настройки солнечного блика в режиме тайлового затенения «2»).

Аудио

  • Новый: Обновлено до версии Wwise 2014.1.2, сборка 5195.
  • Новый: добавлены консольные функции для выполнения/остановки аудио триггеров и установки аудио Rtpcs и переключателей.
  • Новый: добавлено протоколирование ошибок для неудачных запросов к кэшу AFCM, если файл не найден в целевом расположении.
  • Исправлено: (ACB) Самый первый элемент управления Wwise был скрыт от пользователя.
  • Исправлено: (ACB) ACB аварийно завершал работу на указателе управления NULL во время отмены/повтора (CE-4823).
  • Исправлено: Окружения по-прежнему обновлялись на AAA и AAE, даже несмотря на то, что они были отключены (CE-4570/CE-4719).
  • Исправлено: Недействительность аудиообъекта ID на аудиопрокси во время сохранения/загрузки.
