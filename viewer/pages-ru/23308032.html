Фракционализация — это метод, используемый для подготовки хрупких активов.

Фракционирование объектов в 3ds Max

3ds Max поставляется с плагином ProCutter, который очень полезен для создания фрагментов мусора из объекта. После завершения этого руководства пользователи смогут использовать плагин ProCutter для создания фрагментов мусора.

1. Сначала загрузите объект, который вы хотите фракционировать, в 3ds Max.

2. Создайте несколько объектов-резаков. Избегайте объектов, не имеющих объема, поскольку они могут привести к появлению большого количества мусора в сетке. Убедитесь, что объекты резака имеют правильные координаты UV и идентификаторы материалов. Они будут использоваться в кусках мусора. (Вы можете использовать прилагаемый procutter_example.zip.)

3. Выберите первый объект-резак и превратите его в объект ProCutter.

4. Нажмите Выберите объекты резака и выберите оставшиеся объекты-резаки.

5. Выберите Автоматическое извлечение сетки, Разбить по элементами Запас вне резака установите флажки (красные) и нажмите Выберите стандартные объекты (зеленый).

6. Удалите режущий объект. Теперь у вас должен быть один новый объект на каждый кусок мусора. ProCutter автоматически скопирует координаты UV и идентификаторы материалов из объектов-резаков на новые грани в кусках обломков.

Фракционирование объектов в Maya

У Maya нет конкретного инструмента для Pro Cutter, но существуют различные способы достижения аналогичного эффекта. В этом уроке мы обсудим логические операции.

1. Сначала загрузите объект, который вы хотите фракционировать, в Maya.

2. Создайте несколько объектов, которые вы хотите использовать в качестве «формочек для печенья». Убедитесь, что объекты резака имеют правильные координаты UV и идентификаторы материалов. Они будут использоваться в кусках мусора.

3. Выберите первый объект-резак, а затем выберите основную сетку.

4. Затем перейдите к сетке, логическим значениям, затем у вас будет несколько вариантов, но в большинстве случаев вы просто будете использовать пересечение. Скорее всего, вам придется дублировать этот ресурс несколько раз для каждого нового фрагмента, который вы хотите иметь.

5. Теперь у вас должны быть вырезаны нужные детали. Булева операция автоматически скопирует координаты UV и идентификаторы материалов из объектов-резаков на новые грани в кусках обломков. Обратите внимание, что сетка «формочка для печенья» на самом деле сохраняет все, что находится внутри нее.

Также обратите внимание, что это не должен быть конечный продукт, может потребоваться серьезная очистка в зависимости от того, как настроены ваши два ресурса.
