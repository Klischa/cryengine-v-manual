Обзор

CRYENGINE V представляет новую систему частиц, которая была разработана, чтобы предложить дизайнеру большую гибкость и оптимально использовать современные архитектуры CPU и памяти. Для достижения этой цели серверная часть моделирования частиц реализует ориентированный на данные дизайн, в котором структура памяти оптимизирована для векторизованной обработки.

На стороне интерфейса система частиц представляет собой модульную систему. подход к настройке, который позволяет гибко проектировать эффекты частиц, которые можно настроить для взаимодействия с остальной частью движка посредством передачи атрибутов.

Система частиц обеспечивает плавное переключение между конвейером частиц на основе CPU и GPU, где конвейер частиц на основе GPU реализует подмножество функций частиц CPU, предлагая при этом гораздо более высокие скорости для эффектов массивных частиц, таких как эффекты, подобные жидкости, и фрактальное движение.
