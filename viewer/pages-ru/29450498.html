Обзор

Универсальная система запросов (UQS) поддерживает концепцию «управляемых исключений». Они похожи на исключения C++, но ограничены определенными местами и не используют ключевое слово throw языка программирования C++. Как и в C++, исключения в UQS предназначены для того, чтобы программист мог явно выйти из ситуации и уведомить, например, о том, что некоторые параметры запроса имеют неверные значения, с которыми больше нельзя обращаться безопасным способом.

Подробности

Исключения могут возникнуть в:

  • Генераторы
  • InstantEvaluators
  • DeferredEvaluators
  • Функции

Пример

Допустим, у вас есть оценщик, который должен оценить расстояние между двумя баллами. Потенциальной проблемой, от которой нам следует остерегаться, может быть неожиданное деление на ноль:

UQS::Client::IInstantEvaluator::ERunStatus CInstantEvaluator_ScoreDistance::DoRun(const SRunContext& runContext, const SParams& params) const
{
    // guard against potential div-by-zero and other weird behavior
    if (params.distanceThreshold <= 0.0f)
    {
        runContext.error.Format("param 'distanceThreshold' should be > 0.0 (but is: %f)", params.distanceThreshold);
        return uqs::client::IInstantEvaluator::ERunStatus::ExceptionOccurred;
    }

    const float distanceBetweenPoints = (params.pos1 - params.pos2).GetLength();
    runContext.evaluationResult.score = std::min(distanceBetweenPoints, params.distanceThreshold) / params.distanceThreshold;

    return UQS::Client::IInstantEvaluator::ERunStatus::Finished;
}
