Обзор

Сущности окружения можно использовать для придания уровням большего погружения и реализма. Можно использовать такие вещи, как дождь, молния, торнадо, генераторы пульсаций и другие.

Дверная панель / Поставка

В настоящее время существует две оптимизации для флэш-материалов, используемых классом сущностей DoorPanel.

Использование с переключением слоев

Все дверные панели/контейнеры с припасами MUST размещаются внутри своих слоев и автоматически освобождают память при деактивации слоя.

Совместное использование материалов (затраты памяти становятся 1/2 для двух дверных панелей, расположенных по обе стороны двери)

В основном это используется в случае, когда с обеих сторон двери имеются две дверные панели, выполняющие одну и ту же функцию. Вы можете разместить две дверные панели, а затем добавить к дверной панели ссылку на объект, которая будет использовать общий экран первых панелей.

Единственное, что еще нужно сделать, это уведомить о завершении взлома на обеих дверных панелях с другой панели.

Дождь

В CRYENGINE есть два основных метода добиться дождя. Rain Entity был представлен в версии 3.3 и дополнен несколькими новыми функциями в версии 3.5. Преимущество этой сущности заключается в том, что она обрабатывает окклюзию объектов и применяет эффект влажности ко всем затронутым областям мира.

В качестве альтернативы, если вы хотите больше контролировать внешний вид дождя в мире, все равно можно добавить дождь в мир, используя эффект частиц с правильной конфигурацией.

Сущность дождя

Объект «Дождь» находится в папке «Среда» на сводной панели объектов.

Примеры

Эффекты частиц дождя

Перетащите объект ParticleEffect на свой уровень с вкладки «Частицы» DataBase Посмотреть: погода.Дождь.space_loop

Не рекомендуется перетаскивать объект частицы из RollupBar, так как эмиттерам частиц необходимо, чтобы ось Y была направлена вверх. При перетаскивании непосредственно из Particle Editor по умолчанию Y устанавливается вверх.

Настройки функций частиц можно настроить с помощью настроек свойств на вкладке «Частицы» в представлении DataBase.

Отрегулируйте счетчик, время жизни эмиттера, задержку появления и другие свойства, чтобы настроить размер и скорость частиц дождя.

Если вы хотите ограничить дождь определенными областями вашего уровня, просто активируйте эффект частиц с помощью Flow Graph и триггера области, чтобы, когда игрок входит/выходит из области, частица включалась/отключалась.

Встряхнуть

Землетрясения или дрожания экрана активируются с помощью объекта Shake. Перетащите объект встряхивания на свой уровень (сам объект виден только в режиме редактирования).

Сущность Shake включается или отключается с помощью Flow Graph. Просто добавьте объект в график, а затем активируйте/отключите его.

SmartMine

Торнадо

Вы можете добавить Торнадо на свой уровень через сущность Торнадо. Просто перетащите объект Торнадо на уровень.

На панели свойств Торнадо вы можете изменить скорость блуждания, чтобы он двигался быстрее.

Также можно настроить Flow Graph, где вы сможете управлять траекторией торнадо, используя точки тегов и MoveEntityTo узел.

VicinityDependentObjectMover

Эта сущность позволяет просто управлять перемещением объекта в зависимости от того, насколько близко к нему находится игрок.

Это использовалось на уровне обучения Crysis 3 для управления подъемом/опусканием шестиугольных объектов в зависимости от местоположения игрока.

WaterRipplesGenerator

Позволяет создавать рябь на поверхности воды. Это особенно полезно для кат-сцен, когда нефизизированные сущности движутся по водоему.

Сущность WaterRipplesGenerator можно найти в Создать объект → Устаревшие объекты → Среда.

Ограничения
  • WaterRipplesGenerator работает только с WaterVolumes и не работает с поверхностью океана.
  • Это затронет все WaterVolumes ниже и выше WaterRipplesGenerator.
