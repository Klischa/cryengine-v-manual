Обзор

Частицы второго поколения (SecondGen) позволяют отдельным частицам действовать как субизлучатели других компонентов. С помощью этой функции можно добиться множества различных типов эффектов, но наиболее распространенными являются эффекты со следами.

Хотя эта функция называется SecondGen, что подразумевает связь родитель-потомок, на практике количество возможных поколений не ограничено. Также нет ограничений на количество функций SecondGen, которые можно добавить к одному компоненту, или на количество дочерних компонентов, прикрепленных к этим функциям.

В категории SecondGen доступны следующие параметры:

OnCollide

Эта функция будет срабатывать каждый раз, когда родительская частица с чем-либо сталкивается. Может быть активирован несколько раз для каждого родителя и будет действовать до тех пор, пока родитель не умрет.

Дополнительную информацию о параметрах, доступных в этой функции, см. в разделе «Общие настройки» ниже.

OnDeath

Эта функция будет срабатывать каждый раз, когда родительская частица умирает. Это однокадровое событие; это означает, что дочерние частицы будут появляться только в одном цикле обновления.

Дополнительную информацию о параметрах, доступных в этой функции, см. в разделе Общие настройки. раздел ниже.

OnSpawn

Эта функция начнет создавать дочерние эффекты каждый раз, когда создается новая частица. Это постоянное событие; он вызовет порождение дочерних частиц, когда рождается новая родительская частица, и автоматически остановится, когда родительская частица наконец умрет. Фактическая логика создания дочерних элементов выполняется внутри дочернего компонента. См. Спавн функции для получения более подробной информации. Используйте эту функцию для создания таких эффектов, как следы.

Дополнительную информацию о параметрах, доступных в этой функции, см. в разделе «Общие настройки» ниже.

Общие настройки

Все функции SecondGen имеют общее поведение, которое позже можно будет специализировать, но оно по-прежнему основано на каждой отдельной функции.

GPU Поддержка

Частицы GPU могут быть порождены частицами CPU, но не наоборот. Информация о родительских частицах отправляется в GPU и сохраняется в памяти GPU.
