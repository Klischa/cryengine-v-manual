Обзор

C++ API пытается абстрагировать интерфейсы различных реализаций платформы. Это требует наличия нескольких пользовательских типов, позволяющих идентифицировать службу, из которой происходят данные, а также пользовательских событий и классов, которые позволяют взаимодействовать с различными системами службы платформы.

Обзор возможностей и поддержки см. Возможности GamePlatform (Discord/Steam)

GamePlatform Взаимодействие с плагином

  • Плагин GamePlatform является стандартным плагином CRYENGINE, поэтому доступ к нему можно получить через систему CrySystem PluginManager.
  • Чтобы помочь управлять указателем на плагин GamePlatform, чтобы он возвращал nullptr когда плагин выгружается без каждого запроса интерфейса плагина, используйте Плачь::GamePlatform::CPluginHelper Класс template, предоставляемый интерфейсами GamePlatformNodes (CryPlugins/CryGamePlatformNodes/Интерфейс/Утилиты/PluginUtils.h).

Настройка списков проектов CMakelist

Если вы используете собственный проект CRYENGINE, вы можете включить каталог интерфейса, добавив строку в файл вашего проекта. CMakelists.txt файл. Поскольку CMakelists.txt файл регенерируется при создании решения для вашего проекта, в файле есть специальный раздел, который копируется при каждой регенерации файла.

Найдите следующий блок:

#BEGIN-CUSTOM
# Make any custom changes here, modifications outside of the block will be discarded on regeneration.
#END-CUSTOM

И измените его на следующее:

#BEGIN-CUSTOM
# Make any custom changes here, modifications outside of the block will be discarded on regeneration.
target_include_directories(${THIS_PROJECT}
PRIVATE
    "${CRYENGINE_DIR}/Code/CryPlugins/CryGamePlatform/Interface"
    "${CRYENGINE_DIR}/Code/CryPlugins/CryGamePlatformNodes/Interface"
)
#END-CUSTOM

Использование помощника плагина

В следующем примере показано, как использовать GamePlatformPlugin и, по сути, любые другие модули CryPlugin.

// Include CryGamePlatform core module
#include <IGamePlatform.h>

// Include CryGamePlatformNodes module
#include <IPlugin.h>

// Include Plugin Helper
#include <Utils/PluginUtils.h>

void UseGamePlatformCore()
{
  if (auto pGamePlatform = Cry::GamePlatform::CPluginHelper<Cry::GamePlatform::IPlugin>::Get())
  {
    ...
  }
}
void UseGamePlatformNodes()
{
  if (auto pGamePlatformNodes = Cry::GamePlatform::CPluginHelper<Cry::GamePlatform::IPlugin_GamePlatformNodes>::Get())
  {
    ...
  }
}

Идентификаторы услуг

Каждая служба платформы имеет уникальный 128-битный идентификатор.

  • Этот идентификатор создается с использованием стандартных строк ISO GUID (UUID), которые можно сгенерировать либо с помощью Visual Studio, либо с помощью других генераторов GUID, совместимых с ISO.
  • Затем он используется для идентификации службы по этому 128-битному значению и прикрепляется к каждому создаваемому идентификатору службы.

Идентификаторы также позволяют использовать целочисленные или строковые данные, в зависимости от требований платформы, для которой используется идентификатор.

Специфические идентификаторы услуги:

  • AccountIdentifier - Используется для идентификации уникальной учетной записи на конкретной платформе.
  • LobbyIdentifier - Используется для идентификации уникального экземпляра лобби.
  • InventoryItemIdentifier - Используется для идентификации элемента в инвентаре учетной записи.
  • TransactionIdentifier - Используется для идентификации конкретной микротранзакции, совершенной на платформе.
  • LeaderboardIdentifier — используется для идентификации конкретной таблицы лидеров.


Идентификатор Содержание
  • Данные, хранящиеся в каждом идентификаторе, зависят от платформы. Например, AccountIdentifier с платформы Steam будет содержать 64-битную учетную запись Steam ID.
  • Каждый экземпляр идентификатора также содержит сервис GUID, которому он принадлежит.
