Обзор

CRYENGINE предоставляет ссылки и инструменты для различных пакетов создания ресурсов и программ контроля версий. Для упрощения процесса настройки рекомендуется использовать CryToolsInstaller, доступ к которому можно получить через CRYENGINE Launcher во время установки Engine или через пункт меню CRYENGINE Launcher. Библиотека → Мои движки (развернуть меню) Зависимости → Инструменты и плагины.

  • CryToolsInstaller
  • Установка инструментов 3ds Max
  • Установка инструментов Maya
  • Установка плагина CryTIF для Photoshop
  • Установка плагина CryTIF для XNormal
  • Установка плагина Perforce
