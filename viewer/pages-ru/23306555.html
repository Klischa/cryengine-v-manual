Обзор

Игровые объекты фактически являются расширением стандарта. IEntity реализация, позволяющая применять к сущностям более сложную логику и пользовательский код, содержащийся в модулях, отличных от CryEntitySystem и CryAction.

Основные варианты использования игровых объектов:

  • Привязка объекта к сети осуществляется вызовом IGameObject::BindToNetwork.
Объекты, связанные с сетью, могут инициировать Удаленные вызовы методов, или сериализовать биты данных в удаленную версию того же объекта.
  • Создание расширений для более сложных сущностей, примечательными примерами которых являются актеры (актер) и помощник анимированного персонажа (IAnimatedCharacter).

Имейте в виду, что хотя каждый игровой объект должен иметь родительскую сущность, каждому объекту не обязательно должен быть назначен игровой объект.

Детали реализации

CGameObject (известный как IGameObject для проектов, отличных от CryAction) класс реализован как Entity Proxy, расположенный в ENTITY_PROXY_USER слот. Это означает, что указатель игрового объекта можно получить, вызвав IEntity:GetProxy(ENTITY_PROXY_USER) и трансляция на IGameObject. Обратите внимание, что эта логика заключена в IGameFramework::GetGameObject, что позволяет легко получить доступ к игровому объекту сущности, предполагая, что ее идентификатор известен.

Методы создания игрового объекта

Создание новой сущности с помощью игрового объекта

Система игровых объектов поддерживает регистрацию новых расширений игровых объектов с целью автоматического создания игрового объекта с предварительно активированным экземпляром рассматриваемого расширения игрового объекта. Это делается путем вызова IGameObjectSystem::RegisterExtension с pClsDesc параметру присвоено описание класса сущности, который вы хотите создать.

Пример по умолчанию SDK поддерживает это по умолчанию в REGISTER_GAME_OBJECT и REGISTER_GAME_OBJECT_EX помощники препроцессора внутри Игра/GameDll/GameFactory.h.

Создание нового экземпляра игрового объекта для уже созданной сущности

В некоторых случаях может быть нежелательным поведение, когда каждый экземпляр определенного класса сущности автоматически создает игровой объект (например, при создании сущности со стандартным IEntityClass реализация). В этом случае мы можем создать по одному для каждой сущности:

IEntity *pMyEntity = //..
 
IGameObjectSystem *pGameObjectSystem = gEnv->pGame->GetIGameFramework()->GetIGameObjectSystem();
IGameObject *pGameObject = pGameObjectSystem->CreateGameObjectForEntity(pMyEntity->GetId());

Приведенный выше код предоставляет недавно созданный игровой объект, который постоянно прикреплен к объекту и теперь может быть получен через IGameFramework::GetGameObject.

Расширения игровых объектов

Расширения игровых объектов определяются путем наследования от IGameObjectExtension интерфейс и обозначают расширение игрового объекта (и косвенно объекта, с которым он связан) с помощью специального (обычно специфичного для игры) кода.
