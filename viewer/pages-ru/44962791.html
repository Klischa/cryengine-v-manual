Обзор - CRYENGINE 5.5.0 Предварительная версия 4

Мы очень рады представить вам версию 5.5.0 Preview 4. Наша команда разработчиков работала над улучшением предыдущих предварительных версий, выпущенных 20 марта 2018 г., 3 мая 2018 г. и 24 мая 2018 г.

Как всегда, мы приветствуем дальнейшие отзывы и комментарии от сообщества CRYENGINE, но, пожалуйста, не могли бы они приходить через наши обычные каналы, т. е. Репортер по проблемам Github и .

Доступ к версии 5.5.0 Preview 4

Версии движка теперь доступны через панель запуска CRYENGINE.

  1. Войдите в панель запуска CRYENGINE.
  2. Перейти к LIBRARY -> Мои двигатели где перечислены ваши установленные и доступные двигатели. Оттуда двигатели можно обновить (установить).

Гитхаб

Версии Preview Engine также доступны на Github, однако исходный код редактора Sandbox доступен только через Github.

  1. Перейти к: https://github.com/CRYTEK/CRYENGINE/releases/5.5.0_preview4
  2. Скачать CRYENGINE_preview_5.5.0.208_pc.zip
  3. Разархивируйте его куда-нибудь и откройте каталог «CRYENGINE_preview_5.5.0.208_pc».
  4. Дважды щелкните по InstallEngine.bat

  • UI: Окно «График зависимостей» не реагирует при открытии из окна выбора. WORKAROUND: его можно закрыть с панели задач Windows, однако, если у вас не включены отдельные значки для разных окон редактора на панели задач, это может стать проблемой. NOTE: открытие графика зависимостей, например, из браузера активов или из глобального меню. Тинструменты -> Граф зависимостей работает нормально.

  • RENDERER: (EDITOR ONLY) Теневой квадрат, следующий за камерой.
