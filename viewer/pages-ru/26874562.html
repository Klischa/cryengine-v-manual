В настоящее время CRYENGINE позволяет использовать предопределенные шаблоны C#, которые позволяют пользователям легко создавать игровой уровень с нуля. template позволяет вам:

  • Быстро начните игру.
  • Используйте CRYENGINE в качестве тренировочной платформы, где вы сможете опробовать определенные функции, которые можно использовать в ваших играх.

Пустой шаблон

Заготовка template предназначена для тех ситуаций, когда вы хотите начать проект с нуля. Этот template включает в себя только счетчик FPS и базовую настройку CryEnginePlugin который можно использовать в качестве отправной точки для инициализации вашего проекта. Если вы не знакомы с программированием на C# в CRYENGINE, мы рекомендуем вам сначала начать с другого из доступных базовых шаблонов.

См. также: Пустой шаблон C#

Шаблон катящегося шара

The Rolling Ball template — простая игра, в которой вы можете управлять шариком, который катится по уровню. template покажет вам, как это сделать;

  1. Используйте EntityComponent чтобы изменить поведение сущностей в вашей игре.
  2. Как получить ввод от игрока.
  3. Как использовать физику для перемещения объектов.

Если вы не знакомы с программированием на C# в CRYENGINE, рекомендуется сначала взглянуть на template.

См. также: Шаблон C# Rolling Ball

Шаблон шутера от третьего лица

Шутер от третьего лица template предоставляет самые основы игры-стрелялки от третьего лица. template покажет вам, как:

  1. Настройте персонажа игрока, используя EntityComponent.
  2. Анимировать персонажа.
  3. Создавать пули и обнаруживать столкновения.

См. также: Шаблон шутера от третьего лица на C#
