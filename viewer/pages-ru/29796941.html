Обзор

Категория объектов «Другие» содержит объекты, которые не вписываются в существующие категории или используются в нескольких категориях.

CameraShake

Сущность дрожания камеры — это объект, который можно активировать в сценарии, чтобы заставить поле зрения игрока дрожать, когда он находится в сфере влияния объекта.

CameraSource

Объект «Источник камеры» — это опорная позиция, из которой можно смотреть сценарный вид камеры. Точка, на которую указывает камера, определяется в диалоговом окне «Связи объектов».

Нажмите «Выбрать цель», затем выберите объект, на который вы хотите нацелиться, чтобы создать ссылку.

CloneFactory

Основная цель — уменьшить количество неактивных AI на вашем уровне. Вам нужен только один персонаж AI, где-то отключенный и спрятанный на вашем уровне в зоне обзора (не под местностью), который будет использоваться в качестве вашей базы.

С помощью Flowgraph эту базу теперь можно клонировать неограниченное количество раз.

DecalPlacer

Объект Decal Placer будет размещать декали перпендикулярно определенной нормали. Он предназначен для использования в качестве средства динамического размещения декалей через поток-графики и кат-сцены. Его также можно прикрепить к другим объектам.

EntityFlashTag

Сущность EntityFlashTag в настоящее время используется для отображения имени над головами персонажей в многопользовательской игре.

Используется плоская модель .cgf и Флэш-материал применяется к модели, которая затем может отображать имя пользователя игрока.

Вентилятор

Сущность вентилятора используется для имитации потолочного вентилятора. Той же функциональности можно достичь, используя простой блок-граф.

Опасность

Объект опасности наносит урон объектам, входящим в любые области, связанные с ним. Урон, получаемый сущностями, наносится посекундно и может быть настроен в свойствах. Объект опасности используется путем привязки к нему областей, которые вызовут повреждение при входе, аналогично триггеру области.

Кроме того, в свойствах можно задать тип урона, определяющий вид экранного эффекта, который получит игрок при входе в зону опасного объекта. Тип повреждения определяет, какой эффект постобработки будет применен к экрану. Например, если тип урона установлен на «мороз», экран начнет медленно замерзать, пока игрок получает урон. На данный момент существует три типа урона: мороз, огонь и электричество.

Объект опасности настраивается так же, как и триггер области: создайте фигуру области и выберите объект опасности в качестве цели.

InteractiveEntity

Интерактивный объект используется в качестве основы для создания интерактивных объектов в мире. Это пользовательский объект для создания таких вещей, как телевизоры, компьютеры, торговые автоматы и т. д.

Функциональность сущности можно настроить в свойствах с множеством различных опций. Одно из применений сущности — создание частиц, воспроизведение звуковых событий или даже создание новых сущностей.

Лестница

Мой

Сущность мины — это объект, который имитирует поведение взрывной мины. Можно изменить размер взрыва, задержку между триггером и взрывом и различные другие настройки.

MissionObjective

Сущность «Цель миссии» — это объект, который используется для определения положения целей игрока на уровне и текста, связанного с каждой целью.

Объект миссии может ссылаться на другой объект в качестве цели миссии, например, на движущуюся цель, требующую взаимодействия с игроком.

PrecacheCamera

Объект Precache Camera используется системой предварительного кэширования уровней. Сразу после загрузки уровня движок внутренне отрисует уровень, используя положения и ориентации камеры, указанные этими объектами.

Это решение используется для предварительной активации всех ресурсов рендеринга и, таким образом, минимизации задержек во время игры. Предварительное кэширование уровней можно активировать с помощью e_PrecacheLevel переменная.

Твердое тело

DEPRECATED (Используйте RigidBodyEx вместо этого)

Объект Rigid Body — это твердый объект с дополнительными связанными параметрами физического моделирования.

Стрельба по мишени

DEPRECATED

Объект стрельбы — это объект, который можно использовать для создания стрельбища. Он способен подсчитывать попадания и выводить счет.

Звукоподавитель

Звукоглушитель — это объект, используемый системой AI для уменьшения видимой громкости звуков в пределах ее радиуса действия до символов AI, что означает, что эти звуки с меньшей вероятностью будут замечены и на них отреагируют. Используется вместе с Flowgraph.

SpawnPoint

Точка появления в одиночной или многопользовательской игре, определяющая стартовую точку игрока. Если вы не используете SpawnPoint на своем уровне, игрок появится в координатах 0,0,0. Не рекомендуется располагать точки появления на расстоянии ближе 4 метров друг от друга.

Переключатель

Сущность переключателя — это объект с состоянием включения/выключения, используемый для моделирования выключателей света и других переключателей. Он имеет различные порты потокового графа, позволяющие проверять его активность.

UIEntity

UIEntities используются в префабе HUD для создания 3D-элементов HUD. Вы можете указать модель, на которой будет отображаться материал UI.

В случае с HUD эти модели взяты из: GameSDK/Objects/hud/HUD_Plane_x.cgf
