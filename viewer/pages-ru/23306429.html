Обзор

В этом уроке вы узнаете, как изменять существующие и создавать новые CVar (консольные переменные).

Эти переменные можно использовать для управления многими настраиваемыми вариантами поведения в CRYENGINE, а также в вашей игре.

Это руководство предназначено для программистов, большая часть его содержания посвящена коду.

Создание новых CVar

В вашем коде IDE откройте Code\GameSDK\GameDll\GameCVars.h файл, этот файл объявляет все CVar, специфичные для игры.

Найдите SCVars struct и внутри struct объявите новую переменную:

struct SCVars
{ 
  int g_tutorialVar; //add this line
 
  //... pre-existing code ...
};
Вы также можете добавить переменную типа float, если вам нужно хранить дробные числа.

Добавленная вами переменная будет использоваться для хранения текущего значения переменной.

Теперь CVar необходимо зарегистрировать в движке, чтобы его значение можно было изменить через консоль.

Откройте Code\GameSDK\GameDll\GameCVars.cpp файл и найдите InitCVars функция:

void SCVars::InitCVars(IConsole *pConsole)
{
  m_releaseConstants.Init( pConsole );
 
  REGISTER_CVAR(g_tutorialVar, 42, VF_NULL, "This CVar was added using the tutorial on CVars"); //add this line
 
    //... pre-existing code ...
}

В приведенном выше примере мы указываем значение по умолчанию 42 для переменной и добавляем текст справки, который можно будет показать другим пользователям.

Вы можете инициализировать переменную любым значением, допустимым для типа переменной, объявленного в файле заголовка.

Не забудьте также отменить регистрацию переменной при выгрузке игры. В том же файле .cpp найдите ReleaseCVars функция:

void SCVars::ReleaseCVars()
{
  IConsole* pConsole = gEnv->pConsole;
 
  pConsole->UnregisterVariable("g_tutorialVar", true); //add this line
 
  //... pre-existing code ...
}

После того, как вы закончите вносить изменения в код, обязательно скомпилируйте изменения!

Использование CVar

Теперь вы можете написать код, использующий значение CVar.

В вашем игровом коде теперь вы можете получить доступ к значению через g_pGameCVars указатель

int myTutorialVar = g_pGameCVars->g_tutorialVar;

Конечно, поскольку переменная теперь является CVar, вы также можете вызвать консоль и получить доступ к ее значению.

Откройте консоль и введите следующее, чтобы установить значение переменной 1337:

g_tutorialVar = 1337

Также возможно изменить значение CVar с одного из .cfg файлы, чтобы изменить значение по умолчанию.

Всякий раз, когда присваивается значение CVar, предыдущее значение отбрасывается. Таким образом, последнее назначение будет видно.

Поэтому важно знать порядок инициализации CVar. От первого до последнего порядок следующий:

  • Значение, указанное в GameCVars.cpp файл, когда используется REGISTER_CVAR.
  • Значение, указанное в system.cfg.
  • Значение, указанное в пользовательском user.cfg.
  • Любое значение, присвоенное во время выполнения игры.

Чтобы изменить значение по умолчанию существующего CVar без необходимости компиляции, вы можете добавить строку в system.cfg на override по умолчанию.
