CryENGINE 3 бесплатно SDK — журнал изменений сборки 2572

Выпущен 17 октября 2011 года.

  • Добавлена возможность сохранять уровни в проектах для использования с CryDev База данных проектов
  • Добавлена избыточность при выходе из системы для предотвращения ошибок «Учетная запись заблокирована».
  • Добавлена большая гибкость при входе в имя пользователя/пароль, разрешенные символы.
  • Для любого пользователя CryDev добавлена возможность загружать любой уровень в панели запуска.
  • Добавлена поддержка сборки GameDLL с помощью Visual C++ Express.
  • Добавлена возможность игроку менять места в некоторых транспортных средствах.
  • Добавлен поток Time:FrameDelay для задержки действий всего на один кадр.
  • Исправлено несколько сбоев при входе и выходе из системы.
  • Исправлен сбой при создании новых уровней.
  • Исправлен редкий сбой при удалении представления редактора анимационных графиков, а также несколько других исправлений и изменений в редакторе анимационных графиков.
  • Исправлен редкий сбой, если звуковая система отключена.
  • Исправлено несколько предупреждений/проблем, характерных для 64-разрядной версии.
