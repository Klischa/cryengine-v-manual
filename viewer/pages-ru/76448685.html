Требования

  • Винда 10 х64.
  • Пар.
  • Действительная игра разработчика Steam с действительным Steam AppId.
  • Хотя Windows 11 x64 может работать, официально она не поддерживается.

  • Обязательно скопируйте steam_api64.dll из Steamworks SDK в папку двоичного вывода вашего проекта CRYENGINE (по умолчанию: мусорное ведро/win_x64 для сборок профиля). Поскольку плагин Steam CryGamePlatform динамически ссылается на этот DLL, этот DLL должен находиться там, где приложение может его найти (например, в двоичной папке).

  • По умолчанию steam_api64.dll файл можно найти в папке Код/SDK/Steamworks/redistributable_bin/win64 папка вашего проекта.

Настройка конфигурации

По умолчанию реализация Steam не загружается, если вы запускаете проект через редактор Sandbox. Чтобы включить реализацию в редакторе Sandbox:

  • Установите steam_editor_support CVar для 1.
  • Объявить steam_appid — идентификатор вашего игрового приложения, созданного через портал разработчиков Steam.

Их можно поместить в один из файлов .cfg по умолчанию (system.cfg, game.cfg или user.cfg) или встроен в ваш .cryproject файл.

Пример

Вот пример CVar и идентификатора приложения, объявленных в проекте шаблона First Shooter:

  "console_commands": { },
  "console_variables": {
    "cl_DefaultNearPlane": "0.05",
    "sys_target_platforms": "pc,ps4,xboxone,linux",
        "steam_appid": "480",
        "steam_editor_support": "1"
  }

Дополнительную информацию о настройке собственного приложения Steamworks см. Документация разработчика Steamworks.
