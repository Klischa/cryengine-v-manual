Расширенная анимация

Компонент Advanced Animations можно использовать для воспроизведения сложных настроек анимации. Это можно использовать для управления анимацией игрока или NPC в игре.

Перегонная сетка

Компонент Alembic Mesh позволяет вам добавить Геометрические кэши сущности.

Анимированная сетка

Компонент Animated Mesh воспроизводит анимацию для анимированной сетки. Обычно это используется для базовой геометрии с одной простой анимацией, например веером.
