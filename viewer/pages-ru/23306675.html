Обзор

CRYENGINE поддерживается на Убунту 16 64бит Дистрибутив Linux. Другие дистрибутивы Linux, вероятно, также будут работать, однако они не тестируются и не поддерживаются командой разработчиков.

Предварительные условия компиляции

Для компиляции CRYENGINE в Linux необходимо, чтобы в вашей системе были установлены некоторые внешние пакеты. В следующей таблице объясняется, как убедиться, что у вас установлены все пакеты, необходимые для компиляции.

Компиляция

Среду выполнения и код игры CRYENGINE можно скомпилировать для 64-разрядной версии Linux с помощью системы сборки WAF.

Для компиляции вы можете ввести следующую команду в терминале Linux в корневом каталоге:

./cry_waf.sh build_linux_x64_<compiler>_<configuration> --project-spec=<spec>

со следующими заменами

Например, чтобы построить CRYENGINE с проектом GameSDK в конфигурации профиля с GCC введите:

./cry_waf.sh build_linux_x64_gcc_profile --project-spec=gamesdk

Эта команда создаст двоичные файлы проекта во подпапке BinLinux64<compiler> (в данном случае BinLinux64gcc).

Посетите WAF Система сборки для получения дополнительной информации о WAF и дополнительных параметрах.

Предварительные условия для запуска

CRYENGINE не поддерживает графические драйверы с открытым исходным кодом, которые обычно включены по умолчанию в дистрибутивах Linux, поскольку они часто не полностью совместимы с OpenGL.

Убедитесь, что вы установили последнюю версию проприетарных драйверов для вашей видеокарты.
Для Ubuntu вы можете следовать этим руководствам, чтобы установить правильные драйверы поставщика:

  • NVIDIA видеокарты: https://help.ubuntu.com/community/BinaryDriverHowto/Nvidia
  • AMD видеокарты: https://help.ubuntu.com/community/BinaryDriverHowto/AMD

CRYENGINE в Linux также использует среду выполнения библиотеки SDL2.
Команда для его установки в Ubuntu:

sudo apt-get install libsdl2-2.0-0

Трассировки стека и дампы ядра

Трассировки стека будут записаны в имя файла. backtrace.log в текущем рабочем каталоге исполняемого файла.


Чтобы включить дампы ядра, запустите средство запуска со сгенерированным сценарием оболочки Launch_GameSDK.sh в папке bin/linux_x64_<compiler>/.

Известные проблемы

Это известные на данный момент ограничения, характерные для версии CRYENGINE для Linux:

  • Аппаратная тесселяция не поддерживается.
  • Для CRYENGINE требуется как минимум система, совместимая с OpenGL 4.3.
  • Некоторые старые графические драйверы не поддерживаются. По этой причине рекомендуется обновить графический драйвер перед запуском CRYENGINE.
