Версия лаунчера 1.10.0

Бэкэнд

Новое: Версии движка теперь можно загрузить без необходимости предварительного создания проекта. Примечание. В представление «Список движков» был добавлен баннер, который информирует пользователей, когда движок не установлен: «Перед созданием проектов необходимо установить версию движка».

Целевая страница

Новое: На панель запуска панели запуска добавлен баннер, информирующий пользователей о последней версии CRYENGINE, доступной для установки.

Новое: Добавлены ярлыки версий движка на панель запуска — позволяют пользователям создавать проекты быстрее, т. е. без необходимости переходить в «Библиотека» -> «Мои движки» для создания проектов.

Новое: На панель запуска программы добавлена постоянная кнопка «Создать проект» (появляется после завершения установки).
