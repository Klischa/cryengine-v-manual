Обзор:

Иконки:

Иконки создаются в оттенках белого/серого и тонируются при использовании нашего собственного CryIcon. Требуемый формат для всех значков — .ico, и в одном файле должно быть указано несколько разрешений. Все значки встроены в исполняемый файл с помощью файлов ресурсов qt (.qrc). Наш основной файл QRC можно найти по адресу Код/Sandbox/Плагины/EditorCommon/EditorCommon.qrc. При использовании этого файла ресурсов или создании нового выполните следующие действия:

  • Убедитесь, что высший уровень префикс названный "\значки" определяется для всех значков.
  • Любой файл значка в QRC должно иметь свойство псевдонима, которое должно быть эквивалентно пути, но без папки исходного значка.
  • При ссылке на файл в QRC, путь должен выглядеть так: "значки:CategoryFolder/MyIcon.ico" и нет "Иконки/CategoryFolder/MyIcon.ico". Кажется, что оба работают, но первый позволит нашим дизайнерам работать над значками без необходимости создавать исполняемый файл редактора каждый раз, когда они меняют значок.

Для получения дополнительной информации о системе ресурсов Qt см. здесь.

Стиль и цвета:

Стилизация в редакторе достигается с помощью таблиц стилей QSS. Существует один файл, который управляет стилем всего редактора. Его можно найти в Редактор/Стили/stylesheet.qss. Использование QПалитра for style запрещен, так как противоречит использованию таблиц стилей. Цвета палитры определены в QSS и доступны через EditorStyleHelper.

Полный список объектов и свойств, которым можно стилизовать, см. Справочник QSS.
