Обзор

В этом документе описано, как добавлять новые группы данных в Statscope.

Формат журнала является самоописывающим, поэтому инструмент не требует обновления при добавлении новой статистики. Все, что необходимо сделать, это создать реализацию IStatoscopeDataGroup и зарегистрируйте его в CStatscope::RegisterDataGroup().

Базовый пример

Вот пример простейшей группы данных:

struct SFrameLengthDG : public IStatoscopeDataGroup
{
  virtual SDescription GetDescription() const
  {
    return SDescription('f', "frame lengths", "['/' (float frameLengthInMS)]");
  }
  virtual void Write(IStatoscopeFrameRecord& fr)
  {
    fr.AddValue(gEnv->pTimer->GetRealFrameTime() * 1000.0f);
  }
};
...
RegisterDataGroup(new SFrameLengthDG());
...

Его можно включить, добавив «f» к e_StatoscopeDataGroups, «длины кадров» появятся в строке справки e_StatoscopeDataGroups, и каждый кадр будет выводить одно значение float, которое отображается как «/frameLengthInMS» в Обзор древовидное представление в инструменте.

Добавляя новую группу данных, обязательно выбирайте букву, которая еще не используется. Проверьте уже существующие группы в Statoscope.cpp и Статоскоп — Группы данных.

Пример группы данных профилировщиков

Вот группа данных профилировщиков фреймов, которая показывает, как записывать данные о полосах:

struct SFrameProfilersDG : public IStatoscopeDataGroup
{
  virtual SDescription GetDescription() const
  {
    return SDescription('r', "frame profilers", "['/Threads/$' (int count) (float selfTimeInMS)]");
  }
  virtual void Enable()
  {
    IStatoscopeDataGroup::Enable();
    ICVar *pCV_profile = gEnv->pConsole->GetCVar("profile");
    if (pCV_profile)
      pCV_profile->Set(-1);
  }
  virtual void Disable()
  {
    IStatoscopeDataGroup::Disable();
    ICVar *pCV_profile = gEnv->pConsole->GetCVar("profile");
    if (pCV_profile)
      pCV_profile->Set(0);
  }
  virtual void Write(IStatoscopeFrameRecord &fr)
  {
    for (uint32 i=0; i<m_frameProfilerRecords.size(); i++)
    {
      SPerfStatFrameProfilerRecord &fpr = m_frameProfilerRecords[i];
      string fpPath = GetFrameProfilerPath(fpr.m_pProfiler);
      fr.AddValue(fpPath.c_str());
      fr.AddValue(fpr.m_count);
      fr.AddValue(fpr.m_selfTime);
    }
    m_frameProfilerRecords.clear();
  }
  virtual uint32 PrepareToWrite()
  {
    return m_frameProfilerRecords.size();
  }
  std::vector<SPerfStatFrameProfilerRecord> m_frameProfilerRecords;  // the most recent frame's profiler data - filled out externally
};

При такой статистике полос один и тот же формат выводится много раз за кадр, в данном случае считать и selfTimeInMS для каждого именованного профилировщика. Количество элементов, которое необходимо вернуть PrepareToWrite(). Чтобы указать имя каждого элемента, поставьте «$» в соответствующем месте строки формата GetDescription() и первое выходное значение будет использоваться для его замены. В этом примере, если fpPath является "Main/Action/CFlowSystem::Update()", выходные значения будут относиться к "/Threads/Main/Action/CFlowSystem::Update()" и отображаться в иерархии в инструменте.

Значениям может быть присвоен тип float или int и в конечном итоге сохраняются в инструменте как числа с плавающей запятой. Разница с целыми числами заключается только в более аккуратном отображении (т. е. 423, а не 423.0000000).
