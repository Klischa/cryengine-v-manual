После того, как нам удалось правильно скомпилировать наш файл GFx, нам нужно предоставить элемент UI Flow Graph или Schematyc (Experimental), чтобы мы могли связать функциональность игрового процесса с нажатием кнопок.

Это делается путем перехода к существующему пути в Libs папку или создав собственную папку для хранения элементов UI.

  • Имейте в виду, что вы действительно можете объединять группы элементов в категории, как показано по имени в XML ниже.
  • По умолчанию GameSDK поставляется с файлом элемента HUD и меню UI, который инкапсулирует все функции меню в один файл. Это полезно в более сложных сценариях, где вы предоставляете как функции, так и события для расширенных настроек.

Регистрация элемента UI

  1. Создайте файл XML с именем uiQuickStart.xml и поместите его на путь <корень движка>\Game\Libs\UI\UIElements\>.

    uiQuickstart.xml

  2. Ниже вы можете увидеть пример самого простого XML, который необходимо нарисовать, чтобы его можно было увидеть в Flow Graph/Schematyc (экспериментальная версия). По умолчанию в настройки включено несколько атрибутов. Помимо объявления файла, следует учитывать два наиболее важных раздела — это атрибуты слоя и ограничения, которые позволяют вам определить, как отображается контент.

    Слои по умолчанию определяют, в каком порядке отрисовываются элементы, если у вас одновременно работает несколько файлов Flash и вам необходимо их логически отсортировать. Что касается ограничений, они позволяют вам динамически позиционировать объект так, чтобы он соответствовал середине вертикальной оси, горизонтальной оси или того и другого.

    Важно отметить, что вы также можете изменить эти атрибуты позже в Flow Graph/Schematyc (Experimental) и что значения, установленные в этом файле, являются просто отправной точкой для работы.

    <!-- Category name, of your own choosing -->
<UIElements name="uiQuickStart">
  <!-- Object name, again, of your own choosing -->
  <UIElement name="uiQuickStart" render_lockless="1">
    <!-- Point it to the correct files and give it some default settings -->
    <GFx file="uiQuickStart.gfx" layer="0">
      <Constraints>
        <Align mode="dynamic" valign="center" halign="center" scale="0" max="0"/>
      </Constraints>
    </GFx>
  </UIElement>
</UIElements>

Использование элемента UI для визуальных сценариев

Не рекомендуется смешивать подходы Flow Graph и Schematyc (экспериментальный), поскольку совместное использование экземпляров элемента UI может привести к запутанным результатам и проблемам, которые трудно отследить.

Flow Graph

  1. После сохранения перезапустите редактор Sandbox и создайте пустой объект. Щелкните объект правой кнопкой мыши и выберите Создать Flow Graph в открывшемся контекстном меню.

    Создать Flow Graph

  2. Чтобы открыть элемент UI, подключите Игра: Старт узел к UI::Display::Display узел, а затем установите Элемент стоимость недвижимости до uQuickStart показывать при запуске игры.

    UI::Display::Display


    Установите элемент на uiQuickStart


Схема (экспериментальная)

  1. После сохранения перезапустите редактор Sandbox и создайте новый объект схемы через браузер ресурсов в выбранном вами месте. Назовите объект «uiquickstart» и выберите Нет во всплывающем диалоговом окне с вопросом, хотите ли вы использовать другой объект схемы в качестве основы.

    Создайте новый объект схемы


    Нажмите «Нет» во всплывающем диалоговом окне.

  2. Чтобы отобразить элемент UI, добавьте сгенерированный компонент элемента UI в свой объект схемы. Компонент может сохранить сгенерированное по умолчанию имя «FlashElement:uiQuickStart».

    Добавить компонент


    Оставьте имя по умолчанию FlashElement:uiQuickStart.

  3. К графику сигнала добавьте Функции → Компоненты → FlashElement:uiQuickStart → SetVisibility узел.

    Добавьте узел SetVisibility

  4. Подключите Выход контакт узла Start к в закрепить на узле SetVisibility, добавленном на предыдущем шаге; убедитесь, что Видимый проверяется свойство узла SetVisibility.

    Проверьте свойство Visible узла SetVisibility.

  5. Для выполнения графа Schematyc (Экспериментальный) на уровне должен существовать экземпляр объекта. Перетащите объект схемы uiquickstart из шага 1 в любое место в окне просмотра перспективы, чтобы создать его экземпляр.

    Нарисуйте объект схемы uiquickstart в окне просмотра Perspective.

Теперь вы сможете видеть свой UI на экране при входе в игровой режим в редакторе Sandbox.
