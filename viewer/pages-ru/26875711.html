CRYENGINE использует CMake упростить процесс создания движка и проектов на всех платформах, а это означает, что мы не надо используйте проект Visual Studio напрямую. Это означает, что для добавления исходных файлов нам нужно изменить файл CMakeLists.txt файл, содержащийся внутри нашего проекта Код папка.

Добавление исходных файлов в CMake

Глядя на содержимое нашего CMakeLists.txt файле, вы должны увидеть следующий фрагмент:

sources_platform(ALL)
add_sources("Code_uber.cpp"
    PROJECTS Game
    SOURCE_GROUP "Root"
    "GamePlugin.cpp"
    "StdAfx.cpp"
    "GamePlugin.h"
    "StdAfx.h"
)
add_sources("Components_uber.cpp"
    PROJECTS Game
    SOURCE_GROUP "Components"
    "Components/Player.cpp"
    "Components/Player.h"
)

Это то, что сообщает CMake, какие исходные файлы нам следует использовать. В нашем случае мы разделили сборку на две части. Исходные файлы Unity. Исходные файлы Unity эффективно объединяют несколько исходных файлов C++ в один блок, чтобы ускорить время компиляции. Каждый из них обозначается макросом «add_sources» и уникальным именем файла unity.

Каждый файл Unity может содержать любое количество групп, известных как фильтры в Visual Studio. В нашем случае у нас есть «Корень» и «Компоненты». Затем сразу после этого мы объявляем файлы для загрузки в зависимости от того, где CMakeLists.txt есть на диске.

В нашем случае мы можем легко добавить сюда новый исходный файл, в результате чего:

sources_platform(ALL)
add_sources("Code_uber.cpp"
    PROJECTS Game
    SOURCE_GROUP "Root"
    "GamePlugin.cpp"
    "StdAfx.cpp"
    "GamePlugin.h"
    "StdAfx.h"
    "MySourceFile.cpp"
)

Затем он будет включен в нашу сборку, как только мы попытаемся выполнить сборку в Visual Studio.
