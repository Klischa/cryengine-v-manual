Обзор

Взаимодействие с клавиатурой или геймпадом — наиболее важная часть превращения программного обеспечения в игру. Прослушивание изменений состояния клавиши осуществляется путем вставки метода обработчика событий в static. OnKey мероприятие Input класс.

Метод обратного вызова получает аргумент события, который содержит информацию о срабатывании определенной клавиши или кнопки.

Ключевые состояния

В следующем списке показаны несколько состояний, в которых может находиться клавиша или кнопка:

  • KeyPressed: Это событие запускает первый кадр, когда клавиша удерживается нажатой.
  • KeyDown: Это событие генерируется каждый кадр, когда клавиша удерживается нажатой.
  • KeyUp: Это событие срабатывает при отпускании клавиши.
  • KeyChanged: Это событие используется для аналоговых устройств ввода, которые предоставляют значения от 0 до 1. Это событие, например, вызывается при изменении положения мыши.
public virtual void OnAwake()
{
  // Hook on to Key input events.
  Input.OnKey += OnKey;
}

private void OnKey(InputEvent inputEvent)
{
  // Commands which are only allowed when game is currently running and not paused.
  if(State == GameState.Running)
  {
    // Fire primary player weapon.
    if((inputEvent.KeyPressed(KeyId.Space) || inputEvent.KeyPressed(KeyId.XI_A)) && Playership.Entity.Exists)
    {
      Playership.Fire();
    }
  }
}

Управление игроком

Управление игроком осуществляется с помощью функции UpdateSpeed из Player класс. игрока направление движения определяется переменными xVal и yVal, которые инициализируются на основе значений входа аналогового игрового контроллера.

var xVal = Input.GetInputValue(KeyId.XI_ThumbLX);
var yVal = Input.GetInputValue(KeyId.XI_ThumbLY);

Далее значения могут быть установлены на максимальное значение при использовании ввода с клавиатуры или ввода цифрового игрового контроллера.

if (Input.KeyDown(KeyId.Left) || Input.KeyDown(KeyId.XI_DPadLeft))
  xVal = -1f;
if (Input.KeyDown(KeyId.Right) || Input.KeyDown(KeyId.XI_DPadRight))
  xVal = 1f;
if (Input.KeyDown(KeyId.Down) || Input.KeyDown(KeyId.XI_DPadDown))
  yVal = -1f;
if (Input.KeyDown(KeyId.Up) || Input.KeyDown(KeyId.XI_DPadUp))
  yVal = 1f;

На этом этапе значения x и y представляют предполагаемое направление движения. Чтобы создать впечатление инерции, значения умножаются на константу ускорения и в конечном итоге применяются к значениям движения (_forwardSpeed и _upSpeed). Чтобы игрок не вылетел за пределы экрана, скорость игрока ограничивается ClampSpeed прежде чем назначить его обратно Speed переменная. Если позиция находится за пределами заданной границы, значения скорости изменяются, поэтому они всегда будут возвращаться к краю границы.

// In case new position on screen is outside of bounds
ClampSpeed(ref _forwardSpeed, ref _upSpeed);

Speed = new Vector3(0, _forwardSpeed, _upSpeed);

Значения движения сохраняются в Speed переменной и применяются к PhysicsEntity установив Velocity в Move метод DestroyableBase сорт. Для получения дополнительной информации о физической обработке см. главу Физическое взаимодействие.
