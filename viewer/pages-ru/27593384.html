Обзор

Объекты области используются для создания трехмерных зон на уровне, которые можно использовать для запуска событий. Доступ к объектам области через Инструмент «Создать объект».

Коробка

Этот объект позволяет вам создать поле, к которому вы можете связать триггеры и другие объекты, которые должны включаться, когда игрок входит в поле или покидает его.

Твердый

Пожалуйста, ознакомьтесь с AreaSolid документацию для получения дополнительной информации.

Сфера

К AreaSphere вы можете связать триггеры и другие объекты, которые должны включаться, когда игрок входит в сферу или покидает ее.

OccluderArea

Область окклюдера позволяет создавать плоскость окклюзии произвольной формы с несколькими краями, в отличие от объекта «Плоскость окклюдера», который может иметь только квадратную форму.

Цель этого объекта — помешать движку отрисовывать все, что находится за ним. Он используется для оптимизации производительности в областях, где автоматическое закрытие кистей и ландшафта работает не очень хорошо.

OccluderPlane

Плоскость окклюдера можно использовать для перекрытия объектов, находящихся за плоскостью. Как и в случае с областью окклюдера, это обычно не требуется, поскольку окклюзия выполняется автоматически с помощью ресурсов; их можно использовать в качестве запасного метода.

Портал

Пожалуйста, ознакомьтесь с Район Вис и Портал страницы документации для получения дополнительной информации.

Форма

Этот объект позволяет вам создать фигуру, к которой вы можете связать триггеры и другие объекты, которые должны быть включены, когда игрок входит в фигуру области или покидает ее.

Район Вис

Пожалуйста, посмотрите Район Вис и Портал документацию для получения дополнительной информации.

WaterVolume

Пожалуйста, ознакомьтесь с Объем воды статью для получения дополнительной информации.
