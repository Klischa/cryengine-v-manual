Обзор

Sydewinder — это простая игра, созданная на C#, которая показывает, как взаимодействовать с CRYENGINE из C#. Это руководство проведет вас через все необходимые шаги, чтобы начать работу с C# с нуля.

Демо-игра напоминает бесконечный сайд-скроллер со счетчиком рекордов. Космический корабль летит слева направо через космическую станцию, подвергаясь атаке вражеских кораблей. Игра создана в простой форме, ориентирована на реальную миссию и демонстрирует взаимодействие с подсистемами CRYENGINE.

У CRYENGINE есть потенциал для создания совершенно новых миров с помощью редактора Sandbox. Однако игра Sydewinder намеренно фокусируется на разработке игр, основанной на программировании. Вся конструкция уровня, логика и точки появления сущностей управляются исключительно сценарием в модели уровня, ориентированной на игрока. Таким образом, уровень, поставляемый с образцом игры, содержит жестко запрограммированные ссылки и не может быть изменен.

Начало работы

В руководстве описаны различные концепции, используемые в игре Sydewinder, которую можно бесплатно загрузить с сайта CRYENGINE. База данных активов Имейте в виду, что для загрузки любых ресурсов из базы данных активов CRYENGINE вам необходимо иметь учетную запись CRYENGINE и загрузить программу запуска CRYENGINE. Для получения дополнительной информации об этих элементах посетите Cryengine.com.

Каждая глава руководства посвящена различным концепциям разработки игр и основана на частях исходного кода.
