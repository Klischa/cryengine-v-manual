Обзор

Целью этого руководства является объяснение процесса замены персонажа игрока из проекта Isometric Pathfinding Template C++ template на другую анимированную модель.

Обратите внимание, что GameSDK — это NOT, используемый в этом уроке. Он основан на шаблонах, поставляемых с движком, поэтому создать новый проект используя Изометрический поиск пути template.

Если вы предпочитаете посмотреть видеоурок, а не читать письменный, ознакомьтесь с видеоурок внизу этой страницы.

Это руководство можно использовать в качестве основы для других шаблонов, но они не работают точно так же, как Изометрический поиск пути template. Пожалуйста, будьте осторожны, пытаясь это сделать.

Используемые инструменты

  • Character Tool
  • Mannequin Редактор
  • Microsoft Visual Studio® (бесплатная Версия сообщества доступен)
  • Любой XML-редактор, например Notepad++.

Файлы

Загрузите следующий файл и распакуйте его куда угодно:

deer_tutorial.zip

Это всего лишь пример актива. Конечно, можно использовать и другие символы .fbx.

Импорт модели персонажа

  1. Откройте Character Tool и перетащите deer.fbx файл в его область просмотра:

  2. Сохраните его под предметы/персонажи/

    При импорте будет создано несколько различных ресурсов, связанных с этой моделью персонажа, поэтому рекомендуется создать внутри новую папку. объекты/персонажи, например предметы/персонажи/олени.

Импорт и назначение текстуры

ZIP-файл также содержит файл текстуры. deer_texture.tif. Чтобы назначить это модели оленя:

  1. Перетащите deer_texture.tif в ту же папку в Обозревателе ресурсов.

  2. Дважды щелкните материал оленя и в только что открывшемся Material Editor под Карты текстур, удалите Нормальный.
  3. Измените Диффузный к deer_texture в олень папка.
  4. Файл -> Сохранить и закройте Material Editor.

Импорт и настройка анимации

Если посмотреть раздел «Анимации», станет ясно, что одна анимация, которая была в комплекте с этой моделью (т. Возьми 001) на самом деле состоит из трех разных анимаций: анимации ожидания, анимации ходьбы и анимации бега.

Во-первых, важно знать, какие кадры представляют какую анимацию. Чтобы это узнать, зайдите на Character Tool -> Воспроизведение панель и изменить Секунды чтобы Рамки:

Преобразование секунд в кадры

Проверьте, когда начинается анимация и какой кадр является последним в каждой анимации. Запишите эти кадры для дальнейшего использования.

Первый кадр — это поза по умолчанию и, следовательно, не является частью анимации. Обязательно пропустите этот кадр и запустите первую анимацию с кадра 1.


Чтобы разделить анимацию:

  1. Откройте импортер анимации одним из следующих способов:
    В Character Tool собираюсь Файл -> Импорт FBX -> Анимация. или;
    В основной Sandbox UI, собираюсь Инструменты -> Импорт FBX -> Анимация.
  2. Перетащите deer.fbx файл в область просмотра импортера анимации.
    На панели слева теперь появилась анимация long:


    Начальный анимационный клип
    Чтобы разделить эту анимацию на анимацию простоя, ходьбы и бега, все, что нужно сделать, — это создать 3 анимационных клипа. Настройте уже доступный анимационный клип так, чтобы он содержал только праздный анимацию, установив соответствующие номера начального и конечного кадров. Используйте записанные ранее кадры, например, праздный анимация начиная с кадра 1 и заканчивается на кадре 616.

  3. Переименуйте анимационный клип из Возьми 001 к чему-то значимому, например deer_idle.

    Необязательно

    Нажмите Предварительный просмотр протестировать анимацию.

  4. Нажмите кнопку небольшая кнопка раскрывающегося списка рядом с анимационными клипами и выбери Добавить.
  5. Таким же образом добавьте анимацию ходьбы.
  6. Анимация бега в этом примере использоваться не будет, поэтому просто выберите Файл -> Сохранить и выйдите из импортера анимации.

Добавление скелета

Поскольку список скелетов не используется в версии Engine, начиная с 5.6, любые ссылки на skeletonlist.xml в этом руководстве можно игнорировать.

Это означает, что если вы используете CRYENGINE 5.6 или новее, ваш следующий шаг должен быть Изменение модели от третьего лица на модель оленя.

Чтобы добавить скелет оленя, можно использовать либо файл Character Tool, либо отредактировать файл skeletonlist.xml.

В Character Tool

  1. В Активы панель слева, развернуть Сжатие (анимации/).

    Местоположение списка скелетов
  2. Выбрать Список скелетов.
  3. Перейти к Свойства -> Псевдонимы, нажмите на маленькая кнопка раскрывающегося списка и выбери Добавить.


    Добавление скелета
  4. Используйте кнопку обзора справа от вновь созданного псевдонима для поиска /Objects/Characters/<папка, выбранная выше>/deer.chr. Слизать Открыть.

Через Skeletonlist.xml

  1. В проводнике Windows откройте <Папка проекта>/Assets/Animations/skeletonlist.xml.

  2. Скопируйте и вставьте строку существующего скелета в следующую строку и замените имя и путь, чтобы они соответствовали вашему скелету оленя, например.
    <Скелет name="deer" file="Objects/Characters/deer/deer.chr"/>.

    Рекомендуется назвать скелет так же, как имя файла, который был импортирован ранее, в этом случае олень.

  3. Выберите Файл -> Сохранить и закройте Character Tool.

Изменение модели от третьего лица на модель оленя

Теперь, когда модель и все связанные с ней части (скелет, текстура и т. д.) импортированы в Sandbox, необходимо изменить исходный код template, чтобы вместо этого загрузить новую модель оленя.

  1. Закройте Sandbox.
  2. Перейдите в корневую папку проекта, щелкните правой кнопкой мыши на игра.cryproject и выбери Создать решение.
  3. новый Решения появится папка. Откройте эту папку и следующую подпапку (Win64 если вы создали решение для 64-битной Windows) и откройте game.sln.
  4. В Обозреватель решений справа, найдите player.cpp и откройте его:


    Ищу player.cpp

  5. Найдите строку 25, которая содержит m_pAnimationComponent->SetCharacterFile и заменить thirdperson.cdf с deer.cdf, включая его путь. Тогда строка будет выглядеть примерно так:
    m_pAnimationComponent->SetCharacterFile("Объекты/Персонажи/олени/deer.cdf");

    Упомянутый здесь номер строки может различаться в зависимости от версии двигателя.

  6. Теперь скомпилируйте всю сборку, перейдя в Сборка-> Сборка решения.
  7. Закройте Visual Studio.
  8. Открыть Активы/Анимации/Mannequin/Preview/Player.xml.

  9. Измените модель в конце строки 4 и 5 к твоему deer.cdf, включая его путь (как на шаге 5).

  10. Сохраните и закройте.

Изменение анимации

Персонажа по-прежнему необходимо настроить для использования новых анимаций, которые были импортированы ранее, поскольку анимации от третьего лица template (персонаж Мотуса) несовместимы с новым скелетом оленя.

  1. Откройте Sandbox еще раз и oоткройте редактор Mannequin (Инструменты -> Анимация -> Редактор Mannequin).
  2. Перейти к Файл -> Загрузить настройки предварительного просмотра и выбери player.xml.
  3. Нажмите кнопку Фрагменты вкладка в левом нижнем углу.

  4. В Фрагменты дерево в левом верхнем углу, разверните Простой -> Ходьба анимацию и нажмите double Вариант 1:

    Поиск анимации ходьбы

  5. Теперь в нижней части редактора фрагментов справа щелкните панель под ThirdPerson(Третье лицо): Прогулка:

    Анимация ходьбы в редакторе фрагментов

  6. Справа в Свойства анимационного клипа, щелкните поле рядом с Анимация и измените это на deer_walk анимация:

    Изменение анимационного клипа

    Необязательно
    Анимация FirstPerson не обязательна, поскольку это пример изометрической игры, поэтому при желании можно FirstPerson(FirstPerson): Прогулка анимацию, которая не была изменена, можно удалить. Если его не удалить, это не повлияет на игру.
  7. Сделайте то же самое для Режим ожидания -> По умолчанию -> Вариант 1, но измените это на deer_idle анимация.
  8. Выберите Файл -> Сохранить изменения и закройте редактор Mannequin.

Тестирование персонажа

Теперь нажмите Ctrl + Г протестировать оленя на уровне template. Щелчок в любом месте уровня или на рампе должен заставить оленя пройти туда.

Рекомендуется назвать скелет так же, как имя импортированного нами файла, в данном случае олень.
