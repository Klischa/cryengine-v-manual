Настройка окклюзии с помощью AISAC

Значения окклюзии передаются в ADX2 с помощью AISAC, который также можно использовать для модуляции громкости или фильтрации высоких частот Cue. Чтобы создать AISAC для окклюзии:

  • Добавьте элемент управления AISAC в Глобальные настройки → AISAC-Управление в дереве Project/Globals и назовите его окклюзия. По умолчанию окклюзия рассчитывается в диапазоне от 0 до 1, где 1 соответствует максимальной окклюзии.
  • Щелкните правой кнопкой мыши сигнал, который должен быть перекрыт, и выберите Новый объект → Создать AISAC... вариант.
  • Дайте AISAC имя по вашему выбору в открывшемся окне Добавить AISAC и установите Элемент управления AISAC (ID: Имя) поле для окклюзия.


Добавить AISAC

Несколько AISAC можно объединить с помощью одного и того же элемента управления AISAC для создания более сложного поведения. Например, в этом случае окклюзия Параметр может использоваться для управления как громкостью, так и частотой среза высоких частот.
