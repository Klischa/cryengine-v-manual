Обзор

Начиная с CRYENGINE 5.2, теперь можно использовать ограничения (включая самоограничения) с персонажами/живыми скелетами.

Если ограничение не должно влияют на анимацию персонажа, масса скелета должна быть установлена на 0.


Видео ниже иллюстрирует использование ограничений со скелетом живого персонажа:

Создание ограничений для живых персонажей

Вы можете использовать следующие методы для создания ограничений для анимированного объекта/живого скелета:

  • Lua-скрипты
  • С++

Чтобы быстро проверить эту функцию, можно изменить объект ограничения (Scripts/Entities/Physics/Constraint.lua), чтобы разрешить ему автоматическое подключение к живым скелетам, добавив ent_independent в список объектов выборки:

    local ents = Physics.SamplePhysEnvironment(self:GetPos(), self.Properties.radius, ent_static+ent_rigid+ent_sleeping_rigid+ent_independent+ent_sort_by_mass);
