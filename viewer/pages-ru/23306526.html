Обзор

Оружие — это предмет, который содержит четыре следующих компонента:

  • А Класс оружия, который определяет общую логику вашего оружия (Что происходит, когда вы берете оружие?, Что происходит, когда вы бросаете оружие?, ...).
  • А Класс пожарного режима, который определяет все виды параметров огня, такие как отдача, эффекты и т. д.
  • А Класс снаряда, который определяет, например, логику при попадании в другой объект.
  • А Класс режима масштабирования, который определяет, как обрабатывать различные шаги масштабирования для вашего оружия.

Основная функциональность реализована на C++, но эти компоненты считывают данные, хранящиеся в файлах сценариев XML, расположенных в: <Game_Folder>/Scripts/Entities/Items/Weapons.

Класс оружия

Новый класс оружия можно добавить, реализовав CItem и IОружие интерфейсы. Базовая реализация оружия поставляется в GameDLL проект, который обеспечивает наиболее часто требуемые функции оружия:

class CMyWeapon : public CItem, public IWeapon
{
   // IItem, IGameObjectExtension
   virtual bool Init(IGameObject * pGameObject);
   virtual void InitClient(int channelId) { CItem::InitClient(channelId); };
   virtual void Release();
   //...other IItem, IGameObjectExtension methods

   // IWeapon
   virtual void StartFire();
   virtual void StartFire(const SProjectileLaunchParams& launchParams);
   virtual void StopFire();
   virtual bool CanFire() const;
   virtual bool CanStopFire() const { return true; }
   //... other IWeapon methods
}

При реализации нового класса оружия рекомендуется наследовать его от класса CWeapon. Следующие функции из CОружие наиболее распространенные из них переопределяются для предоставления новых функций игрового процесса:

Последним шагом для того, чтобы ваше специальное оружие можно было использовать в XML-файле оружия, является его регистрация в файле Фабрика игр (Code\Game\GameDll\GameFactory.cpp), центральная точка регистрации новых игровых объектов:

#include "MyWeapon.h"
//...
void InitGameFactory(IGameFramework *pFramework)
{
   //...
   REGISTER_FACTORY(pFramework, "MyWeapon", CMyWeapon, false);
   //...
}

Класс пожарного режима

Пример кода GameSDK уже включает множество уникальных режимов огня:

  • Автоматический
  • AutomaticShotgun
  • Взрыв
  • Зарядка
  • Взорвать
  • LTagSingle
  • ближний бой
  • Завод
  • Рапид
  • Дробовик
  • Одинокий
  • Спамер
  • Бросок

В случае, если этих режимов огня недостаточно, можно реализовать новый режим огня, производный от IFireMode интерфейс:

class CMyFiremode : public IFireMode
{
   virtual void Init(IWeapon *pWeapon, const struct IItemParamsNode *params, uint32 id);
   virtual void PostInit();
   virtual void Update(float frameTime, uint32 frameId);
   virtual void PostUpdate(float frameTime);
   virtual void Reload(int zoomed);

   //...other IFireMode methods
}

Последним шагом для создания пользовательского режима огня, который можно будет использовать в XML-файле оружия, является его регистрация в файле XML. Система оружия реализация (Code\Game\GameDll\WeaponSystem.cpp):

  m_tokensUpdated(false)

   RegisterFireMode("MyFireMode", &CreateIt<CMyFireMode, IFireMode>);
   //...
}

Класс снаряда

CСнаряд класс, реализованный в GameDLL Проект предоставляет большую часть необходимой функциональности. Этот класс можно расширить, производя от него, например, реализацию новых функций самонаведения ракет или создание нового класса взрывчатых веществ.

При выводе из CСнаряд, следующие функции должны обеспечивать достаточную гибкость для расширения возможностей игрового процесса.

Последним шагом для вашего пользовательского снаряда является его регистрация в Система оружия реализация (Code\Game\GameDll\WeaponSystem.cpp):

CWeaponSystem::CWeaponSystem(CGame *pGame, ISystem *pSystem)

  m_wetEnvironment(false),

Оружие XML

Создание окончательного оружия полностью выполняется в легко редактируемом файле XML, который следует хранить в папке <Game_Folder>/Scripts/Entities/Items/Weapons/.

Хорошей отправной точкой для создания собственного оружия XML является использование прилагаемого Rifle.xml сценарий. Он уже включает в себя все необходимое, чтобы иметь практичное и реалистичное оружие. Более подробную информацию об общей структуре реализации оружия XML можно найти в комментариях внутри файла.
