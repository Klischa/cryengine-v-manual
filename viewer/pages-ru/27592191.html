Создание решения Visual Studio

Чтобы импортировать игровой проект, вам необходимо выполнить следующие шаги:

  1. Щелкните правой кнопкой мыши Game.cryproject файл и выберите Создать решение
  2. Перейдите к своему Решения каталог в том же каталоге. Откройте Win64 каталог, содержащий Game.sln
  3. Двойной щелчок твой Game.sln файл в откройте решение с помощью Visual Studio. После открытия вы должны увидеть вид, похожий на изображение 2 ниже.

Заключение

Это представляет нам наш проект; Игра (видно под Проект папка в папке Обозреватель решений), он содержит все исходные файлы C++, содержащиеся в нашем игровом плагине.

Даже игровые проекты представлены в CRYENGINE в виде плагинов. Это означает, что любой игровой код, который вы пишете, технически является плагином для движка.

Кроме того, нам представлены три пусковые установки:

  • GameLauncher - Используется для того, чтобы играть в вашу игру так, как это сделал бы конечный пользователь.
  • GameServer - Используется для запуска выделенного сервера, на котором работает ваш проект.
  • Sandbox — Используется для открытия редактора CRYENGINE для создания уровней для вашего проекта.

По умолчанию выбран GameLauncher. Это означает, что если мы нажмем F5, проект будет собран и запущен в чисто игровом контексте:
