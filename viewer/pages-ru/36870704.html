Обзор

Редактор дерева поведения предоставляет интуитивно понятный пользовательский интерфейс для разработки сложных деревьев поведения на языке высокого уровня.

Эта документация предназначена для предоставления пользователям краткого технического обзора управления памятью дерева поведения, а также информации о создании и реализации пользовательских узлов на C++.

Язык разметки (XML)

В CRYENGINE деревья поведения описываются с помощью XML и загружаются в горячем режиме каждый раз, когда пользователь заходит в игру через редактор.

Модель памяти

Деревья поведения занимают относительно небольшой объем памяти, разделяя неизменяемые данные (только для чтения) между экземплярами одного и того же дерева и выделяя память только для объектов/действий, которые необходимы в текущей ситуации.

Эта память разделена на две категории, а именно: данные конфигурации и данные времени выполнения.

Данные конфигурации

Данные конфигурации относятся к тем данным, которые остаются неизменными, т. е. никогда не изменяются во время выполнения дерева поведения. Он содержит следующую информацию, связанную с конфигурацией Дерева:

  • События
  • Переменные
  • Временные метки
  • Дескрипторы событий
  • «Скелет» дерева поведения с конкретными данными конфигурации для каждого узла.

В коде эти данные конфигурации находятся в структуре, называемой шаблоном дерева поведения, которую можно изменить только тогда, когда дерево не запущено (т. е. в режиме «Редактирование»). Хотя события, переменные, временные метки и дескрипторы событий также можно изменить с помощью Определения данных блоке редактора дерева поведения, «скелет» можно модифицировать, изменяя структуру дерева и параметры узла с помощью BTE.

Память для данных конфигурации выделяется из кучи уровней.

Он освобождается при выгрузке уровня при запуске игры через панель запуска или когда игрок выходит из игрового режима и возвращается в режим «Редактирование», то есть в редактор дерева поведения.

Данные времени выполнения

При создании агента AI создается экземпляр дерева поведения, который связывается с агентом.

Его обязанностью является выполнение дерева поведения на основе последней версии шаблона дерева поведения, предоставленной кодом редактора дерева поведения. Можно сказать, что экземпляр дерева поведения запускает дерево поведения с предоставленными данными конфигурации.

Дерево запускается следующим образом:

  • Создаются активные узлы (узлы, которые посещает агент во время выполнения Дерева).
  • Когда узел создается и ставится галочка в первый раз, объект Runtime Data выделяется узлу и агенту AI.
  • Объект Runtime Data сохраняется в течение long, пока агент продолжает посещать узел (это может быть в течение нескольких кадров), и освобождается, как только агент покидает узел.

Эти данные времени выполнения находятся в каждом посещаемом узле дерева и, в отличие от данных конфигурации, изменяются и с большой вероятностью изменятся во время выполнения дерева.

Память для данных времени выполнения выделяется распределителем сегментов.

Это сделано для минимизации фрагментации; поскольку данные времени выполнения обычно имеют размер в несколько байт и часто выделяются и освобождаются, будет сложно найти смежные блоки памяти для больших фрагментов данных. Распределитель ковша очищается по уровню выгрузки.
