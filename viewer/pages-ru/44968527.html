Обзор

Инструмент Substance использует файлы Substance Archive (*.sbsar) для создания экземпляров Substance Graph и генерации на их основе текстур.

Словарь

Архив веществ: .sbsar Этот файл содержит все конфигурации Substance Graph, полученные из Substance Designer.
График веществ: Каждый архив может включать в себя несколько графиков. Каждый граф может предоставлять несколько настроек для изменения внешнего вида, а также предоставлять выходные данные, которые позже станут текстурами.
Экземпляр вещества: Экземпляр графика с измененными настройками и определениями выходных данных текстур.

Важно помнить, что реализация CRYENGINE не непосредственно производить выходные данные графа из Substance Graph, а не предварительно настроенные выходные данные текстуры (которые используют выходные данные Substance Graph в качестве входных данных) обеспечивают максимальную гибкость при создании текстур из Substance.

Вещество меню (под Инструменты) имеет три варианта: Редактор графов архива веществ, Сопоставление графа веществ по умолчанию и Редактор экземпляров веществ.

Редактор графов архива веществ

Что касается архивов веществ, то настройки вывода по умолчанию для всех графиков в архиве можно изменить. Это позволяет автору Архива Вещества заранее определить правильные выходные данные из архива для каждого экземпляра, созданного на основе архивных графиков.

Эти настройки сохраняются отдельно от конфигурации проекта по умолчанию, поэтому при изменении настроек проекта по умолчанию будут отражены настройки графика по умолчанию.

Чтобы открыть редактор архива веществ double-нажмите на Значок архива веществ в Обозреватель активовили, альтернативно, через Инструменты -> Вещество -> Редактор графов архива веществ., затем откройте Архив Вещества через Файл -> Открыть.

1. График
Узел вывода графика вещества

Этот узел представляет выходные данные, определенные в графике веществ. Заданными являются только выходные данные, доступные в графике веществ (красные текстовые узлы).

Узел вывода текстур

Эти узлы представляют собой реальные выходные данные текстуры, которые будут сгенерированы из экземпляра вещества с использованием этого графа (зеленые текстовые узлы).

Вы можете свободно добавлять или удалять существующие узлы вывода текстур, чтобы добавлять или удалять выходные текстуры из графа вещества.

Вы можете перемещаться по этому графику, щелкая и перетаскивая средняя кнопка мыши.

Создание новых узлов

Чтобы создать новые узлы в графе, щелкните правой кнопкой мыши на пустом месте панели графика и выберите один из перечисленных типов узлов.

Переименование выходного узла

Чтобы переименовать выходной узел, double клик по имени узла в графе и переименуйте.

Соединение узлов

Каждому узлу вывода текстуры требуются некоторые входные данные от узла вывода графа вещества, чтобы иметь контент при генерации выходной текстуры.

Для простоты использования узлы предоставляют несколько типов выходов и входов.

  • RGBA - Весь вывод RGBA графа будет использоваться в выходной текстуре. В этой конфигурации выходной слот RGBA (график вещества) должен быть подключен к входному слоту RGBA на данном узле вывода текстуры. Примечание. В конфигурации RGBA никакие другие входные слоты на данном узле вывода текстуры использоваться не могут.
  • RGB — Выходной слот RGB (график вещества) может быть подключен только к входному слоту RGB на данном узле вывода текстуры. Примечание. В этой конфигурации А входной слот (используемого узла «Вывод текстуры») может получать входные данные от другого узла «График вещества».
  • Р/Г/Б/А - Индивидуальные слоты каналов. Отдельные выходные слоты могут быть свободно подключены к любому отдельному входному слоту. Примечание. Исключения, упомянутые выше.

Редактор сопоставления диаграммы веществ по умолчанию

Каждый граф и экземпляр вещества может иметь свою собственную конфигурацию выходов. Чтобы облегчить процесс настройки, создается цепочка выходных конфигураций, которая начинается с выходов по умолчанию для каждого проекта.

Зачем мне это делать? Текущая настройка по умолчанию соответствует необходимости использования CRYENGINE по умолчанию, но, конечно, вы сами можете изменить то, как вы хотите, чтобы ваши текстуры назывались и использовались. В проектах могут быть представлены новые выходные данные, а новые шейдеры могут потребовать другого расположения каналов для текстур и т. д.

Чтобы отредактировать выходные данные проекта по умолчанию, перейдите в раздел Инструменты -> Вещество -> Редактор сопоставления диаграммы веществ по умолчанию.

Определение основных выходов

Полученный файл конфигурации сохраняется в <game_data>/default_substance_output_mapping.json, так что не забудьте отправить его после сохранения в VCS.

Когда нет <game_data>/default_substance_output_mapping.json система принимает Редактор/DefaultSubstanceOutputMapping.json по умолчанию. Это запасной вариант, и для этого файла нет редактора.

Редактор экземпляров веществ

Substance Instance — это настоящий template для генерации текстур. Вся предыдущая конфигурация в основном ускоряла окончательную настройку экземпляра и не требовала от пользователей повторять действия при создании нескольких экземпляров одного графа веществ.

Редактор экземпляров вещества открывается double нажимает на экземпляр вещества в Обозреватель активов или через

Инструменты -> Вещество -> Редактор экземпляров вещества..

Экземпляр субстанции имеет те же возможности конфигурации вывода, что упоминалось ранее, но на этот раз модификация затронет только конкретный экземпляр. Кроме того, в редакторе экземпляров Substance вы можете изменять входные данные Substance, доступные пользователям через Substance Designer.

Работа с веществами

Импорт архивов веществ

Перетащите архив *.sbsar в браузер ресурсов.

Создание экземпляра вещества

Чтобы создать экземпляр Substance, щелкните правой кнопкой мыши по архиву Substance в Обозреватель активови в контекстном меню выберите Создать экземпляр.

Откроется диалоговое окно создания экземпляра:

В этом диалоговом окне вы можете выбрать местоположение вновь созданного экземпляра и снова изменить разрешение экземпляра и выходные данные, если это необходимо для этого конкретного экземпляра.

После нажатия OK, будет создан экземпляр и сгенерированы текстуры.

Сгенерированные текстуры следуют одному и тому же неизменяемому шаблону:

{instance_name}_{output_name}.dds

и расположены в той же папке, что и экземпляр.

Например, если ваш экземпляр

текстуры/натуральные/moss_01, результирующие текстуры с картинки выше будут

  • текстуры/натуральные/moss_01_diff.dds
  • текстуры/натуральные/moss_01_spec.dds
  • текстуры/натуральные/moss_01_ddna.dds

Через несколько секунд вновь созданные текстуры появятся в браузере ресурсов рядом с экземпляром вещества. На данный момент вам придется вручную добавлять текстуры к материалам в Material Editor, чтобы использовать их в моделях.

Редактирование экземпляра вещества

Двойной щелчок по экземпляру вещества в Обозреватель активов откроет Редактор для редактирования Веществ:

Файлы экземпляров вещества имеют этот значок:

Помимо редактирования выходных данных, вы также можете изменить входные параметры, представленные в Графике веществ, чтобы изменить внешний вид результирующей текстуры.

В этом случае, если полученные текстуры используются в материалах сцены, их содержимое динамически обновляется, поэтому вы сразу видите результаты, хотя и в более низком качестве.

После закрытия редактора экземпляров текстуры высокого качества рассчитываются в фоновом режиме и загружаются движком.

Поскольку расчеты модификаций графика занимают некоторое время, иногда желательно снизить выходное разрешение в целях настройки. Однако изменение разрешения графика по умолчанию может быть опасным и привести к отправке неправильных настроек качества. Для предварительного просмотра в реальном времени используются значения из «Разрешение предварительного просмотра"комбобоксы, в то время как "Выходное разрешение" Настройки входа используются при создании высококачественных выходных данных.
