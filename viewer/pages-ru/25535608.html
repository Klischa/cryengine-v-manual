Обзор

На этой странице рассказывается о базе данных AnimEvent и базе данных треков. Общие сведения о файле .chrparams и о том, как отображать анимацию, см. Руководство CRYENGINE V и Файл параметров символов (chrparams) документация.

Файл .chrparams, или файл параметров персонажа, содержит справочный список файлов анимации (.caf) для анимации конкретных персонажей в игре. Файл .chrparams имеет то же имя, что и символьный файл, на который он ссылается.

Помимо списка всех анимаций, которые движок должен загрузить для персонажа, файл .chrparams содержит специальные записи, которые позволяют указать базу данных анимационных событий и базу данных треков. Обе записи являются необязательными.

Настройка

Создание событий временной шкалы

Вы можете добавить анимационные события, нажав double на временную шкалу. Каждая анимация может иметь их набор:

Доступ к контекстному меню

Временная шкала имеет контекстное меню, которое дает вам возможность переключаться между кадрами и событиями. Он также содержит подсказки о сочетаниях клавиш.


Свойства события

Они хранятся в отдельном файле ANIMEVENTS. Такой файл ссылается на параметры скелета (CHRPARAMS) и содержит списки событий анимации для каждой анимации.

То есть с несколькими анимациями в одном файле. Тем не менее, они сохраняются при сохранении записи анимации. Точно так же, как вы сохраняете *.animsettings.

Если вам нужно быстро создать большое количество событий, вы можете использовать панель «Пресеты» AnimEvent.

Пресеты

Переключить

Toggle предоставляет вам набор быстро доступных анимационных событий. Вы можете добавить их на временную шкалу щелчком double или с помощью назначаемых горячих клавиш (цифровые клавиши 1-0).
