Обзор

Сущность-архетип основана на обычной сущности и определяет индивидуальные значения параметров для этой сущности. Если значение параметра Архетипа изменено, все экземпляры этого Архетипа в сцене будут обновлены автоматически.

Сущности архетипов организованы в библиотеки, которые можно создать в DataBase Посмотреть.

Таким образом, дизайнеры технических уровней могут заранее определить варианты классов Entity как архетипы Entity, которые можно использовать на протяжении всей игры. Для глобальных изменений, затрагивающих все экземпляры, достаточно один раз изменить объект Archetype в представлении базы данных.

Панель поиска

В строке поиска вверху вы можете отфильтровать любые архетипические сущности, введя часть их имени. Затем инструмент покажет вам только архетипические сущности и группы, в которых они находятся.

Предварительный просмотр

Кнопка рядом с панелью поиска переключает предварительный просмотр выбранного вами архетипа. Этот предварительный просмотр будет показан в нижней части инструмента.

Как показано на изображении ниже, нажатие кнопки «Открыть» откроет Legacy Material Editor, где вы сможете изменить параметры, а также свойства материала сущности архетипа.

Параметры сущности архетипа

Параметры сущности архетипа — это базовый набор параметров, общий для всех сущностей архетипа.
