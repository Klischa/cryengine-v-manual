Разделы

Кисти — это твердые объекты, которые нельзя изменять или перемещать динамически во время игры, за исключением случаев, когда в файле ресурсов указана точка останова, например разрушаемая деревянная хижина.

Обычно кисти представляют собой объекты static, размещенные в мире. Они являются одними из самых дешевых визуализированных объектов в мире, поскольку в них нет никаких затрат на сущность или физику, как у других объектов.

Большой процент визуальных структур в ваших мирах, вероятно, будет создан с использованием кистей.

Обозреватель объектов и предварительный просмотр

На панели браузера отображается содержимое <root>\GameSDK\Objects.pak файл (точнее, файл <root>\GameSDK\Objects\*.* папка) и содержит такие объекты, как оружие, транспортные средства и реквизит.

Общее количество файлов указано в нижней части панели.

Фильтр

Текстовое поле «Фильтр» позволяет отображать объекты с выбранным ключевым словом в заголовке. Чтобы использовать его, просто начните вводить текст в поле фильтра, и список браузера отфильтрует все объекты, которые не соответствуют текущему запросу.

Количество файлов, соответствующих запросу, будет отображаться под текстовым полем «Фильтр».

Перезагрузить

Нажмите Перезагрузить когда вы добавляете новый объект в библиотеку, когда вы меняете объект в пакете DCC и хотите обновить геометрию или чтобы фильтр вступил в силу.

Параметры кисти

Разместив кисть на уровне, выберите ее, чтобы просмотреть ее свойства.

Параметры кисти — это базовый набор параметров, общий для всех кистей.

DrawLast

Флажок DrawLast дает дизайнерам возможность индивидуального контроля над проблемами альфа-сортировки, такими как эффекты частиц перед стеклянными объектами.

В примере, показанном ниже, фоновые стеклянные купольные панели имеют непрозрачность 50% и неправильно визуализируются перед эффектом частиц.

Установив для DrawLast значение true для объекта фонового купола, движок знает, что любые альфа-объекты, отображаемые между игроком и им самим, должны иметь приоритет порядка.

Отладка

Существуют различные консольные команды, которые помогают отладить LOD в Sandbox или в игровом режиме.

e_Lods

Load and use LOD models for static geometry

e_LodMin

Min LOD for objects

e_LodMax

Max LOD for objects

e_DebugDraw

Draw helpers with information for each object (same number negative hides the text)
 1: Name of the used cgf, polycount, used LOD
 2: Color coded polygon count
 3: Show color coded LODs count, flashing color indicates no Lod
 4: Display object texture memory usage
 5: Display color coded number of render materials
 6: Display ambient color
 7: Display tri count, number of render materials, texture memory
 8: RenderWorld statistics (with view cones)
 9: RenderWorld statistics (with view cones without lights)
10: Render geometry with simple lines and triangles
11: Render occlusion geometry additionally
12: Render occlusion geometry without render geometry
13: Display occlusion amount (used during AO computations). Warning: can take a long time to calculate, depending on level size! 
15: Display helpers
16: Display debug gun
17: Streaming info (buffer sizes)
18: Streaming info (required streaming speed)
19: Physics proxy triangle count
20: Display object instant texture memory usage
21: Display animated object distance to camera
22: Display object's current LOD vertex count
