Обзор

Чтобы реализовать новую сущность с использованием Lua, в папке игры необходимо сохранить два файла.

Первый — это файл Ent, который анализируется системой Entity, чтобы узнать местоположение файла сценария Lua. Второй — скрипт Lua, реализующий нужные свойства и функции.

При использовании SDK файлы .ent и .lua хранятся внутри <Game_Folder>\Scripts.pak файл.

Входной файл

Все файлы Ent хранятся внутри <Game_Folder>\Entities каталог и должен иметь расширение файла .ent. Содержимое представляет собой файл XML, как показано в примере ниже.

<Entity
 Name="RadarBase"
 Script="Scripts/Entities/Others/RadarBase.lua"
/>

В следующей таблице описаны свойства, анализируемые Entity System.

Lua-скрипт

Сценарий Lua состоит из одной основной таблицы, которая должна иметь то же имя, что и имя, предназначенное для класса сущности.

Таблица свойств

Таблицу свойств необходимо поместить внутри таблицы классов сущностей. Он будет проанализирован редактором Sandbox и предоставит редактору уровней возможность изменять параметры класса сущности через пользовательский интерфейс.

Чтобы иметь параметры, перечисленные в таблице выше, необходимо использовать следующую таблицу свойств.

Properties =
{
  object_Character = "objects/library/architecture/airfield/radar/radar.cga",
  sAnimation = "Default",
  sDestroyedEffect = "explosions.C4_explosion.ship_door",
  fHealth = 100,

  Physics =
  {
    bRigidBody=1,
    bRigidBodyActive = 1,
    bRigidBodyAfterDeath =1,
    bResting = 0,
    Density = -1,
    Mass = 500,
  },
},

Значения, присвоенные внутри таблицы Lua, используются для предоставления значений по умолчанию в Sandbox. Значения свойств для каждого экземпляра, размещенного на уровне, будут сохранены индивидуально в файле уровня.

Sandbox предоставляет инструмент Archetype для назначения свойств общего набора, повторно используемых для нескольких экземпляров (даже на нескольких уровнях). Более подробную информацию об архетипах можно найти в Руководстве Sandbox.

Каждый раз, когда свойство экземпляра изменяется в Sandbox, будет вызываться функция OnPropertyChange(), если она реализована для объекта Script.

Можно дать редактору подсказки относительно желаемого типа значения для значения свойства. Это делается с помощью одного из следующих префиксов в имени значения.

Таблица редактора

Таблицу редактора можно добавить внутрь таблицы классов сущностей. Он предоставляет Sandbox дополнительную информацию, которую можно использовать для экземпляров сущности.

Специальные комментарии

Вы можете добавить специальные комментарии к переменной, которая может использоваться движком. В настоящее время вы можете изменить ползунки по умолчанию внутри редактора, предоставив информацию о числовой переменной.

Например:

Комментарий...

--[25,100,0.1,"Damage treshold"]

... сообщает движку, что:

  • Значение ограничено значениями от 25 до 100.
  • В случае десятичной дроби будет использоваться шаг 0,01, это определяет точность, с которой значение можно изменить в редакторе.
  • «Порог повреждения» будет добавлен во всплывающую подсказку, которая появляется при наведении курсора на переменную и предоставляет дополнительную информацию.
