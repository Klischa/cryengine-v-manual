Окружающая среда (4/4) – Система сущностей

Пространственные запросы: GetPhysicalEntitiesInBox

ИИ и транспортные средства являются объектами системы сущностей.

Для создания сущности требуется ее класс сущности.

Определяется либо с помощью файла .ent в каталоге Game/Entities.

Или через вызов C++ RegisterFactory(…) в коде игры.

Пул сущностей можно использовать для ограничения количества активных субъектов AI (ИИ) для каждого указанного класса сущностей.

Дерево выбора поведения – обзор

Фактически государственная машина

Определяет условия изменения поведения («состояния»)

Поведенческие переменные используются для выбора поведения.

Они могут быть установлены в Lua или в результате получения сигнала.

Использует древовидную систему принятия решений с проверкой условий

Условия задаются в виде строк, но могут быть более сложными, чем просто проверка одной переменной.

например "IsHurt и !InCover и HasTarget"

Если условие не выполнено, обход переходит к следующему брату.

Если ни один листовой узел не достигнут, переключение поведения не производится.

Код может использоваться несколькими BST.

Дерево выбора поведения — пример

<SelectionTrees>

<SelectionTree name="FogOfWar" type="BehaviorSelectionTree">

<Переменные>

<Имя переменной="IsFar"/>

<Имя переменной="IsClose"/>

<Имя переменной="AwareOfPlayer"/>

</Переменные>

<SignalVariables>

<Signal name="OnEnemySeen"variable="AwareOfPlayer" value="true"/>

<Signal name="OnNoTarget"variable="AwareOfPlayer" value="false"/>

<Signal name="OnLostSightOfTarget"variable="AwareOfPlayer" value="false"/>

</SignalVariables>

<Имя приоритета="Корневой">

<Leaf name="FogOfWarSeekST" условие="IsFar"/>

<Leaf name="FogOfWarEscapeST" условие="IsClose"/>

<Leaf name="FogOfWarAttackST" условие="AwareOfPlayer"/>

<Leaf name="FogOfWarIdleST"/>

</Приоритет>

</SelectionTree>

</SelectionTrees>

Дерево выбора поведения – определение

Файл XML, который находится в папке Scripts/AI/SelectionTrees.

Используйте тег <SelectionTree>

При необходимости в одном файле можно определить несколько деревьев выбора поведения (BST).

<SelectionTrees>

<SelectionTree name="FogOfWar" type="BehaviorSelectionTree">

[…]

</SelectionTree>

</SelectionTrees>

Дерево выбора поведения – Теги

Чтобы определить BST, используйте теги <Leaf> и <Priority>.

Имя листа должно совпадать с именем соответствующего поведения (или узла перевода листа).

Листья оцениваются (как определено в атрибуте «состояние») по порядку. Выбирается поведение первого листа, оцененное как true.

<Имя приоритета="Корневой">

<Leaf name="FogOfWarSeekST" условие="IsFar"/>

<Leaf name="FogOfWarEscapeST" условие="IsClose"/>

<Leaf name="FogOfWarAttackST" условие="AwareOfPlayer"/>

<Leaf name="FogOfWarIdleST"/>

</Приоритет>

Деревья выбора поведения – переменные

Переменные могут быть только логическими

<Переменные>

<Имя переменной="IsFar"/>

<Имя переменной="IsClose"/>

</Переменные>

Деревья выбора поведения – сигналы

Сигналы AI можно использовать для изменения значений определенных переменных BST.

<SignalVariables>

<Signal name="OnEnemySeen"variable="AwareOfPlayer" value="true"/>

<Signal name="OnNoTarget"variable="AwareOfPlayer" value="false"/>

<Signal name="OnLostSightOfTarget"variable="AwareOfPlayer" value="false"/>

</SignalVariables>

Поведение

По сути, его можно рассматривать как состояние FSM.

Написан на Lua и содержит таблицу функций, каждая строка которой определяет ответ на сигнал.

Скрипты должны находиться в папке «Scripts/AI/Behaviors» (или ниже).

Каждый сценарий поведения должен содержать вызов

определено в AIBehavior.lua, чтобы его можно было добавить в таблицу доступных поведений.

Вратарские трубы

Goalpipe — это предопределенная последовательность атомарных целей (goalops), которые должен выполнить AI.

В Lua проще создавать голпайпы на лету, если это необходимо.

В XML определения ворот выглядят намного понятнее.

Пример ворота XML:

<GoalPipe name="ApproachAndShootObject">

<Блокировка скорости="false" id="Выполнить"/>

<FireCmd mode="Серийная съемка"/>

<LookAroundblocking="false" lookAroundRange="360" scanRange="5" интервал="60" breakOnLiveTarget="true"/>

<Тайм-аут intervalMin="1.0" intervalMax="4.0"/>

</GoalPipe>

Система процентов

Если игрок может тайно приближаться к ИИ, просто воспроизводить анимацию бездействия может быть недостаточно, чтобы выглядеть круто.

Система интересов в основном запускает предопределенные действия AI, как только простаивающие ИИ соответствующих классов AI оказываются рядом с соответствующими (интересными) объектами.

Примеры:

AI внимательно осматривает труп

AI внимательно осматривает брошенную машину

AI «находит» удачное место и в бинокль внимательно рассматривает ландшафт.

Система тактических очков – обзор

Тактическая система очков

Позволяет ИИ задавать интеллектуальные вопросы об окружающей среде.

Это структурированный язык запросов к наборам точек мира.

Используется для поиска укрытий, точек атаки или навигационных точек.

Автоматически оптимизирует запросы и обрабатывает их с разделением по времени.

Доступно через Lua, XML, C++.

coverSuperior = правда,

},

Веса = { distance_from_referencePoint = -1,0,

distance_from_puppet = -1,0,

friendlyDistance = 1,0,

},

},

AI Территории и волны

Контролируйте количество активных ИИ в любое время с помощью простой логики Flow Graph

Все ИИ, назначенные на территорию AI, могут быть активированы, деактивированы и созданы с помощью одного узла FG.

При желании волны AI можно прикрепить к территориям AI и разрешить независимую активацию AI.

Если ИИ были помечены как «Созданные через пул» и назначены волне AI, волна AI обрабатывает проблемы пула сущностей, например погрузка/выгрузка – автоматически
