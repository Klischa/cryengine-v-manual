Контейнеры сущностей — это система для управления наборами сущностей и работы с ними в рамках логики FlowGraph.

Обзор

Контейнер сущностей — это способ определить набор/список/группу сущностей, которые затем можно динамически изменять и использовать с логикой FlowGraph.

Общие полезные операции, которые можно применять к контейнерам, — это добавление/удаление сущностей, запрос о том, находятся ли сущности в контейнере, прослушивание, перебор сущностей контейнера и применение к ним действий, например скрытие или отображение.

Настройка контейнера сущностей

Контейнер сущностей сам по себе является сущностью. Чтобы настроить один:

  1. Добавьте на уровень сущность типа Entity Container.
  2. Установите его начальное содержимое с помощью связывающие сущности во вкладке Свойства.

Использование контейнеров сущностей

Контейнеры сущностей предназначены для использования через FlowGraph с узлами в категории. GameEntity:Контейнеры. Контейнер можно идентифицировать по его сущности ID.

Доступные узлы позволяют:

  • редактирование контейнера.
  • операции между разными контейнерами.
  • запрос, находится ли объект в контейнере.
  • запрос и упорядочивание объектов-контейнеров по близости к другому объекту.
  • прослушивание событий сущностей в контейнере.
  • применение действия ко всем объектам контейнера путем итерации с комбинацией «QueryContainerSize» и «QueryEntityByIndex» или с помощью узла «Действия», запустив Модуль Flow Graph по каждой сущности.
