Обзор

CryScriptSystem абстрагирует машину LUA virtual для использования в других системах и в коде игры.

Предоставляемый функционал включает в себя:

  • Вызов функций скрипта.
  • Предоставление переменных и функций на основе C++ сценариям.
  • Создание таблиц сценариев, хранящихся в памяти машины virtual.

CryScriptSystem основан на Lua 5. Дополнительную информацию о языке Lua можно найти по адресу http://www.lua.org.

Доступ к таблицам сценариев и вызов функций сценария из C++

Глобальную таблицу сценариев можно получить, вызвав IScriptSystem::GetGlobalValue(). IScriptTable используется для представления всех таблиц/переменных сценария.

Предоставление функций и значений C++ сценариям

Чтобы предоставить скриптам функции и переменные C++, необходимо реализовать новый класс. Самый простой способ сделать это — создать класс CScriptableBase, который обеспечивает большую часть функциональности.

Предоставление констант скриптам

Чтобы предоставить скриптам любые константные значения, следует использовать IScriptSystem::SetGlobalValue(). Например, чтобы предоставить нашим сценариям константу с именем MTL_LAYER_FROZEN, используйте следующий код:

gEnv->pScriptSystem->SetGlobalValue("MTL_LAYER_FROZEN", MTL_LAYER_FROZEN);
Предоставление функций сценариям

Чтобы предоставить скриптам функции C++, рекомендуется написать новый класс, производный от CScriptableBase.

class CScriptBind_Game :
  public CScriptableBase
{
public:

  CScriptBind_Game( ISystem* pSystem );
  virtual ~CScriptBind_Game() {}

  int GameLog(IFunctionHandler* pH, char* pText);

};

Внутри конструктора этого класса должен присутствовать следующий код:

  Init(pSystem->GetIScriptSystem(), pSystem);
  SetGlobalName("Game");

  #undef SCRIPT_REG_CLASSNAME
  #define SCRIPT_REG_CLASSNAME &CScriptBind_Game::

  SCRIPT_REG_TEMPLFUNC(GameLog, "text");

В следующем примере показано, как эта новая функция ScriptBind будет доступна для скриптов Lua.

Game.GameLog("a message");
