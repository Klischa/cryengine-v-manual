Обзор

CryFont используется для создания текстур шрифтов, необходимых для отображения текста на экране. Различные особенности рендеринга шрифтов можно увидеть с помощью r_DebugFontRendering консольная переменная.

Результатом является не только тестирование функциональности, но и документирование того, как эти функции можно использовать.

Поддерживаемые функции

CryFont поддерживает следующие функции:

  • Шейдеры шрифтов для настройки внешнего вида шрифтов. Поддерживаются несколько проходов с настраиваемым смещением и цветом, позволяющие создавать тени или контуры.

    Следующие XML файл показывает пример шейдера шрифта:

    <fontshader>
  <font path="VeraMono.ttf" w="288" h="416"/>
  <effect name="default">
    <pass>
      <color r="0" g="0" b="0" a="1"/>
      <pos x="1" y="1"/>
    </pass>
  </effect>
  <effect name="console">
    <pass>
      <color r="0" g="0" b="0" a="0.5"/>
      <pos x="2" y="2"/>
    </pass>
  </effect>
</fontshader>

Атрибуты ш и ч элемента шрифта XML укажите ширину и высоту текстуры шрифта. Порядок проходов в XML определяет порядок рендеринга проходов. А пройти элемент без дочерних элементов означает, что проход отображается с настройками по умолчанию. Тег позиция позволяет смещать шрифт, в то время как цвет используется для его тонирования и определения прозрачности с помощью альфа-канала.

  • Юникод.
    Примечание. Шрифт по умолчанию, который мы используем намеренно, не поддерживает все символы Юникода для экономии памяти, но можно использовать и другие шрифты.
  • Шрифты Truetype в качестве источника кэшируются в небольшой текстуре (общие символы предварительно кэшируются, но обновления во время выполнения возможны и поддерживаются).
  • Рендеринг цветного текста.
  • Регулируемая прозрачность.
  • Изменение цвета внутри строки.
    Использование: $ 0..9 для установки одного из 10 доступных цветов, $$ для печати символа $ и $o для отключения этой функции.
  • Возвраты и табуляция внутри строки.
  • Выравнивание (слева, по центру и справа).
  • Вычисление ширины и высоты строки (используется внутри для выравнивания по центру и правому краю).
  • Разные размеры шрифта.
    Примечание. Билинейная фильтрация допускает некоторое размытие, но, поскольку MIP-карты не используются, это имеет ограничения при минимизации.
  • Пропорциональные и моноширинные шрифты.
  • Идеальный рендеринг пикселей с точным отображением текселей в пиксели для наилучшего качества.
