Как создать собственный целевой текст для уровня

Файл Objectives_global.xml

Файл, который будет содержать всю информацию о цели, находится по адресу: <root>\Assets\Levels\<level name>\leveldata\objectives.xml.

Открыв файл в текстовом редакторе, вы увидите несколько строк примера целей. В следующем примере показан текст, разбитый на полезные части.

Настройка файла

Текст в файле будет выглядеть следующим образом: (По умолчанию в файле Objectives_global.xml будет указан пример, идентичный приведенному ниже. Если он не находится в каталоге вашей игры, вам необходимо извлечь папку libs из файла gamedata.pak.)

Objectives_global.xml — это жнайдено в:

<root>\Assets\Libs\UI\Objectives_global.xml. 

<Root>
  <Example>
    <Objective_01 Name="Example Objective 1" Description="Example Text." />
    <Objective_02 Name="Example Objective 2" Description="Example Text." />
    <Objective_03 Name="Example Objective 3" Description="Example Text." />
  </Example>
</Root>

В начале и конце файла целей находятся теги <Root> и </Root>.

Теперь мы добавим наши собственные цели. Вам необходимо создать тег для уровня. Если уровень называется LevelName, тегами будут <LevelName> и </LevelName>:

<Root>
  <Example>
    ...
  </Example>

  <LevelName>
  </LevelName>
</Root>

Номер цели

<Root>
  <Example>
    ...
  </Example>
  <LevelName>
    <Objective_01 Name="Mission Objective Title" Description="Mission Objective Description" />
  </LevelName>
</Root>

Теперь приступим к настройке цели и ее текста.

Внутри тегов уровней поместите еще один тег, содержащий ссылочный номер цели short. Например, если это первая цель на уровне, откройте тег с помощью <Objective_01.

Обратите внимание: если вы хотите, чтобы на уровне было несколько целей, вам следует клонировать всю эту строку со второй линией цели, как показано ниже:

<Root>
  <Example>
    ...
  </Example>
  <LevelName>
    <Objective_01 Name="Mission Objective Title" Description="Mission Objective Description" />
    <Objective_02 Name="Mission Objective Title" Description="Mission Objective Description" />
  </LevelName>
</Root>

Имя цели

<Root>
  <Example>
    ...
  </Example>
  <LevelName>
   <Objective_01 Name="Mission Objective Title" Description="Mission Objective Description" />
  </LevelName>
</Root>

Затем добавьте имя цели. После <Objective_01 добавьте Name="Название цели миссии", где Название цели миссии — это название вашей цели, например. «Нижние стержни управления».

Для названия и описания целей можно использовать текстовые теги. Это может быть полезно, поскольку затем их можно будет связать с электронной таблицей локализации. Для этого вам необходимо поставить «@» в начале и использовать правильный текстовый тег из файла локализации.

Пример показан ниже:

 <Objective_01 Name="@texttagexample01" Description="@texttagexample02" />

Пожалуйста, обратитесь к UI Документация по локализации дополнительную информацию о системе локализации.

Цель Описание

<Root>
  <Example>
    ...
  </Example>
  <LevelName>
    <Objective_01 Name="Mission Objective Title" Description="Mission Objective Description" />
  </LevelName>
</Root>

Теперь создайте описание цели. Описание представляет собой более длинный текст под названием цели. Заменить Описание цели миссии с необходимым текстом. Чтобы закончить, закройте тег с помощью />.

Пример

Цели миссии, действительные более чем для одного уровня, — это цели, которые вам следует добавить в Objectives_global.xml. Примером из Crysis 3 может быть информация о тактическом сканировании (визоре) или простые базовые задачи, такие как пойти сюда, убить это, уничтожить то и т. д.

<Root>
    <Intro>
      <Intro_Objective_01 Name="Plant C4" Description="Plant C4" />
      <Intro_Objective_02 Name="Plant C4" Description="Plant C4" />
      <Intro_Objective_03 Name="Plant C4" Description="Plant C4" />
      <Intro_Objective_04 Name="Meet Psycho" Description="Meet Psycho" />
      <Intro_Objective_05 Name="Follow Psycho" Description="Follow Psycho" />
    </Intro> 
    <BasicObjective>
        <BasicObjective_Follow name="Follow" Description="Description" />
        <BasicObjective_Infiltrate name="Infiltrate" Description="Description" />
        <BasicObjective_Attack name="Attack" Description="Description" />
        <BasicObjective_Defend name="Defend" Description="Description" />
    </BasicObjective>
    <TacticalScan>
        <TacticalScan_Flank Name="@TacticalScan_Flank_Name" Description="@TacticalScan_Flank_Description" Secondary="true"/>
        <TacticalScan_Attack Name="@TacticalScan_Attack_Name" Description="@TacticalScan_Attack_Description" Secondary="true"/>
        <TacticalScan_Defend Name="@TacticalScan_Defend_Name" Description="@TacticalScan_Defend_Description" Secondary="true"/>
        <TacticalScan_Enter Name="@TacticalScan_Enter_Name" Description="@TacticalScan_Enter_Description" Secondary="true"/>
    </TacticalScan> 
</Root>

Зависит от уровня Objectives.xml

Иногда, в зависимости от количества уровней, которые вы хотите включить в свою игру, этот Objectives_global.xml может стать довольно большим. И некоторые цели миссии действительны только для определенного уровня. Чтобы составить специальный список целей для конкретного уровня, вы можете воссоздать этот файл, встроенный в сам уровень.

Например: уровень Woodland, поставляемый с примером проекта GameSDK, содержит собственный специальный файл objectives.xml, сохраненный в папке woodland\leveldata.
