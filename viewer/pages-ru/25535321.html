Обзор

В статьях документации CRYENGINE вы можете найти упоминания о «Чистом игровом режиме». Имеется в виду запуск игры из пусковая установка приложение, а не запускать игру изнутри Sandbox.

Когда игра будет выпущена, игроки будут использовать для игры программу запуска и, следовательно, «чистый игровой режим». Его можно найти в обоих Bin32 и Bin64 каталоги внутри основной папки SDK.

По умолчанию файл называется GameSDK.exe но вы можете переименовать его как угодно в соответствии с вашей игрой.

Вы также можете установить заголовок окна запуска, используя следующую переменную в файле system.cfg: sys_game_name=YOURTITLEHERE

Загрузка уровня

Чтобы загрузить уровень, нажмите «Одиночная игра» или «Многопользовательская игра», в зависимости от того, в каком режиме игры вы хотите играть.

Хостинг/присоединение к мультиплееру

Вы также можете организовать многопользовательскую игру или присоединиться к ней через меню «Многопользовательская игра».

Удобные переменные

карта

Load a map

i_reload

Reloads item scripts.

log_Verbosity
DUMPTODISK

defines the verbosity level for log messages written to console
-1=suppress all logs (including eAlways)
0=suppress all logs(except eAlways)
1=additional errors
2=additional warnings
3=additional messages
4=additional comments

r_DisplayInfo
DUMPTODISK, RESTRICTEDMODE

Toggles debugging information display.
Usage: r_DisplayInfo [0=off/1=show/2=enhanced]

r_VSync
DUMPTODISK, RESTRICTEDMODE

Toggles vertical sync.
0: Disabled
1: Enabled
2: Enabled, use asynchronous swaps on X360

r_Width
DUMPTODISK

Sets the display width, in pixels. Default is 1024.
Usage: r_Width [800/1024/..]

r_Height
DUMPTODISK

Sets the display height, in pixels. Default is 768.
Usage: r_Height [600/768/..]

sys_spec

Tells the system cfg spec. (0=custom, 1=low, 2=med, 3=high, 4=very high, 5=XBox360, 6=Playstation3)

s_SoundEnable
DUMPTODISK

Toggles sound on and off.
Usage: s_SoundEnable [0/1]
Default is 1 (on). Set to 0 to disable sound.

t_Scale

Game time scaled by this - for variable slow motion
