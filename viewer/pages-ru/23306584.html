Обзор

XML-файлы повреждений тела можно найти в этой папке: GameSDK/Libs/BodyDamage/

Можно создать любое количество файлов, обычно достаточно одного для каждого типа символов. Соглашение об именах следующее: BodyDamage_NameOfCharacter.xml

Например:

  • BodyDamage_AlienGrunt.xml
  • BodyDamage_CryNetOps.xml

Эти файлы обычно редактируются дизайнерами игр. Для каждой из «частей тела», определенных в соответствующем BodyParts_NameOfCharacter.xml, может быть предоставлен набор множителей урона.

Содержимое и структура файла

Ниже приведена свернутая версия настройки повреждения тела инопланетного пехотинца. Вы можете сравнить его с файлом настройки частей тела инопланетного пехотинца, который можно найти в разделе Части Тела раздел.

<BodyDamage>
  <!--  PART DEFINITIONS IN "BodyParts_AlienGrunt.xml" -->
  <Multipliers>
    <Multiplier part="armor" value="0.75" valueMelee="0.8" valueCollision="0.5" />
    <Multiplier part="armorHead" value="0.25" />
    <Multiplier part="jellyBack" value="3.0" />
    <Multiplier part="jellyBody" value="1.0" >
      <GaussBullet value="5.0" />
      <HeavyBullet value="2.0" />
    </Multiplier>
    <Multiplier part="jellyHead" value="20.0" />
    <Multiplier part="tentacles" value="2.0" />
  </Multipliers>
  <ExplosionMultipliers>
    <LTagGrenade value="1.25" />
    <Rocket value="0.8" />
  </ExplosionMultipliers>
  <ImpulseFilters>
    <ImpulseFilter part="armor" scale="0.0" passTo="Spine1" passOnScale="0.5"/>
    <ImpulseFilter part="jellyBack" scale="1.2" />
    <ImpulseFilter part="jellyBody" scale="1.1" />
    <ImpulseFilter part="tentacles" scale="0.0" passTo="Spine1" passOnScale="0.75"/>
  </ImpulseFilters>
</BodyDamage>

Множитель урона частей тела

Для каждой части тела можно добавить набор множителей урона. Есть только один, который является обязательным и обязательным. ценность, который используется как множитель урона по умолчанию для любого типа удара.

Опционально могут быть предоставлены другие множители:

  • valueMelee для масштабирования урона от ударов в ближнем бою.
  • valueCollision для масштабирования урона от столкновений.
  • Список конкретных попаданий Bullet. Для каждого из них добавьте новый тег с названием типа маркера (с учетом регистра) и соответствующим значением.

Множители взрыва

Удары взрывами распространяются не на какую-то конкретную часть тела, а на всего персонажа. Тем не менее, можно определить собственные множители урона для каждого типа снаряда, чтобы сделать определенный тип взрывчатки более эффективным, чем другие, против определенного типа врагов.

Для этого просто добавьте имя снаряда (с учетом регистра) и соответствующее значение.

Если взрыв генерируется снарядом, не указанным в этом списке, по умолчанию он будет равен 1 в качестве множителя урона.

Импульсные фильтры

Импульсы, приложенные к определенным частям, можно масштабировать или передавать на другую кость со своим собственным масштабом. Таким образом, например, даже при ударе персонажа по руке импульс может быть передан на туловище, чтобы получить последовательный эффект при ударе по верхней части тела персонажа.

Передаваемые импульсы могут иметь и свой масштаб. passOnScale ценность.
