OnAddTaggedEntity( shooterId, targetId )

Вызывается всякий раз, когда игрок добавляется в качестве отмеченного на мини-карте.

Подсказка

Вызывается только на Сервере.

OnClientConnect( channelId )

Вызывается всякий раз, когда игрок подключается.

Подсказка

Вызывается только на Сервере.

OnClientDisconnect( channelId )

Вызывается всякий раз, когда игрок отключается.

Подсказка

Вызывается только на Сервере.

OnClientEnteredGame( channelId, playerScriptTable, bReset, bLoadingSaveGame )

Вызывается всякий раз, когда игрок входит в игру и является частью игрового мира.

Подсказка

Вызывается только на Сервере.

OnDisconnect(причина, описание)

Вызывается при отключении игрока и только на этом клиенте.

Подсказка

Вызывается только на Клиенте.

OnChangeSpectatorMode( entityId, режим, targetId, resetAll )

Вызывается всякий раз, когда игрок меняет режим просмотра.

Подсказка

Вызывается только на Сервере.

OnChangeTeam( entityId, teamId )

Вызывается всякий раз, когда игрок меняет команду.

Подсказка

Вызывается только на Сервере.

OnExplosion( explosionInfoTable )

Вызывается всякий раз, когда моделируется взрыв.

Подсказка

Вызывается на Сервере и Клиенте.

OnHit( shooterId, targetId )

Вызывается всякий раз, когда объект добавляется как отмеченный объект на мини-карту.

Подсказка

Вызывается только на Сервере.
