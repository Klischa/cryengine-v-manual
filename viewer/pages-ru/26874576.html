Обзор

C# Framework имеет собственную систему UI, которая используется для создания пользовательских интерфейсов и Проекционные дисплеи (HUD) в игре. В игре Sydewinder есть главное трехмерное меню, которое используется для Старт и Выйти игру, а также внутриигровую 2D-версию HUD для просмотра Текущий счет и Энергия игрока. Кроме того, доступно 3D-меню рекордов для сравнения результатов. баллы между Игроки «Сайдевиндера». Доступ к меню рекордов можно получить через главное меню. Главное меню и меню рекордов текстуры визуализируются с помощью CRYENGINE и размещаются на геометрии в 3D-среде, в то время как внутриигровой 2D-изображение HUD отображается поверх экрана.

Главное меню – Обзор

После инициализации игры игроку отображается главное меню. Это достигается за счет рендеринга главного меню в виде материала на заранее размещенной плоской геометрии на уровне каньона. Аналогичным образом камера размещается перед самолетом.

Все это происходит в основной точке входа приложения Sydewinder с помощью метода InitializeMainMenu в SydewinderApp класс.

Меню инкапсулирует свою собственную логику в MainMenu класс, который наследуется от тот SceneObject класс. Это делает MainMenu класс — собственный элемент UI, экземпляр которого можно создать как любой другой элемент UI.

Новые экземпляры MainMenu класс можно создать, как в следующем примере:

public sealed class MainMenu : SceneObject
{
  // ...
  private static MainMenu _instance;

    public static MainMenu GetMainMenu(SceneObject root)
  {
    if (_instance == null)
    {
      _instance = SceneObject.Instantiate<UI.MainMenu> (root);
    }
    return _instance;
  }
  //...
}

Иерархия создается путем добавления родительского элемента при создании новых элементов UI.

private void CreateMainMenu()
{
  _mainMenuPage = SceneObject.Instantiate<Canvas>(Root);
  //...
  Window mainMenuWindow = SceneObject.Instantiate<Window>(_mainMenuPage);
 
  _startButton = SceneObject.Instantiate<Button>(mainMenuWindow);
  //...
  _highscoreButton = SceneObject.Instantiate<Button>(mainMenuWindow);
  //...
  _exitButton = SceneObject.Instantiate<Button>(mainMenuWindow);
  //...
}

Canvas, Window и Button классы являются частью C# UI Framework и Table Класс, который используется для меню рекордов, является частью проекта Sydewinder. Для создания пользовательских элементов UI систему UI можно расширить.

Внешний вид главного меню

Чтобы придать игре уникальный вид, упомянутые выше элементы UI оформлены в различных стилях.

Все Window и Button элементы будут использовать один и тот же стиль, а общий стиль будет применяться с помощью одной функции.

private void ApplyMenuStyle()
{
  var backgroundImageURL = Path.Combine(Engine.DataDirectory, "Textures/ui/scroller_window_512.png");
  var buttonBackgroundURL = Path.Combine(Engine.DataDirectory, "Textures/ui/Ui_button.png");
  var buttonHighlightedURL = Path.Combine(Engine.DataDirectory, "Textures/ui/Ui_button_selected.png");
  Root.ForEach<Window>(x =>
  {
    x.Caption = "Sydewinder";
    x.Background.Source = ResourceManager.ImageFromFile(backgroundImageURL);
    x.CaptionHeight = 40;
    x.RectTransform.Size = new Point(TEXTURE_RESOLUTION, TEXTURE_RESOLUTION);
    x.RectTransform.Alignment = Alignment.Center;
    // Apply common style to all buttons within the window.
    x.ForEach<Button>(b =>
    {
      b.RectTransform.Size = new Point(300, 120);
      b.Ctrl.Text.Height = 48;
      b.BackgroundImageUrl = buttonBackgroundURL;
      b.BackgroundImageInvertedUrl = buttonHighlightedURL;
      b.Ctrl.OnPressed += () => Audio.Play("menu_select");
      b.Ctrl.OnFocusEnter += () => Audio.Play("menu_switch");
    });
  });
 }

Навигация по главному меню

После нажатия кнопки Рейтинг кнопку, камера плавно перемещается в сторону Рейтинг плоскости и возвращается в плоскость главного меню, когда Назад кнопка нажата.

private static void StartCameraMove(int seconds, Vec3 finalPosition, Vec3 finalFordwardDirection)
{
  _startPosition = Camera.Position;
  _endPosition = finalPosition;
  _startDirection = Camera.ForwardDirection;
  _endDirection = finalFordwardDirection.Normalized;
  _animationProgress = 0;
  _animationSpeed = 1 / (Math.Max(seconds, 0.01f));
}
 
public override void OnUpdate()
{
  if(_animationProgress < 1.0f)
  {
    // No need to clamp it because Lerp is already clamped.
    _animationProgress += _animationSpeed * FrameTime.Delta;
    Camera.Position = Vector3.Lerp(_startPosition, _endPosition, _animationProgress);
    Camera.ForwardDirection = Vector3.Lerp(_startDirection, _endDirection, _animationProgress);
  }
}

HUD — Обзор

Когда вы играете в игру Проекционный дисплей (HUD) показывает статус текущей игровой сессии.

В отличие от MainMenu класс, Hud класс наследует от Component class и не отображается как материал 3D-объекта. Вместо этого оно всегда отображается поверх текущего экрана и независимо от положения и уровня камеры.

HUD управляется Hud класс. Он также несет ответственность за Игра приостановлена и Игра окончена параметры диалога. Все элементы UI инициализируются с помощью InitializeMainHud метод и отображаются или скрываются в зависимости от состояния игры.

Подобно главному меню, HUD представляет собой иерархическую коллекцию элементов UI с Canvas класс, используемый как самый верхний элемент. Они расположены в следующей иерархии:

  • Холст
    • Панель (Верхняя часть экрана)
      • Текст (Оценка)
      • Текст (Уровень)
    • Панель (Нижняя часть экрана)
      • Текст (Энергия)
      • Текст (Оружие)
    • Панель (Диалоговое окно «Игра приостановлена»)
      • Текст (Игра приостановлена)
      • Кнопка (Возобновить игру)
      • Кнопка (Выйти из игры)
    • Панель (Диалог «Игра окончена»)
      • Текст (Игра окончена)
      • Текст (Ваше имя:)
      • TextInput
      • Кнопка (OK)

Игра приостановлена и Игра окончена параметры диалога управляются ссылками на соответствующие Panel элементы в сочетании с Показать/Скрыть методы.

public class Hud : Component
{
  //...
  private Panel _gamePausedDialogPanel;
  //...
 
  private Hud(SceneObject root, Color backgroundColor, Color foregroundColor)
  {
    //...
    _gamePausedDialogPanel = CreateDialogPanel();
    //...
  }
 
  public void ShowGamePauseDialog()
  {
    // Show mouse cursor
    Mouse.ShowCursor();
    _gamePausedDialogPanel.Active = true;
  }
  
  public void HideGamePauseDialog()
  {
    // Hide mouse cursor
    Mouse.HideCursor();
    _gamePausedDialogPanel.Active = false;
  }
}

HUD Обновления

Чтобы обновить счет, уровень, энергию или название оружия во время игры, Hud класс внутренне хранит ссылки на Text элементы и предоставляет различные методы для установки соответствующих значений. Эти методы вызываются в игровом цикле.

public class Hud : Component
{
  //...
  private Text _scoreText;
  //...
 
  public void SetScore(double score)
  {
    Score = score;
    _scoreText.Content = string.Format("Score: {0}", Score.ToString("N0", CultureInfo.GetCultureInfo("de-DE")));
  }
  //...
}
 
public class SydewinderApp : Application
{
  //...
  public virtual void OnUpdate()
  {
    //...
    Hud.CurrentHud.SetScore(_gameData.Score);
    //...
  }
  //...
}
