CRYENGINE предоставляет мощную систему моделирования физики, которая позволяет объектам вести себя так же, как объекты реального мира. Дополнительные параметры, определяющие, как объект должен вести себя при движении или столкновении, также могут быть добавлены к физическому объекту.

Сайдевиндер использует физическую систему для перемещения игрока, врагов и снарядов оружия по игровому уровню, а также для обнаружения столкновений между снарядами, окружающей средой, игроком и врагами. Для более глубокого понимания рекомендуем вам прочитать Физические объекты статья.

Физическая реализация сущности

Функция сущности Physicalize включает физику конкретного объекта, используя прокси для его моделирования. Прокси-объект — это упрощенная версия геометрической модели, используемой в игре. Чтобы позволить CRYENGINE рассчитывать физически правильное движение и столкновения, необходимо установить минимальное количество свойств.

// Create a new Entity.
var entity = Entity.Spawn(position, rotation, scale);

// Add a geometry to the Entity.
entity.LoadGeometry(0, EnemyTypes[type].Geometry);

// Physicalize the Entity as a rigid type.
entity.Physics.Physicalize(new RigidPhysicalizeParams
{
  Density = 1,
  Mass = 0
});

Либо Density или Mass необходимо указать свойство. Другое значение автоматически вычисляется с использованием соотношения масса = плотность * объем.

Сущности можно физически реализовать как несколько типов, изменив тип PhysicalizeParams, например, изменив его на StaticPhysicalizeParams или LivingPhysicalizeParams. Более подробную информацию о различных типах физики можно найти на странице Страница типов физических объектов.

Физическое движение

Обычный способ перемещения объекта внутри CRYENGINE — указать его физическое поведение, чтобы движок перемещал объект соответствующим образом. Это можно сделать, задав свойства PhysicsEntity Сущности.

// Retrieve the PhysicsEntity from the Entity.
var physics = Entity.Physics;
if(physics.PhysicsType != PhysicalizationType.None)
{
  // Assign a value to the Velocity.
  physics.Velocity = new Vector3(x, y, z);
}

Скорость необходимо установить только один раз fили предметы, летящие по прямой. Это идеально подходит для снарядов, выпущенных из оружия, такого как пистолет по умолчанию в Сайдевиндере.

Однако любой объект с переменной скоростью или объект, который может периодически менять свое направление, необходимо обновлять всякий раз, когда это необходимо.

Столкновение

Обнаружение столкновений является важной частью игры Sydewinder. Он используется для обработки снарядов, поражающих игрока и вражеские корабли, или для определения попадания в геометрию уровня. В Sydewinder один или оба объекта, попавшие в столкновение, будут уничтожены, но неуничтоженные объекты могут двигаться по исходному пути.

Чтобы отреагировать на столкновения, Сущность может override OnCollision метод для получения сообщения всякий раз, когда происходит столкновение с этим объектом. Если произойдет коллизия, метод будет вызван с CollisionEvent который содержит больше информации о столкновении, например об объектах, участвующих в столкновении. Например, для Сайдевиндера Player класс, мы проверяем, есть ли Tunnel или DefaultAmmo Объект поражен и обрабатывает столкновение в зависимости от типа.

    protected override void OnCollision(EntitySystem.CollisionEvent collisionEvent)
    {
      // Determine wether the Player is the source or the target of the collision.
      var hitEntity = collisionEvent.PhysicsObjects[1].OwnerEntity;

      if(hitEntity != null)
      {
        var component = hitEntity.GetComponent<DestroyableBase>();

        // Handle player collision with lower tunnel by changing the player location.
        if(component is Tunnel)
        {
          // As the only colliding tunnel is a lower tunnel, always change player position.
          Vector3 playerPos = Entity.Position;
          Entity.Position = new Vector3(playerPos.x, playerPos.y, 75);
          return;
        }

        // Don't let player collide with own projectiles.
        var defaultAmmo = component as DefaultAmmo;
        if(defaultAmmo != null && !defaultAmmo.IsHostile)
        {
          return;
        }

        ProcessHit(component is Door);
      }
    }
