Интегрированная документация

Интегрированная документация — это набор доступных вам практик и систем, целью которых является документирование инструментов и максимальное руководство пользователем в процессе его открытия. Это значительно упрощает использование инструментов без необходимости открывать настоящую страницу документации. Последний шаг — убедиться, что полная страница документации связана с инструментом через справочную систему.

Мы рассмотрим различные системы, доступные для этого.

Подсказки

Всплывающие подсказки — это самая простая и практичная форма интегрированной документации.

Это текстовые наложения, которые появляются при наведении курсора мыши на интерактивный элемент UI. Используйте их щедро, по сути, наши Рекомендации по пользовательскому опыту диктуют, что каждый интерактивный элемент, поддерживающий всплывающую подсказку, должен иметь ее. Обратной стороной является то, что всплывающая подсказка не должна быть слишком long и, следовательно, иногда может не содержать подробностей или быть двусмысленной.

Перетаскивание-подсказка

Подсказка перетаскивания — это специальная система Sandbox, которая позволяет отображать всплывающую подсказку, которая следует за мышью во время операции перетаскивания.

Цель этой всплывающей подсказки — сообщить пользователю, что будет вызвано действием перетаскивания, а в сочетании с «невозможностью перетаскивания» изменений курсора значительно упростить обнаружение функции перетаскивания, чем догадки.

Подсказка перетаскивания доступна из CDragDropData используется в нашей системе перетаскивания. Просто вызовите CDragDropData::ShowDragText в обработчике падения, чтобы активировать его.

Пожалуйста, используйте это для каждого действия перетаскивания.

F1 — перейти к документации

Клавиша F1 (ярлык по умолчанию) или меню справки перенаправят пользователя на соответствующую страницу документации, открыв ее в браузере по умолчанию. Эта система чрезвычайно ценна и ее следует добавлять к каждому новому инструменту. Обратите внимание, что эта система не обязательно должна быть ограничена инструментом, и каждый Qt Widget при необходимости может указать свою собственную страницу документации.

Вот как подключить виджет к его ссылке на документацию:

  • Если виджет представляет собой CEредактор или наследуется от CEditor:
    • Обратите внимание, что CEditor также ищет ссылку на документацию из файла JSON для большинства редакторов, встроенных в CryEngine. В этом случае необходимо редактировать только файл JSON.

//This virtual method will be called by CEditor if the help command is invoked
void OnHelp() final
{
  QDesktopServices::openUrl("www.example.com");
}
  • Любой QWidget: должен реализовывать обработку пользовательского SandboxEvent

void ExampleWidget::customEvent(QEvent* event)
{
  if (event->type() == SandboxEvent::Command)
  {
    CommandEvent* commandEvent = static_cast<CommandEvent*>(event);

    const string& command = commandEvent->GetCommand();
    if (command == "general.help")
    {
      QDesktopServices::openUrl("www.example.com");
    }
  }
  else
  {
    QWidget::customEvent(event);
  }
}
