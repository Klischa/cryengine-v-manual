Введение

В CRYENGINE 5.1 мы улучшили общее качество кода и применили новый единый стандарт кодирования для всех модулей Engine. На этой странице описан наиболее удобный способ обновления предыдущей версии Engine (3.8.x) до CRYENGINE 5.1 или более поздней версии кода.

Автоформатирование в Visual Studio

Интегрируя снимать корку с помощью Visual Studio можно автоматически форматировать ваш код в соответствии с рекомендациями каждый раз, когда вы сохраняете свою работу. Это устраняет любые усилия, необходимые для соблюдения стандарта.

Шаг 1: Подготовка

Вы можете найти инструмент в корне/Code/Tools/uncrustify.

Получить и сохраните его во временном месте. Откройте его и измените исполняемый файл и параметры пути, чтобы они соответствовали каталогу установки CRYENGINE (всего 4 места).

Шаг 2. Загрузите расширение Code Beautifier.

Загрузите и установите «Code Beautifier» со следующей страницы: Расширение Code Beautifier для Visual Studio 2015.

Шаг 3: Откройте параметры улучшения кода

Шаг 4. Импортируйте настройки

Нажмите кнопку Импортировать... кнопку и загрузите свой индивидуальный CodeBeautifierSettings.xml.

Шаг 5. Проверка настроек

Убедитесь, что путь к приложению и путь к аргументам действительны, затем Сохранить.


Теперь вы готовы!

Теперь вы можете форматировать документы из меню, как показано в шаге 3 (или вы можете привязать это к горячей клавише/создать кнопку на панели инструментов с функциями настройки VS по умолчанию).
