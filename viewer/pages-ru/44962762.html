Нижеследующее не является полным списком изменений CRYENGINE 5.5 C++ API, а скорее указывает на наиболее важные изменения, о которых программистам необходимо знать.

Оглавление

Уведомления об устаревании

Этот выпуск официально устарел

  • CryLobby / Система лобби — заменен новым плагином CryGamePlatform, охватывающим API Steam и PSN. Xbox One последует за ним в будущем. Система лобби будет удалена в будущем выпуске.

Рендерер

  • r_Fullscreen и CVar r_FullscreenWindow заменены на r_WindowType.
    • Использование: r_WindowType [0=обычное окно/1=окно без полей/2=полноэкранный режим без полей/3=эксклюзивный полноэкранный режим].
  • Ключ Windows теперь включен в движке по умолчанию. Используйте g_disableWinKeys=1, чтобы вернуться к предыдущему поведению. Это исправляет невозможность перемещения окна запуска с помощью Windows и клавиш со стрелками.

Система сущностей и схема

  • Компонентам сущностей больше не требуется функция IID.

Плагины

  • Интерфейс ICryPlugin был перенесен в Cry namespace и переименован в IEnginePlugin.
  • Плагинам больше не нужно реализовывать функции GetName и GetCategory, поскольку были добавлены реализации по умолчанию.

Обновления

Поддержка обновлений плагинов была переработана, чтобы предоставить больше возможностей для подключения к различным системным событиям. Функция OnPluginUpdate была заменена несколькими различными обратными вызовами и соответствующей записью перечисления:

Чтобы включить конкретное обновление, вызовите IEnginePlugin::EnableUpdate с конкретной записью перечисления шагов.

Удаление игрового фреймворка

Game Framework, также известный как CryAction, в настоящее время удаляется, а важные части перемещаются в другие части движка.

Изменения инициализации

Game Framework ранее отвечал за запуск движка:

Предыдущий процесс инициализации

  1. Лаунчер запускается путем ручной загрузки CryAction.dll, поиска адресов точек входа и т. д.
  2. Создан экземпляр IGameFramework (gEnv->pGameFramework).
  3. Платформа игры загружает CrySystem.dll
  4. Платформа игры создает экземпляр ISystem (gEnv->pSystem).
  5. Система инициализирует другие модули двигателя

Новый поток инициализации

  1. Лаунчер запущен
  2. Экземпляр ISystem автоматически создается путем вызова новой функции CryInitializeEngine, что приводит к загрузке CrySystem.dll и инициализации экземпляра ISystem.
  3. Система инициализирует другие модули движка, включая игровой фреймворк.

Это приводит к возможным проблемам с существующим кодом, в котором предполагалось, что игровая среда в определенный момент существует. В этом случае исправьте свой код, переместив использование IGameFramework в системное событие ESYSTEM_EVENT_GAME_POST_INIT.

Обновить изменения

Game Framework ранее отвечала за обновление движка. Теперь это было изменено: управление каждым кадром перенесено на CrySystem. Это изменение не должно повлиять на существующий код.

Разное

  • eCryM_Game был удален, измените существующие ссылки на eCryM_EnginePlugin для новых проектов, в противном случае — на eCryM_LegacyGameDLL.
