Обзор

Бьющееся стекло — наиболее распространенный тип бьющегося стекла, позволяющий создавать стекло, которое игрок может разрушить.

Загрузите пример макс-файла с различными настройками стекла. glass_example.rar. Извлечь в: GameSDK\Objects\props\glass_example

Общие рекомендации по настройке

Настройка в 3DS Max

  • Используйте фиктивный помощник в качестве узла экспорта (=корень объекта) — его имя будет использоваться для имени cgf.
  • Для правильной работы каждое окно (стекло) должно быть отдельным узлом. Не объединяйте узлы.
  • Следите за тем, чтобы общее количество полигонов не превышало 200 треугольников. Если вам нужно больше треугольников в стеклянном объекте, создайте отдельный объект.
  • Стекла должны быть обращены в одну сторону. если угол между панелями слишком велик (>10 градусов), разделите их на отдельные объекты.
  • Назовите свой бьющийся стеклянный предмет. "BreakGlass_xx" (xx = 01,02,03,...) для упрощения отладки активов.
  • Создайте материал Multi/Sub-Object для всего объекта и уникальный коврик ID для бьющихся стеклянных объектов. Все грани бьющегося стеклянного предмета должен назначьте этот мат ID для правильной работы.

  • Свяжите узел бьющегося стекла напрямую с узлом экспорта.
  • Совместите ось узла бьющегося стекла с узлом экспорта (помощник по корневому шаблону) и сбросьте преобразования.
  • Включите физику для стеклянных объектов. Mat ID: в разделе «Физизация» включите Физически и установите его на По умолчанию.
  • Не назначайте этот коврик ID какой-либо другой части вашей сетки, кроме узла бьющегося стекла!

  • Не создавайте LOD или геометрию столкновений для вашего разрушаемого стеклянного узла.
  • Будьте особенно осторожны, чтобы не назначать стеклянный коврик ID сетке рендеринга или ее LOD.

Настройка в Sandbox

Выберите один из этих типов поверхности, чтобы включить функцию бьющегося стекла в игре или Sandbox:

  • mat_glass_breakable_thin_small
  • mat_glass_breakable_thin_large
  • mat_glass_breakable_safetyglass_small
  • mat_glass_breakable_safetyglass_large
  • mat_glass_unbreakable_roosevelt
  • mat_glass_unbreakable_spiderweb

  • Поверхность процедурно изменится на другой тип. Нет необходимости создавать второй материал "_broken".

Полностью бьющееся стекло

Типы поверхностей, которые поддерживают эту функцию:

  • mat_glass_breakable_thin_small
  • mat_glass_breakable_thin_large
  • mat_glass_breakable_safetyglass_small
  • mat_glass_breakable_safetyglass_large

..._small следует использовать для стеклянных плоскостей меньшего размера, к которым игрок может приблизиться (более высокая тесселяция, более высокая детализация кусков стекла, более дорогая)
..._large следует использовать для больших стеклянных плоскостей, к которым игрок не может подойти слишком близко (меньшая тесселяция, меньшая детализация кусков стекла, дешевле)

Используйте для окон, которые игрок может разрушить и пройти через них, например, стеклянные окна на первом этаже помещений, окна автомобилей и т. д. Полностью исчезнут при выстреле.

Ограничения

  • Бьющееся стекло должно иметь простую форму, практически не иметь кривизны — в идеале коробки или плавающие плоскости с небольшой мозаикой. Старайтесь поддерживать Polycount ниже 100 трис на стеклянную оболочку.
  • Количество уникальных разбиваемых стеклянных узлов на объект не должно превышать 5.
  • Геометрические объекты не поддерживают бьющееся стекло. Поместите любой объект с бьющимся стеклом как базовый объект с отключенным жестким телом или как обычный cgf.
  • Бьющееся стекло не поддерживает uvBorders в вашей текстуре. Он должен быть сопоставлен с одной уникальной областью вашей текстуры. При выстреле каждая УФ-оболочка разрушается сама по себе.
  • Наличие в материале материала ID, содержащего поверхность бьющегося стекла, приведет к нарушению слияния статообъектов на объекте. Для сочлененных бьющихся предметов, которые необходимо объединить во время выполнения, вам необходимо разделить бьющееся стекло на отдельный cgf, используя собственный mtl. (Сверьтесь с e_debug_draw 1 - Желтая рамка, объединено = хорошо, синяя рамка, не объединено = плохо).
  • Если ваш хрупкий стеклянный объект инкапсулирован прокси-сервером вашей сетки рендеринга, обязательно установите для прокси-серверов тип прокалываемой поверхности (g_bulletpenetrationdebug 1).
  • Вашему стеклянному узлу должен быть назначен один физический matID. Любой другой узел рендеринга не должен содержать физический matID с назначенным типом поверхности бьющегося стекла.

Устранение неполадок/часто задаваемые вопросы

Вопрос: Стекло исчезает или перемещается при выстреле.

A: Отцентрируйте точку поворота на помощнике по экспорту и сбросьте преобразования на узлах стекла разрыва.

Вопрос: Я получаю следующее сообщение об ошибке: «Ошибка в расчете физической сетки, узел «Объединен» в файле [путь] содержит как физикализованную геометрию рендеринга, так и физический прокси».

О: Убедитесь, что в настройках экспорта отмечен флажок «Объединить все узлы» NOT. Нод стекла и сетка рендеринга должны быть связаны с манекеном, который экспортируется через «Экспорт файла для каждого узла».

Вопрос: Стекло не разбивается при выстреле.

О: Убедитесь, что в 3dsmax для материала установлено значение «Физизированный по умолчанию». Проверьте, отображаются ли стеклянные предметы в физической форме при p_draw_helpers включен.

Если нет, выполните повторный экспорт с правильными настройками физической реализации, пока он не появится в физическом виде. Проверьте, размещен ли объект как Geom. Объект. Если да, измените его на кисть или базовый объект с отключенным жестким телом.

Вопрос: Стекло по-прежнему не разбивается при выстреле.

О: Убедитесь, что в submatID установлен тип разрушаемой поверхности. Используйте любой из mat_glass_breakable_... для тестирования.

Убедитесь, что для прокси, инкапсулирующего Glass, установлен тип прокалываемой поверхности (g_bulletPenetrationDebug 1)

Вопрос: При съемке стекла на консоли отображается «геометрия недостаточно тонкая, разлом запрещен».

О: Убедитесь, что ваш узел бьющегося стекла содержит только один материал ID. Если да, то ваша геометрия слишком сложна или ориентирована на слишком много разных направлений.

Разделите геометрию breakGlass на более мелкие части и создайте дополнительные узлы breakGlass.

Вопрос: Мой объект исчезает при стрельбе по стеклу.

О: Лицу вашей сетки рендеринга присвоен идентификатор материала бьющегося стекла. Вашему узлу break_Glass назначено более одного идентификатора материала.

Вопрос: Несколько стекол разбиваются, когда я стреляю в одно.

О: Физический прокси был расположен слишком близко друг к другу и был оптимизирован. Попробуйте поместить их в отдельные объекты.

Вопрос: Я получаю сообщения об ошибках «Физическая сетка имеет слишком много островов» и «Геометрия не подходит для разрушения, нарушение запрещено».

О: Убедитесь, что вы не настроили физический прокси на использование типа поверхности «Стекло».

Физический прокси следует создавать только для сетки рендеринга без стекла, такой как рама. Никогда не следует использовать стеклянную (бьющуюся) поверхность.
