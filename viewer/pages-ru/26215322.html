Обзор

Кэшированные тени — это очень эффективный метод оптимизации, который используется для уменьшения количества вызовов отрисовки теней и в то же время увеличения дальности отбрасывания и приема теней. Начиная с определенного номера каскада, последующие теневые каскады могут быть отображены один раз, а затем сохранены в памяти. CRYENGINE по-прежнему выбирает тени из кэшированных каскадов, но после инициализации кэшированного каскада больше не требуется вызовов отрисовки для его обновления. Эта стратегия позволяет long перемещать дальние тени практически бесплатно.


Визуализация теневого каскада: начиная с синего каскада, все последующие каскады кэшируются, обеспечивая дальность покрытия тени более 16 км.

Размещение и обновление

Кэшированные каскады теней по умолчанию центрируются вокруг камеры и автоматически центрируются (и обновляются), когда камера приближается слишком близко к границе каскада.

Потенциально это может вызвать небольшую задержку, поскольку за один кадр необходимо отрисовать большое количество элементов, отбрасывающих тени. Однако на практике это пока не вызвало никаких проблем. Для удобства в консоли каждый раз при обновлении кэшированного теневого каскада отображается предупреждающее сообщение.

Однако автоматическое размещение можно переопределить с помощью потокового графа. Окружающая среда:RecomputeStaticShadows node принимает минимальные/максимальные позиции ограничивающей области в мировом пространстве для первого кэшированного каскада. Ограничительные рамки для последующих кэшированных каскадов представляют собой масштабированные версии предыдущих каскадов и основаны на NextCascadeScale множитель. Триггер ввод вызывает обновление всех кэшированных теневых каскадов.

Динамические тени на расстоянии

Кэшированные тени очень хорошо работают с объектами static, однако тени динамических объектов не обновляются при перемещении. Это может быть более или менее заметно в зависимости от случая – например, для большой ветряной мельницы ошибка может быть совершенно очевидной на среднем расстоянии. Чтобы обойти эту проблему, динамические объекты можно выборочно исключать из кэша и отображать в стандартных каскадах. Накладные расходы на производительность при включении этой функции для ограниченного числа объектов обычно довольно низкие.

Чтобы включить динамические тени на расстоянии для объекта, включите опцию DynamicDistanceShadows на сущности.

Примечания

  • Кэшированные тени требуют довольно много памяти: конфигурация по умолчанию требует примерно 130 MB видеопамяти.
  • Разрешения для отдельных кэшированных каскадов можно установить через CVar (см. ниже):
    • При автоматическом размещении выбранное разрешение в сочетании с желаемой плотностью пикселей мирового пространства (полученной из приблизительной схемы логарифмического разделения) определяет область мирового пространства, охватываемую каждым каскадом. Таким образом, понижение разрешения уменьшит диапазон затенения для каждого каскада, но при этом сохранит качество теней.
    • При ручном размещении доступное разрешение равномерно растягивается по всему каскаду. Таким образом, более низкое разрешение приведет к снижению качества теней при том же покрытии мирового пространства.
  • Прежде чем запускать обновление, убедитесь, что все ваши шейдеры скомпилированы, иначе некоторые объекты могут не отображаться в кэшированных картах теней.

Связанные переменные

  • r_ShadowsCache: Кэшировать все каскады солнечных теней выше CVar 0 = нет кэшированных каскадов, 1 = кэшировать первый каскад и выше, 2 = кэшировать второй каскад и выше.

  • r_ShadowsCacheResolutions: Разрешение кэшированных каскадов.

  • r_ShadowsCacheFormat: Формат хранения кэшированных карт теней: 0=D32: 32 бита float, 1=D16: 16 битное целое число.

  • e_ShadowsCacheUpdate: Запуск обновлений кэшированных карт теней: 0=нет обновления, 1=одно обновление, 2=непрерывные обновления.

  • e_ShadowsCacheObjectLod: LOD, используемый для рендеринга объектов в кэшированные карты теней.

  • e_ShadowsCascadesDebug: Включает режим просмотра отладки: 0 или 1, где 1 = включить (как показано выше).

  • e_DynamicDistanceShadows: включает поддержку отбрасывания динамических теней выбранными объектами.
