Поддержка IME в UI

Некоторые языки (например, китайский) имеют экранные помощники и различные функции раскладки клавиатуры, помогающие вводить текст.
Эта функция также поддерживается Scaleform.

Пожалуйста, обратитесь к Включение IME в коде чтобы узнать, поддерживает ли ваша версия IME.

Проверка поддержки IME

Чтобы проверить доступность поддержки IME, воспользуйтесь главным меню примера проекта GameSDK в панели запуска игры.
Перейдя в меню «Мультиплеер», а затем «Хост-сервер», у вас появится несколько текстовых полей для ввода текста.

В зависимости от текущих языковых настроек OS вам будут предложены различные варианты.

Обновление Flash-файлов для поддержки IME

В GameSDK/Libs/UI/FlashAssets/cryflash папка будет файлом LanguageBar.as это оборачивает функциональность языковой панели.
Это позволяет легко реализовать поддержку этой функции в других Flash-файлах.

Платформа UI по умолчанию активирует языковую панель при записи текстового поля.

Примечание: Файл списка кандидатов IME создан для импорта из библиотеки шрифтов по умолчанию SDK (HUD_Font_LocFont.gfx).
Из этого файла он прочитает Font_Body Символ ActionScript для отображения глифов.
