Обзор

Анимации запускаются слоями:

Всего у нас доступно 16 слоев анимации.

Слой 0 является особенным, поскольку он считается базовым слоем. Слой 0 поддерживает пространства смешивания и извлечение движения.

Анимации смешиваются путем одновременного запуска их на разных слоях. Слои, не имеющие анимации, не оказывают никакого эффекта (например, анимацию можно иметь только на слоях 0 и 6).

Базовый слой обычно содержит анимацию всего тела (влияющую на большинство суставов и содержащую движение), тогда как более высокие слои обычно воспроизводят override или аддитивную анимацию части тела (влияющую только на подмножество суставов).

Очереди перехода

При запуске анимации в слое поведением по умолчанию является смешивание текущих анимаций в этом слое (уменьшение их текущего веса до 0) и удаление из очереди, когда их вес достигает 0, а также смешивание новой анимации (увеличение ее веса с 0 до 1).

Это смешивание анимаций и их исчезновение обрабатывается компонентом, называемым очередью перехода.

Очереди перехода ведут себя как FIFO (Первым пришел — первым ушел) очереди.

Каждый слой анимации имеет свою собственную очередь перехода.

Очередь перехода также содержит информацию о состоянии всех воспроизводимых в ней анимаций (время, вес, флаги).

Анимации также будут удалены из очереди, как только они будут полностью воспроизведены один раз. Это поведение по умолчанию можно изменить, запустив анимацию с флагом цикла (CA_LOOP_ANIMATION) или флагом повторения последней клавиши (CA_REPEAT_LAST_KEY). Эти флаги заставят анимацию оставаться в очереди до тех пор, пока на том же слое не будет запущена новая анимация.

Код

Связь со слоями анимации и очередями переходов персонажа всегда осуществляется через интерфейс ISkeletonAnim.

Чтобы получить интерфейс ISkeletonAnim, вызовите функцию GetISkeletonAnim() для экземпляра вашего персонажа (ICharacterInstance).

Запуск анимации

Анимация запускается на слоях с помощью функций StartAnimation или StartAnimationById. 

ISkeltonAnim& skeletonAnim = ...;
 
CryCharAnimationParams params;
params.m_nLayerID = 2;
params.m_nFlags |= CA_LOOP_ANIMATION;
params.m_fTransTime = 0.5f;
 
// Starting the animation by id. Alternatively use StartAnimation to start an animation by name.
skeletonAnim.StartAnimationById(animationId, params);

В приведенном выше примере мы запрашиваем запуск циклической анимации на слое 2 и хотим, чтобы она полностью смешалась за 0,5 секунды.

Подробная информация обо всех возможных параметрах и флагах, доступных для CryCharAnimationParams можно найти в файле CryCharAnimationParams.h в CryCommon.

Остановка анимации

Чтобы плавно смешать анимацию в слое, мы можем использовать функцию StopAnimationInLayer:

ISkeltonAnim& skeletonAnim = ...;
 
// Blend out all animations in layer 2 in 0.5 seconds:
skeletonAnim.StopAnimationInLayer(2, 0.5f);

Чтобы заставить TransitionQueue на определенном слое немедленно очистить всю анимацию:

ISkeltonAnim& skeletonAnim = ...;
 
skeletonAnim.ClearFIFOLayer(layerId);

Чтобы немедленно очистить все TransitionQueues во всех слоях, мы можем использовать StopAnimationsAllLayers.

ISkeltonAnim& skeletonAnim = ...;
 
skeletonAnim.StopAnimationsAllLayers();

Проверка очереди перехода

Чтобы получить количество анимаций в очереди перехода, мы можем использовать GetNumAnimsInFIFO.

Затем мы можем получить анимацию из очереди с помощью GetAnimFromFIFO.

Последняя анимация в очереди (numAnims - 1) всегда является последней анимацией, которая была отправлена, и в большинстве случаев это анимация, с которой пытается вписаться очередь перехода. В некоторых разделах кода ее можно называть «верхней» анимацией.

GetAnimFromFIFO получает структуру CAnimation, содержащую состояние определенной анимации в очереди перехода.
