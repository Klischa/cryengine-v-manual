Описание

Состояние тега представляет собой комбинацию теги из определение тега. Состояния тегов могут быть представлены списком тегов, разделенных символами «+». Например, «приседание+пистолет» определяет состояние тега, объединяющее теги «приседание» и «пистолет».

Есть много разных мест, где встречаются подобные наборы тегов. Вот наиболее часто используемые из них и как их обычно называют:

Глобальный TagState

В любой момент в игре можно установить глобальные теги, описывающие текущее состояние персонажа. Они называются глобальным состоянием тега. Обычно они содержат глобальную информацию о состоянии, такую ​​как позиция («стоять», «плавать» и т. д.), тип персонажа, какое оружие экипировано и т. д.

Для программистов: глобальное состояние тега — это теги член контроллера действий SAnimationContext, который вы можете найти с помощью IActionController::GetContext().

Фрагмент тегового состояния

Каждый фрагмент помечается тегами в Mannequin Браузер фрагментов. Это могут быть глобальные теги или Теги, специфичные для FragmentID (фрагтеги).

Они используются для поиска фрагментов во время выбор фрагмента.

Теги области действия

Теги, связанные с областью, которая настроена в Файл определения контроллера (xxxControllerDefs.xml). Все фрагменты, воспроизводимые в этой области, требуют установки этих тегов. Обычно он содержит только один тег. Рекомендуется использовать определенное соглашение об именах для тегов области, в отличие от других тегов, например, добавляя к ним префикс слова «Область».
