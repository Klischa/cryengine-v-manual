Обзор

Абстракция «Достижения» обрабатывает статистику и достижения (например, трофеи на PlayStation).

Чтобы облегчить работу с интерфейсом, была выбрана локальная конфигурация достижений с помощью файла XML; вы можете заполнить файл XML достижениями и статистической информацией для конкретной платформы. Он будет прочитан системами Flow Graph и Schematyc (Experimental) для создания специализированных узлов, которые вы сможете использовать в своих графиках.

  • Правильное заполнение файла конфигурации достижений необходимо, если вы хотите использовать плагин GamePlatformNodes (Flow Graph/Schematyc Nodes и кеш сведений о достижениях).
  • Поскольку функциональность достижений различается в зависимости от платформы, мы рекомендуем прочитать документацию поставщика платформы о том, как на ней реализованы достижения и статистика.

Конфигурация достижения

Файл данных о достижениях XML (statistics.xml) может храниться где угодно (относительно вашего проекта). Активы каталог), используя переменную g_PlatformStatsFile.

g_PlatformStatsFile

Позволяет указать путь (относительно Активы каталог), где находится statistics.xml Файл данных достижений должен быть расположен.

  • Использование: g_PlatformStatsFile <путь к файлу>
  • По умолчанию: лibs/конфигурация

Как видите, некоторые платформы, такие как Steam, используют статистику как метод записи данных; другие платформы могут иметь свои собственные реализации и методы записи статистических данных и использования этих данных для запуска разблокировки достижений.

На большинстве платформ достижения можно присуждать напрямую, а в некоторых случаях отменять. Обычно предпочтительно разрешать разблокировку достижений только авторитетному серверу, чтобы пользователь не мог обойти требования и разблокировать достижения, которые он не получил законным путем.

Дополнительную информацию см. в документации соответствующей платформы. о том, как это реализовать и является ли это жизнеспособным вариантом.

Функции службы достижений

Скачать

Пытается загрузить текущие статистические данные из службы удаленной платформы.

Получить

Извлекает float или целочисленное значение статистики, используя имя API или ID.

GetAchievement

Получает достижение, соответствующее указанному имени API или ID.

ResetAchievements

Сбрасывает все достижения, связанные с локальным пользователем.

ResetStatistics

Сбрасывает все статистические данные, связанные с локальным пользователем.

Установить

Устанавливает float или целочисленное значение статистики, используя имя API или ID.

Загрузить

Пытается загрузить текущие статистические данные в сервис удаленной платформы.

Конкретные функции достижения

Реализация конкретной функции достижения различается в API, Flow Graph и Schematyc:

  • В API вы получаете достижение непосредственно на основе его имени или ID, а затем также напрямую вызываете действия над ним (например, для вручения достижения).
  • В Flow Graph узлы генерируются в категории узлов GamePlatform::Stats::[Platform]. Затем вы можете инициировать определенные действия, активируя определенные контакты на узле.
  • В Schematyc (Experimental) достижение — это тип данных (аналог API). Выбор типа данных генерируется с помощью файла конфигурации достижения, поэтому доступны только допустимые параметры. Затем вы можете вызвать служебные функции и передать им достижение, над которым хотите работать.
Flow Graph и Schematyc предоставляют дополнительные данные, которые хранятся в файле конфигурации. По умолчанию GamePlatformPlugin API не знает о файле конфигурации и, следовательно, не имеет возможности предоставить эти данные. Однако плагин GamePlatformNodes имеет интерфейс, из которого вы можете получить эти данные, если хотите сделать это программно.

Достичь

Награждает достижение в сервисе платформы, если оно еще не присуждено.

GetName

Получает название достижения.

GetProgress

Получает текущее значение прогресса достижения.

IsCompleted

Возвращает true, если достижение уже было присвоено локальному пользователю.

Сброс

Сбрасывает достижение, если это возможно, на сервисе платформы.

SetProgress

Сets текущее значение прогресса достижения. Достижение разблокируется, еслиЗначение прогресса превышает максимальное значение, указанное в файле конфигурации достижения.
