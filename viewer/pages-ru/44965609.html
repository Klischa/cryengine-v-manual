Обзор

Хотя CRYENGINE поставляется с набором сочетаний клавиш по умолчанию, по-прежнему возможен высокий уровень пользовательской настройки в соответствии с потребностями проекта или отдельных пользователей. Все индивидуальные настройки можно вернуть к значениям по умолчанию с помощью Сбросить все кнопка.

Окно сочетаний клавиш

Сочетания клавиш можно найти в разделе Редактировать -> Сочетания клавиш. из строки меню главного интерфейса редактора Sandbox.

Категории в CRYENGINE, такие как «Дизайнер», «Режим редактирования», «Редактор», «Общие» и «Уровень», отображаются в окне «Сочетания клавиш». Действия, команды и ярлыки, применимые к каждой категории, могут сделать видимым/невидимым с помощью расширяемых/сворачиваемых меню — это следует за обычной стрелкой, указывающей вправо, чтобы указать свернутый набор действий, и стрелкой, указывающей вниз, чтобы указать, что действия находятся в развернутом состоянии.

На снимке экрана выше категория «Уровень» была расширена и теперь отображает соответствующие действия, команды и сочетания клавиш (в данном случае сочетания клавиш по умолчанию).

Кастомизация

Настройка очень проста и дает отдельным пользователям и руководителям большую гибкость в изменении сочетания клавиш по умолчанию, создании сочетания клавиш для действия, которое не имеет настроек по умолчанию, и/или создании нескольких сочетаний клавиш для данного действия/команды.

Настройка сочетания клавиш

В приведенном ниже примере мы собираемся дать ярлык действию Terrain Painter (в состоянии поставки для этого действия нет настроек по умолчанию).

  1. Используйте функцию поиска, чтобы найти, где находится Terrain Painter (это, безусловно, самый быстрый способ найти то, что вы ищете).
  2. Это позволит определить, в какой категории находится Terrain Painter (в нашем случае — категория «Режим редактирования»).
  3. Разверните меню, чтобы открыть Action Terrain Painter, команду и ярлык по умолчанию (в нашем случае его нет).
  4. Наведите указатель мыши на действие Terrain Painter, чтобы текст стал белым, затем переместите его вправо (под полем «Ярлык»). Затем нажмите double в поле «Ярлык» — оно откроется и можно будет редактировать.
  5. Добавьте нужный ярлык; в нашем примере мы использовали клавишу обратной косой черты.
  6. Если вы хотите добавить дополнительные ярлыки, сначала нажмите на значок + подпишите и добавьте нужный ярлык.
  7. Будьте осторожны и не добавляйте уже используемые ярлыки! Если вы добавите уже используемый ярлык, то действие/настраиваемый ярлык будет выделено красным, и при наведении курсора мыши на действие появится предупреждение о конфликте.
  8. Х Символ можно использовать для удаления записей.
    Примечание: Это не приведет к отмене индивидуальной настройки после ее сохранения. Чтобы удалить пользовательскую настройку, необходимо нажать на кнопку Сбросить все кнопка.
  9. Когда вы сделали свой выбор, нажмите на заголовок Terrain Painter — это сохранит ваши изменения (см. снимок экрана ниже).

10. Ваш новый индивидуальный ярлык будет сохранен на вашем компьютере. Keybinds.json файл, который можно найти в вашем пользователе Данные приложения папка.

Данные приложения папка является скрытой папкой. См. Восстановление настроек по умолчанию чтобы узнать, как сделать эту папку видимой.

Экспорт

Если вы хотите, чтобы другие пользователи могли делиться вашими настроенными сочетаниями клавиш, вам необходимо создать *.json файл и сохраните его — это процесс экспорта.

  1. Нажмите на Экспорт Кнопка — открывает окно «Экспорт сочетаний клавиш» (см. снимок экрана ниже).
  2. Место сохранения файла, конечно, зависит от вас или требований/правил вашей организации.
    Примечание: По умолчанию файл будет сохранен в вашем Данные приложения папка
  3. В Имя файла поле введите имя для настроенного файла сочетания клавиш.
  4. Нажмите кнопку Экспорт кнопка, чтобы сохраните файл в папке, выбранной на шаге 2.

Импорт

Процесс импорта позволяет пользователям делиться настроенными сочетаниями клавиш, которые были созданы другими или предназначены для использования только в определенных проектах и т. д. По сути, это обратный процессу экспорта, описанному выше.

  1. Откройте окно «Сочетания клавиш». Редактировать -> Сочетания клавиш...
  2. Нажмите Импорт - откроется окно «Импорт сочетаний клавиш».
  3. Перейдите в папку, в которой находится *.json нужный файл сохранен (см. скриншот ниже)
  4. Нажмите Импорт - это сохранит файл на вашем компьютере Данные приложения папка

Общие замечания по настройке и сохранению файлов

  • Привязки клавиш в настоящее время можно изменить с помощью редактора привязок клавиш, расположенного под Редактировать -> Сочетания клавиш...
  • При загрузке сочетания клавиш можно найти в одном из двух мест. А keybinds.json файл под пользователем Данные приложения или внутри текущей папки игрового проекта в каталоге Keybinds. Примечание: Пользовательские сочетания клавиш всегда будут иметь приоритет над сочетаниями клавиш проекта.
  • Настройки привязки клавиш можно экспортировать для совместного использования или использования в качестве привязок клавиш игрового проекта.
  • Также поддерживается импорт настроек привязки клавиш. Любая импортированная привязка клавиш заменит привязки клавиш в пользовательском интерфейсе. Данные приложения папку (см. выше информацию о создании Данные приложения папка видна).
