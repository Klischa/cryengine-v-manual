Обзор

Следующее руководство проведет вас через начальные шаги по передаче звука из CRIWARE ADX2 для работы с CRYENGINE с помощью Редактор управления звуком (ACE) и органы управления аудиосистемой.

Первые шаги с ADX2 в CRYENGINE

Настройка ADX2 в CRYENGINE

Включите промежуточное программное обеспечение ADX2 в консоли CRYENGINE, установив s_ImplName CVar для CryAudioImplAdx2. Альтернативно вы можете добавить следующую строку в свой system.cfg или user.cfg файл (находится в корневой папке вашего проекта CRYENGINE):

s_ImplName = CryAudioImplAdx2

Местоположение проекта ADX2 и Soundbank

Данные, специфичные для ADX2, по умолчанию расположены в следующих местах вашего проекта CRYENGINE:

  • Саундбанки
    <ProjectFolder>\assets\audio\adx2\assets
  • Проект ADX2
    <ProjectFolder>\assets\audio\adx2_project

CRYENGINE проверяет указанные выше папки, чтобы найти все элементы управления ADX2 и двоичные файлы CueSheet, которые затем отображаются в ACE.

Чтобы установить другой путь для вашего проекта ADX2, выберите Правка → Настройки опция в редакторе управления звуком меню, чтобы открыть диалоговое окно «Настройки аудиосистемы». Установите желаемый путь, введя его в поле Путь проекта поле или с помощью поля кнопка.


Настройки аудиосистемы

Проект ADX2 и двоичные файлы CueSheet

CueSheet Двоичные файлы — это ADX2-эквивалент звуковых банков, которые используются другим промежуточным программным обеспечением для аудио. При отправке игры обязательно добавляйте в папку игры только двоичные файлы CueSheet, поскольку они содержат все данные из вашего проекта ADX2.

Проверка поддерживаемой версии ADX2

CRYENGINE всегда обновляется для поддержки последней версии ADX2.

Чтобы убедиться, что вы используете правильную версию ADX2 с CRYENGINE, откройте редактор управления звуком. Версия ADX2, поддерживаемая вашей сборкой движка, указана в заголовке окна ACE, как показано ниже.

Создание звукового сигнала в CRI Atom Craft

В Atom Craft (инструмент разработки ADX2) вы можете импортировать аудиофайл в Cue, перетащив его на CueSheet. Вы также можете перетащить файл в папку с именем MaterialRootFolder в Дереве материалов, прежде чем перетащить его на CueSheet, чтобы создать Cue.

Окно FX/AISAC в Atom Craft позволяет вам настраивать различные параметры для каждого сигнала; это окно находится под окном временной шкалы.

Здание CueSheets в Atom Craft

Вам нужно создать CueSheet, чтобы интегрировать новый Cue в вашу игру.

Двоичный файл Cue Sheet, который создается во время процесса сборки, может быть загружен с помощью CRYENGINE. Чтобы построить CueSheet:

  1. Выберите Построить → Построить двоичный файл Atom CueSheet... опция в главном меню Atom Craft. Альтернативно, вы можете использовать Ctrl + Б ярлык.
  2. В открывшемся окне Build Atom CueSheet Binary установите целевую платформу под Цели панель слева.
  3. Выберите CueSheets, который вы хотите построить, из раздела CueSheets панель справа и нажмите Построить в правом нижнем углу окна.


Построить двоичный файл Atom CueSheet

Бинарные файлы CueSheet должны храниться в папке <ProjectFolder>/audio/adx2/assets чтобы их мог обнаружить ACE. Чтобы автоматизировать это:

  • В окне «Построить двоичный файл Atom CueSheet» нажмите кнопку Путь по умолчанию кнопка рядом с Выходной путь поле, чтобы установить для него путь по умолчанию. Также активируйте Настройка постпроцесса флажок.
  • Скачать crytek_audio_scripts.zip и скопируйте пользовательский скрипт в папку с именем криптоскрипты в папке вашего проекта AtomCraft.
  • Войти ./crytekscripts/move_binaries_pc.bat в Путь выполнения поле двоичного окна сборки атома CueSheet. Этот пакетный файл перемещает все общие двоичные файлы CueSheet в папку <ProjectFolder>/audio/adx2/assets папку и все локализованные звуковые банки в папку <ProjectFolder>локализация/ папка.
  • Наконец, убедитесь, что только С "acb_info" XML и С двоичным файлом ACF параметры активируются в окне «Построить двоичный файл Atom CueSheet». Используйте Сборка двоичного файла AtomCueSheet изображение выше для справки.

AtomCraft теперь должен собирать все двоичные файлы CueSheet в правильном месте.

Подключение элементов управления ADX2 к элементам управления аудиосистемы


ACE

В ACE перечислены все элементы управления ADX2, содержащиеся в вашем проекте CRI Atom Craft, а также все сгенерированные двоичные файлы CueSheet. Эти элементы управления и двоичные файлы CueSheet необходимо подключить к аудиосистеме CRYENGINE, прежде чем их можно будет интегрировать в ваш уровень.

Для этого:

  1. Создайте новую библиотеку на панели управления аудиосистемой ACE;
  2. Перетащите элементы управления ADX2 во вновь созданную библиотеку. CRYENGINE автоматически создаст соответствующие элементы управления аудиосистемой, назвав их в честь аналогов ADX2.

Можно создать два типа элементов управления аудиосистемой: триггеры и предварительные загрузки; Триггер используется для вызова сигнала ADX2, а предварительная загрузка используется для загрузки двоичных файлов ADX2 CueSheet (содержащих все данные, относящиеся к сигналу) в память.

Поскольку для воспроизведения звуков на уровне CRYENGINE требуются двоичные файлы ADX2 CueSheet, содержащие данные Cue, обязательно подключайте двоичные файлы ADX2 CueSheet к предварительным загрузкам и обновляйте их каждый раз, когда вы добавляете новый контент в свой проект ADX2.

Также убедитесь, что Автозагрузка активируется свойство созданного Preload; ценность его Контекст имущество тем временем может быть оставлено на Глобальный. Более подробную информацию об этих объектах можно найти здесь.

Размещение аудио-триггера в игре

Чтобы услышать созданный звуковой триггер в игре, его необходимо подключить к звуковому объекту, расположенному на вашем уровне, чтобы объект выполнял звуковой триггер во время игры.

Звуковой триггер также можно просмотреть в ACE, щелкнув его с помощью double или нажав пробел когда он выбран.

Для каждого уровня рекомендуется создать отдельный слой в Level Explorer для всех ваших аудиоданных.

  1. Откройте Level Explorer с помощью Инструменты → Редактор уровней → Level Explorer опция в главном меню редактора.
  2. Выберите Файл → Новый слой вариант из Level Explorer меню для создания нового слоя. Дважды щелкните слой, чтобы сделать его активным.

Когда слой установлен в качестве активного слоя (выделен синим цветом), все объекты, которые вы размещаете на своем уровне, будут автоматически включены в этот слой.


Активный слой

Затем откройте инструмент «Создать объект» (Инструменты → Редактор уровней → Создать объект) и выберите Аудио → Аудио-триггер Сущность. Поместите эту сущность на свой уровень.


Аудио-триггер

Рекомендуется использовать сокращения для звуковых сущностей, чтобы улучшить читаемость в больших проектах. Например, точка аудио-триггера под названием frog_idle можно назвать ats_frog_idle.

После размещения объекта Audio Trigger Spot перейдите к Имя триггера воспроизведения поле на панели свойств редактора. Нажмите кнопку кнопку рядом с этим полем и выберите созданный вами триггер в открывшемся окне «Выбор управления аудиосистемой»; созданный вами триггер теперь должен воспроизводиться, как только будет включен объект Audio Trigger Spot.


Размещено звуковое триггерное пятно

Использование StopTrigger

Если Остановить триггер Имя поле останется пустым, CRYENGINE автоматически остановит воспроизведение ADX2 Cue, когда StopTrigger выполняется. Такое поведение одинаково во всех местах, где StopTrigger можно использовать в CRYENGINE.

Однако если вы хотите, чтобы звук затихал, вам необходимо создать модуляцию AHDSR для громкости в CRI Atom Craft, прежде чем добавлять StopTrigger в редакторе управления звуком:

  • Откройте Cue, который вы хотите заглушить, и выберите аудиоматериал, который будет помещен на звуковую дорожку в Cue.
  • В FX/AISAC окно, открой FX2 раздел и установите значение Релиз поле под Конверт раздел до 2000 года; это должно привести к затуханию звука в течение 2 секунд.


Релиз

Эту модуляцию AHDSR также можно использовать для создания постепенного появления.

Чтобы запретить Cue играть в игре, создайте Остановить триггер в редакторе управления звуком:

  1. Создайте новый триггер в ACE. К этому триггеру подключите тот же Cue, который используется для вашего PlayTrigger.
  2. Выбрав вновь созданный триггер в окне «Элементы управления аудиосистемой», установите Действие поле на панели свойств ACE, чтобы Стоп.


Действие

Также можно использовать дорожку действий в AtomCraft для остановки сигналов.

  • Создайте новый Cue в AtomCraft, щелкните правой кнопкой мыши в окне Timeline и выберите Новый объект → Создать трек действий вариант.
  • Щелкните правой кнопкой мыши созданную дорожку действий и выберите Новый объект → Создать действие остановки. вариант; перетащите сигнал, который необходимо остановить, на дорожку действия.


Трек действий

Используйте префиксы в именах триггеров или сигналов, чтобы указать, используются ли они для запуска (Play_...) или перестань(Stop_...) звук.
