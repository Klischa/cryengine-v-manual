Обзор

Редактор сопоставления UV предназначен для предоставления простых и мощных способов определения UV-объектов объекта Designer, например, встроенного в Maya, 3dsMax или Blender и т. д.


Элементы управления

Мышь

Клавиатура

Открытие редактора картографии UV

1. Перейдя в Инструменты -> Designer Tool -> UV Сопоставление.

2. В самом дизайнере:

  • Выберите объект дизайнера
  • В инструменте «Дизайнер» перейдите к Дополнительно -> Группы/UV
  • Нажмите UV Сопоставление, за которым следует Откройте редактор карт UV. на панели, которая появляется внизу:

Основной рабочий процесс разворачивания

После открытия редактора карт UV (см. выше):

  1. Выберите полигоны, которые вы хотите развернуть, в 3D-окне просмотра.
  2. Выберите плоскость, куб, вид, сферу или цилиндр в редакторе картографии UV, чтобы развернуть выбранные полигоны.
  3. Проверьте вывод результатов в редакторе карт UV.

Развертывание функций

По сути, полигоны в объекте Designer необходимо вручную развернуть, чтобы присвоить им координаты UV. Для этого сначала выберите полигоны, которые вы хотите развернуть, и выберите из них. Самолет, Куб, Сфера, Цилиндр или Посмотреть кнопки в редакторе картографии UV. Выбранные полигоны будут перенесены в вид отображения UV, и им будет назначен текущий подматериал ID.

Самолет

Для развертывания многоугольников используется плоская проекция, нормальное направление которой определяется одним из X, Y, Z или средним направлением выбранных многоугольников.

  1. Выделите нужные полигоны (через Designer Tool -> Выбор -> Многоугольник а затем удерживая Ctrl щелкая левой кнопкой мыши по нужным полигонам)
  2. Откройте редактор картографии UV (щелкнув Designer Tool -> Сопоставление UV -> Открыть редактор сопоставления UV)
  3. В редакторе карт UV нажмите кнопку Самолет кнопка

Если вы выберете несколько групп полигонов, которые отделены друг от друга, то будут созданы острова UV (столько, сколько выбрано групп полигонов), как показано ниже.

Куб

Направление проекции каждого выбранного многоугольника будет определяться ближайшим направлением из числа Вверх(0,0,1), Вниз(0,0,-1), Влево(-1,0,0), Вправо(1,0,0), Вперед(0,1,0) и Назад(0,-1,0). Если нормальное направление многоугольника направлено в сторону (0,4082,0,4082,0,8164), то многоугольник будет проецироваться в направлении вверх.

Посмотреть

Все выбранные полигоны будут проецироваться на плоскость, нормальное направление которой совпадает с направлением обзора камеры.

Сфера

UVs будут определяться сферическими координатами.

Цилиндр

UVs будут определяться цилиндрическими координатами.

Функции манипуляции

Остальные параметры инструмента сопоставления UV — это способы управления UV-развертками.

Остров/Многоугольник/Ребро/Вершина

Элемент представляет собой остров, многоугольник, край или вершину.

Вы можете выбрать элементы, нажав LMB или нарисуйте прямоугольник, перетаскивая мышь, удерживая LMB. Удерживая Ctrl Также возможен выбор нескольких элементов.

Выбранные элементы отображаются оранжевым цветом, а соответствующие элементы — синим, как показано ниже:

Выделенные элементы можно трансформировать, манипулируя гизмо или перетаскивая мышь. Гизмо можно переключить на Переместить, Поворот и Масштаб режим, нажав кнопку 1, 2 или 3 кнопки или нажав соответствующую кнопку на панели инструментов.

Положение поворота определяется либо центром выбранных элементов, либо положением курсора UV. Это устанавливается через Тип поворота поле со списком в редакторе карт UV.

Выберите «Общий»

Если вы хотите выбрать синие элементы, соответствующие выбранным элементам, нажмите эту кнопку. Смотрите фотографии ниже.

Выбор петли

Выбор петли в редакторе картографирования UV охватывает как края границ, так и внутренние края, как и Петля инструмент в инструменте моделирования.

Выбран край границы (слева: выбрана начальная граница, справа: результат после выбора контура)

Выбран внутренний край (слева: выбрана начальная граница, справа: результат после выбора контура)

Выбрано несколько ребер (слева: выбрана начальная граница, справа: результат после выбора цикла)

Отменить карту

Удаляет полигоны UV из редактора карт UV. Когда полигоны не сопоставлены, их UV-развертки будут генерироваться автоматически в зависимости от положения.

Нормали и несопоставленные многоугольники больше не отображаются в представлении редактора картографии UV.

Шить

Прикрепляет первую выбранную границу Edge вдоль второй выбранной границы Edges, но не перемещает остров, принадлежащий выбранным Edges.

Двигайтесь и шейте

Перемещает остров, принадлежащий первым выбранным краям границы, чтобы сориентировать их по второй границе, и присоединяет первую границу ко второй границе.

Умное шитье

Если функция интеллектуального вышивания не используется, для сшивания краев с другими соответствующими краями обычно требуется четыре шага:

  1. Выбор края
  2. Щелчок Выбор петли
  3. Щелчок Выберите «Общий»
  4. Щелчок Двигайтесь и шейте

Необходимость повторять эти шаги каждый раз, когда вы хотите сшить края, занимает много времени, поэтому Умное шитье был введен, чтобы сделать этот процесс намного проще и быстрее.

  1. Выбран один край (оранжевый край на снимке экрана ниже). Выбор петли, Выберите «Общий» и Двигайтесь и шейте выполняются последовательно. Соответствующий край выделен синим цветом:



    Нажмите Умное шитье и два острова UV будут объединены в один остров UV:

  2. Выбрано несколько кромок (края оранжевого цвета) (Выберите «Общий» и Двигайтесь и шейте выполняются последовательно). Соответствующие края выделены синим цветом:



    Нажмите Умное шитье и два острова UV объединяются в один остров UV:

Отдельный

Отделяет выбранные полигоны UV от острова, которому они принадлежат.

На первом снимке экрана ниже показан выбранный остров. На втором скриншоте показаны некоторые выбранные полигоны UV с острова. Выбор Отдельный затем отделит выбранные полигоны UV, и они станут отдельным островом (третий скриншот):

Отразить по горизонтали/Отразить по вертикали

Переворачивает выбранные элементы по горизонтали или вертикали относительно поворотного положения.

Исходное, Отразить по горизонтали, Отразить по вертикали

Выравнивание

Выравнивает выбранные позиции UV по оси X или Y. Для выравнивания используется ось с наибольшей длиной связанного прямоугольника (из выбранных элементов).
