Пользовательское свойство (UDP) — это свойство, которое определяется при создании потока сообщений с помощью редактора потока сообщений. Преимущество UDP состоит в том, что их значения могут быть изменены оперативным персоналом во время развертывания и выполнения без необходимости изменения кода на уровне узла сообщения.

В CryENGINE UDP используются для воздействия и изменения физических свойств объектов static и особенно хрупких ресурсов!

Настройка UDP в Maya

Нажмите на значок с надписью «UDP», чтобы открыть меню.

Несколько примечаний для пользователей Maya:
  • Строки UDP должны быть назначены узлу, оканчивающемуся на имя "_group", которое не было преобразовано относительно родительского "cryexportnode".
    • Если это отклоняется, движок попытается подогнать содержимое данных сетки ниже узла группы к назначенному примитиву UDP. В большинстве случаев такая настройка работает, но следует отметить, что она не идеальна и иногда может привести к непредсказуемому поведению.
  • Для каждого используемого примитива UDP; у каждого должен быть свой собственный узел _group.
  • Для представления капсул следует использовать цилиндры, поскольку в Maya они не предусмотрены по умолчанию. Чтобы отображать цилиндры в виде капсул, включите «Круглую крышку» во входных параметрах.
  • Для символов строки UDP должны быть назначены суставу желаемого используемого физического прокси.
