Обзор

Чтобы играть на карте в Программа запуска исполняемых файлов игры Используя приложение запуска игры, уровень необходимо подготовить, сгенерировав и экспортировав некоторые данные.

Экспорт уровня в движок

На Файл меню, нажмите Экспорт в движок:

Это запишет данные уровня в level.pak файл, который читается движком в режиме чистой игры через лаунчер.

Оценка SDK

Для ознакомительной версии SDK экспортированные уровни шифруются по соображениям безопасности. Чтобы программа запуска могла читать зашифрованные уровни, необходимо предоставить ключ дешифрования, который отображается Sandbox после «Экспорт в движок» был использован. Ключ копируется в буфер обмена и его можно легко использовать. Приложение Launcher ожидает ключ дешифрования в файле system.cfg. Чтобы установить ключ, напишите в файл следующую строку:

level_decryption_key = ключ

Где ключ должен быть заменен ключом в буфере обмена.

Только программа запуска PC может читать зашифрованные уровни таким образом. На консоли шифрование не требуется. Поэтому экспортируйте уровни специально для консоли, используя опцию меню. «Файл/Экспорт в движок для консоли». Если вы переходите от ознакомительной версии к полной лицензии, уровни, созданные на этапе оценки, изначально не могут быть прочитаны полной лицензией, поскольку полная лицензия не может обрабатывать зашифрованные файлы. Поэтому, если вы хотите перенести уровни из ознакомительной версии в полную лицензию, отправьте эти уровни в Crytek для их расшифровки.

Создание областей навигации и поверхностей покрытия

  1. В меню выберите Игра → AI → Восстановить навигацию → Восстановить все слои.

  2. Игра -> AI -> Создать поверхности обложки

    Этот второй шаг необходим только в том случае, если вы разместили объекты Cover Surface на своем уровне.

Создание текстуры поверхности уровня

На Файл меню, нажмите Создать текстуру поверхности:

Это запишет окрашенные текстуры земли в terraintexture.pak файл.

Для окончательного качества выберите 16384 х 16384 вариант, а также выберите параметр Высокое качество и Рассчитать доступность ландшафта неба флажки.

Для тестирования подойдет разрешение по умолчанию 4096 x 4096.
