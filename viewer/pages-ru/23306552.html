Обзор

Flowgraph — это реализация визуальных сценариев, позволяющая непрограммистам взаимодействовать с различными частями CRYENGINE.

Дополнительную информацию о Flowgraph в Руководстве по Sandbox см.: Flow Graph Редактор.

Добавление таблицы FlowEvents

Таблица FlowEvents необходима для определения пользовательских входных и выходных данных, поддерживаемых объектом Script.

NewEntity.FlowEvents =
{
  Inputs =
  {
    PowerOn  = { NewEntity.Event_PowerOn,  "bool" },
    PowerOff = { NewEntity.Event_PowerOff, "bool" },
    Position = { NewEntity.Event_Position, "Vec3" },
  },

  Outputs =
  {
    PowerOn = "bool",
    PowerOff = "bool",
  },
}

Типы значений, поддерживаемые для входов и выходов:

  • строка
  • bool
  • идентификатор объекта
  • int
  • float
  • век3

Добавление входа узла потока

Следующая строка, взятая из таблицы входов, содержащейся внутри FlowEvents, описывает добавление входа узла потока.

PowerOn = { NewEntity.Event_PowerOn, "bool" },

Каждый входной элемент определяется его именем и таблицей, содержащей два элемента:

  1. Ссылка на функцию сценария, вызываемую при активации входа.
  2. Тип значения, принимаемый на входе.

Следующий фрагмент кода представляет собой скелет реализации функции, которая будет получать входные данные потока.

function NewEntity:Event_Position(sender, position)
  -- read the position value and set it somewhere
end

Следующий фрагмент кода представляет реализацию функции, которая считывает входное значение.

function NewEntity:Event_PowerOn(sender)
  -- code to implement a reaction to the flow node input
end

Добавление вывода узла потока

В таблицу «Выходы» необходимо добавить новый элемент с именем и типом значения вывода. Пример:

PowerOn = "bool",

Выход активируется вызовом функции BroadcastEvent со строкой, представляющей имя активируемого выхода.

BroadcastEvent(self, "PowerOn");

Если выходное значение имеет значение, используйте функцию ActivateOutput:

self:ActivateOutput("ActiveCount", self.nActiveCount);
