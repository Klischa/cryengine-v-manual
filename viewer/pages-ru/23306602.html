← Содержание ScriptBind_Particle RU

CreateEffect

Создает новый эффект частиц. 

Particle.CreateEffect( name, params )

DeleteEffect

Удаляет указанный эффект частиц. 

Particle.DeleteEffect( name )

IsEffectAvailable

Проверяет, доступен ли указанный эффект частиц. 

Particle.IsEffectAvailable( name )

SpawnEffect

Создает эффект. 

Particle.SpawnEffect( effectName, pos, dir )

SpawnEffectLine

Создает линию эффекта. 

Particle.SpawnEffectLine( effectName, startPos, endPos, dir, scale, slices )

SpawnParticles

Создает эффект частиц. 

Particle.SpawnParticles( params, pos, dir )

CreateDecal

Создает декаль с указанными параметрами. 

Particle.CreateDecal( pos, normal, size, lifeTime, textureName )

CreateMatDecal

Создает декаль материала. 

Particle.CreateMatDecal( pos, normal, size, lifeTime, materialName )

Прикрепить

Добавляет эффект. 

Particle.Attach()

Отсоединить

Отключает эффект. 

Particle.Detach()
