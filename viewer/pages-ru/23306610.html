← Содержание ScriptBind_Inventory RU

Уничтожить

Уничтожает инвентарь. 

Inventory.Destroy()

Очистить

Очищает инвентарь. 

Inventory.Clear()

Дамп

Сбрасывает инвентарь. 

Inventory.Dump()

GetItemByClass

Получает элемент по имени класса. 

Inventory.GetItemByClass( className )

GetGrenadeWeaponByClass

Получает гранатовое оружие по имени класса. 

Inventory.GetGrenadeWeaponByClass( className )

HasAccessory

Проверяет, есть ли в инвентаре указанный аксессуар. 

Inventory.HasAccessory( accessoryName )

GetCurrentItemId

Получает идентификатор текущего элемента. 

Inventory.GetCurrentItemId()

GetCurrentItem

Получает текущий элемент. 

Inventory.GetCurrentItem()

GetAmmoCount

Получает количество указанного имени боеприпаса. 

Inventory.GetAmmoCount(ammoName)

GetAmmoCapacity

Получает емкость для указанных боеприпасов. 

Inventory.GetAmmoCapacity( ammoName )

SetAmmoCount

Устанавливает количество указанных боеприпасов. 

Inventory.SetAmmoCount( ammoName, count )
