Создание консольных команд

Консольная команда в C# — это тип делегата со следующей сигнатурой:

public delegate void ManagedConsoleCommandFunctionDelegate(params string[] arguments);

Существует два способа создания консольных команд в C#:

  1. Применение атрибутов C#
  2. Ручная регистрация и снятие с регистрации

Применение атрибутов C#

Консольную команду можно реализовать, применив атрибут C# к любой функции static. Пример показан ниже:

[ConsoleCommand("AConsoleCommand", (uint)EVarFlags.VF_DEV_ONLY, "This is a Console Command from CSharp" )]
static void AConsoleCommand(string[] arguments)
{
// other code
}

При успешном выполнении консольной команды аргументы будут переданы обратно в виде аргументов в массиве строк (включая имя команды).

Атрибут ConsoleCommand, примененный к функциям, отличным от static, будет игнорироваться. Для функций, отличных от static, используйте регистрацию вручную, как показано ниже.

Ручная регистрация и снятие с регистрации

Консольные команды также могут быть созданы путем вызова функции. Это единственный способ создать консольную команду в функциях, отличных от static. Чтобы зарегистрировать функцию консольной команды, используйте следующую функцию:

ConsoleCommand.RegisterManagedConsoleCommandFunction(string commandName, uint nFlags, string commandHelpText, ManagedConsoleCommandFunctionDelegate consoleCmd Delegate)

Чтобы отменить регистрацию функции консольной команды, используйте следующую функцию:

ConsoleCommand.UnregisterManagedConsoleCommandFunction(string commandName)

Проверка консольных команд

Консольные команды проверяются с помощью ConsoleCommandAttributeManager. Проверка атрибутов консольной команды будет активирована, если "DEBUGАтрибут объявлен в коде. Если нестатические функции применяются с атрибутом ConsoleCommand, ConsoleVariableConfigurationException будет выброшено исключение.
