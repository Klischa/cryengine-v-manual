Обзор

Существует 2 способа отладки MBT:

  • Внутриигровая визуализация: отображает выполняемые в данный момент ветки определенного персонажа AI в игре.
  • История выполнения: записывает стеки выполнения для определенного или всех символов AI.

Внутриигровая визуализация

Используйте косую черту («/») на клавиатуре или квар «ai_DebugAgent centerview", чтобы увидеть, какие части дерева в данный момент выполняются в символе AI, ближайшем к камере:

  • Действующие в настоящее время ветки MBT
  • Временные метки MBT
  • Переменные MBT
  • События, произошедшие недавно

Числа рядом с активными в данный момент ветвями соответствуют номерам строк в файле XML.

Слэш-клавиша — это просто ярлык для ввода «ai_DebugAgent centerview" и реализован как таковой только в GameSDK DLL.

История выполнения

Функция истории выполнения позволяет записывать стеки выполнения покадрово в файлы журналов. Это контролируется cvar:

"ai_LogModularBehaviorTreeExecutionStacks 0/1/2":

  • 0 = не войти
  • 1 = протоколировать историю выполнения только для того агента, который в данный момент отлаживается (см. cvar "ai_DebugAgent centerview")
  • 2 = записать историю выполнения для всех агентов AI

Файлы журналов представляют собой обычные текстовые файлы, которые записываются в каталог. .\user\mbt_logs.

Каждый агент AI будет хранить свою историю выполнения в отдельном файле, имя которого соответствует его имени объекта и объекту ID (например, "mbt_human1_3.txt" будет относиться к агенту AI с именем "Human1", EntityID которого = 3).
