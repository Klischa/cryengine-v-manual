Обзор

Вода — относительно сложное природное явление, которое невозможно достичь при рендеринге в реальном времени, из-за множества незначительных факторов, влияющих на него как визуально, так и физически.

Основная информация о шейдере воды:

  • Surface больше не использует процедурную карту рельефа, а вместо этого использует FFT карту градиента/нормалей/высот на основе шума с несколькими частотами/масштабами для окружающих волн.
  • Взаимодействие пользователя с поверхностью приведет к распространению волн.
  • Для высоких требований мы продолжаем использовать смещение вершин с добавленной поддержкой взаимодействия с водой.
  • Дешевое приближение для солнечных теней.
  • Отдельные проходы водяного тумана были объединены с рендерингом водной поверхности для оптимальной производительности.
  • Последним небольшим шагом вперед стала унификация рендеринга воды. Это означает, что океан, водные объемы и реки могут проходить один и тот же путь окончательного рендеринга, что будет проще использовать художникам и дизайнерам, поскольку оба они настроены одинаково.

Некоторые свойства воды

Обратите внимание, откуда берется основной цвет/вид воды: все это происходит из-за отражения от поверхности воды и того, как свет взаимодействует с молекулами воды/взвешенными частицами (мы называем это «подводным туманом» на CRYENGINE).

Это означает, что никогда не пытайтесь добиться акварельного цвета/вида только с помощью отражения, это сумма обоих.

Рекомендации по настройке воды

  • Параметры по умолчанию были тщательно проработаны, чтобы изначально выглядеть красиво по умолчанию, но каждый уровень — это отдельный уровень, поэтому всегда потребуется некоторая тонкая настройка.
  • Никогда, никогда не пытайтесь добиться акварельного эффекта/эффекта только с помощью отражения, это сумма того и другого, что дает вам окончательный правильный вид.
  • Поскольку одним из двух основных факторов, влияющих на внешний вид, являются отражения, если у вас скучная среда, вы получите тусклые/скучные отражения. Всегда стремитесь к интересному виду неба, с красивым градиентом линии горизонта и яркими пятнами (последнее особенно важно для ночных сцен).
  • Используйте пену осторожно, это дешевый вариант – не переусердствуйте, иначе может выглядеть неуместно.
  • Расстояние прорисовки отражения океана привязано к расстоянию прорисовки текстуры деталей местности.
Океан против воды
  • При настройке водных материалов для океана убедитесь, что объем воды вариант нет проверил.
  • При настройке водных материалов для водных объемов или рек убедитесь, что объем воды вариант есть проверил.

Рекомендации по производительности

Включайте только те параметры, которые действительно хотите использовать:

  • Вам нужно отражение солнца? Если нет, отключите.
  • Вам нужна пена? Если нет, отключите.
  • Установите множитель каустики на 0, чтобы отключить рендеринг каустики, когда он не нужен.


CVar, связанные с производительностью:

e_WaterOcean

Activates drawing of ocean. 
1: use usual rendering path
2: use fast rendering path with merged fog

e_WaterVolumes

Activates drawing of water volumes
1: use usual rendering path
2: use fast rendering path with merged fog

r_WaterReflectionsQuality
DUMPTODISK

Activates water reflections quality setting.
Usage: r_WaterReflectionsQuality [0/1/2/3]
Default is 0 (terrain only), 1 (terrain + particles), 2 (terrain + particles + brushes), 3 (everything)

r_WaterUpdateFactor
DUMPTODISK

Distance factor for water reflected texture updating.
Usage: r_WaterUpdateFactor 0.01
Default is 0.01. 0 means update every frame
