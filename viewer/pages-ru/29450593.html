Контейнеры

Действия

Узел для выполнения действий над всеми объектами в контейнере.

Добавить/удалить объект

Узел для добавления/удаления сущностей в контейнер сущностей.

Очистить

Узел для удаления всех сущностей из контейнера сущностей.

Фильтры

Узел для фильтрации компонентов контейнера сущностей и получения отсортированного вывода.

Слушатель

Узел, который выводит количество элементов в контейнере сущностей при каждом добавлении или удалении в него элементов.

Объединить

Узел для перемещения объектов из исходного контейнера в контейнер этого узла.

QueryContainerId

Узел для запроса, к каким контейнерам принадлежит данный идентификатор объекта.

QueryContainerSize

Узел для запроса размера контейнера сущностей.

QueryEntityByIndex

Узел для получения идентификатора объекта n-го члена группы.

QueryIsInContainer

Узел для запроса, находится ли сущность в контейнере сущностей.

QueryRandomEntity

Узел для извлечения случайного элемента из контейнера.
