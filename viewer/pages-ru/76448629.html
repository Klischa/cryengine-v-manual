Обзор

Абстракция удаленного хранилища плагина GamePlatform пытается унифицировать интерфейсы пользовательского хранилища в сервисах платформы.

Это можно, например, использовать для хранения сохраненных файлов в удаленном облачном сервисе на платформе. Удаленные файлы, обрабатываемые интерфейсом удаленного хранилища, можно использовать совместно, чтобы другие клиенты могли загружать и использовать файлы.

  • Имя удаленного файла должно содержать имя и расширение файла, а также путь (каталог). Если имя удаленного файла не имеет имени и расширения, файл не будет сохранен в службе платформы (чтение и запись не удастся).
  • На данный момент только Steam поддерживает возможность удаленного хранилища.

Удаленный кэш файлов

Чтобы обеспечить более эффективное использование Flow Graph по отношению к интерфейсу удаленного хранилища, используется кэш удаленных файлов, который находится в плагине GamePlatformNodes.

  • Простое открытие/создание файла сохранит его локальным. При попытке записи данных плагин GamePlatform попросит платформу создать соответствующий удаленный файл в кэше удаленных файлов.
  • Один и тот же файл можно открывать сколько угодно раз; поскольку long используется кеш, дубликаты файла не будут создаваться локально (дублирование на удаленной платформе невозможно).
  • Однако если вы используете C++ API, у вас могут быть отдельные отдельные копии удаленного файла, которые могут совпадать или не совпадать. Удаленный файловый кэш находится в плагине GamePlatformNodes и по умолчанию используется реализациями Flow Graph и Schematyc.

Вы должны не забыть очистить этот кеш, когда вы больше не используете удаленные файлы; вы можете сделать это для каждого файла или для каждого файла на платформе.

Пользовательский контент

Помимо системы удаленного хранения, CRYENGINE также предоставляет интерфейс к службе пользовательского контента для Steam. Это позволяет создавать предметы мастерской прямо в игре.

Рекомендуется прочитать документацию Steamworks для получения дополнительной информации о настройке страниц Мастерской для ваших игр и о том, как предметы Мастерской ведут себя на платформе.

Функции службы удаленного хранения

IsEnabled

Проверяет, доступна ли возможность удаленного хранения на платформе.

GetFile

Получает ссылку на удаленный файл.

  • Для C++ API это возвращает структуру данных, которая позволяет вам затем запрашивать размер файла или читать/записывать данные по требованию.
  • В реализации Flow Graph функции записи/чтения/размера и т. д. используются напрямую, каждый раз указывая имя файла.
  • Для Schematyc это позволит получить тип данных, который вы можете передать функциям чтения/записи/размера и т. д. (например, идентификатор).

GetSharedFile

Получает ссылку на общий удаленный файл.

События службы удаленного хранения

OnDownloadedSharedFile

Запускается, когда запрос на загрузку общего файла завершен.

OnFileShared

Вызывается, когда локальный пользователь поделился файлом.

Функции удаленного файла

Удалить

Пытается удалить файл из удаленного хранилища.

Скачать

Пытается загрузить указанный общий файл из удаленного хранилища.

Слушайте OnDownloadedSharedFile событие после запроса на загрузку.

Существует

Проверяет, существует ли указанный файл в удаленном хранилище.

GetCacheList

Извлекает все кэшированные файлы указанного типа в памяти для указанной платформы.

Эта функция не работает в сборках Release; он не будет компилироваться (если не защищен) в сборках Release и должен использоваться только в целях отладки.

GetFileSize

Пытается получить размер файла из удаленного хранилища.

GetIdentifier

Пытается получить общий файл ID указанного удаленного файла.

GetSharedFileSize

Пытается получить размер общего файла из удаленного хранилища.

Читать

Пытается прочитать данные из удаленного хранилища.

ReadDataToFile

Пытается прочитать данные из удаленного хранилища и записать их в локальный файл.

ReadSharedData

Пытается прочитать общий файл из удаленного хранилища.

ReadSharedDataToFile

Пытается прочитать общий файл и записать данные в указанный локальный файл.

ReleaseRemoteFile

Освобождает кэшированный удаленный файл из кэша удаленного хранилища.

ReleaseSharedFile

Освобождает кэшированный общий файл из кэша удаленного хранилища.

ShareRemoteFile

Попытка поделиться файлом из удаленного хранилища.

  • Эта функция запрашивает у платформы разрешение другим пользователям запрашивать этот файл, используя предоставленный общий идентификатор.
  • В случае успеха, OnFileShared событие, содержащее идентификатор для передачи другим пользователям, будет запущено для локального пользователя.

WriteFromFile

Пытается записать данные из локального файла в удаленное хранилище.

CryPak обрабатывает разрешение пути, и вы можете добавлять префикс %USER% или %ENGINEROOT% к путям к файлам. Это означает, что вы можете использовать все псевдонимы и даже читать данные из файлов внутри зашифрованных файлов PAK (данные не могут быть записаны в файлы PAK).

WriteData

Пытается записать данные в файл в удаленном хранилище.

Функции службы пользовательского контента

CreateContent

Создает новый элемент контента, созданный пользователем, на указанной платформе.
