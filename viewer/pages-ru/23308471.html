Описание

Определение контроллера содержит настройку персонажа-манекена.

Это относится к Файл определения тега (xxxTags.xml) и Файл определения FragmentID (xxxActions.xml) используется этим персонажем. Обычно на него ссылается сущность игры, поскольку файл необходим сущности для создания Mannequin ActionController. См. обзорное изображение в Mannequin Файлы документ.

Он определяет, какие области действия назначены каждому из FragmentIDs, т. е. масок области. См. FragmentIDs и Маски области видимости.

Он определяет, какие области видимости и контексты областей действия имеет персонаж. См. Mannequin Области применения и Контексты области действия.

Создание определения контроллера

Определение контроллера создается вручную. См. FileFormat раздел.

Редактирование определения контроллера

Маски области видимости и соответствующие флаги можно редактировать в Mannequin FragmentID Редактор.

Все остальное приходится редактировать вручную в XML-файле. См. FileFormat раздел.

Формат файла

Это пример файла определения контроллера:

<ControllerDef>
 <Tags filename="Animations/Mannequin/ADB/sampleTags.xml"/>
 <Fragments filename="Animations/Mannequin/ADB/sampleFragmentIds.xml"/>
 <SubContexts/>
 <FragmentDefs>
  <move scopes="FullBody+Torso" flags="Persistent"/>
  <burst_fire scopes="Torso+Weapon">
   <Override tags="heavyMortar" fragTags="boosted" scopes="Torso"/>
  </burst_fire>
 </FragmentDefs>
 <ScopeDefs>
  <FullBody layer="0" numLayers="3" context="MainContext"/>
  <Torso layer="3" numLayers="3" context="MainContext"/>
  <Face layer="6" numLayers="0" context="MainContext" Tags="scope_face"/>
  <Weapon layer="0" numLayers="2" context="WeaponContext"/>
 </ScopeDefs>
</ControllerDef>

Теги элемент содержит ссылку на Файл определения тега (xxxTags.xml) используется этой настройкой.

Фрагменты элемент содержит ссылку на Файл определения FragmentID (xxxActions.xml) используется этой настройкой.

SubContexts элемент перечисляет все различные Mannequin SubContexts доступен для этого определения контроллера.

FragmentDefs элемент должен содержать ровно одну запись для каждого fragmentID, указанного в определении FragmentID. Обычно редактирование этих элементов выполняется редактором автоматически.
Для каждого из fragmentIDs:

  • объемы атрибут: определяет ScopeMasks для этого fragmentID.
  • флаги атрибут: дополнительно предоставляет флаги в атрибуте Flags. Если установлено более одного флага, разделите их знаком «+». Поддерживаемые флаги:
  • Переопределить элемент: переопределяет маску области для этого fragmentID, когда определенные теги (и фрагтеги) совпадают. В этом примере, когда запрашивается fragmentID "burst_fire", обычно маска области будет "Торс+Оружие". Но если в это время установлены глобальный тег «heavyMortar» и фрагментный тег «boosted», вместо него используется маска области «Torso».
