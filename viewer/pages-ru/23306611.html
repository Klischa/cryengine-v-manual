Сброс

Сбрасывает систему предметов. 

ItemSystem.Reset()

GiveItem

Дает указанный предмет. 

ItemSystem.GiveItem( itemName )

GiveItemPack

Предоставляет пакет предметов указанному актеру. 

ItemSystem.GiveItemPack( actorId, packName )

GetPackPrimaryItem

Получает основной элемент указанного пакета. 

ItemSystem.GetPackPrimaryItem( packName )

GetPackNumItems

Получить количество предметов в указанном пакете. 

ItemSystem.GetPackNumItems()

GetPackItemByIndex

Получает элемент пакета из его индекса. 

ItemSystem.GetPackItemByIndex( packName, index )

SetActorItem

Устанавливает элемент актера. 

ItemSystem.SetActorItem( actorId, itemId, keepHistory )

SetActorItemByName

Устанавливает элемент актера по имени. 

ItemSystem.SetActorItemByName( actorId, name, keepHistory )

SerializePlayerLTLInfo

Сериализует информацию об игроке LTL. 

ItemSystem.SerializePlayerLTLInfo( reading )
