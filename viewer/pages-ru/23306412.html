Обзор

Можно запросить физическую систему, чтобы получить все физические объекты/сущности, содержащиеся в определенном объеме коробки, определяемом минимальной и максимальной точкой, используя GetEntitiesInBox функция

virtual int GetEntitiesInBox(Vec3 ptmin,Vec3 ptmax, IPhysicalEntity **&pList, int objtypes, int szListPrealloc=0) = 0;

... следующим образом:

IPhysicalEntity** entityList = 0;
int entityCount = gEnv->pPhysicalWorld->GetEntitiesInBox(m_volume.min, m_volume.max, entityList,
      ent_static | ent_terrain | ent_sleeping_rigid | ent_rigid);

Функция использует внутреннюю двухмерную сетку для возврата объектов, ограничивающие рамки которых перекрываются с указанным прямоугольником. Функция поддерживает опциональную сортировку выходного списка по массе сущностей (в порядке возрастания). Если ent_alloctate_list указан, функция выделяет память для списка (позже память можно освободить вызовом pWorld->GetPhysUtils()->DeletePointer). В противном случае будет возвращен внутренний указатель. Следует иметь в виду, что физическая система использует этот указатель почти во всех операциях, требующих формирования списка сущностей, поэтому такие вызовы не должны выполняться, когда список используется (иначе список будет признан недействительным). Если такие вызовы необходимы и выделение памяти нежелательно, можно скопировать список в локальный предварительно выделенный массив перед выполнением итерации по нему. Чтобы убедиться, что указатели объектов в списке остаются действительными во время доступа к ним, ent_addref_results флаг можно установить.
