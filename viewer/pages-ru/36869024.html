Обзор

Библиотека предустановок Particle Editor содержит полный список предопределенных эффектов частиц, таких как взрывы, огонь, угли или дым, которые можно добавить на ваш уровень. Эти эффекты служат основой для создания гораздо более сложных эффектов частиц.

Чтобы получить доступ к библиотеке пресетов частиц, просто щелкните правой кнопкой мыши пустой раздел в График эффектов.

Параметры предустановки частиц

Расширенная папка

Компоненты, которые можно найти в папке «Дополнительно», позволяют пользователям добавлять более сложные эффекты частиц со свойствами движения и поведения. Эти компоненты включают в себя функции и модификаторы, которые, скорее всего, понадобятся для создания определенных эффектов. как жогонь, взрывы, дождь и т. д.. В основном он включает в себя большинство функций, которые могут понадобиться пользователям, чтобы сделать свои эффекты еще лучше..

Большинство эффектов будут работать нормально, но может потребоваться добавление текстуры и настройка освещения.

Существует также расширенный → по умолчанию компонент; своего рода стартовый узел, который можно использовать для создания более сложных эффектов с добавлением других функций.

Папка по умолчанию

Содержит эффекты, которые можно использовать для создания самых простых компонентов. В этой папке можно найти минимальные настройки настроек, такие как звук, спрайты, спрайты GPU, лента и т. д. Эти компоненты не включают в себя какие-либо функции движения или синхронизации и не зависят от конкретного эффекта.

Компонент по умолчанию

Самый базовый компонент узла. Компонент, который автоматически создается при добавлении в редактор нового эффекта.

Для получения дополнительной информации о ссылках на узлы Particle Editor см. Особенности эффекта частиц.
