Обзор

Частицы относятся к элементам движка, которые используются для создания визуальных эффектов, или к небольшим физическим объектам, которые могут двигаться, ударяться о поверхности, излучать свет, реагировать на столкновения и т. д. Particle Editor позволяет пользователям просматривать существующие объекты частиц или создавать новые с нуля. Используя определенные компоненты и функции, пользователи могут создавать уникальные и мощные визуальные эффекты, такие как дым, погодные эффекты и/или взрывы.

В этом редакторе можно изменить функции эффекта частиц и зависимости родительских и дочерних частиц. Это особенно полезно, когда пользователи хотят создавать частицы второго поколения, порожденные из частиц первого поколения. Это также позволяет пользователю использовать частицы GPU и упрощает переключение с частиц CPU на частицы GPU. Эта функция гарантирует, что частицы имеют гораздо более высокий уровень физического взаимодействия и что на экране одновременно может отображаться больше частиц.

Particle Editor можно найти в разделе Инструменты → Particle Editor.

Вы можете создать эффект частиц по умолчанию через браузер ресурсов. Для этого откройте браузер ресурсов, перейдите к папке, в которой вы хотите создать частицу, щелкните правой кнопкой мыши на пустом месте в папке и выберите Новое → Частица из контекстного меню.

Дополнительную информацию о рабочем процессе создания эффектов частиц см. Создание эффекта частиц страница.

3. Обозреватель активов

Панели обозревателя ресурсов для конкретных инструментов позволяют пользователям просматривать и редактировать ресурсы в инструменте, который используется в данный момент. В отличие от автономного инструмента «Обозреватель ресурсов», ресурсы, отображаемые на этой панели, по умолчанию предварительно фильтруются; это означает, что он отображает только те ресурсы, которые относятся к самому инструменту.

Параметры меню и их функциональные возможности как в автономном, так и в специализированном браузере активов одинаковы и могут использоваться для достижения одной и той же цели. Для получения дополнительной информации о параметрах меню браузера ресурсов см. Обозреватель активов страница.

Когда выбор синхронизации Кнопка на панели инструментов активна, выбор другого актива в браузере ресурсов для конкретного инструмента мгновенно откроет его. Эта кнопка позволяет легко переключаться между различными ресурсами и редактировать их на лету.

4. График эффекта

График эффектов — это панель редактирования по умолчанию, на которой пользователи могут изменять существующие эффекты частиц или создавать новые с нуля; это панель на основе узлов, где пользователи могут просматривать и редактировать компоненты, их отношения родитель-потомок и функции эффектов частиц.

Если предпочтителен древовидный макет, вместо этого можно использовать панель «Дерево эффектов» для редактирования и создания эффектов частиц. Для получения дополнительной информации см. Дерево эффектов раздел на этой странице.

Пользователи могут перемещаться по панели «График эффектов», удерживая и перетаскивая RMB на пустом месте.

Каждую функцию, доступную в компоненте, можно перемещать путем перетаскивания.

Контекстное меню

Панель «График эффектов» также позволяет выбирать компоненты из контекстного меню. Он включает в себя предустановленные компоненты, которые можно использовать для создания новых эффектов частиц или модификации существующих для достижения более сложных и изысканных результатов.

Чтобы получить доступ к контекстному меню, щелкните правой кнопкой мыши пустой раздел на панели «График эффектов».

5. Инспектор

Панель «Инспектор» позволяет пользователям просматривать свойства объекта и параметры атрибутов. Это может отображать либо все свойства компонента, либо свойства выбранного объекта или атрибута. Другими словами, яЕсли компонент выбран, все доступные функции и их свойства будут показаны на панели «Инспектор»; однако, если выбран один объект, вместо него будут отображаться только свойства этого конкретного объекта.

Нажав на Кнопка на панели «Инспектор» блокирует отображаемые в данный момент параметры объекта и гарантирует, что содержимое панели «Инспектор» не изменится даже при выборе другого объекта.

Параметры эффектов

Кнопка «Параметры эффекта» позволяет добавлять атрибуты к выбранному в данный момент эффекту частицы.

Параметры эффекта можно отобразить, щелкнув значок кнопку на панели инструментов «Эффект».

Атрибуты

Атрибуты используются для установления уровня связи между Particle Editor и другими системами в Engine или для индивидуального и/или динамического влияния на значение свойства.

Их можно, например, использовать;

  • В Компонент: ActiveIf и Компонент: EnableIf Функции для включения или отключения определенного компонента.
  • Как Модификатор для линейного масштабирования значения свойства.
  • Как Домен в применимом модификаторе, выступая в качестве входных данных для функции модификатора, масштабируя значение свойства по выходным данным функции.

При использовании в сочетании с другими системами, например. Flow Graph узлы, Атрибуты могут работать в соответствии с внутриигровыми событиями, влияя на свойство, к которому они прикреплены, определенным образом и в определенное время.

Чтобы добавить атрибут к эффекту частицы, нажмите кнопку Атрибуты кнопку раскрывающегося списка и выберите Вставить или Добавить.

Чтобы удалить все атрибуты, выберите Удалить все вариант из раскрывающееся меню, показанное на изображении выше.

Чтобы удалить атрибуты по отдельности, щелкните один из них правой кнопкой мыши и выберите Удалить.

Свойства

Когда объект выбран, его свойства можно изменить на панели «Инспектор». Это позволяет пользователям создавать различные эффекты для используемых ими частиц.

Подробную информацию о свойствах отдельных объектов см. Особенности эффекта частиц.

6. Редактор кривых

Редактор кривых можно использовать для настройки определенных свойств так же, как это делают пользователи в Environment Editor. Это показывает прогресс значений выбранного признака в течение определенного времени и то, как постепенно они меняются. Это особенно полезно, когда для эффекта частиц предусмотрены периодические изменения, основанные на времени.

Чтобы отредактировать функции эффекта частиц на панели «Редактор кривых», Модификаторы цвета или следует выбрать объект с модификатором Curve или Double Curve.

Дополнительную информацию о модификаторах Curve и Double Curve см. Модификаторы страница.

Дополнительную информацию о функциях, поддерживающих модификаторы, см. Особенности эффекта частиц.

Дерево эффектов

Панель «Дерево эффектов» можно использовать для проверки компонентов эффекта частиц, функций и отношений «родитель-потомок» в древовидной компоновке. Он также позволяет пользователям перемещаться по функциям эффектов частиц и изменять их параметры.

Дерево эффектов не является частью макета по умолчанию Particle Editor. Чтобы получить доступ к панели «Дерево эффектов», перейдите в раздел Окно → Панели → Дерево эффектов.

Панель «Дерево эффектов» имеет две разные подпанели: Дерево компонентов. (1) и дерево функций (2):

1. Дерево компонентов

Дерево компонентов отображает все доступные компоненты в виде более простого древовидного списка.

Следующие параметры могут появиться, когда щелчок правой кнопкой мыши на компоненте или пустом месте в списке:

Компоненты можно включать и отключать с помощью щелчок левой кнопкой мыши на флажке рядом с полем имени любого компонента.

Чтобы переименовать компоненты, double-нажмите в поле имени компонента.

Чтобы переместить и изменить родительский компонент, выберите компонент и перетащите его на нового родительского элемента.

Чтобы отделить дочерний компонент от родительского компонента, перетащите дочерний элемент в пустое поле ниже или выше другого компонента. При перемещении компонента появится линия, указывающая, на каком уровне окажется выбранный компонент после его отпускания.

2. Дерево функций

Дерево функций отображает все доступные функции эффектов частиц в более простом древовидном списке.

Чтобы отобразить и отредактировать функции компонента, выберите компонент в дереве компонентов, чтобы заполнить дерево функций всеми доступными функциями выбранного компонента. Выбор одного из них впоследствии заполнит панель Инспектора его параметрами.

Когда функция или пустое место в дереве функций щелкнул правой кнопкой мыши, в контекстном меню появятся следующие параметры.

Функции можно включить или отключить, установив флажок рядом с полем имени.
