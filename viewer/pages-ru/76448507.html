Обзор

Платформа имеет различные интерфейсы уровня обслуживания, которые не попадают в другие категории.

Сюда входит получение информации о службе (например, о доступности службы), а также о некоторых событиях уровня платформы, таких как ошибки службы или события завершения работы.

GamePlatformPlugin также предоставляет каждому сервису «переменные среды», которые позволяют реализации предоставлять данные с платформы, не имеющей абстрактного интерфейса.

Общие функции обслуживания

GetApplicationId

Получает приложение ID игры на платформе.

GetBuildId

Получает сборку ID игры на платформе.

GetEnvironmentValue

Получает переменную среды платформы.

GetService

Получает сведения о зарегистрированной службе игровой платформы.

MarkContentCorrupt

Приказывает платформе проверить файлы данных при следующем запуске.

OwnsApplication

Проверяет, является ли локальный пользователь владельцем указанного приложения на платформе.

Общие служебные мероприятия

OnEnvironmentVariableChanged

Вызывается при обновлении переменной среды.

OnOverlayActivated

Запускается, когда пользователь активировал оверлей (например, оверлей Steam).

OnShutdown

Вызывается, когда служба собирается завершить работу.
