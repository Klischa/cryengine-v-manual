Компонент Sensor Volume можно использовать в качестве триггера. Всякий раз, когда другой том сенсора с определенными тегами попадает в текущий объем сенсора или проходит через него, может быть выполнен триггер события.

Например, его можно использовать для создания дверного триггера, который будет открываться или закрываться всякий раз, когда игрок входит в сенсорный объем.

Для получения дополнительной информации о том, как настроить громкость датчика, см. Компонент объема датчика страница варианта использования.
