AIReload()

Перезагружает aiconfig.lua Lua-скрипт (Игра/Скрипты/AI/).

AIDebugToggle()

Переключает ai_DebugDraw консольная переменная включается и выключается.

ShowTime()

Регистрирует текущее системное время на консоли. Форматирование выглядит следующим образом: День/Месяц/Год, Часы:Минуты

количество( _tbl )

Возвращает количество пар ключ-значение данной таблицы.

новый( _obj, norecurse )

Создает новую таблицу на основе заданной в параметре. _obj. Обычно используется для создания локальной таблицы на основе таблицы параметров объекта.

слияние (dst, источник, рекурсия)

Используется для частичного объединения двух таблиц без объединения функций из исходной таблицы.

mergef(dst, src, рекурсивный)

Используется для полного объединения двух таблиц со всеми функциями исходной таблицы.

Век2Стр( век )

Используется для преобразования таблицы трехмерных векторов в строку и возвращает ее следующим образом: (x: X.XXX y: Y.YYY z: Z.ZZZ)

LogError( фмт, ... )

Используется для регистрации сообщения об ошибке на консоли и в файле журнала. Цвет текста установлен на красный в консоли.

LogWarning( фмт, ... )

Используется для регистрации предупреждающего сообщения на консоли и в файле журнала. Цвет текста установлен на желтый в консоли.

Журнал( fmt, ... )

Используется для регистрации сообщения на консоли и в файле журнала. Обычно используется для целей отладки.

дамп( _class, no_func, глубина)

Выводит информацию таблицы на консоль.

EmptyString( ул )

Проверяет, установлена ли заданная строка и ее длина больше нуля, и возвращает true, если это так.

NumberToBool( н)

Проверяет, является ли числовое значение правда или ложный. В этом случае правда означает, что число нет равен 0.

EntityName(объект)

Возвращает имя данной таблицы сущностей или идентификатор сущности или пустую строку, если сущность не существует.

EntityNamed(имя)

Возвращает true, если сущность с данным именем существует в системе сущностей. Обычно используется для отладки.

SafeTableGet(таблица, имя)

Проверяет, существует ли подтаблица с заданным именем в данной таблице, и возвращает ее, в противном случае возвращает ноль.
