Обзор - CRYENGINE 5.5.0 Предварительный просмотр 6

Мы очень рады представить вам версию 5.5.0 Preview 6. Наша команда разработчиков работала над улучшением предыдущих превью-версий, выпущенных 20 марта 2018 г., 3 мая 2018 г., 24 мая 2018 г., 7 июня 2018 г. и 26 июня 2018 г.

Как всегда, мы приветствуем дальнейшие отзывы и комментарии от сообщества CRYENGINE, но, пожалуйста, не могли бы они приходить через наши обычные каналы, т. е. Репортер по проблемам Github и .

Доступ к предварительной версии 5.5.0 6

Версии движка теперь доступны через панель запуска CRYENGINE.

  1. Войдите в панель запуска CRYENGINE.
  2. Перейти к LIBRARY -> Мои двигатели где перечислены ваши установленные и доступные двигатели. Оттуда двигатели можно обновить (установить).

Гитхаб

Версии Preview Engine также доступны на Github, однако исходный код редактора Sandbox доступен только через Github.

  1. Перейти к: https://github.com/CRYTEK/CRYENGINE/releases/5.5.0_preview6
  2. Скачать CRYENGINE_preview_5.5.0.327_pc.zip
  3. Разархивируйте его куда-нибудь и откройте каталог «CRYENGINE_preview_5.5.0.327_pc».
  4. Дважды щелкните InstallEngine.bat.

Если вы обновляетесь с CRYENGINE 5.4, прочтите эту тему: Миграция с CRYENGINE 5.4 на CRYENGINE 5.5.

Известные проблемы

  • RENDERER: Отражения нарушаются, если к объекту прикреплен материал. Можно настроить с помощью «r_ssreflsamples» и «r_ssrefldistance».
  • CRASH: Игра вылетает при запуске Vulkan.
  • CRASH: Legacy PFX может вызвать сбой вскоре после добавления на уровень.
  • PARTICLE EDITOR: Изменения эффекта частиц в новом Particle Editor не применяются напрямую к экземплярам эффекта частиц на уровне (в настоящее время необходима перезагрузка уровня).
  • CRASH: Иногда редактор аварийно завершает работу, если эффект частиц размещен на уровне и открыт в Particle Editor.
  • DESIGNER TOOL: Объекты могут быть невидимыми после загрузки уровня/цепочки.
    Обходной путь: включите, а затем отключите e_permanentRenderObjects 0/1.
  • С#: Использование расширения C# CRYENGINE для Visual Studio 2017 для запуска редактора или сервера GameLauncher, Sandbox может привести к ошибке при использовании в последней версии Visual Studio 2017. Дополнительную информацию и исправление этой проблемы можно найти здесь. здесь.
  • ENTITIES: Световой проектор не отбрасывает теней.
  • ENTITIES: Использование объекта/компонента в качестве движения, поворота/сочленения вращения в Trackview не воспроизводит анимацию в игре и/или в чистой игре.

  • Исправлено: Объекты-контейнеры не выводят правильные данные.

Графика и рендеринг

Общий рендерер

  • Исправлено: Платформа GetDebugName ifdef - исправлена компиляция для Durango.
  • Исправлено: Утечка памяти Scaleform.
  • Исправлено: Пул объектов состояния конвейера (PSO) неограниченно растет.
  • Изменено: Разрешить рекурсивное освобождение узлов рендеринга.

Дополнительные исправления

  • Исправлено: (Система сущностей) Вылет после прыжка на любой уровень и попытки выхода.
  • Исправлено: (Система сущностей) Неудаляемые объекты не были скрыты при удалении.
  • Исправлено: (Рендерер) Отсутствует информация в отражениях объема воды.
  • Исправлено: (Редактор Sandbox) При открытии уровня через браузер ресурсов будет установлен неверный путь к уровню. При сохранении уровня устаревший код в миссии, местности, растительности и т. д. не сможет определить путь.
  • Исправлено: (CryDefaultEntities) Утверждение и сбой в MannequinObject после удаления. MannequinObject был изменен на IEntityComponent, но при выключении по-прежнему вёл себя как GameObject.
  • Изменено: (Анимация) Имена параметров Vcloth были изменены, чтобы уточнить, что ограничения применяются и распространяются локально только между ближайшими соседями. NOTE: Пользователям потребуется установить значения по умолчанию для override и установить значения для новых параметров ограничения расстояния до ближайшего соседа (NNDC).
  • Изменено: (Character Tool) Флажок для NNDC теперь отключается после перезагрузки.
  • Изменено: (Объемы воды) Добавлены дополнительные параметры.
  • Изменено: (Объемы воды) Улучшены параметры затухания для подавления ярких ступенчатых артефактов между отсутствующей и неотсутствующей информацией об отражениях в пространстве экрана (SSR).
  • Изменено: (Sandbox) Не обрабатывайте события мыши в окне просмотра редактора уровней, если уровень не загружен.
  • Изменено: (Рендерер) Переместите обновление частиц GPU в Update(), а не в Execute().
