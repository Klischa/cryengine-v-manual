Сущность CRYENGINE представляет собой объект внутри игрового мира, с которым можно взаимодействовать различными способами. Объект можно свободно перемещать, вращать в любой ориентации и масштабировать до разных размеров. Поведение сущности также можно изменить, добавив к ней EntityComponents. Сущности — это основные строительные блоки для Sydewinder или любого другого приложения CRYENGINE.

Доступ к сущности с уровня

Использование объекта, который уже размещен на уровне, например каньон.крик Уровень выборки — это самый простой способ получить контроль над объектом.

// Get Tunnel Spawn Point helper.
Entity tunnelSpawnPointHelper = Entity.Find("TunnelSpawnPoint");

Как только ссылка на объект получена, ее можно использовать, например, для установки положения объекта или для изменения его поведения путем добавления и EntityComponent к Сущности.

Сущности можно найти только после полной загрузки уровня. Чтобы получить уведомление о завершении уровня, к событию можно добавить обработчик событий. LevelSystem.LoadingComplete.

Создание сущности

Иногда сущности необходимо создавать динамически, а не добавлять их на уровень в Sandbox. Это можно сделать с помощью Entity.Spawn метод. Чтобы убедиться, что уровень не заполняется динамически создаваемыми сущностями, все порожденные сущности iп Сайдевиндер получить заранее определенное время жизни. Это позволяет создавать и удалять объекты, если они уничтожены или покидают видимую область.

// Spawn an empty Entity.
var enemy = Entity.Spawn(position, rotation, scale);
 
// Spawn an Entity with an Enemy component.
var enemy = Entity.SpawnWithComponent<Enemy>(position, rotation, scale);

Размещение и перемещение объекта

Вы можете установить положение объекта, назначив Vector3 объекту. Position собственность Организации.

 myEntity.Position = new Vector3(x, y, z);

Существует два распространенных способа перемещения сущности. Либо вручную перемещая объект, обновляя Position свойство или переместить объект, установив Physics.Velocity собственность. Дополнительную информацию о том, как использовать скоростной подход, см. Физическое взаимодействие.

Пример этого можно найти в DestroyableBase класс, который является основой для всех игровых объектов Sydewinder. Объекты, которые не физикализованы или физизированы как static (например, стены на заднем плане), перемещаются путем непосредственной установки Positions собственность. Сущности, которые физикализованы как жесткие, перемещаются путем установки Velocity Сущности. Установка Velocity гарантирует, что коллизии обрабатываются правильно, где установка Position Свойство заставляет сущность переместиться в позицию, из-за которой сущности могут не сталкиваться должным образом.

public virtual Vector3 Move()
{
  if (!Entity.Exists)
    return Vector3.Zero;
  if(Entity.Physics == null || 
     Entity.Physics.PhysicsType == PhysicalizationType.Static || 
     Entity.Physics.PhysicsType == PhysicalizationType.None)
  {
    Entity.Position += Speed * FrameTime.Delta; 
  }
  else
  {
    Entity.Physics.Velocity = Speed;
    Entity.Physics.AngularVelocity = Vector3.Zero;
  }
  return Entity.Position;
}

Speed определяется в метров в секунду (м/с) и представляется в виде трехмерный вектор. Однако, чтобы обеспечить постоянную скорость перемещения по экрану (поскольку все PC имеют разную частоту кадров) FrameTime нормализует скорость, используя время, необходимое для рендеринга предыдущего кадра.

Вращение

Вращение объекта аналогично настройке положения объекта. Но вместо сложения двух векторов вращение осуществляется путем умножения Rotation свойство с другим кватернионом.

В следующем фрагменте показано, как вращать кольца спутников на заднем плане Сайдевиндера вокруг их оси Z:

private void RotateSatelliteRings()
{
  _rotatingRingOne.Rotation *= Quaternion.CreateRotationZ(MathHelpers.DegreesToRadians(FrameTime.Delta * 10f));
  _rotatingRingTwo.Rotation *= Quaternion.CreateRotationZ(MathHelpers.DegreesToRadians(FrameTime.Delta * -10f));
}

Опять же, мы нормализуем скорость вращения с помощью FrameTime для обеспечения плавности движения.
