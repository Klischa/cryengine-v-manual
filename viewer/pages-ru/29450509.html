Обзор

Flow Graph — это система визуальных сценариев, встроенная в редактор CRYENGINE Sandbox. Основное преимущество редактора Flow Graph заключается в том, что пользователям не требуются какие-либо знания сценариев или программирования.

Простую и сложную логику можно построить несколькими щелчками мыши, не требуя каких-либо знаний сценариев или кодирования. Большая библиотека узлов позволяет пользователю полностью контролировать объекты и AI на уровне.

Помимо того, что Flow Graph является основным инструментом, используемым для создания логики миссий на однопользовательских уровнях, его также можно использовать для создания прототипов игрового процесса, эффектов и звукового дизайна. Уровни могут иметь несколько графов, которые одновременно выполняют разные задачи.

Обзор использования

В Flow Graph каждый узел представляет собой логический элемент (компонент потока), где каждый компонент имеет произвольное количество типизированных входов и выходов. Все входные данные (кроме событий и любых других) содержат значения портов по умолчанию, которые можно изменить с помощью редактора Flow Graph, и эти входные порты также служат свойствами компонента.

Когда компонент получает значение на заданном входе, вход активируется. Этот метод проверяет порты, которые фактически активированы, извлекает значение входного порта и выполняет определенное действие узла (например, узел Math:Mul умножает входное значение на множитель, указанный в узле).

Компонент также может активировать выход, если выход подключен к входному порту другого компонента. Он немедленно передает ссылку и активирует входной порт следующего компонента.

Выход любого компонента потока может быть соединен со входом другого компонента потока с помощью направленной связи. Выходы и входы классифицируются по типам данных и могут быть любого из следующих типов (для вашего удобства также имеют цветовую кодировку)

Когда выход одного типа подключен к входу другого типа, при его передаче применяется разумное преобразование типа выходного значения.

Существует набор компонентов сущности (по одному на каждый тип класса сущности), которые предоставляют функциональные возможности сущности (ее события). Такие компоненты можно добавлять в редакторе из выбранных объектов, и они внутри содержат EntityId объекта, с которым они связаны.

Логика Flow Graph хранится в формате XML и может быть легко экспортирована для использования на других уровнях. Поскольку график всегда создается и сохраняется в определенной сущности, он также экспортируется вместе с объектом. Слои полностью поддерживаются в системе Flow Graph.
