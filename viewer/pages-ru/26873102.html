Использование команд

Команды редактора используются для автоматизации работы редактора и создания сценариев и должны быть одним из основных средств расширения функциональности редактора. Это одна из наиболее централизованных систем, и обеспечение доступности всех возможных действий вашего плагина или модуля через команды должно быть приоритетом.

Вот что могут делать команды редактора:

  • Все зарегистрированные команды можно использовать на панели Консоли (Инструменты -> Дополнительно -> Консоль).
  • Команды редактора, не принимающие никаких параметров, можно привязать к сочетанию клавиш (Правка -> Сочетания клавиш).
  • Пользовательские команды могут быть созданы из существующих команд для создания пользовательских ярлыков.
  • Команды являются основным средством создания пунктов меню.
  • Команды можно использовать на созданных пользователем панелях инструментов.

Команда редактора

Чтобы создать простую команду, которую можно выполнить через консоль, используйте REGISTER_EDITOR_COMMAND Марко определен в ICommandManager.h файл.

Пример консольной команды

Он принимает следующие параметры:

  1. Функция должна быть выполнена.
  2. Имя модуля, которому принадлежит команда.
  3. Имя команды.
  4. Описание команды.

Таким образом, эту команду можно выполнить через консоль, набрав «sample.sample_command».

Команды редактора также доступны для Python и других языков сценариев, с которыми может взаимодействовать Sandbox.

Консольная команда Python

Также можно зарегистрировать команду таким образом, чтобы к ней можно было получить доступ через экосистему Python, а также через другие языки сценариев, если Sandbox будет сопряжен с новыми языками сценариев. Не рекомендуется регистрировать команды Python, поскольку команды редактора также доступны для Python.

Для этого можно использовать один из следующих макросов: REGISTER_PYTHON_COMMAND или REGISTER_PYTHON_COMMAND_WITH_EXAMPLE. Это делает команду доступной через консоль, а также через другие инструменты Python (например, Инструменты -> Дополнительно -> Интерактивная консоль Python).

Подпись REGISTER_PYTHON_COMMAND идентичен REGISTER_EDITOR_COMMAND. Для REGISTER_PYTHON_COMMAND_WITH_EXAMPLE, он принимает один дополнительный параметр, который представляет собой строку, показывающую использование команды в сценарии Python.

Привязка к пунктам меню

Команду «Зарегистрировано» можно добавить в меню как таковую. Обратите внимание, что CEditor предоставляет вспомогательные методы для добавления команд в меню.

Установка дополнительных свойств

Для команды можно указать некоторые дополнительные свойства: отображаемый ярлыком текст и значок (для компонентов UI).

Для их установки необходимо REGISTER_EDITOR_UI_COMMAND_DESC нужно использовать макрос. Он принимает следующие параметры:

  1. Имя модуля
  2. Имя команды
  3. Текст для отображения
  4. Ярлык (типа CKeyboardShortcut). Также может быть задано в виде строки, поскольку происходит неявное преобразование в CKeyboardShortcut.
  5. Значок для отображения (форматированная строка).

Есть также несколько удобных макросов на случай, если необходимо установить только одно из вышеупомянутых свойств: REGISTER_EDITOR_COMMAND_SHORTCUT, REGISTER_EDITOR_COMMAND_ICON и REGISTER_EDITOR_COMMAND_TEXT.

Команда консоли двигателя

Команды консоли движка также можно вызывать из консоли редактора, однако они не позволяют использовать какие-либо функции редактора, такие как ярлыки или использование меню.

Чтобы зарегистрировать новую консольную команду, используйте макрос REGISTER_COMMAND определено в CrySystem/ISystem.h. См. документацию CrySystem: Консоль
