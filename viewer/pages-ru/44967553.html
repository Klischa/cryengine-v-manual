Управление арбитром

По соображениям безопасности выделенный сервер по умолчанию не запускается, если он запущен с правами root. При необходимости это поведение можно изменить, переключив OPTION_ALLOW_RUNNING_SERVER_AS_ROOT в CMake, хотя предпочтительнее сменить пользователя, запускающего игровой сервер.

Вот как запустить арбитр выделенного сервера:

  1. Перейдите в корневую папку сборки.
  2. Установить net_dedicatedServerArbitratorPort=<порт> в system.cfg до разумного значения.
  3. Зайдите в Бин32 или Бин64 папку и нажмите double DedicatedArbitrator.exe.
  4. Появится окно «Выделенный арбитр», дайте приложению несколько секунд для полной загрузки.
  5. Теперь арбитра можно оставить работающим в фоновом режиме.

Регистрация выделенного сервера у арбитра

Как зарегистрировать выделенный сервер у арбитра:

  1. Установить net_dedicatedServerArbitratorIP=<адрес> на адрес арбитра IP.
  2. Установить net_dedicatedServerArbitratorPort=<порт> арбитрам слушать порт.
  3. Установить gl_serverIsAllocatedFromDedicatedServerArbitrator=1 сообщить лобби, что это арбитражный сервер.
  4. Запустите сервер, регистрация произойдет автоматически и все должно быть готово к работе.

Запрос выделенного сервера у арбитра

Вот как запросить выделенный сервер у арбитра:

  1. Установить net_dedicatedServerArbitratorIP=<адрес> на адрес арбитра IP.
  2. Установить net_dedicatedServerArbitratorPort=<порт> арбитрам слушать порт.
  3. Установить gl_getServerFromDedicatedServerArbitrator=1 сообщить лобби, что ему следует запросить сервер у арбитра в начале матча.
  4. Запустите игру, теперь вы сможете создавать и проводить сеансы, как и раньше, сервер будет запрошен для использования, когда начнется матч.

Команды арбитра

Команды, которые могут быть полезны при запуске арбитра:

  • net_dedicatedServerArbitratorListFreeServers - список серверов, которые арбитр должен выделить.

Известные проблемы

  • Если levelrotation.xml присутствует при запуске арбитра, он будет загружать, создавать и рекламировать свой собственный сеанс, используя это, постарайтесь этого избежать.
  • Это касается и выделенного сервера.
