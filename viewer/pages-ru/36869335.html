← Содержание Библиотека сущностей RU

Вкладка «Библиотека объектов» в представлении DataBase больше не поддерживается в CRYENGINE. В будущем он будет удален из движка, и некоторые функции могут работать не так, как ожидалось.

Обзор

Сущность-архетип основана на обычной сущности и определяет индивидуальные значения параметров для самой сущности. Если значение параметра Архетипа изменено, все экземпляры этого Архетипа в сцене будут обновлены автоматически.

Сущности архетипов организованы в библиотеки, которые можно создавать в DataBase Посмотреть.

Это означает, что дизайнеры технических уровней могут заранее определять варианты классов Entity как архетипы Entity, которые можно использовать на протяжении всей игры. Для глобальных изменений, затрагивающих все экземпляры, достаточно один раз изменить объект Archetype в представлении базы данных.

Окно содержит общие параметры объекта, которые существуют во всех сущностях Архетипа. Они независимы от отдельных скриптов сущностей.
