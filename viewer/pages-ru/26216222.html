Обзор

В CRYENGINE каждый игрок представлен экземпляром сущности, создаваемым кодом игры, когда клиенты подключаются к серверу.

Пользовательский код может прослушивать события подключения клиента, реализуя INetworkedClientListener. Это позволяет создавать объекты со стороны игры всякий раз, когда подключается клиент, начинать игровой процесс после того, как игрок завершает подключение, и, наконец, предоставляет событие отключения, позволяющее удалить любые объекты, созданные для конкретного клиента.

Локальный игрок

В настоящее время движок предполагает, что объект локального игрока всегда создается с идентификатором 30583, определенным через LOCAL_PLAYER_ENTITY_ID. Это описано в примере прослушивателя сетевого клиента выше. Кроме того, местные игроки должны установить ENTITY_FLAG_LOCAL_PLAYER флаг сущности.

Идентификаторы каналов

События подключения клиента в основном отправляются только на сервер и идентифицируют каждого игрока по идентификаторам каналов. Для получения дополнительной информации см. сеть.
