Описание

Класс CTagDefinition представляет собой набор ключевых слов (тегов). Класс используется для представления нескольких различных наборов ключевых слов в системе манекенов. Это включает в себя Mannequin Теги и определения тегов и FragmentID Файл определения.

Особенности

Теги могут иметь связанные с ними приоритеты. Приоритеты тегов используются в основном для ранжирования. Mannequin Теги.

Теги могут быть присвоены группе. Теги, сгруппированные вместе, будут взаимоисключающими, поэтому мы не сможем иметь TagState, указывающий, что они оба активны одновременно.

Тегам в CTagDefinition присваивается последовательный и уникальный TagId (начиная с 0 и уникальный в пределах TagDefinition), который можно использовать для более эффективного выполнения операций вместо постоянного использования имени тега.

Для повышения эффективности теги можно ссылаться на строчные буквы-crc32, если использование зависящего от порядка TagId слишком ограничительно.

Тегам могут быть назначены битовые последовательности, чтобы они могли стать частью состояний тегов (комбинации тегов) для поиска фрагментов или переходов.

Каждый тег может дополнительно иметь Sub TagDefinition. В основном это используется FragmentID Файлы определений чтобы указать определение тега для их тегов, специфичных для fragmentID (также известных как теги фрагмента).

Загрузка

Можно хранить TagDefinitions в XML-файлах и загружать их через Менеджер базы данных анимации:

// Example of how to load a tag definition stored in an xml file.
IMannequin& mannequinInterface = pGameFramework->GetMannequinInterface();
IAnimationDatabaseManager& animationDatabaseManager = pMannequinInterface->GetAnimationDatabaseManager();
const CTagDefinition* pTagDefinition = animationDatabaseManager.LoadTagDefs( "Animations/Mannequin/ADB/ExampleTagDefinition.xml" );

Создание

TagDefinitions также можно создать напрямую с помощью кода, хотя это встречается гораздо реже.

// Example of how to create a tag definition from code
CTagDefinition example;
example.AddTag("Aiming");
example.AddTag("Crouch", "StanceGroup");
example.AddTag("Stand", "StanceGroup");
example.AssignBits();
