Обзор

Процедурные клипы, как описано в статья о них, представляют собой клипы, которые можно размещать во фрагментах и позволяют выполнять собственный код синхронно с остальной частью фрагмента.

У нас есть процедурные клипы, которые варьируются от воспроизведения звука, управления суставами персонажа до процедурного выравнивания объекта по местоположению, указанному в игре. Текущие типы перечислены в эта статья.

Основными функциями интерфейса, которые предлагает процедурный клип, являются OnEnter(blendTime(blendTime, длительность, параметры) Update(timePassed) и OnExit(blendTime).

На следующей диаграмме показано, когда события запускаются в зависимости от времени существования процедурного клипа.

   +-----+--------------------------+
   |    /|                          |\
   |   / |                          | \
   |  /  |                          |  \
   | /   |                          |   \
   |/    |                          |    \
   +-----+--------------------------+-----+
   [             Update             ]
   ^                                ^
OnEnter                           OnExit

Обработка времени наступления и окончания наложения является обязанностью реализации процедурного клипа.

Обратите внимание, что после того, как клип получит обратный вызов OnExit, он перестанет получать любые обратные вызовы обновления, даже если параметр blendTime, переданный в OnExit, не равен нулю.

Ниже приведен пример класса, реализующего пустой процедурный клип.

// In ProceduralClipEmpty.cpp:
struct SProceduralClipEmptyParams
  : public IProceduralParams
{
  virtual void Serialize(Serialization::IArchive& ar)
  {
    ar(exampleParam, "exampleParam", "Example Parameter");
  }

  float exampleParam;
};

class CProceduralClipEmpty
  : public TProceduralClip<SProceduralClipEmptyParams>
{
public:
  virtual void OnEnter(float blendTime, float duration, const SProceduralClipEmptyParams& params) {}
 
  virtual void OnExit(float blendTime) {}
 
  virtual void Update(float timePassed) {}
};
REGISTER_PROCEDURAL_CLIP(CProceduralClipEmpty, "Empty");

Процессуальный контекст

(не путать с контекст области действия)

Процедурные клипы имеют ограниченный срок жизни. Сами по себе они не могут решить, что делать при смешивании, поскольку после обратного вызова OnExit они больше не обновляются. У них также нет прямого способа узнать, что другие процедурные клипы могут делать в других слоях, и разрешить любые конфликты между ними, если они этого захотят, или работать вместе с другими процедурными клипами, чтобы объединить то, что они делают.

Если в объекте нет базовой системы, которая могла бы позаботиться об этих взаимодействиях, именно здесь пригодятся процедурные контексты. Они предоставляют систему, срок службы которой привязан к ActionController и с которой могут легко взаимодействовать процедурные клипы.

Чтобы создать процедурный контекст и ProceduralClips, которые могут ссылаться на этот процедурный контекст, см. следующий фрагмент кода:

// In ProceduralContextExample.h:
class CProceduralContextExample
: public IProceduralContext
{
public:
  PROCEDURAL_CONTEXT(CProceduralContextExample, "ProceduralContextExample", 0xbd3b8e9b263b4768, 0x8e5444b453233fb7);

  // IProceduralContext
  virtual void Initialise(IEntity& entity, IActionController& actionController);
  virtual void Update(float timePassedSeconds);
  // \~IProceduralContext
};
