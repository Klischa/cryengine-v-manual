Уничтожение потока

Для завершения потока рекомендуется выполнить следующую процедуру. 

// Where m_pMyThread pointed object inherits from IThread
 
// Signal the thread that it should stop
m_pMyThread->SignalStopWork(); // Function implement by you, signaling your thread to exiting IThread::ThreadEntry()

// Wait for the thread to exit IThread::ThreadEntry()
gEnv->pThreadManager->JoinThread(m_pMyThread, eJM_Join); 

// Delete shared data
delete m_pMyThread;
m_pMyThread= nullptr;

1. Подайте сигнал потоку, что ему следует прекратить дополнительную работу.

Подайте сигнал потоку о том, что он должен завершиться, установив некоторое условие выхода.

В нашем примере это делается вызовом SignalStopWork(). Важно отметить, что сигнальный поток не завершается немедленно. Он может выйти из цикла while только после завершения всей работы за итерацию, которая может занять несколько миллисекунд.

m_pMyThread->SignalStopWork();

2. Подождите, пока поток завершит работу без ошибок.

Во многих случаях существует зависимость между потоком, сигнализирующим другому потоку о прекращении работы, и потоком, выполняющим работу. В нашем примере, как только мы вызвали m_pMyThread->SignalStopWork() нам больше не нужен m_pMyThread объект. Однако нам нужно подождать, пока мы не будем на 100% уверены, что поток, которому мы дали сигнал прекратить работу, больше не использует данные. Следовательно, нам придется подождать, пока мы не узнаем, что оно прекращено. Это делается путем присоединения к теме.

gEnv->pThreadManager->JoinThread(m_pMyThread, eJM_Join);

3. Очистка данных общего потока

Как только мы узнаем, что целевой поток завершился и больше не работает с определенным набором данных, мы можем продолжить и удалить все ресурсы, которыми он поделился с сигнальным потоком, а также удалить сам объект IThread.

delete m_pMyThread;
m_pMyThread= nullptr;
