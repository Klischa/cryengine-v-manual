← Содержание 4. Генерация нашего GUID RU

GUID позволяет движку однозначно идентифицировать этот плагин без возможности конфликта с другими плагинами. Этот GUID может быть сгенерирован из Visual Studio внутри Инструменты меню:

Генерируем наш GUID

Теперь нам нужно указать нашему плагину имя и GUID:

  1. Доступ к Создать GUID от входа в Инструменты меню.
  2. В окне сообщения выберите Формат реестра.
  3. Далее нажмите Копироватьи вставьте сгенерированный GUID в наш код.
