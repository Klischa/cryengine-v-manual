Получение элемента Flash для отображения вашего результата

Ниже объясняется, как выполнить функцию, которую мы представили во Flash UI ActionScript, с параметром для изменения значения, отображаемого в текстовом поле, с использованием узлов визуального сценария; эти узлы генерируются путем чтения элементов UI XML, которые мы ранее изменили в этом руководстве.

Для этого мы возьмем элемент UI, который мы отобразили в Глава 3. Элементы UI а затем расширить функциональность с помощью функции, которую мы определили в самом элементе UI XML.

Выполнение функции

Выполните следующие шаги, чтобы выполнить функцию и установить значение, отображаемое в динамическом текстовом поле элемента UI:

Не рекомендуется смешивать подходы Flow Graph и Schematyc (экспериментальный), поскольку совместное использование экземпляров элемента UI может привести к запутанным результатам и проблемам, которые трудно отследить.

Flow Graph

  1. Найдите узел в Flow Graph, расположенный по адресу Добавить узел → UI → Функции → uiQuickStart → UpdateScore и добавьте его в свой график.

    UpdateScore

  2. Подключите Позвонить ввод в узел по вашему выбору; в этом случае мы используем Добавить узел → Отладка → InputKey узел со своим Ключ вход установлен на Ф ключ.

    Подключите вход вызова к узлу по вашему выбору.

  3. Наконец, укажите номер для Значение параметр UpdateScore node и сохраните график.

Схема (экспериментальная)

  1. Сначала добавьте компонент ввода в вашу сущность uiquicktest.

    Входной компонент

  2. Затем добавьте Функции → Компоненты → Ввод → RegisterKeyboardAction node к вашему графику и подключите его к узлу Start.

    RegisterKeyboardAction узел

  3. Установите Имя группы и Имя входные свойства узла RegisterKeyboardAction для ui_input и show_ui соответственно. Также установите Входной идентификатор чтобы Ф и проверь Получайте пресс-мероприятия.

    Установите входы узла, как показано

  4. Далее добавьте Сигнал → Получение → uiquickstart → Ввод → При нажатии действия узел графа.

    При нажатии кнопки «Действие»

  5. Также добавьте Функции → Стандарт → Строка → Равно и Филиал узел, чтобы вы могли проверить имя полученного действия, поскольку мы хотим реагировать только тогда, когда show_ui действие срабатывает.

    Равный узел


    Узел ответвления


    Обеспечение того, чтобы мы реагировали только при срабатывании show_ui

  6. Наконец, добавьте Функции → Компоненты → FlashElement:uiQuickStart → Динамический → UpdateScore узел и установите его Значение ввод в 5; подключить UpdateScore's В вход в Правда выход Филиал узел.

    UpdateScore узел


    Установите входное значение узла UpdateScore на 5.

При входе в игровой режим в редакторе Sandbox вы должны увидеть сообщение UI «Оценка: 0». После нажатия кнопки Ф ключ, вы должны увидеть новое значение, отображаемое в рейтинге UI.


Нажмите клавишу F, чтобы обновить счет.
