Версия лаунчера 1.6.6

Целевая страница

  • Исправлено: Репортер проблемы: Пользователь не может удалить прикрепленный файл — теперь прикрепленный файл можно удалить.
  • Исправлено: Reporter: пользователь может открыть несколько модальных окон «Сообщить о проблеме» — теперь одновременно можно открыть только одно модальное окно «Сообщить о проблеме».
  • Изменено: Reporter: кнопка «Развернуть» в модальном окне «Сообщить о проблеме» не работает должным образом — кнопка «Развернуть» удалена.
  • Изменено: В уведомительном сообщении теперь указывается, что ранее приобретенный пользователем актив был обновлен поставщиком, и это обновление доступно для загрузки пользователем.

Проекты

  • Новое: Кнопки активов: переименованы Кнопка «установить» для «скачать».
  • Исправлено: Импортировано проекты назывались неправильно — импортированные проекты теперь называются правильно.
  • Рефакторинг: нУпростился процесс создания нового проекта.
  • Рефакторинг: Упрощен выбор места хранения проекта (где он будет храниться/сохраняться на жестком диске).
