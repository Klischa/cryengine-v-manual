CryENGINE 3 бесплатно SDK — сборка 6289, журнал изменений

Выпущено 1 февраля 2013 г.

Исправлено
  • PlayerRotation WriteLockCond
  • Выбор объектов за замороженной группой работает с ошибками.
  • Исправлен сбой при взрыве HMMWV.
  • Проблема с выдвижением коробки цилиндров при определенных совмещениях.
  • Фиксированная ориентация частиц
  • Возможный сбой, если SmartObjectManager уже удален (VehicleSeatActionWeapons).
  • Различные исправления: ошибки printf, деление на 0.
  • Исправлено переполнение битовой маски.
  • Исправлено предупреждение о сохранении игры.
  • Оболочка CryLight: галочки в меню не отображаются.
  • Сбой при перезагрузке уровня, если Model3DHud все еще был активен.
  • UI: не блокировать ввод, если элемент исчезает.
  • Исправлен сбой при выходе за счет предотвращения дублирования освобождения D3DSurface. Исправлено несколько других ошибок при выходе.
  • Неправильный выбор локации для многосеточных объектов static.
  • Исправлено и значительно улучшено движение цели частиц: скорость больше не применяется дважды; целевая доля орбиты, рассчитанная на основе возраста начала частицы; радиальное движение правильно отделено от орбитального движения; более быстрый средний радиус для расчета угловой скорости
  • MaxCryExport: отключение расширений скина/скела, конфигурации интегрированного решения для Max2013.
  • ShapeDeformations не существовало, вызывало сбой при загрузке объекта с морфами
  • Всегда сбрасывать пустые и выделять фрагменты, если мы удаляем последний из FixedAllocator
  • Исправлена неверная структура пакета при отсутствии соединений.
  • Исправлена ошибка, из-за которой размер диалогов Material Editor и TOD практически не изменялся, теперь минимум 400x300.
  • Исправлен флажок отрисовки отладки физики на панели рендеринга, который не включался.
  • EntityObject теперь устанавливает правильное мировое пространство SRendParams.fDistance (используя радиус BB для размера)
  • Проблема с 64-битной версией Qhull
  • Надписи на персонажах (цвет отладки декалей bbox изменен на красный, правильное появление декалей на вложениях со скинами, очищен код CreateDecalsOnInstance)
  • Проблема с невыдвижением коробки-цилиндра
  • Гораздо более высокая точность функции MoveRelative, предотвращает дрейф частиц.
  • Принудительное изменение состояния на FallAndPlay при падении актера
  • Поддержка выделенного сервера для пользовательских имен GameDLL (в противном случае произойдет сбой)
  • Добавление имени entityClass к NavigationAreaObject (оно также отображается как тип в списке объектов, доступных на уровне)
  • Исправлена ошибка Normalize-0 для вертикальных углов камеры.
  • Если правила игры не существуют, по умолчанию используется DeathMatch.
  • Неправильное клонирование узлов LogicOnce
  • Исправлена ракетная установка, не создававшая материал для ударных декалей. Закомментирован код декалей/pfx в скриптах боеприпасов.
  • Примитив физики сферы теперь правильно вокселизирован. Добавлена поддержка вокселизации капсул.
  • Неправильное освобождение, если это последний фрагмент в FixedAllocator
  • BST Редактор не перезагружался должным образом из-за отсутствия регистрации.
  • Возможный сбой, если SmartObjectManager больше не существует (VehicleDamageBehaviorBurn).
  • Неправильное использование текстуры декали на Mine Entity (устаревшая функция)
  • Контакт цилиндр-цилиндр - нормальная проблема
  • Неправильная настройка слота объекта при настройке эмиттера частиц (прерывает появление в случайных местах геометрии рендеринга, если эмиттер частиц не связан с другим объектом)
  • Звуки боли не работают с новой системой локализации
  • Чит-код protected, ошибка CVars звука
  • Не заполнять стек UI при отключенных и недействительных действиях UI
  • Проверка работоспособности в UIActions


Оптимизация

  • Оптимизация и консолидация статистики частиц, код на 200 строк меньше. Больше не распределять статистику в CParticleEffect; динамически собирать на карте
  • Удален устаревший код частиц с отрицательным возрастом.
  • Кисть объекта без переключения столкновений
  • Точная отсечка частиц в усеченном виде, на 60 % больше частиц, чем при конусе, примерно та же скорость.
  • Измените размер значка помощников редактора по умолчанию с 1 -> 0,5.
  • Удален сложный кеш XML в CParticleEffect; теперь загружаем все эффекты в библиотеку и удаляем неиспользуемые при запуске уровня, экономится еще больше памяти
  • Небольшие изменения плавучести жестких объектов.


Твик

  • Отключена принудительная обратная связь в system.cfg, не требуется во время разработки.
  • Убрано неправильное утверждение в CreateSound.
  • Переработано стереоскопическое окно, чтобы оно правильно помещалось в сворачивающуюся панель.
  • Минимальный угол падения по умолчанию увеличен до 70 градусов.
  • Убрано отключение создания экземпляров геометрии в system cfg.
  • Добавлено предупреждение для уровней с пробелами в названии. Добавлено предупреждение для карт высот размером более 4096. Исправлена ошибка с обрезанием текста в диалоговом окне конфигурации инструментов.
  • Порт по умолчанию LAN теперь равен 64090.
  • Переместить кнопку изменения разрешения сектора текстуры из художника текстур ландшафта в диалоговое окно импорта/экспорта текстуры ландшафта.
  • Минимальный анизо-фильтр уменьшен до 4, добавлен минимальный анизо-8 до sys_spec 4, добавлен максимальный анизо-16 для всех спецификаций.
  • Обновленный заставка
  • Уникальные имена для префабов, основанные на имени библиотеки, а не только на имени типа.
  • Изменен инструмент создания текстур, чтобы сделать интерфейс более чистым и менее загроможденным. Высокое качество проверено по умолчанию
