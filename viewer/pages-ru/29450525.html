Обзор

Узел — это представление объекта или действия внутри Flow Graph.

Типы узлов

Существует две категории узлов: Узлы сущностей и Узлы компонентов:

Порты

Компоновка узлов Component и Entity аналогична. Узел состоит из двух сторон: входа и выхода. Передача информации узлов осуществляется через порты. Порты могут отправлять или получать информацию. На левой стороне узла вы найдете входные порты, которые используются для подключения входящих ссылок. К этим портам подключаются каналы с других узлов. Порты на правой стороне узла называются выходными портами и активируются в зависимости от поведения узла. Порты визуализируются в виде маленьких стрелок по обе стороны от узлов. Порты могут иметь разные типы данных, которые можно определить по их цвету. Порт может иметь один из шести различных типов данных:

  • Любой: Это неопределенный тип данных; любой входной сигнал может быть подан в этот порт.
  • Логическое значение: Логическое значение может быть либо истинным, либо ложным.
  • Целое число: Целое число – это целое число, которое может быть как положительным, так и отрицательным.
  • Плавающий: Тип данных значения с плавающей запятой.
  • Век3: Тип данных, состоящий из трех значений float, представляющих вектор; используется для хранения положений, углов или значений цвета.
  • Строка: Строка — это массив символов, используемый для хранения текста.

Значения, тип которых не соответствует типу данных входного порта, будут автоматически преобразованы в соответствии с типом порта, к которому они подключены, если это возможно. Любой выходной порт можно подключить к любому входному порту независимо от его типа. Целое число со значением 1 можно подать в логический входной порт, и он будет преобразован как правда чтобы соответствовать типу данных порта. Для некоторых узлов компонентов в верхней части объекта имеется специальный входной порт, который используется для установки целевого объекта узла.

Каждому типу порта присвоен определенный цвет, чтобы помочь пользователям быстро определить тип данных, предоставляемый или принимаемый портом.

Цвета:

  • Ссылки: Линии используются для соединения портов и передачи информации между ними. Длина или форма соединения не имеют значения, поскольку сигнал всегда передается немедленно. При перемещении любого из узлов, связанных ссылкой, ссылка автоматически настраивается. Ссылки создаются путем перетаскивания между входными и выходными портами. Ссылки можно удалить, отключив их от выходного порта или воспользовавшись контекстным меню ссылки.
