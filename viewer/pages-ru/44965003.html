Обзор

Обзор CVar, доступных в конкретной реализации Wwise.

CVars

s_WwiseChannelConfig

Определяет конфигурацию канала.

  • Использование: s_WwiseCommandQueueMemoryPoolSize [51/...]
    0: Настройка динамиков по умолчанию.
    Настройка динамиков 10:1.0.
    11: Настройка динамиков 1.1.
    20: Настройка динамиков 2.0.
    21: Настройка динамиков 2.1.
    30: Настройка динамиков 3.0.
    31: Настройка динамиков 3.1.
    40: Настройка динамиков 4.0.
    41: Настройка динамиков 4.1.
    50: Настройка динамиков 5.0.
    51: Настройка динамиков 5.1.
    60: Настройка динамиков 6.0.
    61: Настройка динамиков 6.1.
    70: Настройка динамиков 7.0.
    71: Настройка динамиков 7.1.
  • По умолчанию: 0

s_WwiseCommandQueueMemoryPoolSize

Указывает размер (в KiB) пула памяти очереди команд Wwise.

  • Использование: s_WwiseCommandQueueMemoryPoolSize [0/...]
  • Значения по умолчанию:
    PC: 256 | XboxOne: 256 | PS4: 256 | Мак: 256 | Линукс: 256 | iOS: 256 | Андроид: 256

s_WwiseDebugListFilter

Определяет, какие списки отображать, когда фильтрация списков включена в отладочной схеме аудиосистемы.

  • Использование: s_WwiseDebugListFilter [0ab...] (флаги можно комбинировать)
    0: Ничего не рисовать.
    a: Нарисовать экземпляры событий.
    б: значения состояний рисования.
  • По умолчанию: аб

s_WwiseEnableCommSystem

Указывает, должен ли Wwise инициализироваться с использованием своей системы связи или нет.

  • Использование: s_WwiseEnableCommSystem [0/1]
  • По умолчанию: 0 (выкл.)
Доступно только для нерелизных сборок.

s_WwiseEnableEventManagerThread

Указывает, должен ли Wwise инициализироваться с использованием своего потока EventManager или нет.

  • Использование: s_WwiseEnableEventManagerThread [0/1]
  • По умолчанию: 1 (вкл.)

s_WwiseEnableOutputCapture

Позволяет записывать выходной звук в WAV-файл.

  • Использование:s_WwiseEnableOutputCapture [0/1]
  • По умолчанию: 0 (выкл.)
Доступно только в нерелизных сборках.

s_WwiseEnableSoundBankManagerThread

Указывает, должен ли Wwise инициализироваться с использованием своего потока SoundBankManager или нет.

  • Использование: s_WwiseEnableSoundBankManagerThread [0/1]
  • По умолчанию: 1 (вкл.)

s_WwiseEventPoolSize

Устанавливает количество предварительно выделенных событий.

  • Использование: s_WwiseEventPoolSize [0/...]
  • Значения по умолчанию:
    PC: 256 | Xbox One: 256 | PS4: 256 | Мак: 256 | Линукс: 256 | iOS: 256 | Андроид: 256

s_WwiseLowerEngineDefaultPoolSize

Указывает размер (в KiB) нижнего пула памяти ядра Wwise.

  • Использование: s_WwiseLowerEngineDefaultPoolSize [0/...]
  • Значения по умолчанию:
    PC: 16384 (16 MiB) | Xbox One: 16384 (16 MiB) | PS4: 16384 (16 MiB) | Mac: 16384 (16 MiB) | Linux: 16384 (16 MiB) | iOS: 16384 (16 MiB) | Андроид: 16384 (16 MiB)

Указывает размер (в KiB) пула памяти монитора Wwise.

  • Использование: s_WwiseMonitorMemoryPoolSize [0/...]
  • Значения по умолчанию:
    PC: 256 | XboxOne: 256 | PS4: 256 | Мак: 256 | Линукс: 256 | iOS: 256 | Андроид: 256

s_WwisePanningRule

Определяет правило панорамирования Wwise.

  • Использование: s_WwisePanningRule [0/1]
    0: Динамики
    1: Наушники
  • Значения по умолчанию:
    PC: 0 | Xbox One: 0 | PS4: 0 | Мак: 0 | Линукс: 0 | iOS: 1 | Андроид: 1

s_WwisePositionUpdateThresholdMultiplier

Расстояние объекта до слушателя умножается на это значение, чтобы определить порог обновления положения.

  • Использование: s_WwisePositionUpdateThreshold [0/...]
  • По умолчанию: 0,02

s_WwisePrepareEventMemoryPoolSize

Указывает размер (в KiB) пула памяти событий подготовки Wwise.

  • Использование: s_WwisePrepareEventMemoryPoolSize [0/...]
  • Значения по умолчанию:
    PC: 2048 (2 MiB) | Xbox One: 2048 (2 MiB) | PS4: 2048 (2 MiB) | Мак: 2048 (2 MiB) | Linux: 2048 (2 MiB) | iOS: 2048 (2 MiB) | Андроид: 2048 (2 MiB)

s_WwiseSecondaryPoolSize

Указывает размер (в KiB) пула памяти, который будет использоваться реализацией Wwise.

  • Использование: s_WwiseSecondaryPoolSize [0/...]

    PC: 0 | Xbox One: 32768 (32 MiB) | PS4: 0 | Мак: 0 | Линукс: 0 | WiiU: 0 | iOS: 0 | Андроид: 0

s_WwiseVelocityTrackingThreshold

Объект должен изменить свою скорость как минимум на эту величину, чтобы выдать сигнал. absolute_velocity запрос обновления параметров аудиосистемы.

  • Использование:s_WwiseVelocityTrackingThreshold [0/...]
  • По умолчанию: 0,1 (10 см/с)
