Обзор

В этом разделе обсуждается, как использовать систему Flash UI в C++.

Доступ к интерфейсу IFlashUI

Чтобы получить доступ к IFlashUI Интерфейс из любого места, где вы можете просто включить IFlashUI.h заголовочный файл и используйте глобальный gEnv->pFlashUI.

#include <IFlashUI.h>

Поскольку FlashUI реализован как расширение, которое по какой-то причине может быть отключено, всегда полезно проверить этот указатель.

if ( gEnv->pFlashUI )
{
  // ...
}

UIArguments и UIData

Для упрощения передачи аргументов между Flash и C++ мы используем тип TUIData как переменные данные и struct SUIАргументы как набор TUIData. Каждая функция и событие используют эти типы для передачи данных между Flash и C++.

TUIData

TUIData тип - это CConfigurableVariant со строгим разговором.

Примеры:

bool bOk;
TUIData data( 7 );
int iVal;
float fVal;
string sVal;
bOk = data.GetValueWithConversion( iVal ); //bOk = true; iVal = 7;
bOk = data.GetValueWithConversion( fVal ); //bOk = true; fVal = 7.f;
bOk = data.GetValueWithConversion( sVal ); //bOk = true; sVal = "7";

bool bOk;
TUIData data( 11.f );
int iVal;
float fVal;
string sVal;
bOk = data.GetValueWithConversion( iVal ); //bOk = true; iVal = 11;
bOk = data.GetValueWithConversion( fVal ); //bOk = true; fVal = 11.f;
bOk = data.GetValueWithConversion( sVal ); //bOk = true; sVal = "11";

bool bOk;
TUIData data( 11.3f );
int iVal;
float fVal;
string sVal;
bOk = data.GetValueWithConversion( iVal ); //bOk = false; iVal = undefined;
bOk = data.GetValueWithConversion( fVal ); //bOk = true; fVal = 11.3f;
bOk = data.GetValueWithConversion( sVal ); //bOk = true; sVal = "11.3";

bool bOk;
TUIData data( string("11") );
int iVal;
float fVal;
string sVal;
bOk = data.GetValueWithConversion( iVal ); //bOk = true; iVal = 11;
bOk = data.GetValueWithConversion( fVal ); //bOk = true; fVal = 11.f;
bOk = data.GetValueWithConversion( sVal ); //bOk = true; sVal = "11";

bool bOk;
TUIData data( string("11.5") );
int iVal;
float fVal;
string sVal;
bOk = data.GetValueWithConversion( iVal ); //bOk = false; iVal = undefined;
bOk = data.GetValueWithConversion( fVal ); //bOk = true; fVal = 11.5f;
bOk = data.GetValueWithConversion( sVal ); //bOk = true; sVal = "11.5";

bool bOk;
TUIData data( string("11.5 foo") );
int iVal;
float fVal;
string sVal;
bOk = data.GetValueWithConversion( iVal ); //bOk = false; iVal = undefined;
bOk = data.GetValueWithConversion( fVal ); //bOk = false; fVal = undefined;
bOk = data.GetValueWithConversion( sVal ); //bOk = true; sVal = "11.5 foo";

SUIАргумент

SUIАргумент struct — это коллекция TUIData. Он предоставляет некоторые базовые функции для установки/добавления/получения данных в этот список аргументов. Он также преобразует разделенные строки (разделитель по умолчанию — «|») и список TUIData и предоставляет функцию для доступа к значениям как указателю на SFlashVarValue вектор (тип данных Scaleform, для получения дополнительной информации см. IFlashPlayer.h).

Пример
// fill some arguments
SUIArguments args;
args.AddArgument( 12 );
args.AddArgument( 7.3f );
args.AddArgument( string("foo") );
args.AddArgument( string("12") );

// get arguments as stringlist
const char* stringlist = args.GetAsString(); // stringlist="12|7.3|foo|12";

// copy arguments from string list
SUIArguments args2;
args2.SetArguments( stringlist );

// get arguments
bool bOk;
int arg1;
float arg2;
float arg3;
float arg4;
bOk = args2.GetArg(0, arg1); // bOk = true; arg1 = 12;
bOk = args2.GetArg(1, arg2); // bOk = true; arg2 = 7.3f;
bOk = args2.GetArg(2, arg3); // bOk = false; arg3 = undefined;
bOk = args2.GetArg(3, arg4); // bOk = true; arg4 = 12;

// iterate thru arguments
for ( int i = 0; i < args2.GetArgCount(); ++i )
{
  TUIData arg = args2.GetArg( i );
  // ...
}

// change delimiter for string lists
args2.SetDelimiter(",");
const char* stringList2 = args2.GetAsString();//stringlist="12,7.3,foo,12";

UIElements

К каждому Flash-ресурсу, определенному в XML-файле, можно получить доступ с помощью IFlashUI интерфейс. См. также UI Элемент.

<UIElements name="HudElements">
  <UIElement name="HUD">
    <GFx file="HUD.gfx" layer="1">
      <Constraints>
        <Align mode="fullscreen" />
      </Constraints>
    </GFx>

    <functions>
      <function name="SetHealth" funcname="myHealthMc.mysubmc.setHealth">
        <param name="Health" desc="Players current health"/>
      </function>
    </functions>

    <events>
      <event name="OnButton1" fscommand="onMyButtonPressed">
        <param name="Arg1" desc="Some argument"/>
        <param name="Arg2" desc="Another argument"/>
      </event>
    </events>

    <variables>
      <variable name="SomeVariable" varname="someVariable"/>
      <variable name="TextField" varname="_root.myTextfield.text"/>
    </variables>

    <arrays>
      <array name="SomeArray" varname="_root.mc2.someArray"/>
    </arrays>

    <movieclips>
      <movieclip name="MovieClip1" instancename="_root.Mc1"/>
      <movieclip name="MovieClip2" instancename="_root.Mc1.subMc"/>
    </movieclips>

  </UIElement>
 </UIElements>

Чтобы получить доступ к элементу "HUD" UI, просто используйте GetUIElement() функция.

#include <IFlashUI.h>
// ...

if ( gEnv->pFlashUI )
{
  IUIElement* pHUD = gEnv->pFlashUI->GetUIElement( "HUD" );
  if ( pHUD )
  {
    // ...
  }
}

Переменные и массивы

Чтобы получить или установить переменную, вы можете просто получить к ней доступ через IUIElement интерфейс.

Обратите внимание: если вы хотите получить доступ к определенному элементу, вам придется использовать имя, определенное в XML для этого элемента и нет настоящее имя в вашем флеш-ресурсе.

pHUD->SetVar( "SomeVariable", 12 );
pHUD->SetVar( "TextField", string("Some text") );

// iVar can be undefined if "SomeVariable" has no valid integer (e.g. string)
int iVar = pHUD->GetVar<int>( "SomeVariable" );

// more safe you can check if TUIData is your expected type
TUIData text;
pHUD->GetVariable( "TextField", text );

// set array
SUIArguments myArray;
myArray.AddArgument( 12 );
myArray.AddArgument( 17 );
myArray.AddArgument( string("str") );
myArray.AddArgument( 23.f );
pHUD->SetArray( "SomeArray", myArray );

// get array
SUIArguments myArray;
pHUD->GetArray( "SomeArray", myArray );

MovieClips

Чтобы получить доступ к определенному вами MovieClips, вы можете использовать GetMovieClip() функция:

IFlashVariableObject* pMC = pHUD->GetMovieClip( "MovieClip1" );
if ( pMC )
{
  // ...
}

Возвращенный IFlashVariableObject можно использовать для изменения этого MovieClip. Проверить IFlashPlayer.h для получения дополнительной информации.

Функции

Чтобы вызвать определенную функцию, вы можете просто использовать CallFunction() метод. Вы можете пройти SUIАргументы в качестве аргументов и, возможно, TUIData указатель в качестве возвращаемого значения.

SUIArguments args;
args.AddArgument( 80.f );

TUIData res;

pHUD->CallFunction( "SetHealth", args, &res ); // You can use the SUIArguments::Create<T>(...) if you only have just one argument you want to pass

События

Чтобы получать события из flash, вам необходимо создать IUIElementEventListenerи зарегистрируйтесь в своем IUIElement.

Обратные вызовы:

  • OnUIEvent - Это вызывается, если событие (fscommand) запускается из флэш-памяти. Эта функция вызывается только в том случае, если событие нашел в UI Элемент XML файл.
  • OnUIEventEx - Это вызывается, если событие запускается из flash и не найдено в UI Элемент XML файл.
  • OnInit - Это называется, когда новый Flash UI Элемент был инициализирован.
  • OnSetVisible - Это называется, когда UI Элемент меняет видимость.
  • OnInstanceCreated - Это называется, когда новый экземпляр из UI Элемент был создан. Экземпляр имеет экземпляр ID больше нуля (базовый экземпляр каждого элемента равен 0).
  • OnInstanceDestroyed - Это называется, когда экземпляр из UI Элемент был уничтожен.
class CHUDEventListener : public IUIElementEventListener
{
public:
  virtual void OnUIEvent( const SUIEventDesc& event, const SUIArguments& args )
  {
    if ( event.sDisplayName == "OnButton1" )
    {
      int arg1;
      int arg2;
      if ( args.GetArg( 0, arg1) && args.GetArg( 1, arg2 ) )
      {
        // do somthing
      }
      else
      {
        // args don't are interger or doesn't exist
      }
    }
    else
    {
      // event is not "OnButton1" event
    }
  }
};

// ...

// Registering the listener
CHUDEventListener eventListener;
 
if ( gEnv->pFlashUI )
{
  IUIElement* pHUD = gEnv->pFlashUI->GetUIElement( "HUD" );
  if ( pHUD )
  {
    pHUD->AddEventListener( &eventListener );

  }
}

Функция обратного вызова OnUIEvent будет только обрабатывать события, которые определены в файле элемента UI XML. Существует также функция обратного вызова OnUIEventEx, которая будет срабатывать для других команд fs, поступающих из вашего элемента UI.

Экземпляры

Если вы хотите иметь более одного экземпляра для каждого элемента Flash, вы можете просто вызвать GetInstance() тебе UIElement. Вам необходимо передать экземпляр ID. Если экземпляра элемента с таким идентификатором не существует, он будет создан автоматически.

if ( gEnv->pFlashUI )
{
  IUIElement* pHUDInstance0 = gEnv->pFlashUI->GetUIElement( "HUD" );
  if ( pHUDInstance0 )
  {
    IUIElement* pHUDInstance1 = pHUDInstance0->GetInstance( 1 );
    IUIElement* pHUDInstance2 = pHUDInstance0->GetInstance( 2 );
    // ...
  }
}

Для перебора всех созданных экземпляров вы можете использовать IUIElementIteratorPtr.

IUIElement* pHUD = gEnv->pFlashUI->GetUIElement( "HUD" );
if ( pHUD )
{
  IUIElementIteratorPtr instances = pHUD->GetInstances();
  while ( IUIElement* pInstance = instances->Next() )
  {
    int instanceID = pInstance->GetInstanceID();
    // ...
  }
}

Необработанный интерфейс IFlashPlayer

Вы всегда можете получить доступ к IFlashPlayer любого IUIElement с помощью GetFlashPlayer() функция. Для получения дополнительной информации загляните в IFlashPlayer.h.

IFlashPlayer* pFlashPlayer = pHUD->GetFlashPlayer();

Как только вы получите доступ к IFlashPlayer Интерфейс, у вас будет прямой доступ к IFlashVariableObjects во Flash. Поскольку вы можете создать IFlashVariableObjects через IFlashPlayer Интерфейс, ты должен обязательно позвони Релиз на них, как только они вам больше не понадобятся. Это тоже очень важно, если вы выгружаете какие-либо IUIElement. Поскольку выгрузка может осуществляться через код или Flowgraph (MANUAL), вам следует реализовать IUIElementEventListener интерфейс в вашем пользовательском коде HUD и выпустите все созданные и еще не выпущенные IFlashVariableObjects в рамках OnUnload() обратный вызов.

UIДействия

Каждый UIAction (Flowgraph) можно получить и выполнить с помощью кода. Чтобы начать действие, вам нужно использовать IUIActionManager.

UIActionManager

IUIActionManager предоставляет простые функции для запуска/остановки или отключения IUIActions.

if ( gEnv->pFlashUI )
{
  // The Name "MyAction" is the name of the UIAction FlowGraph
  IUIAction* pAction = gEnv->pFlashUI->GetUIAction( "MyAction" );
  IUIActionManager* pActionManager = gEnv->pFlashUI->GetUIActionManager();
  pActionManager->StartAction( pAction );
}

UIActionListener

Вы можете создать IUIActionListener для прослушивания событий действий.

class CUIActionListener: public IUIActionListener
{
public:
  virtual void OnStart( IUIAction* pAction )
  {
    CryLogAlways( "Action %s was started", pAction->GetName() );
  }

  virtual void OnEnd( IUIAction* pAction )
  {
    CryLogAlways( "Action %s is done", pAction->GetName() );
  }

};

// ...
if ( gEnv->pFlashUI )
{
  IUIActionManager* pActionManager = gEnv->pFlashUI->GetUIActionManager();

  CUIActionListener* pActionListener = new CUIActionListener();
  pActionManager->AddListener( pActionListener );
}
