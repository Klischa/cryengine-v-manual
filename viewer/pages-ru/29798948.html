Обзор

NVIDIA PhysX — это масштабируемое мультиплатформенное решение для игровой физики, которое используется во многих популярных сегодня играх. В дополнение к встроенному физическому движку CRYENGINE (CryPhysics), эта функция позволяет пользователям CRYENGINE использовать NVIDIA сторонний физический движок (PhysX) в качестве внешнего физического движка в CRYENGINE.

Интеграция NVIDIA PhysX является минимально-инверсивным. По сути, интерфейс CryPhysics IPhysicalWorld был реализован для PhysX, чтобы заменить физический движок. Код интерфейса PhysX можно найти в ../Код/CryEngine/CryPhysicsSystem/CryPhysX/. Интерфейс можно скомпилировать с использованием систем сборки CMake и WAF.

Используя NVIDIA PhysX, есть возможность использования NVIDIA PhysX Визуальный отладчик (PVD). Это позволяет записывать и исследовать физику игрового мира, что может быть очень полезно. Вы также можете использовать базовые функции визуальной отладки, доступные непосредственно в CRYENGINE через p_draw_helpers команда в консоли.

Установка и включение PhysX в CRYENGINE

Выполните следующие действия, чтобы установить и включить PhysX в CRYENGINE:

  1. Установить NVIDIA PhysX SDK 3.3 (не поставляется с CRYENGINE, но доступен бесплатно на Нвидиа).
  2. Скомпилируйте CRYENGINE с включенным PhysX (поддерживается в CMake и WAF). Это создаст интерфейс PhysX в CryPhysX.dll.



  3. Убедитесь в следующем PhysX-SDK dll-файлы может быть найден CRYENGINE, либо изменив переменные пути системной среды, либо скопировав следующие файлы PhysX-SDK в папку bin:
    • nvToolsExt64_1.dll
    • PhysX3*_x64.dll
    • PhysX3CharacterKinematic*_x64.dll
    • PhysX3Common*_x64.dll
    • PhysX3Cooking*_x64.dll
  4. Добавьте следующие переменные в CRYENGINE system.cfg файл, это позволит CRYENGINE загрузиться NVIDIA PhysX вместо родного CryPhysics и отключите другие нереализованные функции:
          p_physics_library = "CryPhysX"
          e_OnDemandPhysics = 0
          e_onDemandMaxSize = 999999
          p_draw_helpers_num = 0
          e_PhysOceanCell=0

Ограничения

NVIDIA PhysX не поддерживает динамические вогнутые объекты (в отличие от CryPhysics). Существующие вогнутые прокси (например, транспортные средства) не добавляются в мир физики. Следовательно, прокси должны быть адаптированы к выпуклым, чтобы вести себя правильно.

Интерфейс PhysX на данный момент находится на стадии бета-тестирования. В настоящее время не все функции CryPhysics поддерживаются. Есть несколько ограничений, которые описаны ниже:

  • поддерживаются только 4-колесные транспортные средства.
  • очень простое живое существо (но поскольку оно все равно обычно изменяется игровым кодом, это не является серьезным ограничением).
  • отсутствие пересечения лучей с водными поверхностями.
  • нет систем ломкости.
  • отсутствие водных/воздушных зон.
  • Моделирование веревки очень простое.
  • окклюзия взрывов.
  • ткань персонажа (но вы можете попробовать VCloth 2.0, функцию моделирования одежды CryEngine, которая явно реализует эту функцию).
