Обзор - CRYENGINE 5.5.0 Предварительная версия 3

Мы очень рады представить вам версию 5.5.0 Preview 3. Наша команда разработчиков работала над улучшением предыдущих превью-версий, выпущенных 20 марта 2018 г. и 3 мая 2018 г.

Как всегда, мы приветствуем дальнейшие отзывы и комментарии от сообщества CRYENGINE, но, пожалуйста, не могли бы они приходить через наши обычные каналы, т. е. Репортер по проблемам Github и .

Доступ к предварительной версии 5.5.0 3

Версии движка теперь доступны через панель запуска CRYENGINE.

  1. Войдите в панель запуска CRYENGINE.
  2. Перейти к LIBRARY -> Мои двигатели где перечислены ваши установленные и доступные двигатели. Оттуда двигатели можно обновить (установить).

Гитхаб

Версии Preview Engine также доступны на Github, однако исходный код редактора Sandbox доступен только через Github.

  1. Перейти к: https://github.com/CRYTEK/CRYENGINE/releases/5.5.0_preview3
  2. Скачать CRYENGINE_preview_5.5.0.193_pc.zip
  3. Разархивируйте его куда-нибудь и откройте каталог «CRYENGINE_preview_5.5.0.193_pc».
  4. Дважды щелкните по InstallEngine.bat

NOTE: открытие графика зависимостей, например, из браузера активов или из глобального меню. Инструменты -> Граф зависимостей работает нормально.

Анимация

Общая анимация

  • Исправлено: Вложения (например, пистолет, дробовик) прикреплены неправильно, если используется компьютерная обработка шкур.

  • Исправлено: Аудио-событие (добавленное к анимации в Character Tool) не воспроизводится в режиме редактора/игры.
  • Изменено: Представьте пример API для ISkeletonAnim::StartAnimation.
  • Изменено: Добавлены примеры Mannequin API.
  • Изменено: Добавлены примеры API для модификаторов позы и параметра движения.
