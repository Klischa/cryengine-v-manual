Описание

Файл последовательности содержит последовательность запросов на анимацию, имитирующую то, как игра запрашивает анимацию у системы. Например, он может содержать последовательность оружия fragmentIDs (выбрать/перезарядить/выстрелить/отменить выбор) для проверки настройки оружия. Они создаются либо в редакторе моделей, либо путем записи реального игрового процесса.

Файлы последовательностей хранятся в папке, на которую указывает mn_sequence_path квар. По умолчанию это Анимации/Mannequin/FragmentSequences/.

Их имя файла заканчивается на .xml.

Создание файлов последовательности

Файлы последовательностей создаются либо:

  • сохранив последовательность с помощью Mannequin Предварительный просмотр.
  • записывая игровой процесс с помощью mn_dump консольная команда. См. Mannequin Отладка.

Редактирование файлов последовательностей

Файлы последовательностей редактируются в Mannequin Предварительный просмотр.

Формат файла

Это пример файла последовательности:

<History StartTime="0" EndTime="102.72806">
 <Item Time="32.951611" ScopeMask="Torso1P" FragmentID="idle" OptionIdx="1296707006" TagState="ammo_clipRemaining"/>
 <Item Time="33.082249" ScopeMask="" FragmentID="MotionIdle" OptionIdx="3032444839" Trump="1"/>
 <Item Time="33.209457" TagState="SDKRifle+rifle+rapid+SP+FP+iron+backward+aiming+localClient"/>
 <Item Time="33.872021" TagState="SDKRifle+rifle+rapid+SP+FP+iron+left+aiming+localClient"/>
 <Item Time="34.42939" ParamName="Curving" Type="Location">
  <Value x="0" y="0" z="0" qx="5" qy="5" qz="0" qw="1"/>
 </Item>
</History>

История элемент является корневым элементом и содержит диапазон времени, который эта последовательность представляет как StartTime и EndTime.

Он содержит список Товар элементы, фиксирующие изменения манекена в определенные моменты Времяс:

  • Нажатие фрагмента:
    • FragmentID Атрибут: FragmentID, запрошенный у манекена.
    • ScopeMask Атрибут: маска области, запрошенная у манекена. Обычно это поле можно оставить пустым. Области действия назначаются fragmentID согласно определениям в Файл определения контроллера (xxxControllerDefs.xml).
    • OptionIdx Атрибут: индекс опции, запрошенный у манекена. Обычно это случайное число во время игры, но при желании вы можете выбрать конкретный индекс опции.
    • TagState атрибут: (необязательно) Теги, специфичные для FragmentID (фрагтеги) используется во время запроса.
    • Трамп атрибут: (необязательно) Установите значение 1, чтобы включить Mannequin Трампинг.
  • Глобальный TagState изменения:
    • TagState Атрибут: новое глобальное состояние тега.
  • Изменения параметров:
    • ParamName атрибут: содержит имя Mannequin Параметр.
    • Тип атрибут: устарел, не используется.
    • Значение элемент: Атрибуты 'x', 'y', 'z', 'qx', 'qy', 'qz', 'qw' хранят значение параметра Mannequin. Существует достаточно атрибутов для кодирования смещения и кватерниона, поэтому его можно использовать для описания местоположения (например, типичное использование параметра «TargetPos»). Не все значения используются обязательно (например, параметры движения используют только атрибут «x»).

Код

В коде эти последовательности представлены списком SMannHistoryItem структур в игре и список CFragmentHistory::SHistoryItem структуры в редакторе.
