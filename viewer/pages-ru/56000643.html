Обзор

Это руководство Audio Showcase, созданное для демонстрации возможностей аудиосистемы CRYENGINE и поддерживаемого промежуточного программного обеспечения, знакомит пользователей с процессом реализации окружающих звуков на заранее разработанном уровне с помощью SDL Mixer, FMOD Studio и Wwise. Вы узнаете, как создавать звуковые триггеры в редакторе элементов управления звуком, размещать их в игре и настраивать такие свойства, как задержка и затухание.

Другие используемые инструменты включают инструмент «Создать объект» для определения звука, специфичного для области, Character Tool для добавления звуков к анимации игрока, Particle Editor для привязки звуков к эффектам частиц и даже Environment Editor для настройки атмосферы в зависимости от времени суток.


Китайский сад

Урок разделено на четыре главы и использует бесплатный уровень Audio Showcase, который можно бесплатно получить на сайте CRYENGINE. База данных активов.

Вы можете реализовать руководство с помощью любого поддерживаемого промежуточного программного обеспечения (SDL Mixer, FMOD Studio, Wwise), поскольку инструкции для промежуточного программного обеспечения описаны в каждой из глав, где это необходимо, или вы можете вообще пропустить шаги, специфичные для промежуточного программного обеспечения.

Загрузка и установка необходимых ресурсов

Начните с загрузки Сhowcase_Level.zip пакет, содержащий файлы уровня Audio Showcase. Далее,

  • Если вы хотите реализовать действия, специфичные для промежуточного программного обеспечения, описанные в этом руководстве, загрузите Showcase_Audio_Source.zip пакет, содержащий исходные аудиофайлы для разделов SDL Mixer, FMOD Studio и Wwise.
  • Если вы предпочитаете пропустить реализации промежуточного программного обеспечения, загрузите Showcase_Assets.zip пакет, в котором уже реализованы шаги, специфичные для промежуточного программного обеспечения.

Прежде чем начать обучение, убедитесь, что ни один из загруженных файлов ресурсов не имеет записи protected.
