Компиляция CRYENGINE для Mono применима только при самостоятельной сборке движка путем получения исходного кода из Гитхаб. В сборках, загруженных через программу запуска CRYENGINE, по умолчанию включен монофонический режим.

Чтобы иметь возможность использовать C# в CRYENGINE, в CMake необходимо включить дополнительную опцию. Чтобы настроить эту опцию, откройте CMake, открыв cry_cmake.exe (при использовании источника из главный филиал) в исходной корневой папке или <root>/Инструменты/CMake/cmake_create_win32_solution.bat. После открытия CMake убедитесь, что включены следующие параметры:

  • OPTION_CRYMONO
  • OPTION_CRYMONO_SWIG
  • OPTION_BUILD_CSHARP_WITH_MCS

Если у вас возникли проблемы с поиском параметров, проверьте, есть ли в правом верхнем углу CMake параметр. Сгруппировано включен. Все параметры сгруппированы в OPTION группа. Если некоторые параметры отсутствуют, попробуйте включить те параметры, которые у вас есть, и нажмите Настроить кнопку внизу CMake. После настройки новые значения будут отображаться красным цветом.

После этого просто нажмите кнопку Настроить кнопку, и если после настройки некоторые строки все еще остаются красными, нажмите Настроить снова. Как только все линии станут белыми, нажмите Генерировать и будет создан файл решения с поддержкой C#. Решение теперь будет содержать дополнительные С# проекты, расположенные в г. CryMono папка. Проект CryMonoBridge можно найти по адресу CRYENGINE/CryMono/.

CryMonoBridge запускает компиляцию только в том случае, если один из исходных файлов генерации интерфейса (<root>/Code/CryManaged/CryMonoBridge/SWIG/*.i) изменился или если временный каталог (<root>/BinTemp/<платформа>/BinTemp/swig_files) для сгенерированного интерфейса отсутствует. Компиляция будет нет срабатывать, если один из файлов исходного кода CRYENGINE изменился.
