В версии CRYENGINE 5.7 LTS исходный код Engine теперь распространяется через репозиторий private для зарегистрированных разработчиков, доступ к которому предоставляется только по запросу.

Прежде чем приступить к оформлению запроса, убедитесь, что у вас есть:

  • А аккаунт CRYENGINE.
  • Аккаунт в GitHub (зарегистрируйтесь здесь)
  • На ваш PC установлен рабочий стол GitHub для Windows (доступен здесь)

Запрос доступа к исходному коду

  1. Перейдите к контактная форма на веб-сайте CRYENGINE и войдите в свою учетную запись CRYENGINE, нажав кнопку значок в правом верхнем углу страницы.

  2. После входа в систему заполните контактную форму, используя следующий код template:

    Hello, 

I would like to formally request access to CRYENGINE 5.7 LTS source code via GitHub.

My GitHub username is [Your GITHUB NAME].

Kind regards,
[NAME]

    Обязательно укажите свое имя пользователя GitHub в своем сообщении.

После этого подождите, пока мы ответим на ваш запрос по электронной почте.

Приглашение присоединиться к Crytek по электронной почте на GitHub

Добавить contact@cryengine.com в свой список адресов электронной почты, чтобы наши электронные письма не пропустили вас.

Загрузка исходного кода

После того как ваш запрос будет одобрен по электронной почте, как описано выше, просто перейдите на веб-сайт GitHub, войдите в систему, используя свою учетную запись GitHub, и примите приглашение к исходному коду CRYENGINE.


GitHub приглашение

Это откроет CRYENGINE_Source хранилище.

Альтернативно, как только ваш запрос будет одобрен, вы можете получить доступ к исходному коду следующим образом:

  1. Перейдите в свою учетную запись GitHub, нажмите на свой аватар и выберите Организации.
  2. Выберите Crytek → Репозитории → CRENGINE_Source вариант.

    CRYENGINE_Source

Чтобы клонировать CRYENGINE_Source репо:

  1. Откройте репозиторий и выберите Код → Клонировать вариант из раскрывающегося списка вверху.

    Код → Клонировать
  2. Чтобы завершить процесс, вы можете выполнить одно из следующих действий:
    1. Выберите Скачать ZIP и разархивируйте файл ZIP в выбранное вами место;
    2. Нажмите Открыть на рабочем столе GitHub, а затем перейдите в приложении к каталогу, в который вы хотите его клонировать, или;

    3. Вручную скопируйте файл HTTPS URL/SSH/GitHub CLI в приложение GitHub, а затем перейдите в каталог, в который вы хотите его клонировать.

      Если вы хотите скомпилировать код Engine, настоятельно рекомендуется сохранить репозиторий на SSD.

Теперь вы сможете увидеть свой клонированный репозиторий как в настольном приложении, так и на веб-сайте GitHub.

Код ограниченного доступа
