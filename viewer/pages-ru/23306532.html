Обзор

Создать UI с помощью CRYENGINE легко и просто. Мы начинаем наше путешествие в мир UI с основ, которые должен знать и понимать каждый, кто работает над UI. После того, как все базовые системы представлены и объяснены, пользователь может выполнить учебник для создания простой кнопки, которая отправляет события в код игры и реагирует на ввод пользователя.

CRYENGINE использует Scaleform в качестве пользовательского интерфейса игры. Масштабная форма внешнее промежуточное программное обеспечение, которое обеспечивает функциональность для рендеринга/запуска Flash-ресурсов. Отрисованные ресурсы можно использовать для реализации меню, HUD и т. д. Они могут даже выступать в качестве материалов, к которым можно применять в мире. геометрию см. Элементы UI как динамические текстуры.

Ключевые компоненты

Есть три ключевых элемента, лежащих в основе реализации UI в CRYENGINE:

  • UI Элементы - Это настоящие Flash-ресурсы UI. Они определяют, что отображается на экране, а также содержат всю логику, доступную Flowgraph или доступен из кода C++. Их можно рассматривать как мельчайшую неотъемлемую часть, на которой построена вся система UI.
  • UI Действия - Это особая версия Flowgraph. Обычно они используются для определения, инкапсуляции и связывания логики UI с кодом игры.
  • UI Система событий - Чтобы упростить связь между кодом игры, кодом UI и Flowgraph более того, CRYENGINE предоставляет собственную систему событий, которая обрабатывает отправку событий в обоих направлениях.

Полезные переменные

Есть разные CVars который может управлять средой Flash:

  • sys_flash = включает/выключает Flash-рендеринг.
  • sys_flash_info = включает профилирование Flash и отображает различную информацию.
  • sys_flash_log_options = включает регистрацию нескольких аспектов, связанных с Flash (загрузка Flash, выполнение скрипта действий Flash и т. д.).
