Обзор

Можно использовать Flow Graph для создания полноэкранных эффектов. В этом документе объясняются узлы и функции для создания этих эффектов.

Чтобы воспроизвести следующие настройки в Flow Graph, необходимо базовое понимание этого инструмента. Для получения дополнительной информации, пожалуйста, обратитесь к Flow Graph страница.

Узлы эффектов

Узлы камеры

Найдено в Камера. Эти узлы могут создавать эффекты камеры. ViewShake генерирует случайную анимацию дрожания камеры. Эффективно соединить с взрывным воздействием.

  • Триггер: активирует эффект.
  • Ограничить: выбирает условие для ViewShake. Для этого параметра можно установить значение «Нет» при отсутствии условий, «NoVehicle», если встряхивание должно применяться только в том случае, если игрок не находится в транспортном средстве, или «VehicleOnly», если эффект следует применять, только если игрок находится внутри транспортного средства.
  • Посмотреть: выбор камеры для применения эффекта. Может быть «FirstPerson» для игрока или «Текущий», если вы хотите применить ViewShake например, для последовательности просмотра треков.
  • GroundOnly: Когда эта функция включена, встряхивание применяется только тогда, когда игрок стоит на земле.
  • Угол: управляет углом дрожания камеры.
  • Сдвиг: управляет расстоянием смещения при дрожании камеры.
  • Продолжительность: управляет длительностью эффекта от начала до конца.
  • Частота: управляет частотой встряхивания.
  • Случайность: управляет случайностью встряхивания.

Узлы изображения

Это можно найти в разделе «Добавить». Узел → Изображение. Узлы изображений используются для отображения эффектов постобработки, которые можно использовать в игровом процессе или в видеороликах.

Одновременно можно использовать несколько узлов для смешивания результатов для разных эффектов, но имейте в виду, что каждый из этих узлов добавляет дополнительный проход рендеринга по экрану, поэтому обязательно ограничивайте количество одновременно используемых узлов до разумного уровня. Большинство дорогих эффектов GPU отмечены в этом документе пометкой «дорого».

При использовании узлов изображения или камеры нет необходимости устанавливать сущность для узлов изображения, они будут автоматически назначены локальному игроку, и даже несмотря на то, что большинство узлов имеют включено и отключен input безопаснее игнорировать отключенный ввод и просто использовать включенный ввод и установить для него значение true или false. Входные данные также имеют логический тип, поэтому всегда лучше комбинировать эти узлы с Математика:BooleanTo node, чтобы быть уверенным, что правильные значения отправляются на узел изображения.

MaterialFX Узлы

Чтобы реализовать полноэкранный эффект для эффекта частиц, его потоковый граф должен использовать эти узлы. Найдено в Добавить узел/MaterialFX.

HUDstartFX

Отключить запуск полноэкранного эффекта в движке.

Входной порт

  • Старт: Запускается автоматически MaterialEffects системы

Выходные порты

  • Началось: срабатывает при запуске эффекта
  • Расстояние: Расстояние до игрока
  • Парам 1-4: Пользовательские параметры float, которые можно установить в описании эффекта XML.

HUDEndFX

Отключить окончание полноэкранного эффекта для движка.

  • Триггер: Запустите этот порт, когда эффект закончится. Это MUST делается для уведомления о том, что эффект можно использовать повторно.

Внедрить полноэкранный эффект в игру. Чтобы реализовать полноэкранный эффект в игре, вам необходимо сохранить Flow Graph и вызвать его в игре.

  • Создайте эффект Flow Graph.
  • Сделайте HUDstartFX и HUDendFX узел.
  • Сделайте Задержка узел ( Добавить узел/время/задержку ).
  • Установите Задержка значение до минимально необходимой длительности, чтобы задействовать всю продолжительность эффекта Flow Graph.
  • Подключите Началось из HUDstartFX к каждой начальной точке каждого узла эффекта, и В порт измененных Задержка узел.
  • Подключите Выход из Задержка узел к Триггер из HUDendFX узел.
  • Сохраните Flow Graph в Libs/MaterialEffects/Flowgraphs.
  • Если вы используете полноэкранный эффект в качестве эффекта удара пули или взрыва, укажите имя сохраненного XML-файла. /Effect/FlowGraph/name строка соответствующего эффекта, в Libs/MaterialEffects/FXLibs/bulletimpacts.xml. Этот XML-файл авторизует необходимые элементы эффекта, такие как эффект частиц, звук, наклейка пули.

Примеры

Чтобы действительно создать полноэкранный эффект Flow Graph, вам нужно использовать несколько более общих узлов. Вот несколько примеров:

Отрегулируйте время, анимируйте значение

Это пример Flow Graph ударного эффекта ядерного оружия.

  • Используйте HUDstartFX и HUDendFX узел, подключенный к Задержка узел, поэтому эффект длится всю длительность Flow Graph.
  • Используйте Задержка узел, предшествующий каждому из узлов эффекта. Этот узел часто используется для настройки времени активации каждого узла.
  • Используйте Плавать узел ( Добавить узел/Интерпол/Float ), чтобы анимировать некоторые значения Цветокоррекция . Он может установить Время , StartValue и EndValue. Когда он получает входные данные, он интерполирует значение между StartValue чтобы EndValue в течение Время , а затем передает выходное значение следующему узлу. Это полезный способ создания анимированных значений.
  • Некоторые узлы получают одинаковое выходное значение от одного и того же узла. Обычно выходное значение может быть подключено к нескольким входам. Это хороший момент для уменьшения количества узлов.

Проявление текстур на экране

Это пример Flow Graph эффекта грязи на экране, когда игрок был близок к взрыву.

  • Используйте RandomSelect узел ( Добавить узел/логику/RandomSelect ), чтобы случайным образом выбрать текстуру из трех доступных.
  • Используйте ScreenFader узел для исчезновения каждой текстуры. Этот узел изначально был разработан для исчезновения всего экрана. Используя этот метод, вы можете отображать текстуры, а затем исчезать через несколько секунд.
  • Всплывающая текстура: при получении ввода ScreenFader узел начинает постепенно исчезать на всем экране и отображать текстуру в течение FadeOutTime. В этом случае FadeOutTime установлено значение 0, поэтому текстура появляется немедленно.
  • Задержка появления: FadeIn задерживается на 4 секунды из-за Задержка node, поэтому текстура некоторое время остается на экране. Через 4 секунды весь экран начнет исчезать, в течение FadeInTime ценность. Затем кажется, что текстура исчезает за 3 секунды.
  • Используйте Любой узел ( Добавить узел/логику/любой ), чтобы собрать выходные текстуры и выбрать ту, которую нужно отобразить.
