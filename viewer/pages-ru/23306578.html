Обзор

Game Rules Precache — это игровая подсистема, предназначенная для централизации предварительной загрузки и кэширования ресурсов.

Во время LoadLevel LevelSystem вызывается функция PrecacheLevel для системы GameRules. На этом этапе ресурсы, перечисленные в файле XML Scripts/GameRules/PrecacheLists.xml файл предварительно кэшируется.

Ресурсы, перечисленные в файле XML, сгруппированы по типу актива, режиму игры и названию уровня. Если ресурс необходим только для одиночной игры или если он необходим только для определенного многопользовательского режима или уровня, его можно пометить как предзагруженный только для этого режима или уровня.

Поддерживаемые типы активов

Имя, указанное в таблице, соответствует тегу XML в PrecacheLists.xml файл. См. пример ниже.

Расположение кода

Код, управляющий обработкой XML и предварительной загрузкой его ресурсов, можно найти в GameRulesPrecache.cpp.

Срок службы и право собственности

Модуль GameRulesPrecache принадлежит GameRules. Его время жизни привязано к времени жизни GameRules, что означает, что GameRulesPrecache создается при запуске уровня и уничтожается при выгрузке уровня.

Выгрузка активов

Обработка выгрузки ресурсов зависит от их конкретного типа и в большинстве случаев не обрабатывается непосредственно классом GameRulesPrecache.

Например:

  • CGF и CGA управляются кэшем геометрии предметов, который также позаботится об их выгрузке при выгрузке уровня.
  • Администраторы баз данных управляются CharacterManager, который по умолчанию освобождает все ресурсы и уничтожается во время выгрузки уровня и воссоздается во время загрузки уровня.
  • Для некоторых других типов ресурсов GameRulesPrecache может хранить список интеллектуальных указателей на каждый из предварительно загруженных ресурсов, чтобы увеличить их счетчик ссылок и убедиться, что активы не выгружаются во время работы уровня, а когда GameRules уничтожается во время выгрузки уровня, векторы будут уничтожены.
