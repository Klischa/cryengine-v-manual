← Содержание Узлы отладки RU

CSVDumper

Используется для хранения значений ячеек указанного .csv файл.

ConsoleVariable

Устанавливает/получает значение консольной переменной (CVar).

DisplayMessage

Если сущность не указана, вместо нее будет использоваться локальный игрок.

ExecuteString

Выполняет строку, как при использовании консоли.

FloatToString

Выводит float в строковом формате с ограниченным количеством десятичных знаков. Используется для визуализации отладки.

Рамка

Используется для вывода текущих данных о частоте кадров.

FrameExtended

При активации этот узел выводит текущие данные о частоте кадров, а также самую низкую, самую высокую и среднюю частоту кадров.

InputKey

FlowNode, чтобы перехватить ввод ключевых слов. Используйте только для отладки. Он включен по умолчанию. Ввод сущностей необходимо использовать в многопользовательской игре.

Журнал

Регистрирует входное сообщение строки на консоль. Полезно для отладки событий.

Память

Используется для отображения данных видеопамяти.
