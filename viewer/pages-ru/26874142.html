Обзор

Лицевую анимацию можно добавить в эпизод Track View несколькими способами в зависимости от того, как лицевая анимация изначально создается в вашем проекте.

Различные способы настройки персонажа определяют формат лицевой анимации:

  • Вы можете использовать лицевую анимацию, состоящую из морфов (смесь форм). Они настраиваются в редакторе лиц, а анимация лица сохраняется как файлы .fsq. Этот метод использовался для всех персонажей в Crysis.
  • Если у вашего персонажа лицевая часть сделана из костей:
    • Вы можете создавать анимации в своем DCC и экспортировать их как файлы .caf. Затем они обрабатываются так же, как и анимации тела. Именно этот метод использовался для персонажей A-уровня в Crysis 2.
    • Вы можете настроить выражения в редакторе лиц, используя Bone Expressions. Затем они сохраняются как файлы .fsq. Именно этот метод использовался для персонажей C-уровня в Crysis 2.

Анимации, созданные в DCC

Персонажи уровня A используют отдельные файлы .caf для лицевой анимации. Обычно имена файлов лицевой анимации совпадают с именами строк диалога персонажа.

Лицевую анимацию необходимо разместить на отдельной дорожке анимации в Track View. Первая дорожка анимации персонажа должна содержать анимацию тела, вторая дорожка анимации — анимацию лица. Важно соблюдать этот порядок, потому что от него зависит анимация.

В большинстве случаев лицевая анимация будет соответствовать одноименной строке диалога, поэтому обе анимации должны начинаться одновременно.


Первая дорожка анимации содержит анимацию тела, вторая — анимацию лица. Звуковая дорожка внизу содержит строки диалога, которые воспроизводятся вместе с мимикой лица.

Добавление лицевой анимации

Лицевая анимация добавляется так же, как и другие анимации:

  • Добавьте новый ключ на дорожку анимации, которую вы используете для анимации лица.
  • Щелкните значок папки в поле свойства анимации ключа, чтобы открыть браузер анимации.
  • Выберите нужную анимацию в браузере анимаций (она будет указана в разделе «лицо»).
Blend Gap не следует использовать для анимации лица.
Добавление звуковых файлов диалогов для игры с мимикой лица
  • Добавьте новую клавишу на звуковую дорожку, которую вы используете для диалога персонажа.
  • Щелкните значок папки в поле свойства звукового файла клавиши, чтобы открыть обозреватель звуков.
  • Нажмите на Просмотр файла... кнопка.
  • Нужные файлы диалогов будут находиться в папке languages/dialog/[CRYENGINE:LevelName] папка.
Для персонажей A-Level включите флаги Голос и 3D-звук в свойствах клавиши Звук.


Флаги звуковых клавиш, необходимые для персонажей A-уровня. Установка флага LipSync не требуется.

Глаза мерцают и мигают

Дополнительное движение глаз можно добавить персонажу с помощью специальной анимации движения глаз. Эти анимации следует поместить в отдельную дорожку анимации и добавить после двух дорожек, используемых для анимации тела и обычного лица.

Мерцание и моргание глаз следует использовать, особенно когда лицо персонажа показано крупным планом. Его не обязательно использовать на персонажах, которых игрок может видеть только издалека (однако помните о функции масштабирования игрока).

Анимации движения глаз также перечислены в разделе «лицо» в браузере анимаций:

  • facial_eyes_blink
  • facial_eyes_flicker – тонкое движение глаз, чтобы персонаж выглядел более живым
  • facial_eyes_flicker_01 – немного более сильная версия

Анимации, созданные в редакторе лиц

Персонажи уровня C не используют отдельные файлы .caf для лицевой анимации. Их лицо будет автоматически анимировано при воспроизведении строки диалога. Дополнительно можно воспроизвести фиксированное выражение лица.

Настройка звукового файла диалога

Настройка в основном такая же, как и для персонажей A-уровня. Отличия заключаются в следующем:

  • Для воспроизведения лицевой анимации не требуется отдельная дорожка анимации.
  • Вам также необходимо включить LipSync флаг вместе с Голос и 3D-звук в свойствах клавиши Звук.


Флаги звуковых клавиш, необходимые для персонажей уровня C.
