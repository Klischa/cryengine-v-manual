Обзор

Благодаря функции теней для каждого объекта можно назначать собственные карты теней для выбранных объектов. Это может привести к повышению качества теней из-за более высокой плотности текселей теней мирового пространства и уменьшенного диапазона глубины.

Недостатками являются повышенное потребление памяти дополнительными картами теней и повышенная стоимость фильтрации теней. Например, дополнительные затраты составили примерно 0,25 мс для главного героя Ryse на XboxOne.

Использование

В настоящее время существует два способа назначить карту теней для каждого объекта:

  • Через Окружающая среда:PerEntityShadows узел графа потока.
  • Непосредственно из кода игры через I3DДвигатель функции интерфейса.

Узел «Тени объекта» Flow Graph

Создайте PerEntityShadows node и назначьте целевой объект слоту «entity». Триггерный вход применит настройки к двигателю.

Обратите внимание, что узел не имеет состояния по отношению к. сущность, поэтому вы можете добавить несколько PerEntityShadow узлы для одной и той же сущности. Вступит в силу тот, который сработает последним.

Существуют различные настраиваемые параметры для настройки внешнего вида тени:

  • ConstBias/SlopeBias: Может использоваться для предотвращения артефактов самозатенения.
  • Дрожание: Размер ядра фильтра напрямую влияет на мягкость теней.
  • BBoxScale: Масштабный коэффициент для ограничивающей рамки выбранного объекта. Может быть полезно в случае, если ограничивающая рамка двигателя слишком мала или слишком велика.
  • ShadowMapSize: Размер пользовательской карты теней. Примечание: автоматически округляется до следующей степени двойки.


Ограничения

На тени каждого объекта распространяется ряд ограничений:

  • Они влияют только на солнечные тени.
  • По соображениям производительности тени для каждого объекта не выбираются по прямой геометрии (например, частицы, волосы и глаза, визуализированные вперед).

Связанные переменные

e_ShadowsPerObject: 0=0выкл., 1=вкл., -1=не рисовать тени объектов.
