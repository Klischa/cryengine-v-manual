5.7 Обзор

Эта версия CRYENGINE 5.7 с долгосрочной поддержкой (LTS) направлена на улучшение рабочих процессов движка с помощью новейшего программного обеспечения для разработки.

Помимо исправления нескольких ошибок, о которых сообщили как внутри компании, так и от сообщества, он также включает такие обновления, как плагин GamePlatform (с добавлением узлов Flow Graph и Schematyc для вашего удобства), а также поддержку Scaleform 4.

Основные моменты

Масштабная форма 4

Интеграция Scaleform 4 является улучшением по сравнению с Scaleform 3 и обеспечивает настраиваемый рендеринг для повышения производительности на всех платформах.

Он обратно совместим с ActionScript 2.0, предоставляя вам преимущества в производительности Scaleform 4 без необходимости переделывать ваши Flash-проекты в ActionScript 3.0, а также поддерживая ActionScript 3.0, что, в свою очередь, позволяет использовать Adobe Animate. Однако Scaleform 3 по-прежнему доступен на случай, если обновление до Scaleform 4 приведет к непредвиденным ошибкам, блокирующим ваши проекты.

Схема масштабной формы

Плагин Scaleform Schematyc предназначен для эмуляции необходимых функций, предоставляемых Flow Graph для системы UI. Элементы UI доступны как компоненты, а функции и события, соответствующие этим элементам, могут быть определены в файле элемента XML.

Он поддерживает как Scaleform 3, так и 4.

Плагин GamePlatform

Плагин GamePlatform — это обновление плагина, поставляемого с CRYENGINE 5.6.

Расширенные функции включают поддержку различных платформ, таких как Steam, PlayStation и Xbox. Кроме того, он включает дополнительный новый плагин, который предоставляет узлы визуальных сценариев для Flow Graph и Schematyc. Устаревшая версия Discord Rich Presence SDK также была обновлена ​​до версии Discord Game SDK.

Новую документацию для плагина GamePlatform можно найти здесь.

Visual Studio 2017–2022 Поддержка

Код ядра и CMake обновлены для поддержки версий Visual Studio 2017, 2019 и 2022 годов, а поддержка Visual Studio 2015 года прекращена.

Наряду с этим обновлением была добавлена ​​поддержка стандартной реализации C++17, а Windows SDK была обновлена ​​до версии 10.0.20348.0.
