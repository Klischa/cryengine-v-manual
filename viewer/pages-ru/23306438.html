Обзор

Анимации в CryENGINE можно пометить для отправки пользовательских событий в определенное время анимации. Эта разметка используется для согласованного по времени смешивания, например, для сопоставления ног в анимации. Другое применение событий — создание эффектов частиц в нужный момент.

Эти события также можно использовать для различных систем, которым необходимо получать информацию о том, когда анимация достигла определенной точки, например, в сочетании с системой ближнего боя и т. д.

Разметка анимации с помощью событий

События анимации хранятся в XML-файле, который загружается при загрузке персонажа. Чтобы это происходило автоматически, базу данных необходимо включить в файл chrparams. См. эту документацию о том, как создать такую базу данных и как создавать события:

  • Конкретная информация о базе данных AnimEvents: Анимационные события (animevents).
  • Общая информация о файле ChrParams: Ссылка на файл ChrParams.
  • Разметка специально для смешивания с соответствующими событиями: Разметка шагов.

Получение анимационных событий в игровом коде

События анимации передаются в GameObject после их запуска. И Actor, и реализация Player обрабатывают эти события анимации.
