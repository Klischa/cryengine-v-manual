Обзор

Character Tool позволяет создавать определения символов с помощью UI без ручного редактирования XML.

Предварительные условия

Прежде чем продолжить, убедитесь, что у вас есть следующий контент:

  • Готовый к использованию скелет персонажа (файл CHR)
  • Некоторая геометрия со скинами (файл SKIN)
  • Анимации

Обычно они создаются с помощью инструмента DCC и экспортируются оттуда.

Структура определения персонажа

Каждое определение символа (CDF) состоит из ссылки на скелет (CHR) и набора вложений.

Каждый скелет имеет связанные параметры скелета (CHRPARAMS). Он используется для определения списка анимации персонажа.

Вложения могут быть разных типов; наиболее важные из них:

  • Вложения скинов — позволяют добавлять к скелету геометрию со скинами.
  • Суставные крепления — используются для прикрепления жесткой геометрии или других персонажей (например, оружия) к одному из суставов.

Шаги

  1. Создать CDF
    • Перейти в меню Файл -> Новый персонаж...
    • Выберите местоположение для вновь созданного файла CDF.
  2. Выберите скелет
    • В Свойства панель - нажмите на Папка значок рядом с параметром Скелет.
    • Найдите файл скелета (CHR).
    • Чтобы убедиться, что скелет правильно загружен, включите Скелет в Параметры отображения (над верхним правым углом окна просмотра).
  3. Определить список анимации
    • Теперь нажмите на кнопку рядом с Скелет параметр. Это позволит выбрать скелет и отобразить его параметры (содержимое файла CHRPARAMS).
    • Нажмите на цифровая кнопка рядом с Фильтр набора анимации и выбери Добавить.
    • Нажмите на папка Значок рядом с вновь добавленной строкой фильтра выберите папку, содержащую анимацию для этого персонажа.
    • Нажмите кнопку Сохранить кнопка в Свойства панель (или выберите Сохранить в контекстном меню актива).
    • Если вы еще не импортировали анимацию, выполните следующие действия: Импорт анимации.
  4. Добавить вложение SKIN
    1. Теперь вернитесь к CDF. Вы можете использовать Назад на панели инструментов местоположения или нажмите кнопку рядом с Персонаж параметр в Параметры сцены.
    2. Используйте цифровая кнопка рядом с Вложения список для добавления нового вложения.
    3. Убедитесь, что во вложении указан тип вложения. Кожа и нажмите на папка значок рядом с Геометрия параметр для поиска файла SKIN. Подробнее о вложениях можно прочитать здесь: Вложения персонажей.
    4. С этого момента вы должны видеть геометрию персонажа в окне просмотра.
