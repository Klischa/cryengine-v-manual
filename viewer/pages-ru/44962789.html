Обзор — CRYENGINE 5.5.0, превью 2

Мы очень рады представить вам версию 5.5.0 Preview 2. Наша команда разработчиков была занята улучшением первой предварительной версии, выпущенной 20 марта 2018 года.

Как всегда, мы приветствуем дальнейшие отзывы и комментарии от сообщества CRYENGINE, но, пожалуйста, не могли бы они приходить через наши обычные каналы, т. е. Репортер по проблемам Github и .

Доступ к версии 5.5.0 Preview 2

Предварительные версии CRYENGINE теперь доступны через панель запуска CRYENGINE.

  1. Войдите в панель запуска CRYENGINE.
  2. Перейти к LIBRARY -> Мои двигатели где перечислены ваши установленные и доступные двигатели. Оттуда двигатели можно обновить (установить).

Гитхаб

CRYENGINE по-прежнему можно получить на Github, как и полный исходный код редактора Sandbox.

  1. Перейти к https://github.com/CRYTEK/CRYENGINE/releases/5.5.0_preview2
  2. Скачать CRYENGINE_preview_5.5.0.108_pc.zip
  3. Разархивируйте его куда-нибудь и откройте каталог «CRYENGINE_preview_5.5.0.108_pc».
  4. Дважды щелкните по InstallEngine.bat

Изменения интерфейса кода

Для получения дополнительной информации. увидеть Важная информация CRYENGINE 5.5. Изменения данных и кода.

Если вы обновляетесь с CRYENGINE 5.4, прочтите эту тему: Миграция с CRYENGINE 5.4 на CRYENGINE 5.5.

Известные проблемы

  • Аним: Сохранение/загрузка прерывает движение персонажа по умолчанию — примечание: только в одиночной игре).
  • Сохранить: Использование «Сохранить как...» после сохранения приводит к исчезновению кистей и делает их непригодными для использования.
  • Рендеринг: Изменение размера панели «Свойства» приводит к повреждению рендеринга в Character Tool.
  • Дизайнер: Поверхности дизайнера невидимы или мерцают в режиме редактирования и после него.
  • Глобальный VFX: Переключение слоев нарушает работу частиц, визуальных эффектов и звука для них.
  • Площадь: VisArea не скрывает объекты за пределами области.
  • Вещество: Создание пресета графа вещества не приводит к созданию связанных файлов текстур (diff, spec, ddna и т. д.).
  • DX12: Различные проблемы, связанные с DX12.
  • Вулкан: Различные проблемы, связанные с Вулканом.
  • VR: В настоящее время не работает.
  • С#: Повреждение памяти может произойти после перезагрузки скриптов в Sandbox, что приведет к возможным сбоям и неопределенному поведению.
  • Visual Studio 2017 (15,7): Sandbox аварийно завершает работу из-за исключения. Происходит при сборке Sandbox с использованием Visual Studio 15.7 и последующем запуске собранного Sandbox.
    Обходные пути:
    1. Используйте Visual Studio 2015 для сборки CRYENGINE и Sandbox для версии 5.5.
    2. Не обновляйтесь до версии 15.7 и не переходите на версию до Visual Studio 15.7.
