Загрузка

Чтобы загрузить XML из буфера, см. ISystem::LoadXmlFromBuffer - это позволяет анализировать строку в XmlNodeRef объект, который можно анализировать программно.

Сохранение

Сохранение узла XML можно выполнить с помощью IXmlNode::saveToFile. Мы можем либо использовать существующий узел XML, загруженный из буфера или файла (см. выше), либо создать новый узел XML с нуля, используя ISystem::CreateXmlNode функция.
