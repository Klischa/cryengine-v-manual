3DHudInterference

Добавляет эффекты искажения только к HUD.

ColorCorrection

Предлагает контроль над основными настройками изображения, такими как насыщенность, контрастность, яркость, голубой/пурпурный/желтый и т. д.

ColorGradient

Примените текстуру цветовой диаграммы и укажите время плавного появления.

EffectAlienInterference

DEPRECATED - Этот эффект будет удален в будущей версии движка.

Добавляет эффекты искажения к обзору игроков (не влияет на HUD).

EffectBloodSplats

При использовании оставляет пятна крови на экране. Тип и количество пятен крови можно определить с помощью входных портов узла. 0 — человек, 1 — инопланетянин. «Спаун» порождает новые пятна крови.

EffectDepthOfField

Добавляет эффект глубины резкости, позволяя контролировать расстояние, дальность и величину.

EffectFrost

DEPRECATED - Этот эффект будет удален в будущей версии движка.

Имитирует замороженный HUD. Величину и центр эффекта на экране можно регулировать с помощью входных портов узла.

EffectGhosting

DEPRECATED - Этот эффект будет удален в будущей версии движка.

Добавляет на экран эффект ореолов, который перекрывает и размывает предыдущие кадры.

EffectRainDrops

DEPRECATED - Этот эффект будет удален в будущей версии движка.

Добавляет капли дождя на экран, которые скатываются по игрокам HUD.

EffectVolumetricScattering

DEPRECATED - Этот эффект будет удален в будущей версии движка.

Добавляет объемный эффект, который может быть полезен при имитации заснеженной местности. Также есть возможность контролировать цвет, скорость и количество, а также моделировать различные среды, например лаву.

EffectWaterDroplets

Добавляет эффект воды, который появляется на экране из разных источников. В отличие от RainDroplets, это скорее имитирует эффект типа «всплеска», когда вода разбрызгивается на экран в разных местах.

EffectWaterFlow

Добавляет еще один тип эффекта воды, но в данном случае имитирует воду, стекающую по экрану. Этот эффект можно использовать для имитации более плотного взаимодействия с водой, например, стояния под водопадом.

FilterBlur

Размывает весь экран. Может использоваться для имитации таких явлений, как густой дым, влияющий на глаза игроков. На данный момент доступно только размытие по Гауссу.

FilterChromaShift

Смещает информацию о цветности изображения на определенную величину. Лучше всего использовать в небольших количествах для создания тонких киноэффектов.

FilterDirectionalBlur

Применяет размытие в указанном направлении в зависимости от движения. Направление размытия определяется с помощью входного порта vec3 на узле.

FilterGrain

DEPRECATED - Эффект доступен через окно настроек в Environment Editor.

FilterRadialBlur

Размывает экран вокруг определенной 2D-позиции на экране. Величину и радиус эффекта размытия можно определить с помощью входных портов узла.

BlurringRadius устанавливает радиус эффекта размытия вокруг определенного центра. ScreenPos X/Y можно использовать для изменения центра.

FilterSharpen

Добавляет резкость к окончательному изображению. Несмотря на наличие входного порта «Тип», в настоящее время доступен только один тип. Вы также можете использовать отрицательные значения, чтобы размыть экран.

FilterVisualArtifacts

Применяет многочисленные эффекты, которые обычно ассоциируются со старыми телевизорами: зернистость, вертикальная синхронизация, чересстрочная развертка, пикселизация и другие. Вы можете замаскировать текстуру или применить ее ко всему экрану.

По умолчанию все значения эффектов установлены на 0, поэтому вы не увидите никаких эффектов, если не укажете значение для типа ввода. Доступные входы эффектов: VSync, чересстрочная развертка, пикселизация, сдвиг цветности и зернистость.

SetShadowMode

Установите режим тени на «Нормальный» или «HighQuality». Примечание. Это предназначено для очень специфических настроек освещения, и при обычном использовании, скорее всего, это приведет к множеству артефактов самозатенения.
