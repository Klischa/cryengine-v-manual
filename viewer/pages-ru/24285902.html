Полезная информация

При работе над активом обязательно помните о следующих вещах:

  • Не создавайте никаких дополнительных прокси-объектов для частей, которые вы хотите сломать; просто физизуйте видимую сетку SubID для разрушаемых частей
  • Обязательно избегайте пробелов и закройте процедурную разрушаемую сетку (запечатанный прокси)
  • Объедините все в один объект, если вы используете для своего актива разрушаемые и неразрушаемые геометрические части; не создавайте иерархии, связывая несколько частей геометрии вместе
  • Материал для вашего хрупкого предмета должен иметь wood_breakabale и Surface_Type назначается для того, чтобы движок активировал логическое разрушение геометрии
  • Логическое разрушение может быть довольно тяжелым для производительности в зависимости от различных факторов:
    • Геометрическая сложность булевой формы.
    • Геометрическая сложность хрупкого актива.
    • Количество разрушаемых объектов, используемых на уровне.
    • Число последовательных логических значений, примененных к разрушаемому объекту.

Материал

Сначала мы настроим материал для объекта. В 3dsMax откройте Material Editor, и создайте новый мультиматериал под названием tutorial_boolean_destruction, с четырьмя субматериалами. Назовите первого SubId листья, второй багажник, третий SubId как tb_proxy (tb = Touch Bending) и четвертый как препятствовать. Имена SubIds здесь не важны. Просто назовите их что-нибудь конкретное, соответствующее их назначению, для справки. См. Рис2 и обратите внимание на многоматериальный настройка в редакторе материалов 3dsMax.

Настройка идентификатора листьев

Откройте подматериал «листья» (SubId1). Загрузите диффузную карту и карту нормалей для путей материалов. Диффузная карта должна содержать альфа-карту непрозрачности. Карта нормалей также должна содержать альфа-карту для значения сглаживания PBS.

Файл примера относится к следующим текстурам, уже представленным в файлах учебников:

Для работы Boolean Destruction не требуется дополнительная геометрия прокси. Материал для ствола должен физизировать сетку рендеринга, чтобы ствол был прочным и хрупким.

Есть две причины, по которым дополнительная прокси-геометрия не работает с логическим разрушением:

  • Точность: логическая система использует точное обнаружение попаданий. Это делает грубый физический прокси устаревшим и необходимой физикализацией сетки рендеринга.
  • Производительность: как только первый удар вызывает дыру в результате логического вычитания, форма и геометрия сетки рендеринга изменяются. Дополнительный физический прокси будет означать, что второй объект также необходимо разрезать, чтобы следующая пуля прошла через вновь созданное пустое пространство.

препятствовать настройке идентификатора

Откройте препятствовать субматериал (SubId4).

Это физика Параметр obstruct в подматериале используется для определения сопротивления воздуха этому объекту. Величина сопротивления воздуха определяется размером объема препятствия. Чем больше препятствовать объема, тем медленнее будет падать дерево.

Примеры:

  • Если вы сломаете ствол дерева и обнаружите, что его верхняя часть падает слишком медленно, это означает, что ваш прокси-блок слишком велик. Уменьшите размер объема препятствий.
  • Если вы сломали ствол дерева и обнаружили, что его верхняя часть падает слишком быстро, увеличьте размер препятствия.


Рис.6: препятствие SubId4 «Основные параметры шейдера».

В Основные параметры шейдера окно:

  1. Выберите Крайтек Шейдер.
  2. В Физическая реализация раздел, проверьте Физически флажок.
  3. В следующем раскрывающемся меню выберите пункт препятствовать вариант.
В Основные параметры шейдера Crytek раздел, установите диффузный цвет на зеленый и уменьшите непрозрачность до 15–30%. Это не обязательно, но помогает пользователю быстро определить геометрию препятствия внутри актива.

Геометрия

Нашей геометрией для этого урока будет пальма. Это растение идеально подходит для объяснения этого типа технологии, поскольку его ствол достаточно тонкий, чтобы его можно было правдоподобно сломать с помощью логической операции разрушения. Вдобавок ко всему, крона листьев является хорошим примером того, как работают объемы препятствий, когда речь идет о сопротивлении воздуха кускам, которые впоследствии упадут.

Создание багажника

Создайте геометрию ствола дерева и примените материал, который мы только что создали к этому (tutorial_boolean_destruction.mtl). Измените материал SubId на 2 («хобот»). Фнаконец-то тыувидеть Развернуть UVW модификатор для настройки оболочки UV.

Этот раздел нашей геометрии будет разрушаемой частью. Обязательно избегайте дыр в сетке. Логическая операция может быть успешно применена только к полностью замкнутой геометрии.

Форма логического разреза по умолчанию имеет предопределенную ширину, поэтому сохраняйте разумное значение радиуса ствола, чтобы получить чистые разрезы по всей сетке. Ствол сломается только тогда, когда эта операция прорежет его полностью.

Создание листовой кроны

Затем создайте одну большую сетку листьев для вашей пальмы. иприменить материал, который мы только что создали к этому (tutorial_boolean_destruction.mtl). Сповесьте его материал SubId на 1 («листья»). Наконец-то тыувидеть Развернуть UVW модификатор, позволяющий настроить оболочку UV так, чтобы она помещалась только вокруг одного из листьев текстуры.

Добавление сенсорного изгиба

В этом примере крона дерева будет состоять из двух наборов сгибаемых листьев. Это добавит большей правдоподобности процессу взлома. С помощью Touch Bending листья станут физическими, как только они упадут на землю, когда дерево будет разрушено. Сначала скопируйте лист и переместите оболочку UV вашей копии на другую текстуру листа. Теперь создайте две конфигурации сгибания касанием для обеих створок.

Для получения дополнительной информации о настройке сенсорного изгиба перейдите по ссылке HERE для полного объяснения.

Пока не копируйте листья и не добавляйте прокси-сервер Touch Bending, пока мы не перейдем к следующему шагу.

Добавление геометрии сопротивления воздуха (препятствие)

Для этой функции вам необходимо настроить единую часть геометрии, чтобы определить правильное сопротивление воздуха. Чем больше его объем, тем медленнее верхняя часть будет падать после того, как вы выстрелите в дерево. Это поможет дереву упасть более правдоподобно. Создайте простую низкополигональную сферу радиусом примерно 1 м и поместите ее прямо в середину кроны листа.
