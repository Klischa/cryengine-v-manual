Обзор

Движок предоставляет консоль как средство, с помощью которого пользователь может устанавливать и сохранять значения переменные консоли, чтобы манипулировать состоянием игры и движка, не требуя модификации исходного кода. Кроме того, консоль позволяет консольные команды, аналогично переменным, но выполняет функцию всякий раз, когда она выполняется пользователем.

Консолью можно управлять либо с помощью кода, либо нажатием клавиши тильды в игре.

Консольные переменные

Часто называют CVars, переменные консоли можно зарегистрировать в коде, чтобы предоставить глобальную переменную, которую дизайнеры смогут настраивать без дальнейшего изменения кода. CVars представлены ICVar интерфейс в коде. Пример создания CVar см. IConsole::Регистрация.


Добавление CVar можно выполнить разными способами:

  1. Через IConsole::GetCVar и ICVar::Set
  2. Добавив CVar и его желаемое значение в ваш .cryproject.
  3. Путем изменения файла .cfg

Группы переменных консоли

Группы переменных консоли предоставляют удобный способ одновременного применения предопределенных настроек к нескольким переменным консоли. Их обычно называют CVarGroup. Основной вариант использования CVarGroups — изменение графической спецификации с использованием переменной CVar "sys_spec".

Регистрация новой группы переменных

Чтобы зарегистрировать новую группу переменных, добавьте новый текстовый файл .cfg в Config/CVarGroups каталог.
[default]
; default of this CVarGroup
= 4
e_particles_lod=1
e_particles_max_emitter_draw_screen=64

[1]
e_particles_lod=0.75
e_particles_max_emitter_draw_screen=1

[2]
e_particles_max_emitter_draw_screen=4

[3]
e_particles_max_emitter_draw_screen=16

При этом создается новая группа консольных переменных с именем «sys_spec_Particles», которая ведет себя как целочисленная консольная переменная. По умолчанию эта переменная имеет состояние 4 (устанавливается в строке, следующей за комментарием).

При изменении переменной применяется новое состояние. Переменные консоли, не указанные в файле .cfg, не устанавливаются. Все желаемые переменные консоли должны быть частью раздела по умолчанию. В случае нарушения этого правила выводится сообщение об ошибке.

Если переменная консоли не указана в настраиваемом разделе, применяется значение, указанное в разделе по умолчанию.

Консольные команды

Подобно консольным переменным, консольные команды называются CКоманды и обеспечить поддержку выполнения функции при каждом выполнении указанной команды. Пример создания собственных консольных команд см. IConsole::AddCommand.
