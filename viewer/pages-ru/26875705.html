Прежде чем мы начнем, нам нужно будет создать Проект для работы на протяжении всего данного руководства. В приведенных ниже шагах мы будем использовать CRYENGINE V. пусковая установка для создания нашего проекта. После завершения этого шага у вас будет шаблон, который вы сможете использовать в своих будущих проектах.


Предварительные условия

В этом кратком руководстве предполагается, что у вас есть основные предпосылки для программирования CRYENGINE:


Шаги

  1. Откройте программу запуска CRYENGINE.

  2. В окне «Проекты» («Библиотека» > «Проекты») нажмите «Создать» (в правом верхнем углу) и выберите пустой проект C++.

  3. Имя проект.

  4. Выбрать где проект должен быть сохранен.

Файлы проекта хранятся отдельно от движка. А .cryproject файл будет сгенерирован для вас; его можно щелкнуть правой кнопкой мыши, чтобы открыть вспомогательные функции, или открыть в текстовом редакторе, чтобы открыть JSON с подробным описанием проекта.

Когда вы закончите, нажмите Создать проект для создания своего проекта. После этого вы вернетесь на главный экран Launcher. Здесь вы можете запустить Редактор или Игру. Создание проект не автоматически открыть это.


Для начала откройте панель запуска CRYENGINE и нажмите Новый в меню «Проекты».

Конечный результат

Это приведет вас к Создать проект экран, на котором мы можем выбрать версия двигателя, предпочтительный язык, а проект template, проект имя файла и путь .
