Приложение

Прикрепить/отсоединить объект к другому.

Входы

Выходы

AttachmentEx

Этот узел позволяет прикреплять объекты к другим объектам, не требуя объявления соединения прикрепления в файле .cdf.

BeamEntity

Используется для мгновенного перемещения объектов в любую точку уровня. Когда луч порт срабатывает, целевой объект перемещается на вход позиции на Позиция порт.

Кроме того, с помощью входных портов можно настроить вращение и масштаб, чтобы сопоставить передаваемый объект с другим объектом.

Входы

Выходы

BroadcastEvent

Используется для отправки события одному или нескольким объектам. Объекты, которые получат это событие, указываются путем ввода строки в поле имя порт. Каждый объект, в имя которого введена строка, получит событие, установленное в событие порт.

События чувствителен к регистру, поэтому убедитесь, что вы вводите его правильно.

Вы можете получить доступ к списку событий, связанных с объектом, если щелкнете по нему правой кнопкой мыши и перейдете в меню событий.

В этом примере через 5 секунд Сущность: BroadcastEvent узел используется для отправки Убить событие для всех объектов, у которых есть строка 'Squad_A' от их имени.

CallScriptFunction

Вызывает функцию сценария для объекта.

CharAttachmentMaterialParam

Позволяет изменить материал во вложении в файле .cdf. Например, вы можете изменить материал брюк персонажа.

Установить материал это триггер, ForcedMaterial это полная ссылка на материал (например: materials/references/basecolors/grey.mtl) и SubMtId это номер подматериала.

CharAttachmentControl

Этот узел позволяет легко переключать вложение скина и/или его текущий материал и контролировать его видимость.

CheckDistance

Проверьте расстояние между объектом узла и объектами, определенными во входных данных.

CheckProjection

Проверьте проекцию между направлением вперед целевого объекта узла (или направлением обзора камеры, если целевой объект не выбран) и объектами, определенными во входных данных.

ChildAttach

Присоединяет другую сущность к целевой сущности. Дочерняя сущность будет связана с целевой сущностью, пока ссылка не будет удалена. Сущность, определенная в Ребенок входной порт прикреплен к целевому объекту.

ChildDetach

Используется для отделения сущностей от родительской сущности. Обычно ChildAttach узел использовался ранее для связи целевого объекта с другим объектом.

Узел имеет два дополнительных порта для установки настроек физики трансформации. Если установлено «KeepTransform», сущность сохранит свою трансформацию в мировом пространстве даже после отсоединения. Если установлено «EnablePhysics», физика будет снова включена при отсоединении объекта.

Урон

Наносит урон указанному объекту на сумму урона при активации триггера.

EntitiesInRange

Берет позиции двух объектов и проверяет, находятся ли они в определенном диапазоне друг от друга. В зависимости от результата проверки срабатывают выходные порты.

В приведенном выше примере мы делаем сущность1 перемещаться вперед и назад между двумя точками. Мы установили таймер для проверки EntitiesInRange каждые 0,2 секунды.

Когда они находятся в пределах досягаемости, отображается одно сообщение, а когда они находятся вне зоны действия, отображается другое. Мы также получаем отправку проверки расстояния на HUD через другое отладочное сообщение из вывода расстояния.

EntityFaceAt

Заставляет объект просмотреть указанный целевой объект.

EntityId

Выводит номер объекта ID указанного объекта. Узел не требуется запускать, поскольку объект ID никогда не изменяется.

В приведенном выше примере EntityIDs используются для определения целей входных данных для узла EntitiesInRange.

EntityInfo

При срабатывании этот узел выводит ID, имя, класс и архетип целевой сущности. В случаях, когда необходимо сравнить типы сущностей, этот узел очень полезен.

В этом примере имя целевой сущности узла EntityInfo сравнивается со строкой с помощью String:Compare.

EntityPos

Обрабатывает все манипуляции объекта-владельца, связанные с позицией. Вся информация о местоположении указанного объекта может быть прочитана из выходных портов.

В отличие от узла GetPos, выходные порты этого узла срабатывают всякий раз, когда изменяется одно из свойств целевого объекта (т. е. когда объект перемещается, динамически обновляется).

В этом примере порт вывода позиции используется в качестве цели для объекта Grunt1, к которому можно перейти с помощью узла AI:Signal.

FlashInvoke

Вызов функции Flash.

GameVolumes

Это позволяет использовать узлы GameVolume.

DistanceTest

Этот узел позволяет выполнять базовые тесты с помощью GameVolumes. Следует использовать только для прототипирования.

GetInfo

Этот узел позволяет выполнять базовые тесты с помощью GameVolumes. Следует использовать только для прототипирования.

PositionTest

Этот узел позволяет выполнять базовые тесты с помощью GameVolumes. Следует использовать только для прототипирования.

GetBounds

Используется для получения и вывода границ.

Входы

Выходы

GetChildrenInfo

Получает информацию (количество и идентификаторы) дочерних объектов сущности.

GetPos

Функциональность этого узла аналогична узлу EntityPos, но вместо запуска выходных портов при каждом изменении какой-либо информации о местоположении он выводит только при соответствующем срабатывании.

Единственным входным портом является Получить порт, который при срабатывании выводит соответствующую информацию на все выходные порты.

В ситуациях, когда постоянное обновление слишком затратно, следует использовать GetPos вместо узла EntityPos, который непрерывно выводит данные на все порты при изменении любого значения позиции.

GlobalLayerListener

Этот узел позволяет вам прослушивать события скрытия/открытия слоев.

LayerSwitchListener

Этот узел позволяет вам прослушивать события скрытия/показания слоя для данного объекта.

LinksGet

Этот узел позволяет вам проверять конфигурацию связей сущностей.

LinksSet

Этот узел позволяет вам проверять конфигурацию связей сущностей.

ParentId

Получите номер parentID от указанного объекта.

PropertyGet

Получить значение свойства сущности.

PropertySet

Измените значение свойства сущности.

Примечание. Это изменение свойства не будет работать с SaveLoad.

RenderParams

Установите конкретные параметры рендеринга.

Спавн

Создает сущность с указанными свойствами.

SpawnArchetype

Создает сущность-архетип с указанными свойствами.

TacticalScan

Получает идентификатор объекта, сканируемого в данный момент тактическим способом.

TacticalScanComplete

Получает идентификатор объекта, который только что завершил (но до успеха или неудачи) тактическое сканирование.

TacticalScanCurrentControl

Может управлять тактическим сканированием, которое выполняется в данный момент.

TacticalScanStart

Получает идентификатор объекта, тактическое сканирование которого только что началось.

Скорость

Выводит различные компоненты скорости объекта.
