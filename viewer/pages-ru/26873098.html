Базовый класс CEditor

CEредактор class является базовым классом для всех окон редактора, таких как каждый инструмент из меню «Инструменты», каждый редактор ресурсов и большинство закрепляемых окон в Sandbox.

Вы можете найти CEредактор интерфейс в следующем файле: Sandbox/Плагины/EditorCommon/EditorFramework/Editor.h

CEditor предоставляет множество сервисов и функций, предназначенных для использования каждым инструментом в Sandbox. Вот неполный список поддерживаемых функций:

  • Сохранение и загрузка макетов.
  • Более легкий доступ к Персонализация.
  • Система построения меню.
    • Обработка всех общих команд (Новый, Открыть, Сохранить, Отменить/Повторить, Копировать/Вставить...).
    • Настраиваемые меню через плагин.
  • Система стыковки, встроенная в CEditor.
  • Предотвращение закрытия окна в случае несохраненных изменений.

CEditor и его производные являются основным средством создания основы для создания новых инструментов в Sandbox. Хотя вы можете работать за пределами этой структуры, мы рекомендуем использовать ее, чтобы обеспечить согласованность всех инструментов, а также потому, что вы получите выгоду от любых дополнений, исправлений и улучшений, которые мы вносим в эту систему, просто унаследовав ее.

Создание нового окна


Чтобы создать новое окно инструментов, вы должны наследовать CEditor и использовать его многочисленные службы и расширенные функции для создания своего инструмента. Однако существуют более специализированные версии CEditor для конкретных целей, которые рекомендуется использовать.

  • Редактор: Самая базовая версия, не поддерживает стыковку.
  • CDockableEditor: Расширение CEditor, поддерживающее стыковку. Это хороший базовый класс для любого инструмента, кроме редактора активов (см. ниже). Инструмент, который не редактирует никакие ресурсы или файлы, может быть создан на основе CDockableEditor, но большинство новых систем, вероятно, должны быть CAssetEditor и интегрироваться с системой активов.
  • CAssetEditor: Добавляет дополнительные функции, необходимые для редактирования типов активов. В этом случае следуйте документации на Система активов 5.5.2.


Один из самых простых примеров CDockableEditor можно найти в PlaygroundDockable.h/cpp

Вот пример кода, демонстрирующий, как объявить и зарегистрировать новое окно редактора:

class CExampleEditor : public CDockableEditor
{
public:
  CExampleEditor()
  {
    auto exampleContent = new QWidget();
    /*build the content of your editor*/
    SetContent(exampleContent);
  }
  ~CExampleEditor() {}
  virtual const char* GetEditorName() const override { return "Example"; };
};
