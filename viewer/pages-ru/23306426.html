CryLog Функциональность ведения журнала

Вход в CryENGINE должен осуществляться с помощью следующих глобальных функций:

  • CryLog (eMessage)
  • CryLogAlways (eAlways)
  • CryError (eError)
  • CryWarning (eWarning)
  • CryComment (eComment)

Если требуется больший контроль, ILog интерфейс можно использовать напрямую, например:

gEnv->pLog->LogToFile("value %d",iVal);

Уровень многословности и окраска

Консольные переменные log_Verbosity и log_FileVerbosity включить подавление ведения журнала.

В следующей таблице показано, как работает подавление многословия и каким цветом оно отображается в консоли:

  • Х означает, что тип сообщения записывается в консоль или файл
  • ? означает, что задействована какая-то особая логика
  • TIP: Полное ведение журнала (в консоль и файл) можно включить с помощью log_Verbosity 4.

Файлы журналов

Sandbox регистрируется в «Editor.log», тогда как игра по умолчанию использует файл «game.log». Сообщения об ошибках дополнительно записываются в файл «Error.log».

Консольные переменные

log_IncludeTime

Toggles time stamping of log entries.
Usage: log_IncludeTime [0/1/2/3/4/5]
  0=off (default)
  1=current time
  2=relative time
  3=current+relative time
  4=absolute time in seconds since this mode was started
  5=current time+server time

ai_LogFileVerbosity

None = 0, progress/errors/warnings = 1, event = 2, comment = 3

log_Verbosity
DUMPTODISK

defines the verbosity level for log messages written to console
-1=suppress all logs (including eAlways)
0=suppress all logs(except eAlways)
1=additional errors
2=additional warnings
3=additional messages
4=additional comments
