IsNullVector( а )

Возврат правда если все векторные компоненты данного вектора а являются нулевыми.

IsNullVector( а )

Возврат правда если какие-либо векторные компоненты данного вектора а не является нулевым.

LengthSqVector( а )

Возвращает квадрат длины данного вектора а.

LengthVector( а )

Возвращает длину данного вектора а.

DistanceSqVectors( а, б )

Возвращает квадрат расстояния между вектором а и вектор б.

DistanceSqVectors2d( а, б )

Возвращает квадрат расстояния между вектором а и вектор б в 2D-пространстве (без z-компоненты).

DistanceVectors( а, б )

Возвращает расстояние между вектором а и вектор б.

dotproduct3d( а, б )

Возвращает скалярное произведение вектора а и вектор б.

dotproduct2d( а, б )

Возвращает скалярное произведение вектора а и вектор б в 2D-пространстве (без z-компоненты).

LogVec(имя, v)

Записывает заданный вектор на консоль.

Пример:
LogVec("Local Actor Position", g_localActor:GetPos())

Console output:
<Lua> Local Actor Position = (1104.018066 1983.247925 112.769440)

ZeroVector( место )

Устанавливает все векторные компоненты данного вектора место назначения до нуля.

CopyVector( место назначения, источник )

Копирует компоненты вектора источник к вектору место назначения.

SumVectors( а, б)

Складывает компоненты вектора а и вектор б.

NegVector( а )

Отменяет все компоненты данного вектора а.

SubVectors( место, а, б)

Копирует покомпонентное вычитание вектора б и вектор а векторизировать место назначения.

FastSumVectors( место, а, б)

Копирует покомпонентное сложение вектора б и вектор а векторизировать место назначения.

DifferenceVectors( а, б )

Возвращает разницу между вектором а и вектор б.

FastDifferenceVectors( место, а, б)

Копирует покомпонентную разницу между вектором а и вектор б векторизировать место назначения.

ProductVectors( а, б )

Возвращает произведение вектора а и вектор б.

FastProductVectors( место, а, б)

Копирует произведение вектора а и вектор б векторизировать место назначения.

ScaleVector( а, б )

Масштабирует заданный вектор а по коэффициенту б.

ScaleVectorInPlace( а, б )

Возвращает новый вектор на основе копии масштабированного вектора. а по фактору б.

ScaleVectorInPlace( место, а, б)

Копирует масштабированный вектор а по коэффициенту б векторизировать место назначения.

NormalizeVector( а )

Возвращает нормализованный вектор а.

VecRotate90_Z( v )

Вращает вектор в на 90 градусов вокруг оси Z.

VecRotateMinus90_Z( v )

Вращает вектор в на -90 градусов вокруг оси Z.

перекрестное произведение3d( назначение, р, q)

Копирует результат векторного произведения между векторами п и вектор д векторизировать место назначения.

RotateVectorAroundR( назначение, p, r, угол)

Копирует результат векторного вращения вектора п вокруг вектора р по данному угол векторизировать место назначения.

ProjectVector( место назначения, P, N)

Копирует результат векторной проекции вектора П к поверхности с заданной нормалью Н векторизировать место назначения.

DistanceLineAndPoint( а, р, q)

Возвращает расстояние между точкой а и грань между п и д.

LerpColors( а, б, к)

Линейная интерполяция между цветом/вектором а и цвет/вектор б с коэффициентом к.

Лерп( а, б, к )

Линейная интерполяция между скаляром а и скаляр б с коэффициентом к.

__max( а, б )

Возвращает максимум а и б.

__min( а, б )

Возвращает минимум а и б.

зажим( _n, _min, _max)

Зажимает номер _n между _min и _max.

Интерполировать (фактическое, целевое, скорость)

Интерполирует заданное число фактический к данному цель по данному скорость.

знак(а)

Возвращает знак заданного числа (0 возвращает 0).

сгнз( а )

Возвращает знак заданного числа (0 возвращает 1).

площадь( а )

Возвращает квадрат заданного числа.

randomF( а, б )

Возвращает случайное число float между а и б.

тогда и только тогда( с, а, б )

Возврат а если с не ноль, в противном случае он возвращает б.
