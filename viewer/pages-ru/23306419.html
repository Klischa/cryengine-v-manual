Обзор

Этот документ предназначен для людей, которые хотят изменить данные о звездах, используемые при рендеринге неба. Это предполагает некоторое знакомство с созданием двоичных файлов.

  • Файл данных: Build\Engine\EngineAssets\Sky\stars.dat
  • Файл кода загрузчика: CRESky.cpp, функция CStars::LoadData

Главы:

Формат файла
Заголовок (12 байт)
Запись (12 байт)

Формат файла

Файл имеет простой двоичный формат, и вы можете легко записать туда нужные данные самостоятельно с помощью какого-либо инструмента.

Все типы хранятся в формате с прямым порядком байтов, float32 в формате IEEE-754.

Файл начинается с заголовка. Сразу за заголовком следуют записи для каждой звезды (количество записей сохраняется в заголовке).

Планировка и типы следующие:

Заголовок (12 байт)

Запись (12 байт)

Как правило, вы можете использовать существующие звездные каталоги для заполнения этой информации или использовать тот, который представлен в SDK (который основан на реальной информации).
