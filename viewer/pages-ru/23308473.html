Описание

А Файл определения тега содержит определение тега, которое представляет собой набор тегов. Эти теги представляют собой ключевые слова, используемые для маркировки. Фрагменты (и Mannequin Переходы).

См. Mannequin Теги и определения тегов для получения дополнительной информации об этой концепции.

Файлы определения тегов ссылаются на Файл определения контроллера (xxxControllerDefs.xml), любой Файл базы данных анимации (ADB)и (необязательно) FragmentID Файлы определений. Смотрите обзорное изображение на странице о Mannequin Файлы.

Файлы определений тегов могут включать в себя иерархически другие файлы определений тегов.

Создание файла определения тега

Файлы определения тегов можно создать в Mannequin Редактор определений тегов.

Файлы определения тегов хранятся в папке Анимации/Mannequin/ADB/ папка. Это не является абсолютным требованием к двигателю, но Mannequin Редактор определений тегов В настоящее время в этой папке ищет только файлы определений тегов.

Имя файла обычно заканчивается на Tags.xml. Опять же, это не является абсолютным требованием, но редактор будет фильтровать по окончанию этого файла.

Редактирование файла определения тега

Файлы определения тегов редактируются в Mannequin Редактор определений тегов.

Однако в этом редакторе вы не можете редактировать иерархическое включение файлов определений тегов. Чтобы использовать эту расширенную функцию, см. FileFormat раздел.

Формат файла

Это пример текущего формата (версия 2).

<TagDefinition version="2">
 <Imports>
  <Import filename="Animations/Mannequin/ADB/itemTags.xml"/>
 </Imports>
 <Tags>
  <Group name="Stance">
   <Tag name="Relaxed" priority="2"/>
   <Tag name="Alerted" priority="2"/>
   <Tag name="Stand" priority="2"/>
  </Group>
  <Tag name="Slave"/>
  <Tag name="Scope_Aiming"/>
  <Tag name="Scope_Looking"/>
 </Tags>
</TagDefinition>

Корневой элемент TagDefinition должен содержать правильный номер версии.

Импорт Элемент содержит список других включенных файлов определений тегов. Они объединяются во время загрузки. (аналогично оператору #include в коде C) В этом примере мы ссылаемся на общее определение тега itemTags.xml, которое может содержать теги, связанные с обработкой элементов, которые являются общими для нескольких типов символов.

Теги элемент содержит список отдельных тегов (Тег) и группы тегов (Группа). Каждый индивидуальный тег может получить приоритет. Приоритет по умолчанию — 0.

Файл определения тега использует тот же формат, что и файл Файл определения FragmentID (xxxActions.xml), поскольку он использует тот же базовый код, Mannequin CTagDefinition.
