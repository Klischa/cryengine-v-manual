Обзор

CryENGINE предлагает несколько методов анализа. рабочий производительность во время выполнения, а также в автономном режиме.

  • Для быстрого просмотра текущей рабочей нагрузки используйте консольную команду Профиль 5.
  • Для более детального обзора воспользовался Статоскоп инструмент, который можно найти в game_branch/Инструменты папка.

Профиль 5

Консольная команда Профиль5 отображает информацию о рабочих нагрузках отдельных рабочих потоков.

Эту функцию следует использовать для получения приблизительного обзора. Для более подробного анализа данных по каждому кадру см. раздел Статоскоп инструмент.

Как использовать:
  • Команда внутриигровой консоли: Профиль 5
Особенности:

Сводка использования работников:

  • SampleTime: Период времени, в течение которого были взяты пробы

Индивидуальная статистика работников:

  • WorkTime: Общее время, в течение которого этот работник выполнял задания за период выборки.
  • Время простоя: Общее время простоя работника за период выборки.
  • Рабочая нагрузка: Процент WorkTime по отношению к времени выборки.
  • Рабочая нагрузка на работу: Процент, разделенный на количество рабочих мест.
  • Вакансии: Тколичество заданий, выполненных за период выборки.
  • ---
  • Счетчик: время выполнения работника выборочной совокупности.
  • Гистограмма: Время выполнения работника на кадр за последние X кадров.

Ошибки страницы: (только PC)

  • Неисправности: Количество ошибок страниц за период выборки .
  • ---
  • Метр: Представление Log10 ошибок страниц выборки.
  • Гистограмма: Log10 — представление ошибок страниц на кадр за последние X кадров.

Тайминги кадров:

  • Время: Время кадра в миллисекундах.
  • Рамки: Кадры в секунду.
Ограничения
  • Отображаются только неблокирующие/SPU(PS3) рабочие процессы.

Статоскоп

Статоскоп предлагает анализ данных в реальном времени, а также в автономном режиме для каждого кадра.

Ссылка на Руководство по статоскопу где можно найти дополнительную информацию об инструменте.

Как использовать:

Шаг 1:

  • В игровой консоли введите: e_StatoscopeLogDestination 1

Шаг 2:

  • В консоли введите: e_StatoscopeDataGroups WX
  • DataGroup Вт = Информация о работнике
  • DataGroup Х = Сводная информация о работнике
  • (Обратите внимание на заглавные буквы)

Шаг 3:

  • Старт Статоскоп

Шаг 4:

  • Нажмите Файл->Подключиться.

Шаг 5:

  • Подключитесь к платформе, на которой запущена игра.
Особенности:

Информация о работнике:

DataGroup: Вт

Индивидуальная статистика рабочих для различных типов серверной части для данного кадра.

Типы бэкэнда:

  • Нет блокировки
  • Блокировка
  • SPU

На каждого работника:

  • SamplePeriodInMs : Период выборки в миллисекундах.
  • ExecutionTimeInMs: Общее время, затраченное работником на выполнение работы.
  • IdelTimeInMs: Общее время простоя работника (период выборки — время выполнения).
  • UtilPerc: Процент использования за время выборки.
  • NumJobs: Количество выполненных работ.

Сводная информация о работнике:

DataGroup: Х

Сводная информация обо всех действиях исполнителей для различных типов серверной части для данного кадра.

Типы бэкэнда:

  • Нет блокировки
  • Блокировка
  • SPU

Для каждого бэкэнда:

  • SamplePeriodInMs : Период выборки в миллисекундах.
  • ActiveWorkers: Активные работники.
  • AvgUtilPercentage: Средний процент использования за время выборки.
  • TotalExecutionPeriodInMs: Общее время, потраченное на выполнение заданий.
  • TotalNumberOfJobs: Общее количество выполненных работ.
