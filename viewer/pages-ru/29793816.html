Где использовать спавн?

Внутри игр есть определенные жанры, которые требуют бесконечного появления AI, чтобы игрок мог набрать высокий балл, или они могут быть миньонами в битве с боссом, дальнейшее появление которых зависит только от здоровья босса. Возможность понять, как использовать эти архетипы для создания классов AI и сделать их динамичной частью расширенного игрового процесса, является ценным знанием, которое необходимо знать.

В этом уроке мы сосредоточимся на создании точки тега AI, а затем на использовании этой позиции для создания AI каждые три секунды с помощью таймера.

Исходное видео

Как создать волны AI

Вам необходимо выполнить следующие шаги, указанные ниже, чтобы создать волны AI:

  1. Добавить AI Точка тега на место происшествия, перейдя в Создать объект -> AI -> Точка тега и перетащите его на сцену.
  2. Нажмите RMB на Точка тега и выбери Создать Flow Graph.
  3. Добавить Игра:Начать узел, а затем добавив Сущность: SpawnArchetype узел и зацепите Игра:Начать вывод к Архетип: Спаун ввод порт.
  4. Наконец, нажмите RMB и выберите Добавить объект по умолчанию для графика добавить Точка тега. Затем подключите это к Поз. и Гниль входные порты для SpawnArchetype узел для направления нереста в определенное место. Теперь мы можем приступить к уничтожению начального AI.
  5. После первоначального появления нам нужно начать создавать больше в зависимости от временного интервала. Для этого мы будем использовать Время: Таймер узел и установка Период до значения 3 секундные интервалы. Нам нужно будет разделить это с Игра:начать вывод, поэтому нам нужно будет добавить Логика:Любая узел для объединения вывода. Теперь, когда мы прыгаем, мы можем убить несколько AI, которые появляются каждые 3 секунды.
