ActionMaps

ActionMaps:ActionFilter

Этот узел потока может включать/отключать существующие фильтры.

В этом примере мы включаем уже определенный фильтр «кат-сцены».

ActionMaps:ActionListener

Этот узел потока позволит вам прослушивать определенные действия, которые были перенаправлены указанному объекту.

В приведенном выше примере мы начинаем слушать действие «прыжок» для локального игрока. Если объект не указан, узел будет прослушивать все события, соответствующие шаблону.

ActionMaps:ActionMap

Этот узел потока позволит вам включать/отключать карты действий во время выполнения.

В приведенном выше примере мы включаем карту действий «игрок» для локального игрока.

ActionMaps:ActionMapManager

Этот узел потока позволит вам включать/отключать всю систему менеджера карт действий.

В приведенном выше примере мы включаем карту действий «игрок» для локального игрока.

ActionMaps:GetDefaultActionEntity

Этот узел потока позволит вам получить текущий набор объектов действия по умолчанию.

В приведенном выше примере мы получаем текущий объект действия по умолчанию и, установив для AutoUpdate значение 1, мы подписываемся на его обновления.

ActionMaps:SetDefaultActionEntity

Этот узел потока позволит вам установить текущий объект действия по умолчанию.

В приведенном выше примере мы устанавливаем локального игрока в качестве текущего объекта действия по умолчанию.
