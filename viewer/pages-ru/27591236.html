Обзор

Система плагинов CRYENGINE обеспечивает поддержку создания плагинов как на C++, так и на C# и позволяет пользователям просто добавить плагин в свой проект и мгновенно оценить преимущества.

Предполагаемые преимущества

  • Упрощение создания игрового кода
    Уменьшите объем кода, который вам придется использовать при реализации элементарных функций вашего проекта. Для достижения этой цели вы можете использовать как C++, так и C#.

  • Создайте собственный проект, ни разу не касаясь кода.
    Времена, когда приходилось модифицировать устаревшие игровые проекты, остались в прошлом: с новой системой вы можете создать проект, просто добавив к нему заранее написанные плагины.
  • Создание большего количества частей двигателя необязательно.
    Повысьте производительность, удалив системы, которые не требуются вашему проекту. Нет необходимости поддерживать мертвый код.

  • Больше контроля/информации о функциях, используемых вашим проектом
    Получите правильную информацию о плагинах, загруженных во время выполнения, увеличьте время итерации, имея возможность горячей перезагрузки любого плагина во время работы движка.

  • Упрощенная настройка движка для вашего проекта
    Сделайте изменения вашего проекта еще более доступными для членов вашей команды, используя полностью динамическую рабочую среду для плагинов.

Изменения

Изменения в ExtensionSystem:

Проблем совместимости с существующими расширениями нет.

Изменения в CryMonoBridge и MonoRuntime:

CryMonoBridge теперь является частью каждого проекта Windows. Это увеличит время компиляции из-за процесса swig, но также гарантирует, что поддержку C# можно будет легко включить без каких-либо дальнейших изменений или специальных конфигураций. MonoRuntime сильно изменился. MonoLauncher больше не загружается, но все плагины C# управляются непосредственно из менеджера плагинов. Это позволяет пользователям контролировать каждый загруженный двоичный файл.

Изменения в проектах/плагинах C#:

Чтобы сделать ваш двоичный файл C# совместимым с новой системой плагинов, просто напишите вокруг него класс-оболочку, которая наследуется от ICryEnginePlugin. ICryEnginePlugin предлагает вам все необходимые интерфейсы для CRYENGINE. Система плагинов заботится о вызове методов, упомянутых ниже:

  • void Инициализировать()
    Вызывается всякий раз, когда менеджер плагинов инициализирует ваш плагин в первый раз.

  • void OnGameStart()
    Вызывается всякий раз, когда движок запускает вашу игру (после инициализации в панели запуска или при переключении во внутриигровой режим в редакторе Sandbox).

  • void OnGameStop()
    Эквивалент для OnGameStart()

  • void Выключение()
    Вызывается всякий раз, когда система плагинов пытается завершить работу вашего плагина. Здесь следует удалить все выделения, связанные с механизмом. После завершения работы класс будет ожидать очистки сборщиком мусора платформы.

Помимо этого, менеджер плагинов заботится о настройке ссылки на глобальный файл DomainHandler, а также о настройке указанных каталогов двоичных файлов и ресурсов для этого плагина. Доступ к плагину возможен следующими способами:

  • const char* GetBinaryDirectory()
    Получает двоичный каталог этого плагина на вашем локальном компьютере.

  • const char* GetAssetDirectory()
    Получает каталог ресурсов для этого плагина на вашем локальном компьютере.
Все эти методы также доступны для собственных плагинов C++. В будущем мы планируем еще больше приблизить их по функциональности и обеспечить одинаковый рабочий процесс с обеих сторон.
