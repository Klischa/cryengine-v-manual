Обзор

По умолчанию CRYENGINE использует мировую систему координат, в которой ось Z направлена вверх.

При манипулировании объектами напрямую с помощью Axis Gizmo вы можете изменить систему координат, чтобы облегчить манипуляции.

Вы можете изменить систему координат прямо с панели инструментов «Координаты»:

Мировые координаты

Использует ориентацию мировой оси для перемещения/вращения/масштабирования.
Осевой гизмо всегда остается на одной линии с мировой системой координат.

Это концепция движущегося объекта, поэтому ее нельзя объяснить с помощью неподвижного изображения.

Местные координаты

Использует исходную ориентацию поворота выбранного объекта для перемещения, вращения и масштабирования.
На рисунке ниже повёрнут только куб. Обратите внимание, как оси выровнены по кубу.

Посмотреть координаты

Актуально для орфографических представлений. В перспективе равен мировой системе координат.

Родительские координаты

В родительском режиме порядок выбора объектов определяет координаты, вокруг которых необходимо вращать выделение. Первый выбранный объект становится точкой поворота, ориентацией которой управляют для перемещения/вращения/масштабирования.

Это концепция движущегося объекта, поэтому ее нельзя объяснить с помощью неподвижного изображения.
