Регистрация форм взрыва и трещин

Обычно используется для регистрации новых форм взрывов и трещин в физическом движке с помощью двух функций из глобального Lua. Физика.

  • Местоположение файла: Game/Scripts/physics.lua
  • Загружено из: Game/Scripts/main.lua

Функции

  • #RegisterExplosionShape
  • #RegisterExplosionCrack

Физика.RegisterExplosionShape( sGeometryFile, fSize, BreakId, fProbability, sSplintersfile, fSplintersOffset, sSplintersCloudEffect )

Регистрирует логическую форму вырезания для хрупких объектов в физическом движке.

Физика.RegisterExplosionShape( sGeometryFile, BreakId )

Регистрирует новую трещину взрыва для хрупких объектов в физическом движке.
