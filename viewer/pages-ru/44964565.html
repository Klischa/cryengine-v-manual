Обзор

Обновления гибкой подсистемы позволяют вызывать из игрового кода Обновить функции подсистем внутри системы AI. Это позволяет разработчикам легко изменять порядок или частоту обновления этих подсистем путем:

  • Сообщаем системе AI, какие подсистемы обновляются вручную из игрового кода, что делает Обновить функция пропускает обновление этих подсистем. Это сделано для предотвращения повторного обновления одних и тех же подсистем.
  • Ручное обновление подсистем из игрового кода. При этом немедленно выполняется Обновить функционировать в указанных подсистемах.

Доступ к вышеуказанным подсистемам можно получить из кода, набрав IAISystem::ESubsystemUpdateFlag::SubsystemName, где SubsystemName соответствует имени подсистемы AI, которую вы хотите обновить вручную.

Установка флагов обновления переопределения

Как упоминалось в обзоре, первым шагом в изменении порядка/частоты обновления подсистем AI является указание системе AI, какие подсистемы вы хотите обновить override. Это делается путем вызова GetOverrideUpdateFlags только один раз во время инициализации и установки правильных флагов.

В следующем примере показано, как override подсистему NavigationSystem AI.

// Get the IAISystem from gEnv.
IAISystem* pAISystem = gEnv->pAISystem;
 
// Get the Override Update Flags structure.
// By setting the flag to 1 on the updateFlags structure, we indicate which AI subsystems we want to override to update manually.
CEnumFlags<ESubsystemUpdateFlag> updateFlags = pAISystem->GetOverrideUpdateFlags();
 
// This will will prevent the AI system from updating the subsystem (NavigationSystem, in this case) automatically.
updateFlags.Set(IAISystem::ESubsystemUpdateFlag::NavigationSystem);

Обновление подсистемы вручную

Следующим шагом является вызов вручную Обновить функцию в подсистеме NavigationSystem AI, вызвав UpdateSubSystem на системе AI.

// Game loop.
void Game::Update(const CTimeValue frameStartTime, const float deltaTime)
{
  // Get the IAISystem from gEnv.
  IAISystem* pAISystem = gEnv->pAISystem;
 
  // Call the UpdateSubSystem function, mentioning which system we want to manually update.
  pAISystem->UpdateSubSystem(frameStartTime, deltaTime, IAISystem::ESubsystemUpdateFlag::NavigationSystem); 
 
  // Update any other game systems.
  // ...
}
