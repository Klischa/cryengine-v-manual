Обзор

Интерфейс ICrySizer используется для записи подробной информации об использовании памяти классом.

Профилирование памяти

Консольная переменная "MemStats" 0/x = частота обновления в миллисекундах.

Также доступно в редакторе как «Информация о памяти двигателя».

Как использовать интерфейс ICrySizer

Образец:

  void GetMemoryUsage( ICrySizer *pSizer )
  {
    {
       SIZER_COMPONENT_NAME( pSizer, "Renderer (Aux Geometries)" );
       pSizer->Add(*this);
    }
    pSizer->AddObject(<element_ptr>,<element_count>);
    pSizer->AddObject(<container>);
    m_SubObject.GetMemoryUsage(pSizer);
  }
