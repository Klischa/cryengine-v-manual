Обзор

Аудио в движке управляется Плач Аудио::IAudioSystem, уровень абстракции, позволяющий воспроизводить звук через любое промежуточное программное обеспечение, например FMOD Студия и WWise. Это позволяет сопоставить настройку промежуточного программного обеспечения с настройкой движка в Audio Tool в редакторе, в результате чего мы можем запросить типы для воспроизведения звука во время выполнения.

Хотя использование аудиосистемы непосредственно для воспроизведения звука возможно, организации предоставляют IEntityAudioComponent как способ обработки звука, который автоматически настраивается на отслеживание изменений положения и свойств объектов.

Слушатели

Слушатели обычно автоматизируются с размещением камеры, чтобы получать звук из визуализированного места. Слушатели представлены CryAudio::IListener интерфейс и может быть создан с использованием CryAudio::IAudioSystem::CreateListener. После создания преобразование мирового пространства каждого слушателя может быть обновлено с помощью CryAudio::IListener::SetTransformation.

Обратите внимание, что обработка прослушивателя автоматизируется компонентом прослушивателя в подключаемом модуле компонентов по умолчанию, см. Cry::Audio::DefaultComponents::CListenerComponent. Кроме того, компонент камеры автоматически добавит компонент-прослушиватель, который будет соответствовать его преобразованию.

Триггеры

В лице CryAudio::Impl::ITrigger внутренний интерфейс, Триггеры представляют собой просто контейнеры, которые выполняют все связанные с ними элементы управления. Любое количество соединений можно сгруппировать в один триггер. Триггеры могут быть выполнены с помощью IEntityAudioComponent::ExecuteTrigger функция.

Параметры

В лице CryAudio::Impl::IParameter внутренний интерфейс, Параметры используются для плавного изменения значения параметра, на основе которого промежуточное программное обеспечение аудио может получать и управлять соответствующими эффектами. Параметры можно задать с помощью IEntityAudioComponent::SetParameter функция.

Переключатели и состояния

Переключатели может содержать любое количество состояний, которые можно установить с помощью кода или Flow Graph. Примером популярного переключателя может быть тип поверхности для шагов персонажа. Состояние переключателя можно установить с помощью IEntityAudioComponent::SetSwitchState функция.

Предварительная загрузка

Предварительная загрузка — это запросы на загрузку определенных аудиофайлов в память. Любое количество файлов можно сгруппировать в один запрос, избегая чтения с диска во время выполнения.
