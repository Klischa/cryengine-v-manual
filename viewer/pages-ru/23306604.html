LoadScript

Загружает скрипт. 

Script.LoadScript(scriptName)

ReloadScripts

Перезагружает все скрипты. 

Script.ReloadScripts()

ReloadScript

Перезагрузите скрипт. 

Script.ReloadScript()

ReloadEntityScript

Перезагружает указанный скрипт объекта. 

Script.ReloadEntityScript( className )

UnloadScript

Выгружает скрипт. 

Script.UnloadScript()

DumpLoadedScripts

Сбрасывает все загруженные скрипты. 

Script.DumpLoadedScripts()

SetTimer

Установите общий таймер сценария: по истечении времени таймера будет вызвана указанная функция lua. Функция Lua принимает 1 или 2 параметра, если указан userData, luaFunction должен быть: <preformatted>LuaCallback = function( userData,nTimerId ) -- тело функции end;</preformatted>, если userData не указан, luaFunction должен быть: <preformatted>LuaCallback = function( nTimerId ) -- тело функции конец;</preformated> 

Script.SetTimer( nMilliseconds, luaFunction [, userData [, bUpdateDuringPause]] )
Возврат: ID назначен этому таймеру или ноль, если не указано.

SetTimerForFunction

Установите общий таймер сценария: по истечении времени таймера будет вызвана указанная функция lua. Функция Lua принимает 1 или 2 параметра, если указан userData, luaFunction должен быть: <preformatted>LuaCallback = function( userData,nTimerId ) -- тело функции end;</preformatted>, если userData не указан, luaFunction должен быть: <preformatted>LuaCallback = function( nTimerId ) -- тело функции конец;</preformatted> . 

Script.SetTimerForFunction( nMilliseconds, luaFunction [, userData [, bUpdateDuringPause]] )
Возврат: ID назначен этому таймеру или ноль, если не указано.

KillTimer

Останавливает таймер, установленный функцией Script.SetTimer. 

Script.KillTimer( nTimerId )
