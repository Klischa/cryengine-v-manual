Цель CryMovie

CryMovie — это центральная точка управления камерой и эпизодами в CRYENGINE. Он предлагает простой интерфейс, который уже используется другими компонентами движка, такими как блок-граф, области просмотра и новый плагин инструмента TrackView. Это позволяет вам легко анимировать определенные значения объекта, такие как данные о положении или вращении.

Основные моменты CryMovie

  • Общая концепция последовательностей
  • Управление последовательностью
  • Последовательное воспроизведение
  • Последовательность захватов
  • Управление параметрами камеры

Общая концепция последовательностей

  • SequenceObject
    Всякий раз, когда вы создаете новую последовательность с помощью Trackview, Sandbox создаст для вас новую последовательность SequenceObject. Этот SequenceObject обрабатывается как обычный объект на уровне и будет помещен на текущий выбранный слой. Все настройки, связанные с последовательностью, будут прикреплены к этому объекту сущности. Поскольку он не содержит никакой ценной информации о положении или вращении, он будет помещен в 0,0,0. Вы также можете найти его, используя Level Explorer и введя его имя.

  • Дополнительные данные и флаги
    Для каждой последовательности Sandbox также сохраняет время начала и окончания, а также специальные флаги последовательности, которые отражают поведение последовательности. Наиболее важные из них и их назначение перечислены ниже:
  • Узлы
    В зависимости от вашего контента ваш SequenceObject будет содержать различные узлы для разделения данных. Эти узлы могут быть разных типов, например «Сущность», «Камера», «Директор» или особых случаев, например «Глубина резкости».

    Обратите внимание, что ваш SequnceObject не хранит указанный объект сам по себе, а содержит только ссылку на него.
    Когда вы удаляете связанный объект или отключаете слой, на котором он размещен, последовательность игнорирует его узел и данные.

  • Треки
    Каждый узел может содержать разные типы дорожек для разделения данных. Стандартными типами треков являются «Положение», «Вращение», «Масштаб» и т. д. Поскольку для этих упомянутых типов требуется более одного значения (например, x,y,z), данные снова будут разделены на подтреки, которые затем назначат значения трека фиксированному времени в вашей последовательности.
    Trackview отобразит это задание в виде одного ключа на вашей временной шкале.

  • Ключевое время и частота кадров
    Вместо секунд, представленных в виде чисел с плавающей запятой, CryMovie теперь использует тики, чтобы точно сохранить значения времени и избежать проблем с округлением. Текущая константа равна 6000 тактов в секунду, что обеспечивает точность таймингов до 6000 кадров в секунду. Старые десятичные значения будут автоматически преобразованы в новое соответствующее значение тика. Новый инструмент Trackview предлагает автоматическое преобразование тиков, тайм-кода, времени и кадров для упрощения редактирования — имейте в виду, что это не изменит формат этих значений во время сериализации. Таким образом, эпизоды, созданные с помощью новой системы фильмов, не имеют обратной совместимости..

Управление последовательностью

  • CreateSequence
    Создает новую последовательность и добавляет ее в общий список доступных последовательностей.

  • RemoveSequence
    Удаляет существующую последовательность из общего списка доступных последовательностей.

  • FindSequence
    Вы можете искать указанную последовательность по имени, идентификатору или идентификатору.

  • GetNumSequences
    Получить количество зарегистрированных на данный момент последовательностей

  • GetPlayingSequence
    Получить последовательность воспроизведения по индексу

  • GetNumPlayingSequences
    Получить количество воспроизводимых в данный момент последовательностей

Последовательное воспроизведение

  • PlaySequence
    Запустите воспроизведение последовательности либо по имени последовательности, либо по указателю IAnimSequence.

  • StopSequence
    Остановите воспроизведение последовательности либо по имени последовательности, либо по указателю IAnimSequence.

  • AbortSequence
    Прервать последовательность (то, как заканчивается последовательность, может иметь значение для логики блок-схемы и правил игры)

  • StopAllSequences
    Останавливает все воспроизводимые в данный момент последовательности

  • StopAllCutscenes
    Останавливает все последовательности с помощью флажка кат-сцены.

  • Сброс
    Сбрасывает последовательность, необязательными параметрами являются «воспроизведение при сбросе» и «старт».

  • Пауза/возобновить
    Приостанавливает/возобновляет все игровые последовательности (используется для функции паузы в игре)

  • Установить/GetPlayingSpeed
    Вы можете установить скорость воспроизведения текущей последовательности

  • Установить/GetStartEndTime
    Изменение продолжительности текущей последовательности

Последовательность захватов

  • Захваты последовательности в Sandbox
    Находясь в Sandbox, вы можете использовать инструмент «Вывод рендеринга» в Trackview для вывода данных последовательности на диск. Он предоставляет вам все необходимые параметры и предлагает функцию пакетного рендеринга.
