Обзор

Интерфейс наложения плагина GamePlatform абстрагирует различные параметры наложения, предоставляемые API платформы.

Поскольку платформы предоставляют различные уникальные для них наложения, некоторые наложения доступны только для определенных сервисов.

Наложение сервисных функций

OpenBrowser

Открывает браузер платформы на платформе с указанным целевым адресом.

OpenDialog

Открывает диалоговое окно указанной платформы (например, «Добавить друга»).

OpenDialogWithTargetUser

Открывает указанный диалог с указанным пользователем на платформе (например, чат сообщений private).

OpenPurchaseOverlay

Пытается открыть оверлей покупки для указанного продукта.
