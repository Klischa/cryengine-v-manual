Обзор

Детальный изгиб позволяет нам имитировать движение листьев растительности. Это обеспечивает эффект, позволяющий листьям плавно двигаться на ветру. Это контролируется с помощью нескольких слоев рисования вершин (Рис3), используя разные цвета RGB на самом ресурсе. Каждое используемое значение цвета вершин имеет определенную задачу в геометрии для моделирования различных типов движения.

Для получения дополнительной информации об использовании Редактор растительности в CRYENGINE, пожалуйста, обратитесь HERE.

В оставшейся части этой обзорной страницы будут описаны типы изгиба ветра, которые мы поддерживаем в движке. Полезно знать, где и когда следует использовать каждый тип.

Типы изгиба ветра

Прежде чем мы начнем углубляться в детализацию изгиба, мы должны упомянуть типы изгиба ветром, которые CRYENGINE может предложить для объектов растительности, и то, как они влияют друг на друга. В следующем списке описаны различные типы изгиба ветра в CRYENGINE:

  • Объект растительности Изгиб
  • Детальная гибка
  • Вершинная деформация

Сгибание объектов растительности


Рис.1: Ель с максимальным значением изгиба.

Это единственное значение, которое можно изменить в свойствах объектов растительности. Изгиб позволяет объектам растительности сгибаться вперед и назад, используя точку опоры в качестве исходной точки для этого процесса. Этот метод позволяет сгибать только весь объект и только по одной направленной оси, заданной через Ветер вектор. Интенсивность также связана с Ветер вектор и Поколение Бриза. Это значение необходимо активировать, чтобы активировать функцию «Изгиб деталей».

Избегайте использования высоких значений изгиба, поскольку это нарушает эффект иллюзии, и при экстремальных значениях объект становится явно нереалистичным. (См. Рис1).

Ограничения изгиба объектов растительности:

    • Работает только для объектов растительности.
    • Связан с глобальным вектором ветра и генерацией бриза.
    • Активируется только со значением > Ноль.

Детальная гибка


Рис. 3: Цветной цвет вершины куста папоротника для детального изгиба.

Detail Bending работает посредством считывания цвета вершин, при этом все три цветовых канала влияют на определенные типы движения вершин. Это обеспечивает точное перемещение на основе информации о вершинах. Эта система использует мировое пространство для своего движения. Доступ к нему можно получить через ваш Параметры генерации шейдеров в вашем материале.

Ограничения изгиба деталей:

  • Работает только для объектов растительности и объектов геометрии.
  • Привязано только к глобальному вектору ветра.

Вершинная деформация


Рис5: Куст папоротника с примененной к нему вершинной деформацией.

Вершинная деформация работает с помощью различных глобальных алгоритмов и влияет на объекты в зависимости от используемого материала. Это не позволяет индивидуально управлять вершинами объекта по сравнению с Detail Bending. Это по-прежнему следует учитывать для объектов растительности, поскольку движение выглядит более реалистично, особенно при использовании «Волны греха» и «Волны греха» с активным типом цвета вершин. Sin Wave с использованием цвета вершин позволяет лучше контролировать, где должно происходить перемещение вершин и насколько интенсивно оно должно быть.

В отличие от того, как Detail Bending деформирует геометрию, Vertex Deformation использует ось Z объекта UV в качестве опорной точки для перемещения вершин вверх и вниз в соответствии с установленным алгоритмом. Доступ к этой функции можно получить через свойства вашего материала.

Где вы можете это использовать
  • Работает со всеми типами геометрических объектов, таких как кисти, объекты растительности, геометрические объекты и т. д. (поскольку это расширение материала).
  • Для растительности рекомендуется использовать только Sin Wave и Sin Wave с использованием цвета вершин.
