Параметры генерации шейдеров

Шейдер частиц включает в себя следующие параметры генерации шейдера:

Преломление

Преломление обеспечивает преломление частиц, что полезно для имитации тепловой дымки, исходящей от огня или любого источника тепла, или для создания какого-либо особого визуального эффекта. Это немного увеличивает стоимость рендеринга, поэтому его следует использовать экономно. Когда используется опция преломления, пользователи должны убедиться, что они используют карту нормалей также и для деформации.

Деформация экранного пространства

Деформация экранного пространства (SSD) деформирует частицы в экранном пространстве (экранная деформация). Когда Деформация экранного пространства используется, установите карту нормалей, которая будет использоваться в качестве карты деформации в Пользовательский слот.

Деформация

Деформация, в отличие от SSD, где деформация выполняется с выравниванием по экрану, этот тип деформации выполняется в пространстве частиц UV. Если используется опция деформации, установите карту нормалей, которая будет использоваться в качестве карты деформации в Пользовательский слот.

Поиск цвета

Поиск цвета позволяет пользователям использовать текстуру поиска цвета для получения вариаций цветового градиента для одного и того же эффекта частиц. Это полезно, в частности, для экономии видеопамяти, поскольку пользователи могут, например, иметь диффузную карту в оттенках серого и использовать текстуру поиска цвета для получения цветов. Если используется поиск по цвету, установите текстуру градиента поиска в Пользовательский слот 1.

Зеркальное освещение

Позволяет рассчитывать зеркальное освещение в дополнение к рассеянному освещению.

Исправление глубины

Включает глубину записи для глубины резкости и постобработки.

Преломляющая молния

Позволяет использовать цветную текстуру для оттенка преломления.
