Обзор

В этом разделе содержится документация по использованию C# для разработки игры в CRYENGINE, а также дополнительная информация о шаблонах и примерах проектов. Чтобы сразу приступить к делу, программа запуска CRYENGINE предоставляет несколько шаблонов, которые помогут вам познакомиться с C# в CRYENGINE или быстро приступить к разработке игры CRYENGINE на C#.

Начало работы

CRYENGINE поддерживает два способа работы с C#: управляемыми плагинами и ресурсами C#. Управляемые плагины — это автономные плагины, которые можно импортировать в несколько проектов. Ресурсы C# — это файлы C#, которые находятся в папке ресурсов вашего проекта и автоматически компилируются Sandbox. Чтобы начать работу с управляемыми плагинами или ресурсами C#, вам сначала необходимо создать новый проект.

Приведенные ниже шаги предполагают, что у вас уже есть учетная запись CRYENGINE и установлена ​​самая последняя версия программы запуска CRYENGINE и CRYENGINE.

  1. Откройте программу запуска CRYENGINE, нажав значок на рабочем столе, и войдите в свою учетную запись.
  2. Нажмите кнопку +NEW вариант в Проекты раздел (верхняя левая часть окна запуска).
  3. Выберите С# вкладка — здесь будут показаны доступные вам шаблоны.
  4. Выберите template, который вам нужен.
  5. Выберите место, где он будет расположен на вашем PC, и выберите имя для своего проекта. Наконец, нажмите Создать проект.

Если вы используете исходный код двигателя из Гитхаб, вы можете создать новый проект, скопировав нужный template из <root>/Код/GameTemplates/cs/ в то место, где вы хотите, чтобы ваш проект находился в вашей системе. После копирования откройте игра.cryproject файл в Блокноте и измените значение "name" к названию вашего проекта. После изменения имени щелкните правой кнопкой мыши значок игра.cryproject файл и выберите Переключить двигатель и установите его в корневую папку вашего движка. Если вас попросят зарегистрировать ваш движок, выберите Да.

Сгенерированное решение C# для управляемых плагинов и ресурсов C# представляет собой специальный проект C# CRYENGINE, который могут открыть только редакторы с расширением CRYENGINE. Открытие решения с помощью неподдерживаемого редактора может привести к неожиданному поведению и повреждению данных.

Управляемый плагин

Прежде чем приступить к программированию, необходимо создать решение для управляемого плагина.

  1. Чтобы начать программирование, наведите указатель мыши на соответствующее имя проекта (левая часть окна запуска), после чего появится значок настроек. . Нажмите на значок, а затем нажмите на Открыть в проводнике.
  2. Вы попадете в папку, где находится ваш проект. Дважды щелкните папку, и откроется доступ к другим папкам, включая соответствующую template.
  3. Щелкните правой кнопкой мыши Game.cryproject файл в этой папке и затем нажмите Сгенерировать решение.
  4. Откройте Код папку и запустите Game.sln файл с помощью редактора, совместимого с CRYENGINE, например Visual Studio 2017 г..

Ресурсы С#

Для ресурсов C# вам не нужно самостоятельно создавать и компилировать решение. Вместо этого все это делает Sandbox всякий раз, когда файлы изменяются. Чтобы начать, просто откройте Sandbox и щелкните правой кнопкой мыши в браузере активов. В меню выберите Новый...→Скрипт C# который создаст новый файл C# в браузере ресурсов. Вы можете открыть файл, щелкнув его, удерживая клавишу double. Откроется решение C#, содержащее файл C#.

По умолчанию решение открывается с помощью Visual Studio. Если вы хотите открыть решение с помощью другого IDE или открыть файл напрямую вместо решения, вы можете изменить это в настройках, перейдя в раздел Правка→Настройки...→Общие→Файл.

Разработка в CRYENGINE на C#

Файлы проектов C# имеют специальный ProjectTypeGuid, позволяющий идентифицировать их как проекты CRYENGINE. Это позволяет расширению CRYENGINE присоединить отладчик к CRYENGINE, что невозможно по умолчанию. Однако это также означает, что невозможно открыть проекты без расширения CRYENGINE.

Visual Studio 2017 г.

Для работы с Visual Studio 2017 сначала необходимо установить расширение CRYENGINE для Visual Studio. Это можно сделать, запустив установщик, найденный по адресу <engine-root>/Tools/VisualStudioExtensions/CryEngine.Debugger.Mono.vsix. После установки расширения вы сможете открыть решение C# CRYENGINE.

Если после установки расширения вы откроете решение CRYENGINE, вы заметите, что по умолчанию Старт кнопка изменилась на Отладка GameLauncher. Нажатие этой кнопки (или начало отладки с помощью горячей клавиши) теперь запускает GameLauncher и прикрепляется к нему в начале. Вы также можете нажать раскрывающееся меню на кнопке «Пуск», чтобы выбрать другие цели отладки, например Sandbox или выделенный сервер. Эти цели также можно изменить из меню «Отладка» в Visual Studio. Переключение цели приведет либо к GameLauncher.exe, Sandbox.exe или Game_Server.exe start, когда начинается отладка.

На данный момент невозможно подключиться к уже работающему экземпляру CRYENGINE.

Из-за ошибки в Visual Studio 2017 (версия 15.7) расширение CRYENGINE будет отображать ошибку из-за отсутствия файлов. Чтобы это исправить:

  1. Сначала удалите предыдущее расширение в Visual Studio, Инструменты→Расширения и обновления и выберите Удалить в расширении моноотладчика CRYENGINE
  2. Далее установите исправленную версию расширения, запустив установщик, <engine-root>/Tools/VisualStudioExtensions/CryEngine.Debugger.Mono_15.7_FIX.vsix

Примечание: Фиксированная версия расширения включена, начиная с CRYENGINE 5.5.0 Preview 4. Наконец, новое расширение загрузит рабочую нагрузку Xamarin, которая может занять несколько GB дискового пространства.

Старые версии Visual Studio

Файлы проектов C# имеют специальный ProjectTypeGuid, позволяющий идентифицировать их как проекты CRYENGINE. Это позволяет расширению CRYENGINE присоединить отладчик к CRYENGINE, что невозможно по умолчанию.

Однако вы можете изменить файл .csproj вашего проекта, чтобы Visual Studio мог открыть решение.

Сначала сгенерируйте решение, как описано в разделе «Начало работы». В папке с кодом откройте сгенерированные файлы .csproj с помощью текстового редактора, например Notepad++ или Visual Studio Code.

Теперь найдите следующую строку:

<ProjectTypeGuids>{E7562513-36BA-4D11-A927-975E5375ED10};{FAE04EC0-301F-11D3-BF4B-00C04F79EFBC}</ProjectTypeGuids>

Замените строку на:

<ProjectTypeGuids>{FAE04EC0-301F-11D3-BF4B-00C04F79EFBC}</ProjectTypeGuids>

Сохраните файл. Теперь вы можете открыть файл решения в Visual Studio.

Каждый раз, когда решение генерируется снова, щелкните правой кнопкой мыши файл .cryproject и нажмите Создать решение, ProjectTypeGuids будет сброшен, поэтому обязательно настройте файлы .csproj еще раз.
