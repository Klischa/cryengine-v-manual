CryENGINE 3 бесплатно SDK — журнал изменений сборки 3410

Выпущено 23 февраля 2012 года.

Основные новые функции:

  • Отображение параллакса DX9 (POM)
  • DX9 Направленная окклюзия экранного пространства (SSDO)
  • Глобальное освещение частиц DX9 (GI)
  • Новая конфигурация графики «Очень высокая».
  • Добавлена поддержка Scaleform (v3.9.93).


Важные обновления:

  • Улучшена поддержка SLI/CF.
  • Улучшенная поддержка 32-битного редактора.
  • Улучшена поддержка настроек объемного звука 5.1/7.1.
  • Улучшена поддержка размеров шрифтов Windows.
  • Улучшенный Sandbox UI
  • Добавлена поддержка Visual Studio 2010.
  • Удалена поддержка Visual Studio 2008 г.
