Обзор

Профилировщик пропускной способности — это инструмент, который позволяет отслеживать вызовы сетевой сериализации от CryAction и CryGame для отслеживания предполагаемого использования пропускной способности игровых объектов.

В настоящее время он отслеживает все вызовы NetSerialise и DispatchRMI, группируя вызовы по типу класса (например, игрок, правила игры) и предоставляет функциональные возможности для записей бюджета (например, запись не должна превышать 256 кбит/бит).

Использование

Любой файл, который хочет использовать профилировщик, должен включать INetwork.h, это обеспечивает интерфейс.

Профилирование запускается вызовом NET_PROFILE_BEGIN и завершается NET_PROFILE_END. NET_PROFILE_BEGIN принимает два параметра: имя записи профиля и bool, обозначающий, является ли это вызовом чтения или записи. В настоящее время измеряются только вызовы записи.

NET_PROFILE_SCOPE также можно использовать для запуска профилирования, и он автоматически завершит профилирование, если оно выйдет за пределы области действия. Он принимает те же параметры, что и NET_PROFILE_BEGIN.

Кроме того, есть NET_PROFILE_BEGIN_BUDGET и NET_PROFILE_SCOPE_BUDGET. Они принимают третий параметр, который определяет бюджет пропускной способности для этой записи в килобитах. В настоящее время это значение проверяется на соответствие предполагаемому наихудшему случаю, отправленному для этой записи, и в случае превышения этого значения на экране будет отображаться предупреждение.

При профилировании RMI есть NET_PROFILE_BEGIN_RMI и NET_PROFILE_SCOPE_RMI. В настоящее время все известные вызовы RMI перехватываются и протоколируются соответствующим образом на высоком уровне; дальнейшая разбивка (т. е. отдельные вызовы SerialiseWith) при желании может быть выполнена с использованием этих макросов.

Ведение журнала

Net Profile способен вести журнал в два выходных файла, если включены соответствующие переменные.

  • net_profile_logging используется для регистрации статистики по кадрам в net_profile.log. Имя файла можно изменить, установив соответствующий параметр net_profile_logname. Созданные здесь файлы журналов содержат плоское представление данных (только корень и его дочерние элементы) и полную разбивку иерархии, показывающую все узлы и соответствующие данные.
  • net_profile_budget_logging используется для сброса текущей иерархии профилей в net_profile_budget.log, если бюджет записи превышен. Имя журнала можно изменить, задав значение net_profile_budget_logname.

Ограничения

В настоящее время Net Profile можно использовать только с CryNetwork, CryAction и CryGame.

CVars

  • net_profile_logname — имя журнала сетевого профилировщика.
  • net_profile_logging — включить/отключить ведение журнала.
  • net_profile_budget_logname — имя журнала превышения бюджета для сетевого профилировщика.
  • net_profile_budget_logging — включить/выключить ведение журнала бюджета.
  • net_profile_worst_num_channels — максимальное количество каналов, которое ожидается подключить.
  • net_profile_root_budget — максимальный бюджет для корневого узла.
