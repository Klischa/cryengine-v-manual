Обзор

Sandbox от CRYENGINE был интегрирован с системой контроля версий (VCS), чтобы художникам и разработчикам, работающим над одними и теми же ресурсами, было проще сотрудничать друг с другом.

Этот VCS работает совместно с Обозреватель активов и Level Explorer чтобы разрешить загрузку/выгрузку из репозитория измененных ассетов, рабочих файлов и уровней из проекта, проверку на наличие ранее внесенных изменений и т.д.

В настоящее время Perforce — единственный поддерживаемый вариант VCS, хотя в будущем, вероятно, будут добавлены и другие решения для контроля версий.



Обзор системы контроля версий


Окно инструментов

Пользователи могут выбрать решение для контроля версий либо через Инструменты -> Система контроля версий -> Настройки от редактора главное меню, через Редактировать -> Настройки -> Контроль версий -> Общий где необходимо ввести имена сервера Perforce, рабочей области, пользователя и пароля, или через значок в правом верхнем углу редактора.

Функциональность

Активы и слои

При настройке контроля версий текущий статус каждого ресурса в Обозревателе ресурсов обозначается цветным значком на его миниатюрах, как показано ниже.


Контроль версий в браузере ресурсов

Миниатюры ресурсов видны только тогда, когда Посмотреть -> Показать Миниатюры/Разделить Горизонтально/Разделить вертикально активируется из меню браузера активов.

Аналогично, текущий статус каждого слоя в Level Explorer обозначается цветным значком напротив их списков.


Level Explorer контроль версий

Функции контроля версий можно выполнить для актива или слоя, щелкнув правой кнопкой мыши их списки в браузере ресурсов или Level Explorer соответственно. При этом с помощью любого инструмента открывается контекстное меню с тем же набором параметров.


VCS Контекстное меню браузера ресурсов

Вышеуказанные параметры контекстного меню браузера ресурсов и Level Explorer отображаются только в том случае, если VCS настроен правильно.

Рабочие файлы

Рабочие файлы актива с контролем версий также отслеживаются установленным VCS.

Если VCS настроен правильно, Рабочие файлы Пункт меню, который отображается при щелчке правой кнопкой мыши по активу, будет содержать параметры для выполнения Обновить, получить последнюю версию, оформить заказ, отменить изменения, отменить изменения, если они не были изменены и Отправить... функции для рабочих файлов выбранного актива, как показано ниже.


Рабочие файлы VCS

Кроме того, Рабочие файлы Меню контроля версий также включает в себя возможность Удалить локальные файлы который удаляет копии рабочих файлов актива с контролируемой версией из системы пользователя, не удаляя их из репозитория. Поскольку рабочие файлы могут иметь большой размер, этот параметр особенно полезен для освобождения места в памяти.

VCS пользователя CRYENGINE автоматически отслеживает, какие рабочие файлы необходимо добавить или удалить из репозитория.

Всякий раз, когда создается новая связь между извлеченным активом и рабочим файлом, рабочий файл добавляется в репозиторий, если пользователи захотят это сделать. Отправить... новую ассоциацию через меню управления версиями рабочих файлов.

Аналогичным образом, когда связь между активом и рабочим файлом удаляется, этот рабочий файл будет окончательно удален из репозитория только в том случае, если между рабочим файлом и любым другим активом в проекте не существует связи.. Пожалуйста, обратитесь к Связывание рабочих файлов с активами раздел «Справочная страница браузера активов» для получения дополнительной информации о добавлении рабочих файлов в активы.
