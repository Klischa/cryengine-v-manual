Обзор

Обратные вызовы Entity System вызываются Entity System по мере необходимости. Реализация этих функций обратного вызова не является обязательной, но в некоторых случаях требуется наличие объектов, которые ведут себя должным образом внутри Sandbox. то есть; обратный вызов Reset должен использоваться для очистки состояния, когда пользователь входит/выходит из игрового режима в пределах Sandbox.
