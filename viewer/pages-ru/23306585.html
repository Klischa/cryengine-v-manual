Обзор

XML-файлы Body Destructibility можно найти в этой папке: GameSDK/Libs/BodyDamage/

Можно создать любое количество файлов, обычно достаточно одного для каждого типа актера. Соглашение об именах следующее: BodyDestructibility_NameOfCharacter.xml

Например:

  • BodyDestructibility_AlienGrunt.xml
  • BodyDestructibility_CryNetOps.xml

Эти файлы обычно редактируются техническим художником вместе с дизайнерами игр.

Они определяют сопоставление костей и прикреплений персонажа с разрушаемыми «частями тела», событиями разрушения, порогами здоровья актеров и особыми событиями смерти.

Содержимое и структура файла

Поясним это на примере. Ниже приведена свернутая версия частей тела инопланетного пехотинца.

<BodyDestructibility>
  <DestructibleParts>
    <!-- Attachments -->
    <Attachment name="armor_chest_l" >
      <Health ratio="0.05" ratioToDestroyOnDeath="0.01" eventOnDestruction="armor_chest_l_explode" eventOnActorDeath="armor_chest_l_explode" />
      <HitTypes>
        <HitType name="gaussbullet" damageMultiplier="1.0" eventOnDestruction="armor_chest_l_explode" eventOnActorDeath="jelly_explode" />
        <HitType name="mike_burn" damageMultiplier="0" />
        <HitType name="frag" damageMultiplier="0.5" />
      </HitTypes>
    </Attachment>
    ...
 
    <!-- Bones -->
    <Bone name="Head" >
      <Health ratio="1" ratioToDestroyOnDeath="0" eventOnDestruction="head_explode" eventOnActorDeath="head_explode" />
      <HitTypes>
        <HitType name="mike_burn" damageMultiplier="0.0" />
      </HitTypes>
    </Bone>
    ...
  </DestructibleParts>
 
  <Events>
    <Event name="head_explode" >
      <AttachmentsToHide>
        <Attachment name="armor_head" />
        <Attachment name="jelly_alive" />
        <Attachment name="armor_head_tentacles" />
        <Attachment name="eye_left" />
        <Attachment name="eye_right" />
      </AttachmentsToHide>
      <AttachmentToUnhide>
        <Attachment name="jelly_destroyed_head" />
      </AttachmentToUnhide>
      <Effect name="Crysis2_alien_effects.grunt.jelly_head_explode" />
      <DisableEvents>
        <Event name="head_damaged" />
        <Event name="jelly_explode" />
      </DisableEvents>
    </Event>
    ...
  </Events>
  <HealthRatioEvents>
    <HealthRatio ratio="0" bone="" event=""  material="Objects/characters/alien/grunt/grunt_dead" />
  </HealthRatioEvents>
  <ExplosionDeaths>
    <GibEvent minExplosionDamage="200" probability="0.5" event="aliengrunt_gib" bone="jellyBone" /> <!-- Trigger event, and hide actor -->
    <NonGibEvent event="jelly_boiling_explode" bone="jellyBone" material="Objects/characters/alien/grunt/grunt_dead" />
  </ExplosionDeaths>
  <MikeDeath>
    <Destruction event="jelly_boiling_explode" bone="jellyBone" />
    <Attachment name="jelly_destroyed_mike_attach" object="Objects/characters/alien/grunt/jelly_destroyed_mike.cdf" animation="jelly_destroyed_mike" alphaTestFadeOutDelay="0.85" alphaTestFadeOutTimeOut="0.25" />
  </MikeDeath>
</BodyDestructibility>

DestructibleParts

Содержит список Кости и костные крепления которое можно уничтожить. Каждая часть имеет определенное количество очков здоровья — когда они исчерпаны, Событие разрушения срабатывает.

Доступны следующие параметры:

  • Здоровье - соотношение: количество очков здоровья относительно максимального количества очков здоровья актера.
  • Здоровье - eventOnDestruction: Событие, которое срабатывает, когда очки здоровья детали исчерпаны.
  • Здоровье - ratioToDestroyOnDeath: Очки здоровья для eventOnActorDeath относительно максимального количества очков здоровья актера.
    • По умолчанию соотношение если не определено.
  • Здоровье - eventOnActorDeath: Событие, которое сработает, если актер умрет и ratioToDestroyOnDeath Очки здоровья исчерпаны.
    • Это можно использовать для разрушения частей после смерти актера, даже если они не пострадали от фатального удара - добавляет больше расчленений при смерти актера.
    • По умолчанию eventOnDestruction если не определено.
  • HitTypes: можно определить множители урона и события для каждого типа удара.
    • HitType - damageMultiplier: множитель урона для указанного типа удара.
    • HitType - eventOnDestruction: Событие, которое срабатывает, когда деталь уничтожается этим типом удара.
    • HitType - eventOnActorDeath: Событие, которое сработает, когда актер будет убит этим типом удара.

События

Содержит список События разрушения это может быть вызвано разрушением частей тела или превышением порога здоровья актера.

Каждое событие имеет состояние «включено/выключено» и может быть запущено только в том случае, если оно включено. После запуска событие будет отключено.

Доступны следующие параметры:

  • AttachmentsToHide: эти вложения персонажей будут скрыты при запуске события.
    • Это также можно использовать для отключения эффектов частиц, прикрепленных к определенным вложениям - например. светящиеся следы глаз наших инопланетян.
  • AttachmentToUnhide: эти вложения персонажей будут отображаться при запуске события.
  • DisableEvents: Эти события будут отключены при срабатывании этого события, например. голову инопланетянина больше нельзя уничтожить, когда все тело уже взорвалось.
  • Эффект: этот эффект частиц будет появляться при запуске события.
    • Эффект частицы будет прикреплен к кости или родительской кости прикрепленного объекта, который был разрушен.
  • Взрыв: Это приведет к взрыву в центре разрушенной детали. Внимание: это также повредит актера, из которого возник взрыв!
    • Взрыв - ущерб: Повреждения в центре взрыва.
    • Взрыв - minRadius: Размер центра взрыва, где наносится максимальный урон.
    • Взрыв - maxRadius: Размер окончания взрыва, при котором наносится 0 урона.
    • Взрыв - давление: Физическое давление взрыва, отталкивающее физические объекты.
    • Взрыв - эффект: Эффект частиц при взрыве.
  • ScriptCallback: указывает функцию сценария lua, которая будет выполняться при возникновении события.
    • Функция должна быть определена внутри lua-скрипта актера.
    • например Ракетная установка тяжелого пришельца выводится из строя в результате его разрушения.
  • ScriptCondition: указывает функцию сценария lua, которая будет оцениваться до того, как событие произойдет — событие будет продолжаться только в том случае, если эта функция вернет true.
    • Функция должна быть определена внутри lua-скрипта актера.
    • например Мешок с биомассой инопланетного клеща может взорваться только в том случае, если он заполнен.
  • StopEvents: эти события будут остановлены, если они в данный момент выполняются.
    • например может быть использован для остановки кровотечения после смерти актера.

HealthRatioEvents

Содержит список События разрушения что произойдет, когда здоровье персонажа достигнет определенного уровня.

Доступны следующие параметры:

  • соотношение: Коэффициент здоровья, при котором произойдет событие разрушения. Значение должно находиться в диапазоне (0, 1), где 1 означает полное здоровье.
  • кость: определяет, какое место кости персонажа будет использоваться для появления эффектов, связанных с событием разрушения.
  • событие: событие разрушения, которое должно быть запущено.
  • материал: можно использовать для изменения внешнего вида персонажа при достижении определенного уровня здоровья.

ExplosionDeaths

Когда персонаж умирает в результате взрыва, могут произойти два разных события.

  • GibEvent: Если соблюдены определенные условия, персонаж будет скрыт, и это событие сработает. Пользователь может определить следующие параметры:
    • minExplosionDamage: минимальное количество повреждений, которое должен был нанести взрыв, чтобы персонаж мог быть обезглавлен.
    • вероятность: значение внутри диапазона (0, 1), которое случайным образом оценивается во время выполнения, чтобы определить, должно ли оно вызвать событие gib.
    • событие: событие разрушения, которое должно быть запущено.
    • кость: определяет, какое место кости персонажа будет использоваться для появления эффектов, связанных с событием разрушения.
  • NonGibEvent: Если условия события gib не выполнены, это событие будет выполнено. Он запускает событие разрушения в месте кости, и при необходимости можно указать заменяющий материал.
    • событие
    • кость
    • материал

MikeDeath

Блок смерти Майка — это особое событие разрушения в Crysis2. Это событие запускает событие разрушения в месте кости, а также порождает и присоединяет дополнительный анимированный символ к базовому персонажу.

Кроме того, некоторые операции альфа-смешивания выполняются в прикрепленном материале chr.

  • Разрушение:
    • событие
    • кость
  • Приложение:
    • имя: Имя вложения для присоединения объекта chr.
    • объект: объект chr/cdf для присоединения.
    • анимация: Анимация для прикрепленного объекта.
    • alphaTestFadeOutDelay, alphaTestFadeOutTimeOut, alphaTestFadeOutMaxAlpha: контролирует постепенное исчезновение материала на прикрепленном объекте.
