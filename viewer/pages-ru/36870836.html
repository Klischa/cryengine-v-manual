Обзор

Система динамического реагирования (DRS) выполняет различные функции, такие как отображение текущего состояния переменных DRS, всех доступных диалоговых строк и истории ранее отправленных сигналов.

Как видно на справочном изображении ниже, его окно состоит из четырех вкладок, а именно: Переменные, ответы, история диалоговых строк и База данных диалоговых строк.

Вы можете получить доступ к инструменту DRS через Инструменты → Система динамического реагирования.

Дополнительную информацию о логике системы динамического реагирования и связанной с ней терминологии см. Концепция системы динамического реагирования страница.

Меню

Доступ к меню возможен через значок в правом верхнем углу панели. При нажатии открывается Помощь подменю с Перейти к документации... опция, которая направляет пользователя на страницу документации этого инструмента.

Переменные

Вы можете использовать Переменные вкладка для просмотра переменных, указанных в сигнале. Переменная может быть именем или значением, описывающим состояние игры. Он может быть создан или обновлен с помощью игровой логики и DRS. Эти переменные затем можно использовать в условиях, чтобы найти наиболее подходящий диалог для события.

Вкладка «Переменные» состоит из двух разных панелей, а именно: Коллекции переменных и Изменения переменных:

1. Коллекции переменных

Отображает группу связанных переменных.

Каждая переменная является частью коллекции; а в коллекции каждое имя переменной должно быть уникальным.

Есть одна специальная коллекция под названием Данные ответов аВ нижней части обзора коллекций который показывает Счетчик выполнения и временные метки выполнения для каждого ответа, который был запущен на данный момент. Эти значения используются внутри Лимит выполнения и Время с момента ответа состояние. Но эта информация также может быть полезна вам, чтобы проверить, как часто уже выполнялся ответ.

2. Изменения переменных

На этой панели представлена история изменений, внесенных в переменные DRS. Если список пуст, вы можете использовать Автоматическое обновление кнопка для обновления истории. Вы также можете использовать Очистить кнопка для удаления всей истории.

Ответы

Этот раздел позволяет вам изменить ответный сигнал.

Ответ может содержать несколько условий и действий; на основе условий и/или действий, которые были выполнены ранее.
Вкладка «Ответы»

1. Сигналы

Файлы На вкладке панели «Сигналы» перечислены все ответы, которые можно связать с сигналом DRS. Эти ответы сохраняются как .ответ файлы внутри libs\DynamicResponsesystem\Responses папку, которую можно найти в каталоге ресурсов проекта.

Новый ответ можно создать, введя имя ответа в поле Введите новый ответ... поле и нажмите кнопку Создать новый Кнопка рядом с именем вновь созданного ответа.

 Недавние Вкладка предоставляет обзор всех сигналов, отправленных с текущего уровня, а также количество раз, когда был отправлен каждый сигнал.

Основные элементы Недавние вкладка выглядит следующим образом:

Обычно сигнал, который выполняется в игровом режиме Движка (Ctrl + Г), нажав связанную с ним клавишу ввода через Flow Graph. Однако вы также можете выполнить сигнал напрямую, не находясь в игровом режиме, используя команду Отправить сигнал на Actor кнопка в правом верхнем углу страницы Ответ панель, которая описана на следующей вкладке. Вы можете указать точный сигнал для выполнения и желаемого актера, на котором этот сигнал должен быть выполнен.

История диалоговых строк

История диалоговой строки позволяет просматривать сигналы, обработанные через DRS. Вы можете использовать эту информацию для отладки ответного сигнала, когда он не появляется в игровом режиме.

При выборе вкладки «История строк диалога» отображаются следующие параметры:

База данных диалоговых строк

База данных диалоговых линий содержит строки диалога, то есть разговоры, и связанную с ними информацию, которую можно назначить актеру в игровом режиме.

Для того, чтобы добавить новую строку в базу данных, необходимо выбрать пункт База данных диалоговых строк вкладка в инструменте «Система динамического реагирования».

В базе данных хранится вся информация, связанная с диалоговой строкой, такая как субтитры, аудиоресурсы и анимация. Это особенно полезно для группировки фактических данных вместо разделения их на несколько действий.

Редактор диалоговых строк

Редактор диалоговой строки имеет несколько кнопок и панель поиска вверху.

Столбцы диалоговой строки

Столбцы под этими кнопками и панель поиска предоставляют следующую информацию о строке диалога, указанной в базе данных диалоговых строк.

Одна строка может иметь несколько вариантов, то есть даже если вы выполняете одно и то же SpeakLine действие дважды, фактическая произнесенная фраза может быть другой. Это более быстрый способ добавить небольшое изменение к линии. Например, вы можете просто добавить три варианта, щелкнув строку правой кнопкой мыши и выбрав Добавить вариант линии. Обратите внимание, что первый вариант уже сохранен во внутренней строке, поэтому вам нужно добавить еще два, если желаемое количество строк равно трем.

Для каждой строки вы можете определить различные свойства, например, вы можете добавить текст, который будет отображаться в игре, под столбцом. Субтитры. Для получения дополнительной информации см. Добавьте диалоговую строку в базу данных диалоговых строк.

В меню есть еще одна интересная опция, которая называется Запустить сценарий;

Это приведет к выполнению пакетного файла в каждой выбранной строке диалога. Например, это можно использовать для автоматического создания заполнителей для преобразования текста в речь для всех строк вашего диалога. Пакетный файл должен находиться в папке с игрой и называться linescript.bat.

Вот простой пример того, как может выглядеть такой файл сценария преобразования текста в речь (с использованием бесплатного инструмента eSpeak, который необходимо установить):

:: These are the variables you can use in the batch file:
:: LINE_ID (the ID of the lineSet)
:: SUBTITLE (the subtitle text of the current line)
:: AUDIO_TRIGGER (the audio trigger name of the current line)
:: AUDIO_TRIGGER_CLEANED (also the audio trigger name, but with removed prefix, e.g. "PlayTrigger_Test_1" will become: "Test_1". "My_Play_Trigger_Test" will become "Play_Trigger_Test")
:: ANIMATION_NAME (the animation name linked to this line)
:: STANDALONE_FILE (the name of the standalone file linked to this line)
:: Adjust this path to point the folder that contains the espeak executable
cd /d d:\MyEspeakFolder
espeak -vmb-us1 -w "%LINE_ID%.wav" "%SUBTITLE%"

Этот пример сценария передает текст, хранящийся в SUBTITLE переменная в версию командной строки инструмента eSpeak, которая записывает сгенерированный волновой файл в файл с именем LINE_ID + .wav.
