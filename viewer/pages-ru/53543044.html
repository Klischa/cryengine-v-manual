Обзор

CRYENGINE содержит несколько аудиообъектов и узлов Flow Graph, которые подробно описаны ниже.

Аудио-триггер

Аудио-триггер запускает событие в определенной позиции. Это положение может быть автоматически рандомизировано из положения объекта на каждой оси и/или с задержками по времени.

Объект аудиообласти

Объект аудиообласти используется для воспроизведения окружающих звуков в определенной области. Таким образом, объект должен быть связан с Форма области, Площадь Коробка, Площадь Сфера или Площадь Твердого тела.

Объект Audio Area — это расширенный метод настройки окружающих звуков по уровням, требующий логики Flow Graph для воспроизведения и управления окружающим звуком. Это открывает множество возможностей и дает расширенный контроль над атмосферой. При настройке основного окружающего звука используйте Звуковая зона объект, который не требует какой-либо логики Flow Graph.

Примеры этой настройки можно найти на уровнях витрины редактора CRYENGINE Sandbox.

Чтобы узнать, как настроить окружающие звуки на уровне, взгляните на Аудио и атмосфера страница.

Звуковая зона

Звуковая зона используется для настройки простой атмосферы в области без необходимости определять ее функциональность в Flow Graph. Используется при настройке базовых фигур Ambient на уровнях, не требующих более сложного функционала. Поэтому объект должен быть связан с Форма области, Площадь Коробка, Площадь Сфера или Площадь Твердого тела.

Убедитесь, что фигура области, рамка области, сфера области или тело области не имеют перевернутых граней.

Если вы хотите создать атмосферу с большим контролем в Flow Graph, используйте Объект аудиообласти.

Чтобы узнать, как настроить окружающие звуки на уровне, ознакомьтесь со следующей документацией: Атмосфера.

Случайная область аудио

Случайная область аудио запускает рандомизированные одиночные выстрелы в ограниченной области. Поэтому объект должен быть связан с Форма области, Площадь Коробка, Площадь Сфера или Площадь Твердого тела. Звук запускается случайным образом и располагается в радиусе вокруг слушателя, при условии, что он находится внутри подключенной области.

Аудио: предварительная загрузка узла Flow Graph

Предварительная загрузка Узел Flow Graph может загружать и выгружать запрос предварительной загрузки для оптимизации потребления памяти.

В CRYENGINE 5.6.3 этот Flownode заменяет Аудио: PreloadData узел. Функционал обоих узлов одинаков, хотя Аудио: PreloadData узел помечен как устаревший для обратной совместимости.

Аудио: Узел параметра Flow Graph

Параметр Узел Flow Graph устанавливает значение параметра игры.

Если сущность назначена Аудио: Параметр Узел Flow Graph, параметр назначен на Имя ввод изменит только параметры назначенного объекта. Однако если объект не назначен, параметр, назначенный Имя input изменит параметры всех сущностей.

Wwise Конкретно
  • Ан Аудио: Параметр который не назначен объекту, будет устанавливать подключенные игровые параметры для всех игровых объектов в Wwise.
  • Ан Аудио: Параметр который назначен объекту, будет устанавливать только подключенные параметры игры для игрового объекта, соответствующего назначенному объекту в Wwise.
  • В Wwise вы можете отслеживать изменения RTPC для объекта в Профилировщик игровых объектов макет.

В CRYENGINE 5.6 этот Flownode заменяет Аудио: RTPC узел. Функционал обоих узлов одинаков, хотя Аудио: RTPC узел помечен как устаревший для обратной совместимости.

Аудио:SwitchState Flow Graph Узел

SwitchState Узел Flow Graph используется для установки состояния переключения звука.

Wwise Конкретно
  • А Переключить состояние подключенный к переключателю Wwise, установит переключатель Wwise только на игровой объект, соответствующий назначенному объекту.
  • А Переключить состояние подключенный к коммутатору Wwise без назначенного объекта, будет установлен на фиктивном игровом объекте в Wwise.
  • А Переключить состояние подключенный к состоянию Wwise, всегда будет устанавливать состояние глобально, независимо от назначенного объекта.

В CRYENGINE 5.6 этот узел Flow Graph заменяет Аудио: переключатель узел, который был помечен как устаревший для обратной совместимости.

Аудио: переключатель узел позволял переключателям устанавливать несвязанные состояния, что приводило к ошибкам. Аудио: SwitchState node преодолевает этот недостаток, и поэтому впредь рекомендуется использовать его для всех новых настроек Flow Graph.

Аудио:Узел триггера Flow Graph

Триггер Узел Flow Graph просто запускает события.

Wwise Конкретно

Аудиосистема Триггер без назначенного объекта будет выполнено на фиктивном игровом объекте в Wwise.
Аудиосистема Триггер с назначенным объектом, будет выполнено на игровом объекте, соответствующем назначенному объекту.

Аудио: узел TriggerWithCallbacks Flow Graph

Аудио: TriggerWithCallbacks Узел Flow Graph работает как узел Аудио: триггер узел; но в дополнение к своей основной функции он также позволяет пользователю выбирать, получать ли обратные вызовы от промежуточного программного обеспечения или нет.

Wwise поддерживает все обратные вызовы в узле для музыкальных событий.

  • За исключением На пользовательском маркере, ни один из обратных вызовов не требует каких-либо дополнительных настроек со стороны пользователя в Wwise.
  • Чтобы получить обратный вызов «On User Marker», пользователь должен добавить собственный сигнал к музыкальному сегменту в Wwise.

FMOD Студия поддерживает В такт и На пользовательском маркере.

  • Чтобы получить В такт обратные вызовы, пользователю необходимо добавить маркер темпа в событие FMOD. Начиная с этого маркера, каждый такт будет вызывать обратный вызов.
  • На пользовательском маркере требует от пользователя добавить маркер назначения в событие FMOD.
