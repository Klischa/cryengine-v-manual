DumpEntities()

Выводит все идентификаторы объектов (EntityId), имена, классы, позиции и углы, которые в данный момент используются на карте, для консоли.
например:

[userdata: 00000002]..name=Grunt1 clsid=Grunt pos=1016.755,1042.764,100.000 ang=0.000,0.000,1.500
[userdata: 00000003]..name=Grunt2 clsid=Grunt pos=1020.755,1072.784,100.000 ang=0.000,0.000,0.500
...

CompareEntitiesByName(ent1, ent2)

Сравнивает два объекта по имени, что обычно используется при сортировке таблиц.

Пример:
local entities = System.GetEntitiesByClass("SomeEntityClass");
table.sort(entities, CompareEntitiesByName);

CompareEntitiesByDistanceFromPoint(ent1, ent2, точка)

Сравнивает два объекта по их квадрату расстояния. Если расстояние до точки от объекта один больше, чем расстояние до точки от объекта два, он возвращает правда, в противном случае он возвращает ложный.

Пример:
local ent1 = System.GetEntityByName("NameEntityOne");
local ent2 = System.GetEntityByName("NameEntityTwo");

if(CompareEntitiesByDistanceFromPoint( ent1, ent2, g_localActor:GetPos()))then
   Log("Entity One is further away from the Player than Entity two...");
end

BroadcastEvent(отправитель, событие)

Обрабатывает широковещательную рассылку событий объекта.

Пример:
BroadcastEvent(self, "Used");

MakeDerivedEntity( _DerivedClass, _Parent )

Создает новую таблицу, которая является производной версией таблицы родительской сущности. Обычно используется для упрощения создания нового скрипта сущности на основе другой сущности.

MakeDerivedEntityOverride( _DerivedClass, _Parent )

Создает новую таблицу, которая является производным классом родительской сущности. Свойства дочернего элемента override будут соответствовать свойствам родителя.

MakeUsable(объект)

Добавляет полезные функции, такие как OnUsed событие в данную таблицу сущностей.

Пример:
MyEntity = { ... whatever you usually put here ... }

MakeUsable(MyEntity)

function MyEntity:OnSpawn() ...

function MyEntity:OnReset()
  self:ResetOnUsed()
  ...
end

MakePickable(объект)

Добавляет bPickable в таблицу свойств сущности, чтобы добавить базовую выбираемую функциональность к данной сущности.

MakeSpawnable(объект)

Добавляет функциональность появления к данному объекту. Обычно используется для AI актеры во время создания.

EntityCommon.PhysicalizeRigid(объект, nSlot, Свойства, bActive)

Физически применяет объект на основе заданного слота объекта и физических свойств.
