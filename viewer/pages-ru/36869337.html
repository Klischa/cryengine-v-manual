Обзор

Игровой токен — это объект сценария или переменная, которая используется для хранения значений. Эти токены можно использовать для выполнения простых логических манипуляций и проверки значения на языке сценариев игры.

Возможные функции токенов включают состояния (товарищ по отряду = мертв или жив), символы, информацию (результаты исследовательских инструментов), последовательную логику (событие произошло в последовательности «если/то») или объекты (например, оружие, транспортные средства).

Они представлены в различных узлах потока с разными функциями, входами, выходами и проверками.

В базе данных все определенные значения хранятся в библиотеках. Загружая или не загружая одну и ту же библиотеку для каждого уровня, токены можно сделать активными только на одном уровне, на нескольких уровнях или только на части одного уровня.

Создание токенов

Чтобы создать новый игровой токен, нажмите Добавить новый элемент в списке задач Game Token и дайте токену имя. После создания токена вы можете выбрать один из следующих типов: Бул, Int, Плавать, Строка, или Век3.

Сохранение жетонов на уровнях

Есть два конкретных узла Flow Graph, связанных с хранением информации на разных уровнях.

  • Миссия:GameTokensLevelToLevelStore - Запустите его в конце уровня, и он сохранит значения, указанные в перечисленных игровых жетонах.
  • Миссия:GameTokensLevelToLevelRestore - Запустите это в начале следующего уровня, чтобы получить значения с предыдущего уровня.

Отладка

Чтобы выяснить, какие игровые токены активны или изменяются во время сеанса, вы можете включить несколько CVar для отслеживания последних изменений.

Новые элементы добавляются в конец списка и окрашиваются в красный цвет. Со временем они станут белыми, а новые будут добавляться в конец списка.

  • gt_Show - 1=экран и журнал, 2=только экран, 3=только журнал. Отображает журнал недавно измененных токенов в левом верхнем углу (по умолчанию) экрана.
  • gt_showFilter - В историческом списке отображаются только игровые токены, содержащие строку фильтра.
  • gt_showLines - Сколько строк используется в историческом списке.
  • gt_showPosX - Определяет начальный столбец на экране для отладочной информации игровых жетонов.
  • gt_showPosY - Определяет начальную строку на экране для отладочной информации игровых жетонов.
