Выпущено 14 ноября 2014 г.

Редактор

  • Новый: (Flowgraph) Добавлен Flownode для изменения материала океана.
  • Новый: Уточнение плиток текстуры ландшафта добавлено в главное меню «Ландшафт», в дополнение к внутреннему меню инструментов «Слои текстуры ландшафта» (CE-1391).
  • Исправлено: (Trackview) Исправлена ошибка, из-за которой невозможно было настроить освещение ColorParams из-за удаления значения HDRDynamic из сценария light.lua (CE-4802).
  • Исправлено: (TimeofDay) Значения TOD не принимаются, пока не нажата клавиша возврата (CE-4402).
  • Исправлено: (CryDesigner) При отмене назначения материала будет восстановлен материал по умолчанию (CE-2698).
  • Исправлено: Создание AIPath работало только с минимум 3 точками, теперь минимальное значение установлено на 2 (CE-4790).
  • Оптимизированный: (Растительность) Объединить подсказку и макет UI (CE-4642).
  • Оптимизированный: Удалена устаревшая кнопка CloudVolume в RollupBar (CE-4202).

Двигатель

  • Новое: (Частицы) Новые классы и макросы enum для удобного объявления перечислений без префиксов и одновременного создания TypeInfo. Определения ENUM_INFO больше не нужны. Все перечисления ParticleParams вложены в ParticleParams.
  • Новое: (Физика) Открытая окостенелость и поза смерти на трупах/тряпичных куклах (CE-4736).
  • Новое: Использование PhysProxies для вычисления BBox.
  • Новое: Сохраните параметры VCloth в CDF.
  • Новый: добавлено r_DeferredShadingAreaLights=1 в system.cfg для использования AreaLight.
  • Исправлено: (Изгиб) Сбой, когда два потока одновременно используют пул изгиба.
  • Исправлено: (Отладка) e_debugdraw 2 и 3 — проблема с ореолами при создании экземпляров.
  • Исправлено: (RC ImageCompiler) Исправлено неправильное количество параметров, передаваемых в RCLogWarning().
  • Исправлено: (AreaLights) Светятся проекторы, когда включено мозаичное затенение. Освещение области окружающего освещения, когда поддержка освещения области отключена, чтобы сохранить совместимость с предыдущим поведением. Пропускайте обычные прямоугольные источники света, если поддержка отключена. Рисуйте помощники по освещению области только тогда, когда выбран источник света.
  • Исправлено: Материал переопределения должен иметь приоритет над материалом объекта при потоковой передаче текстур. Это устраняет проблему потоковой передачи текстур, возникшую в версии 3.6.10.
  • Зафиксированный: Тупиковая ситуация, когда кэш воспроизводится и уходит в растительность, поскольку C3DEngine::Tick иногда вызывается дважды в одном и том же кадре.
  • Исправлено: дополнительная очистка на VCloth (удален код отбраковки морфов и маркировка лица для касательных).
  • Исправлено: удалено ненужное утверждение в Rasteriser::Raster (CE-4843).
  • Оптимизированный: (Частицы) Измените настройки освещения частиц по умолчанию на 1. Удалите устаревший SunMultiplier.
  • Оптимизированный: (Частицы) Перемещено альфа-отсечение в шейдере для более раннего отклонения.
  • Оптимизированный: (Система) Показать все приоритеты потоковой передачи с помощью sys_streaming_debug.
  • Оптимизированный: (Отладка) Улучшено e_debugdraw 20.
  • Оптимизированный: (Maya, Collada, RC) Переработано/исправлено вычисление преобразований узла (CE-4762).
  • Оптимизированный: Переработан код преобразования координат водной ряби. Добавлен режим отладки для визуализации попадания воды.
  • Оптимизированный: Восстановить задержку рендеринга в 3 секунды при отображении сообщений об ошибках.

Рендерер

  • Исправлено: (Чешуйчатая форма) HUD: На HUD (CE-4415) есть артефакты.
  • Исправлено: Распространить «флаг отключения временных эффектов» на несколько графических процессоров.
  • Исправлено: Регистрируйте несоответствие сэмплера/текстуры один раз для каждого случая, чтобы предотвратить зависание редактора из-за зацикленных/спамовых предупреждений (CE-3950).
  • Исправлено: Включить NullRenderAuxGeom для нулевого рендеринга, исправляет r_debug_renderer_show_window для выделенных серверов для отладки прокси-серверов физики на стороне сервера.

  • Новый: Инициализируйте систему связи Wwise только в случае необходимости, для этого введен новый квар "s_WwiseEnableCommSystem".
  • Исправлено: изменен аудиокод ParticleEffect.lua для соответствия новой функциональности AudioSystem.
  • Исправлено: Эффекты частиц, создаваемые во время выполнения, теперь имеют звук, включенный по умолчанию.
  • Исправлено: Сбой висячего указателя pAudioSystem при выходе из системы.
  • Исправлено: аннулирование итератора в хранилище имен отладки и исправлена проблема с потоками в AudioSystem.
  • Оптимизированный: Небольшая корректировка аудиокода в CParticleSubEmitter::DeactivateAudio.
  • Оптимизированный: добавлен поиск AudioID в строке для внешнего кода. Строки, отличные от NULL, возвращаются, только если определено INCLUDE_AUDIO_PRODUCTION_CODE.
