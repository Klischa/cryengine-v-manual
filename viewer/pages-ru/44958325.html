Обзор

Каждое дерево поведения поддерживает структуру данных, называемую доской, которая содержит переменные и значения, относящиеся к агенту AI. Ее можно рассматривать как память агента AI, и она используется для отделения данных, используемых в дереве поведения, от его логики.

Доступ к Blackboard агента может осуществляться с любого узла для чтения/записи данных во время выполнения Дерева поведения. Однако, поскольку каждый агент поддерживает собственное пространство переменных и значений, переменные Blackboard не могут использоваться совместно в разных экземплярах дерева поведения. Интерфейс доски

Blackboard пользователя CRYENGINE использует структуру данных «ключ-значение», где ключи имеют тип BlackboardVariableId это просто оболочка для имени переменной. 32-битный CRC используется для кодификации имен переменных и ускорения сравнения ключей в Blackboard.

Построение BlackboardVariableId так же просто, как вызвать конструктор, который принимает один аргумент.

//! Constructs a BlackboardVariableId from a variable name.
BlackboardVariableId(const char* _name);
 
// Could be used as follows.
const BlackboardVariableId myVariableId = BehaviorTree::BlackboardVariableId("MyVariable");

Интерфейс Blackboard предоставляет три функции:

//! Creates a a new entry <id, value> in the Blackboard. If the given Id already exists on the Blackboard, the value will be overwritten if, and only if, the existing value type and provided type match. 
//! If types do not match, value won't be modified and the function will return false.
//! \param id Id of the variable.
//! \param value Value of the variable.
//! \return True if successfully set.
template<typename Type>
bool SetVariable(BlackboardVariableId id, const Type& value);
 
//! Gets the value of a variable by id if it exists on the Blackboard, and the existing value type and provided type match. 
//! \param id Id of the variable.
//! \param value Value of the variable.
//! \return True if Id exists and types match.
template<typename Type>
bool GetVariable(BlackboardVariableId id, Type& value) const;
 
//! Gets the Blackboard variable array.
//! \return BlackboardVariableArray containing all Blackboard entries <id, value>.
//! \note Use this only if you need to iterate over Blackboard items. To retrieve single items GetVariable(id, value) should be preferred instead.
const BlackboardVariableArray& GetBlackboardVariableArray() const;

Чтобы продемонстрировать, как используются вышеуказанные функции, следующий код извлекает переменную Здоровье, который затем устанавливается на 100.0ф.

Blackboard blackboard;
 
// Create a BlackboardVariableId from Health.
const BlackboardVariableId blackboardVariableHealth = BlackboardVariableId("Health");
 
// Create an Health entry in the blackboard with a value of 100.0.
const bool variableSetSuccessfully = blackboard.SetVariable(blackboardVariableHealth , 100.0f);
 
// Get the value from the blackboard into the health variable, which after this, should have a value of 100.0.
float health;
const bool variableGetSuccessfuly = blackboard.GetVariable(blackboardVariableHealth health);

Получить доску

Чтобы получить Blackboard определенного экземпляра дерева поведения, доступ к Blackboard осуществляется через доска член класса в UpdateContext параметр любой основной функции дерева поведения (OnInitialize, Обновление, и OnTerminate).

void OnInitialize(const UpdateContext& context)
{
  float health;
  Blackboard& blackboard = context.blackboard;
  
  // Access the blackboard.
  const bool variableGetSuccessfully = blackboard.GetVariable("Health", health));
 
  // Execute specific node logic.
  // ...
}

Чтобы получить доску определенного агента AI, мы используем функцию GetBehaviorTreeBlackboard из BehaviorTreeManager, который принимает идентификатор объекта.

 gEnv->pAISystem->GetIBehaviorTreeManager()->GetBehaviorTreeBlackboard(entityId);

Пример

В следующем примере MoveToPosition создается узел, который позволяет нам переместить агента AI в определенную позицию, которая хранится в переменной на Blackboard.

Узел имеет строковый элемент данных m_bbVariableNameDestination, который определяет имя переменной Blackboard, в которой хранится пункт назначения агента. Это имя переменной может быть жестко запрограммировано, но в идеале оно должно быть установлено для каждого дерева, чтобы обеспечить гибкость.

Кроме того, значение этой переменной в Blackboard может быть установлено любым другим узлом. Например, у нас может быть узел CalculateCoverPosition установите переменную CoverPosition, который затем будет использоваться MoveToPosition узел для перемещения агента на позицию прикрытия.

//! MoveToPosition node moves to the position stored in a variable in the Behavior Tree Blackboard.
class MoveToPosition : public Action
{
  typedef Action BaseClass;
public:
  struct RuntimeData
  {
    MovementRequestID movementRequestID;
    Status pendingStatus;
    RuntimeData()
      : movementRequestID(0)
      , pendingStatus(Running)
    {}

    ~RuntimeData()
    {
      if (this->movementRequestID)
      {
        gAIEnv.pMovementSystem->UnsuscribeFromRequestCallback(this->movementRequestID);
        this->movementRequestID = MovementRequestID();
      }
    }

    void MovementRequestCallback(const MovementRequestResult& result)
    {
      assert(this->movementRequestID == result.requestID);
      this->movementRequestID = MovementRequestID();
      if (result == MovementRequestResult::ReachedDestination)
      {
        this->pendingStatus = Success;
      }
      else
      {
        this->pendingStatus = Failure;
      }
    }
  };

public:
  virtual void OnInitialize(const UpdateContext& context) override
  {
    RuntimeData& runtimeData = GetRuntimeData<RuntimeData>(context);
    Vec3 destination;
    if (context.blackboard.GetVariable(BlackboardVariableId(m_bbVariableNameDestination), destination))
    {
      MovementRequest movementRequest;
      movementRequest.entityID = entityID;
      movementRequest.destination = destination;
      movementRequest.callback = functor(runtimeData, &RuntimeData::MovementRequestCallback);
      movementRequest.style = m_movementStyle;
      runtimeData.movementRequestID = gAIEnv.pMovementSystem->QueueRequest(movementRequest);

      if (runtimeData.movementRequestID.IsInvalid())
      {
        runtimeData.pendingStatus = Failure;
      }
    }
    else
    {
      runtimeData.pendingStatus = Failure;
    }
  }
  virtual Status Update(const UpdateContext& context) override
  {
    RuntimeData& runtimeData = GetRuntimeData<RuntimeData>(context);
    return runtimeData.pendingStatus;
  }

  virtual void OnTerminate(const UpdateContext& context) override
  {
    // Actually, not necessary. Included to help illustrate this example.
  }

private:
  string               m_bbVariableNameDestination;
  MovementStyle        m_movementStyle;
};

Отладка

Записи Blackboard можно отображать на экране во время выполнения дерева поведения в игровом режиме, включив ai_ModularBehaviorTreeDebugBlackboard Cвар. Однако при этом отображаются только переменные типов int, bool, char, float, double, строка, век2 и Век3 как показано.

Ограничения

Текущая реализация Blackboard имеет три ограничения:

  • Поддержка Sandbox: Использование Blackboard не поддерживается на Sandbox, то есть его можно использовать только через C++.
  • Общие переменные: Каждый экземпляр дерева поведения имеет свою собственную доску Blackboard, что означает, что переменные Blackboard не могут использоваться совместно разными экземплярами.
  • Ограниченная система отладки: при отладке отображаются только записи Blackboard определенного подмножества типов.
