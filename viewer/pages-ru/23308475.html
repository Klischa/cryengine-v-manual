Описание

Редактору Mannequin требуется Mannequin Настройка предварительного просмотра настроить себя. По сути, это файл XML, который сообщает редактор, который Файл определения контроллера (xxxControllerDefs.xml) загружать и какие символы и Файл базы данных анимации (ADB) файлы для использования.

Эти файлы настроек предварительного просмотра используются только редактором, они не используются в игре. Вы можете иметь столько таких настроек, сколько захотите.

Не путайте этот файл с последовательности который вы редактируете в Mannequin Предварительный просмотр.

Загрузка настройки предварительного просмотра

Чтобы загрузить настройку предварительного просмотра, используйте параметр «Загрузить настройку предварительного просмотра...» в меню «Файл» Mannequin.

Настройка предварительного просмотра по умолчанию

Когда вы открываете редактор манекенов, он попытается загрузить файл настройки предварительного просмотра Mannequin по умолчанию. Вы можете изменить это значение по умолчанию в Настройки редактора Mannequin, которые вы можете найти в разделе «Правка» -> «Настройки» в главном редакторе UI..

Создание настройки предварительного просмотра

Чтобы создать настройку предварительного просмотра манекена, вам необходимо создать текстовый файл вручную.. См. FileFormat раздел ниже для примера.

Все файлы настроек предварительного просмотра должны храниться в папке Animations/Mannequin/Preview/. Обычно они используют имя, оканчивающееся на «Preview.xml», но это не обязательно.

Редактирование настроек предварительного просмотра

Чтобы отредактировать настройку предварительного просмотра, вы используете Mannequin Редактор контекста.

Формат файла

Пример файла настройки предварительного просмотра выглядит следующим образом:

<MannequinPreview>
 <controllerDef filename="Animations/Mannequin/ADB/playerControllerDefs.xml"/>
 <contexts>
  <contextData name="Player" enabled="1" database="Animations/Mannequin/ADB/playerAnims1P.adb" context="Char1P" model="objects/characters/human/sdk_player/sdk_player.cdf"/>
  <contextData name="PlayerSound" enabled="1" database="Animations/Mannequin/ADB/playerSounds.adb" context="Sound"/>
  <contextData name="Rifle" database="Animations/Mannequin/ADB/rifleWeaponAnims.adb" context="Weapon" tags="rifle" model="objects/weapons/rifle/rifle_fp.cdf" attachment="weapon"/>
  <contextData name="Pistol" database="Animations/Mannequin/ADB/pistolWeaponAnims.adb" context="Weapon" tags="pistol" model="objects/weapons/pistol/pistol_fp.cdf" attachment="weapon"/>
 </contexts>
 <History StartTime="0" EndTime="0">
  <FragmentID Time="0" FragmentID="idlePose"/>
 </History>
</MannequinPreview>

controllerDef определяет, какие Файл определения контроллера (xxxControllerDefs.xml) использовать.

контексты раздел определяет, как заполнить Контексты области действия в редакторе. Вы можете использовать Mannequin Редактор контекста изменить этот раздел.

история раздел определяет fragmentIDs по умолчанию для слоя в Mannequin Редактор фрагментов. Это полезно, например, при редактировании фрагментов, воспроизводимых во вторичных областях, которые зависят от другого фрагмента, воспроизводимого в первой области; здесь вы можете определить, какие фрагменты следует упорядочивать в первой области. Он использует тот же формат, что и Файл последовательности (xml).
