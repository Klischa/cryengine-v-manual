Обзор

При создании ShaderCache.pak предполагается, что на сервере работает удаленный компилятор шейдеров, который содержит набор скомпилированных шейдеров, используемых игрой.

Создание ShaderCache.pak не будет работать если вы не используете Удаленный компилятор шейдеров для компиляции шейдеров.

Чтобы создать ShaderCache.pak, вам необходимо следовать этим инструкциям:

Шаг 1

Получите сборку, для которой вы хотите создать ShaderCache.pak. Набор файлов, который вам действительно понадобится на этом этапе:

  • ShaderCacheGen.exe содержится в папке <root>\bin\win_x64 поставляемой сборки CRYENGINE, на которой основана игра.
  • Все .dll и .pdb из сборки, которая должна быть встроена в Профиль конфигурация.
  • <root>\Engine\Engine.pak и <root>\Engine\Shaders.pak (Shaders.pak можно создать непосредственно из исходного кода шейдера).

Обратите внимание: если вы выполняете сборку из рабочей области, где раньше использовали r_ShadersDebug, у вас могут быть копии шейдеров в папке <root>\<GameName>\Shaders.
Их необходимо удалить перед созданием ShaderCache.

Шаг 2

Скопируйте один из следующих файлов из папки кэша удаленного компилятора шейдеров и переименуйте его в <root>\USER\Shaders\shaderlist.txt. (обратите внимание на регистр в списке шейдеров)

Поддерживаются следующие платформы:

  • ShaderList_PC.txt если вы создаете ShaderCache.pak для платформы PC.
  • ShaderList_Orbis.txt если вы собираете ShaderCache.pak для платформы Playstation 4.
  • ShaderList_Durango.txt если вы собираете ShaderCache.pak для платформы Xbox One.
  • ShaderList_GL4.txt если вы собираете ShaderCache.pak для платформы OpenGL 4

Обратите внимание, что ShaderList обычно генерируется при запуске игры в соответствующей конфигурации с прикрепленным к игре RSC.
Для ShaderList_GL4.txt это означает, что вы должны использовать CryRenderGL.dll в качестве средства рендеринга во время выполнения (с r_driver=GL и работать на целевой платформе).

Шаг 3

Напишите system.cfg файл в папку <root> следующим образом:

sys_no_crash_dialog=1
d3d9_NullRefDevice=1
sys_vr_support = 0
log_IncludeTime=3
log_Verbosity=3
log_FileVerbosity=3
e_profile_level_loading=0
r_driver=DX11
sys_game_folder=<GameName>
r_ShadersAsyncCompiling=3
r_ShadersAsyncMaxThreads=16
r_ShadersRemoteCompiler=1
r_ShaderCompilerServer=<ShaderCompilerIPAddressOrHostname>
r_ShaderCompilerPort=<ShaderCompilerPort>
r_ShadersUserFolder=1
r_ShadersUseInstanceLookUpTable=1
r_multithreaded=0
r_ShadersSubmitRequestline=0
r_ShadersDX11=0
r_ShadersDurango=0
r_ShadersOrbis=0
 
-- For the OpenGL renderer support
-- r_driver=GL
-- r_ShadersGL4=0


Затем, в зависимости от платформы, измените ровно одну из следующих переменных с 0 на 1 в system.cfg файл:

Одновременно может быть скомпилирован только один набор шейдеров. Поэтому одновременно устанавливайте значение 1 только для одной из переменных r_ShadersXXX.

При использовании r_ShadersGL4=1 вы также должны установить r_driver=GL и в вашей сборке должен быть соответствующий CryRenderGL.dll.

Шаг 4

Создайте файлы, необходимые для ShaderCache.pak, запускающего инструмент ShaderCacheGen, с помощью следующей командной строки (результат процесса записывается в файл редактор.журнал):

Если ShaderCache.pak для PC, PlayStation 4 или Xbox Один платформа генерируется, команда:

<root>\bin\win_x64\ShaderCacheGen.exe -noprompt -anygpu /PrecacheShaderList

Важно запускать эти командные строки из корневой папки!
Шаг 5

Упаковку кэша шейдеров можно выполнить вручную или с помощью Tools\PakShaders.bat. Прежде чем делать это, необходимо пройти шаги 1–4. Команда для вызова упаковки:

<root>\Tools\PakShaders.bat <TargetSubfolder>

<TargetSubfolder> можно найти в таблице на шаге 3.

Важно запускать эту командную строку из корневой папки!

Скрипт создаст файлы *.pak в корневой папке. Он обрабатывается накопительным способом, то есть при запуске команды для разных платформ друг за другом все они будут объединены в одни архивы.
Обычно созданный *.pak копируется в папку Engine окончательной сборки.
Для справки взгляните на готовые игры, поставляемые в SDK, шейдеры в них были созданы тем же методом, что и здесь.

В настоящее время имеет смысл упаковывать несколько наборов шейдеров только для платформы PC, в частности, наборы D3D10, D3D11 и GL4 можно комбинировать.
Для других платформ нет смысла упаковывать какие-либо шейдеры, кроме единственного поддерживаемого набора на этом конкретном оборудовании.

Если вы предпочитаете упаковывать кэш шейдеров вручную, продолжайте читать:

Упакуйте файлы в разные пак-файлы. Сопоставление папок для разных платформ:

  • PC платформа должна скопировать данные из следующих папок:

    <root>\USER\Shaders\Cache\D3D9\

    <root>\USER\Shaders\Cache\D3D10\

    <root>\USER\Shaders\Cache\D3D11\

    <root>\USER\Shaders\Cache\GL4\

    ... в:

    Шейдеры\Кэш\D3D9\

    Шейдеры\Кэш\D3D10\

    Шейдеры\Кэш\D3D11\

    Шейдеры\Кэш\GL4\

  • Xbox Один платформа должна скопировать данные из следующей папки:

    <root>\USER\Shaders\Cache\Durango\
    ... в:
    Шейдеры\Кэш\Дуранго\

  • PlayStation 4 платформа должна скопировать данные из следующей папки:

    <root>\USER\Shaders\Cache\Orbis\
    ... в:
    Шейдеры\Кэш\Орбис\


  • ShaderCache.pak должен содержать все из вышеуказанных подпапок.
  • ShadersBin.pak должен содержать только файлы *.cfxb и *.cfib.
  • ShaderCacheStartup.pak должен содержать следующие файлы:
    • <root>\USER\Shaders\Cache\<платформа>\lookupdata.bin -> Shadercache\<платформа>\lookupdata.bin
    • <root>\USER\Shaders\Cache\<platform>\CGPShader\FixedPipelineEmu* -> Shadercache\<platform>\CGPShader\FixedPipelineEmu*
    • <root>\USER\Shaders\Cache\<platform>\CGPShader\Scaleform* -> Shadercache\<platform>\CGPShader\Scaleform*
    • <root>\USER\Shaders\Cache\<платформа>\CGPShader\Stereo* -> Shadercache\<платформа>\CGPShader\Stereo*
    • <root>\USER\Shaders\Cache\<platform>\CGVShader\FixedPipelineEmu* -> Shadercache\<platform>\CGVShader\FixedPipelineEmu*
    • <root>\USER\Shaders\Cache\<platform>\CGVShader\Scaleform* -> Shadercache\<platform>\CGVShader\Scaleform*
    • <root>\USER\Shaders\Cache\<платформа>\CGVShader\Stereo* -> Shadercache\<платформа>\CGVShader\Stereo*
    • <root>\USER\Shaders\Cache\<платформа>\lookupdata.bin -> Shaders\Cache\<платформа>\lookupdata.bin
    • <root>\USER\Shaders\Cache\<платформа>\Common.cfib -> Shaders\Cache\<платформа>\Common.cfib
    • <root>\USER\Shaders\Cache\<платформа>\fallback.cfxb -> Shaders\Cache\<платформа>\fallback.cfxb
    • <root>\USER\Shaders\Cache\<платформа>\fixedpipelineemu.cfxb -> Shaders\Cache\<платформа>\fixedpipelineemu.cfxb
    • <root>\USER\Shaders\Cache\<платформа>\FXConstantDefs.cfib -> Shaders\Cache\<платформа>\FXConstantDefs.cfib
    • <root>\USER\Shaders\Cache\<платформа>\FXSamplerDefs.cfib -> Shaders\Cache\<платформа>\FXSamplerDefs.cfib
    • <root>\USER\Shaders\Cache\<платформа>\FXSetupEnvVars.cfib -> Shaders\Cache\<платформа>\FXSetupEnvVars.cfib
    • <root>\USER\Shaders\Cache\<платформа>\FXStreamDefs.cfib -> Shaders\Cache\<платформа>\FXStreamDefs.cfib
    • <root>\USER\Shaders\Cache\<платформа>\scaleform.cfxb -> Shaders\Cache\<платформа>\scaleform.cfxb
    • <root>\USER\Shaders\Cache\<платформа>\stereo.cfxb -> Shaders\Cache\<платформа>\stereo.cfxb
