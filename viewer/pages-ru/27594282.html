Обзор

Flow Graph — это встроенный инструмент, который используется для управления событиями и игровой логикой на уровнях.

Окно Flow Graph состоит из девяти различных частей:

Помимо основной панели редактирования, все окна можно перемещать, изменять их размер и стыковать друг с другом. Основная панель редактирования всегда будет находиться на заднем плане и использовать все доступное пространство.

Посмотреть

Окно «Просмотр» позволяет скрывать/показывать все различные окна инструмента Flow Graph, например окно «Компоненты» или окно «Точки останова».

По понятным причинам главное окно невозможно скрыть. В разделе компонентов вы можете выбрать отображение всех типов узла Flow Graph.

Инструменты

Отладка

Значок меню

Значок можно найти в правом верхнем углу панели. При нажатии открывается Помощь подменю с Перейти к документации... опция, которая направляет пользователя на страницу документации этого инструмента.

2. ToolBar

Под строкой меню находится панель быстрого доступа.

3. Окно компонентов.

Окно «Компоненты» разделено на две части: поле поиска и список узлов.

Поле поиска

В поле поиска компонентов вы можете ввести любую часть имени узла, и он отфильтрует все узлы, в именах которых есть этот текст. После этого вы сможете перейти к только эти узлы в списке узлов ниже.

Список узлов

В списке узлов можно найти все используемые узлы Flow Graph. Узлы компонентов — это узлы, которые не представляют сущность на уровне, но имеют абстрактную функциональность, которая может использовать одну или несколько сущностей. например Математические узлы.

Добавление узлов в график

Узлы сортируются по категориям и могут быть добавлены в текущий Flow Graph тремя способами:

  1. Перетаскивание узла из списка компонентов на фоновую панель.
  2. Щелкнув правой кнопкой мыши на фоновой панели главного окна и выбрав узел из AddNode Пункт меню в контекстном меню. При этом отображается та же информация, что и в полном списке компонентов.
  3. В главном окне Flow Graph нажмите вопрос чтобы включить всплывающий быстрый список. Продолжайте вводить имя узла, который вы ищете, и список сократится настолько, насколько это возможно. Когда несколько узлов имеют одинаковые имена, вам будет представлен список (1/15), и с помощью стрелок вверх/вниз вы сможете перемещаться по списку short. Нажмите Enter, как только у вас появится нужный узел, чтобы добавить его на график.

4. Список графиков

В этом окне представлен обзор различных графиков и объектов. К объектам может быть прикреплен только один график, а не несколько.

Для переключения между графиками:

  • Нажмите на + рядом с Сущности чтобы расширить список. ( + знак доступен только в том случае, если в папке есть дочерние графики.)
  • В этом списке показаны все доступные объекты с прикрепленными блок-графами (если они присутствуют на уровне).
  • Просто щелкнув различные элементы в списке, вы отобразите информацию о потоковых диаграммах, прикрепленную к этому объекту.
  • Щелкните правой кнопкой мыши элемент списка, чтобы открыть контекстное меню, которое предлагает различные параметры в зависимости от графика:


Помимо обычных графов потоков сущностей, в этом окне перечислены все графы AIAction. Граф AIAction — это особый тип графа, который выполняется Смарт-объект правило.

5. Главное окно

Это главное окно, где происходит все редактирование. Здесь узлы можно добавлять, удалять, перемещать и связывать. Для эффективной работы этому окну требуется много места на экране.

Лучший способ работы с ним — разместить его на втором мониторе (если он есть) и держать его все время открытым, поскольку может возникнуть необходимость переключения между окном игры и Flow Graph. часто.

  • Навигация: Основная панель редактирования не ограничена и может быть расширена в любом направлении. Для навигации нажмите и удерживайте правую кнопку мыши, чтобы перемещаться по графику. Также можно использовать полосы прокрутки окна. Колесо мыши используется для увеличения и уменьшения масштаба.
  • Выбор: Узлы можно выбрать левой кнопкой мыши и отменить выбор, щелкнув где-нибудь на фоновой панели. Несколько узлов можно выбрать, щелкнув на фоновой панели левой кнопкой мыши и нарисовав рамку перетаскивания вокруг узлов, которые необходимо выбрать. Двойной щелчок по узлу выберет назначенный объект на уровне.
  • Контекстное меню: если щелкнуть правой кнопкой мыши фоновую панель, отобразится контекстное меню.

Обычные ярлыки Windows Ctrl-C, Ctrl-Vи т. д. также можно использовать при редактировании в Flow Graph. Дополнительно Ctrl-Shift-V вставляет узлы из буфера обмена, включая все ссылки.

6. Свойства

Панель «Свойства» относится к выбранному в данный момент узлу. Здесь можно редактировать все параметры узла.

Помимо элементов управления вводом имеется информационная вкладка, содержащая описание выбранного в данный момент узла.

7. Панель поиска

В графах потоков и графах действий можно искать определенные узлы и/или значения. Параметры поиска можно настроить для включения или исключения различных частей узлов. Поиск также можно ограничить графами действий или объектами.

Загляни раскрывающийся список определяет, по каким графикам будет производиться поиск:

'Специальный' раскрывающийся список предлагает дополнительные возможности для исключения определенных категорий узлов. Например все Работа в процессе узлы можно исключить из поиска. Кроме того, существует набор флажков для выбора, следует ли включать в поиск порты, значения, объекты или идентификаторы.
Все окна можно перемещать и фиксировать по мере их соответствия доступному экранному пространству.

8. Панель результатов поиска

Результаты поиска будут отображаться в SearchResults окно, и нажатие клавиши double приведет к переходу к соответствующему графику.

Если вы выполняли поиск с помощью «Все потоковые графики», это сначала разделит список результатов на отдельные графики, а затем на каждый экземпляр этого результата на этом графике.


9. Панель точек останова

На этой панели показаны точки останова, которые вы установили для отладки Flow Graph. Точки останова могут быть добавлены к портам ввода и вывода. Они будут представлены на графике в виде красного шарика рядом с портом, для которого вы его установили. Как только игра активирует точку останова, игра приостановится, пока вы не подтвердите ее, нажав F5или нажмите стрелку продолжения, и игра возобновится.

  • Назначение точек останова задается нажатием щелчок правой кнопкой мыши на порту ввода/вывода, которому вы хотите его назначить, и выбрав Добавить точку останова.
  • Отмена назначения точек останова удаляется щелчок правой кнопкой мыши на порте ввода/вывода, из которого вы хотите его удалить, и выберите Удалить точку останова.
  • Альтернативно, через окно точки останова вы можете щелкнуть правой кнопкой мыши конкретную точку останова в списке и удалить отдельную точку останова или, если вы выберете верхнего родительского элемента, удалить все точки останова сразу из графика.
  • После срабатывания точки останова игра приостанавливается, ожидая ввода от пользователя. Нажмите кнопку Играть на панели инструментов Flow Graph, чтобы продолжить игру.

В главном окне графика на следующих двух рисунках показаны два состояния набора и сработавшая точка останова.


Точка останова установлена ​​на выходе Not Equal. Обратите внимание на красный шарик


Точка останова сработала в игре. Обратите внимание на дополнительную желтую стрелку на красном шаре.
