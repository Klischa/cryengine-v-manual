Обзор

Типы элементов — это настраиваемые типы данных, которые можно предоставить универсальной системе запросов (UQS) под определенным именем.

Предметы используются в разных местах внутри UQS:

  • Они представляют собой пространство рассуждений запроса и будут «оцениваться» один за другим выполняемым запросом.
  • Они используются входными параметрами для генераторов, функций и оценщиков.
  • Они представляют возвращаемое значение функций.

Типы элементов могут быть дополнительно зарегистрированы с помощью обратных вызовов для визуализации отдельных элементов, которые оцениваются в запросе.

Типичным типом элемента будет Vec3, обозначающий очки, которые необходимо набрать и протестировать в трехмерном мире.

Стандартная библиотека UQS уже предоставляет несколько типов, ориентированных на Vec3, особенно Pos3, Ofs3 и Dir3.

Более подробную информацию о том, как эти типы элементов (среди прочих) добавляются в ядро UQS, можно найти на странице private. UQS::StdLib::CStdLibRegistration::InstantiateItemFactoriesForRegistration() метод.

Регистрация типов элементов

Регистрация типов элементов происходит в коде C++ с помощью удобного вспомогательного класса. CItemFactory<>, это встроено в UQS:

UQS::Client::CItemFactory<>

Затем регистрация происходит через глобальный экземпляр static CItemFactory<> класс template:

struct SMyCustomType
{
  int a, b, c;
};

// ...

UQS::Client::CItemFactory<SMyCustomType>::SCtorParams ctorParams;
ctorParams.szName = "my::CustomType";
ctorParams.guid = "0142838d-9c8b-454c-866f-b1d4b925f803"_uqs_guid;
// ...
 

// Notice: This instance of CItemFactory<> must _not_ go out of scope for the lifetime of UQS, 
//         since the UQS core will keep a pointer to this particular factory!
static const UQS::Client::CItemFactory<SMyCustomType> itemFactory_MyCustomType(ctorParams);

Вы можете зарегистрировать столько разных типов элементов, сколько захотите. При этом убедитесь, что все они имеют разные идентификаторы GUID и ни один тип данных не регистрируется более одного раза.

Чтобы наконец предоставить доступ к вашим типам элементов (а также генераторам, функциям и оценщикам) ядру UQS, вам просто нужно вызвать этот вспомогательный метод static после получения UQS::Core::EHubEvent::RegisterYourFactoriesNow событие:

UQS::Client::CFactoryRegistrationHelper::RegisterAllFactoryInstancesInHub()
