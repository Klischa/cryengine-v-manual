Обзор

Вы можете использовать Flow Graph для создания полноэкранных эффектов. В этом разделе объясняются узлы и функции для создания этих эффектов.

Убедитесь, что Расширенный Компоненты отображаются в списке Компоненты. Вы можете установить эту опцию в Flow Graph Редактор панель инструментов, под Вид -> Компоненты.

Узлы эффектов

Узлы камеры

Вы можете найти эту опцию в контекстном меню, Добавить узел -> Камера. Эти ноды можно использовать для создания эффектов камеры. Например, ViewShakeEx генерирует случайную анимацию дрожания камеры. Эффективно соединить с взрывным воздействием.

  • Триггер: активирует эффект встряхивания.
  • Ограничить: Устанавливает предел условий для ViewShake. Вы можете установить следующие параметры:
    • Нет: Никакие условия не применяются.
    • NoVehicle: Эффект применим только в том случае, если игрок находится вне транспортного средства.
    • VehicleOnly: Эффект применим только в том случае, если игрок находится внутри транспортного средства.
  • Посмотреть: выбор камеры для применения эффекта. Это может быть Первое лицо для игрока или Текущий если вы хотите применить эффект к последовательности просмотра дорожки.
  • GroundOnly: применяет встряску, когда игрок стоит на поверхности земли.
  • Угол: управляет углом дрожания камеры.
  • Сдвиг: управляет расстоянием смещения при дрожании камеры.
  • Продолжительность: управляет длительностью эффекта от начала до конца.
  • Частота: управляет частотой встряхивания.
  • Случайность: управляет случайностью встряхивания.
  • Расстояние: Расстояние, на котором произойдет встряхивание. Если объект связан с узлом, будет использоваться расстояние от этого объекта до текущей камеры.
  • RangeMin: Минимальный диапазон силового воздействия.
  • RangeMax: Максимальная дальность действия силы.
  • SustainDuration: Общая продолжительность встряхивания.
  • FadeOutDuration: Общее время исчезновения дрожания (в секундах).
  • Стоп: Общее время, необходимое для прекращения встряхивания.
  • Предустановка: Предустановленные входные значения. При использовании этого параметра все вводимые параметры игнорируются.

Узлы изображения

Вы можете найти эту опцию в контекстном меню, Добавить узел -> Изображение. Узлы изображения используются для отображения эффектов постобработки, которые можно использовать в игровом процессе или в кат-сценах.

Одновременно можно использовать несколько узлов для смешивания результатов для различных эффектов, но имейте в виду, что каждый из этих узлов добавляет дополнительный проход рендеринга по экрану, поэтому обязательно ограничивайте количество одновременно используемых узлов до разумного уровня. Большинство дорогих эффектов GPU отмечены в этом документе пометкой «дорого».

При использовании узлов изображения или камеры нет необходимости устанавливать сущность в узлах изображения; они будут автоматически назначены локальному игроку. Несмотря на то, что большинство узлов имеют включен и отключен портов, безопаснее игнорировать отключенный вход и использовать включенный вход и установить для него значение true или false. Входные данные также имеют логический тип, поэтому всегда лучше комбинировать эти узлы с Математика:BooleanTo node, чтобы быть уверенным, что правильные значения отправляются на узел изображения.

MaterialFX Узлы

Вы можете найти эту опцию в контекстном меню, Добавьте узел ->MaterialFX. Вы можете использовать эти узлы для реализации полноэкранного эффекта к эффекту частиц. Эти графики материала FX вызываются из кода.

Например:

  • График dirt_bullet_hit вызывается, когда игрок стреляет по поверхности, и камера также находится близко к этой поверхности.
  • График blood_bullet_hit вызывается, когда игрок получает урон от какого-либо события в игровом мире. (Выстрел AI, урон от падения и т. д.)

Ниже приведен пример dirt_bullet_hit График вызывается, когда игрок стреляет по земле с mat_grass, назначенным в качестве типа поверхности.

  • Через файл Libs\MaterialEffects.xml мы находим комбинацию пистолетбуллет и mat_grass. (строка 50, столбец 25).
  • Это указывает на библиотеку Библиотеки\MaterialEffects\FxLibs\projectiles.xml.
  • А конкретно эффект внутри библиотеки: bullet_grass (что показано ниже).
  • Внизу эффекта мы находим ссылку Flowgraph: <FlowGraph name="dirt_bullet_hit" maxdist="2"/>.
  <Effect name="bullet_grass" delay="0.05">
    <Audio trigger="Play_p_pro_impact_bullet_hit_mat_grass">
    </Audio>
    <RandEffect name="particles1">
      <Particle>
        <Name minscale="0.3" maxscale="1" maxscaledist="80">bullet.hit_grass.a</Name>
      </Particle>
      <Particle>
        <Name minscale="0.4" maxscale="1.3" maxscaledist="80">bullet.hit_grass.b</Name>
      </Particle>
      <Particle>
        <Name minscale="0.6" maxscale="1.2" maxscaledist="80">bullet.hit_grass.c</Name>
      </Particle>
    </RandEffect>
    <RandEffect>
      <Decal minscale="0.04" maxscale="0.06">
        <Material>materials/decals/dirt/ground</Material>
      </Decal>
    </RandEffect>
    <FlowGraph name="dirt_bullet_hit" maxdist="2"/>
  </Effect>


Для правильной работы график материала FX должен содержать узлы «Начало» и «Конец». Логика внутри этих двух узлов зависит от вас.

HUDstartFX

Запуск полноэкранного эффекта, который будет применен в движке.

Входной порт

  • Старт: Запускается автоматически MaterialEffects системы.

Выходные порты

  • Началось: срабатывает при запуске эффекта.
  • Расстояние: Расстояние до игрока.
  • Парам 1-2: Пользовательские параметры float, которые можно установить в описании эффекта XML.
  • Интенсивность: Общая интенсивность эффекта. Это динамическое значение (в диапазоне 0,0–1,0).
  • BlendOutTime: Общее время, необходимое для растушевки эффекта FX (в секундах).

HUDEndFX

Конец полноэкранного эффекта для движка.

  • Триггер: этот порт срабатывает, когда эффект завершен. Это необходимо сделать для уведомления о том, что эффект можно использовать повторно.

Реализация полноэкранного эффекта в игре.

Чтобы реализовать полноэкранный эффект в игре, вам необходимо сохранить Flow Graph и вызвать его в игре. Убедитесь, что вы установили следующие параметры в своем Flow Graph:

  • Создайте Flow Graph для эффекта.
  • Добавить HUDStartFX и HUDEndFX узел.
  • Добавить Задержка узел (Добавить узел->Время->Задержка).
  • Установите Задержка значение до минимально необходимой длительности, чтобы задействовать всю продолжительность эффекта Flow Graph.
  • Подключите Началось порт HUDStartFX к каждой начальной точке каждого узла эффекта, и В порт модифицированного Задержка узел.
  • Подключите Выход из Задержка узел к Триггер из HUDEndFX узел.
  • Сохраните Flow Graph в Libs/MaterialEffects/Flowgraphs.
  • Если вы используете полноэкранный эффект в качестве эффекта воздействия пули или взрыва, переименуйте имя сохраненного XML-файла (/Effect/FlowGraph/name) для достижения соответствующего эффекта в Libs/MaterialEffects/FXLibs/bulletimpacts.xml. Этот XML-файл авторизует необходимые элементы эффекта, такие как эффект частиц, звук или надпись пули.

Примеры

Для создания полноэкранного эффекта Flow Graph вам необходимо использовать несколько дополнительных общих узлов. Вот несколько примеров:

Отрегулируйте время, анимируйте значение

Рис.2: Пример Flow Graph воздействия ядерного оружия.

  • Используйте HUDStartFX и HUDEndFX узел, подключенный к Задержка узел, поэтому эффект длится всю длительность Flow Graph.
  • Используйте Задержка узел непосредственно перед узлами каждого эффекта. Этот узел часто используется для настройки времени активации каждого узла.
  • Используйте Плавать узел (Добавить узел/Интерпол/Float), чтобы анимировать некоторые значения Цветокоррекция. Он может установить Время, StartValue и EndValue. Когда он получает входные данные, он интерполирует значение между StartValue чтобы EndValue в течение Время, а затем передает выходное значение следующему узлу. Это эффективный способ создания анимированных значений.
  • Несколько узлов могут получать одинаковое выходное значение от одного и того же узла. Обычно выходное значение может быть подключено к нескольким входам. Это уменьшает использование узлов.

Проявление текстур на экране

Рис3: Пример Flow Graph эффекта грязи на экране, когда игрок находится на месте взрыва.

  • Используйте RandomSelect узел (Добавить Узел->Логика->RandomSelect), чтобы случайным образом выбрать текстуру из трех доступных выходных данных.
  • Используйте ScreenFader узел для исчезновения каждой текстуры. Используя этот метод, вы можете всплывающие текстуры, а затем исчезнуть через несколько секунд.
  • Когда входной сигнал получен, ScreenFader нод начинает затемнять весь экран и отображать текстуру, основываясь на FadeOutTime ценность. В этом случае FadeOutTime установлено значение 0, поэтому текстура появляется немедленно.
  • FadeIn задерживается на четыре секунды с помощью Задержка node, поэтому текстура некоторое время остается на экране. По истечении четырех секунд весь экран начинает постепенно проявляться в зависимости от продолжительности FadeInTime ценность.
  • Используйте Любой узел (Добавить узел->Логика->Любой), чтобы получить несколько выходных текстур и передать одну выходную информацию на дисплей.
