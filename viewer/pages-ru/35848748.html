Обзор

Меню панели инструментов позволяет пользователям быстро и легко получить доступ ко многим функциям редактора Sandbox с помощью значков в верхней части экрана. В следующей статье представлен краткий обзор панелей инструментов по умолчанию и настроек, доступных в редакторе Sandbox.

Хотя большинство панелей инструментов не требуют пояснений, некоторые требуют более подробного объяснения их использования. Для этих конкретных панелей инструментов были созданы подстраницы (дочерние) страницы этой главной страницы панелей инструментов.

Размер значка на панели инструментов также можно настроить: Правка -> Настройки -> Общие настройки -> Общие -> Размер значка панели инструментов. По умолчанию установлено значение «0» (по умолчанию = 32 пикселя).

Доступ к контекстному меню панели инструментов

Щелкните правой кнопкой мыши на панели инструментов (справа от последнего отображаемого значка на панели инструментов), откроется контекстное меню панели инструментов. Выбор панели инструментов (щелкните левой кнопкой мыши) добавит ее на главную панель инструментов. Каждую панель инструментов можно перемещать и располагать горизонтально вверху редактора, вертикально по бокам или можно полностью открепить от редактора Sandbox, например, поместив на другой монитор.

Панель инструментов аудио

Панель инструментов аудио содержит кнопки для управления воспроизведение звуков во вьюпорте при редактировании: Отключить звук, Остановить все звуки и обновить звук.

Панель инструментов «Ограничения»

Панель инструментов «Ограничения» содержит кнопки для ограничения движения, вращения и масштабирования объектов по определенным осям: X, Y, Z и XY.

Панель инструментов «Координаты»

Панель инструментов «Координаты» содержит кнопки для изменения системы координат: Мир, Местный, Посмотри, родитель.
Пожалуйста, посмотрите эта страница для получения дополнительной информации о системе координат.

Панель инструментов редактирования режимов

Панель инструментов «Режимы редактирования» содержит стандартные кнопки, используемые для манипулирования объектами: «Выбрать», «Переместить», «Повернуть» и «Масштабировать».

Панель инструментов игры

Панель инструментов игры содержит инструменты, которые помогут вам проверить свой уровень: «Переключиться в игру», «Включить физику/AI», «Переключить одношаговый режим физики» и «Выполнить один шаг».

Панель инструментов «Макеты»

Инструмент «Макеты» содержит кнопки для активации различных предустановленных макетов: макет по умолчанию, макет анимации, кинематографический макет, макет дизайна уровней и макет Flow Graph.

Панель инструментов «Физика»

Панель инструментов «Физика» содержит кнопки «Сбросить физическое состояние», «Получить физическое состояние», «Имитировать объекты» и «Включить». Инструмент физики режим.
Пожалуйста, посмотрите эта страница для получения дополнительной информации о новом Инструмент физики.

Панель инструментов выбора

Панель инструментов выбора содержит кнопки, которые можно использовать при выборе элементов: «Перейти к выбору», «Найти», «Группировать», «Разгруппировать», «Связать», «Отсоединить», «Создать префаб», «Зафиксировать выбор» и «Разморозить все объекты».

Стандартная панель инструментов

Стандартная панель инструментов содержит стандартные параметры «Сохранить», «Открыть», «Экспорт в Engine», а также «Отменить» и «Повторить».

Настройка панелей инструментов

CRYENGINE позволяет создавать и настраивать панели инструментов по своему вкусу. Для получения дополнительной информации о том, как это сделать, нажмите здесь.

Панели инструментов проекта

Работая в команде разработчиков и используя систему контроля версий, можно очень легко делиться своими пользовательскими панелями инструментов с другими.

Для этого:

  1. Скопируйте его .json файл из локальной папки настроек (C:\Users\<User_Name>\AppData\Roaming\Crytek\CRYENGINE\<User_Data_Version>\Toolbars\Mainframe, по умолчанию).
  2. Вставьте этот файл в Редактор\Панели инструментов\Мейнфрейм папка в папке проекта игры. Эту последнюю папку, возможно, придется создать, поскольку по умолчанию она не существует.

Имейте в виду, что поскольку AppData — это скрытая папка, вам может потребоваться изменить настройки, чтобы увидеть скрытые элементы.

Теперь настраиваемую панель инструментов можно вернуть в систему управления версиями вместе с остальными данными проекта, чтобы они отображались и для остальной части команды рядом с любыми панелями инструментов, которые они создали для себя.

Панели инструментов для конкретных инструментов

Некоторые инструменты имеют свои собственные панели инструментов, на которых есть кнопки, специфичные для этого инструмента. Их можно настроить так же, как и основную панель инструментов, упомянутую выше, а это означает, что Настройка ToolBars относится и к ним.
