Обзор

Модуль Matchmaking абстрагирует функции подбора игроков каждой платформы в более унифицированный интерфейс. Он позволяет создавать и искать лобби на основе определенных пользователем данных лобби или количества игроков. Это позволяет реализовать группировку навыков или пользовательские игры с настраиваемыми свойствами, заданными игровыми клиентами.

Каждая платформа реализует подбор игроков по-своему, и вам может потребоваться настроить дополнительные свойства вашей игры в менеджере продуктов вашей платформы, чтобы включить определенные функции подбора игроков.

Эта документация также включает в себя специальные функции лобби; хотя лобби не полагаются на подбор игроков, они обычно используются в тандеме.

Лобби предоставляют абстрактный набор функций, таких как настройка данных лобби (например, типа игры), а также пользовательских данных (например, какую команду предпочитает пользователь) и текстовая связь между каждым участником лобби. На некоторых платформах один пользователь может быть частью нескольких лобби, и каждое лобби будет иметь свои собственные функции и события (например, выход из определенного лобби).

Функции службы сватовства

AddLobbyQueryFilterString

Добавляет фильтр запросов лобби, который будет использоваться в следующем QueryLobbies позвони.

CreateLobby

Попытки создать новое лобби для сватовства.

GetQueriedLobbyIdByIndex

Возвращает лобби по указанному индексу из QueryLobbies результат (после OnLobbyQueryComplete событие).

GetUserLobby

Попытки получить идентификатор лобби, в котором проживает указанный пользователь (если есть).

JoinLobby

Заставляет локального пользователя присоединиться к указанному лобби.

QueryLobbies

Запрашивает у серверной части лобби, соответствующие всем фильтрам, добавленным с момента последнего вызова QueryLobbies.

Слушайте OnLobbyQueryComplete событие после запроса к бэкэнду.

События службы сватовства

OnCreatedLobby

Вызывается, когда локальным пользователем создано лобби.

OnJoinedLobby

Вызывается, когда локальный пользователь присоединяется к лобби.

OnLobbyJoinFailed

Вызывается, если запрос на присоединение к лобби не выполнен.

OnLobbyQueryComplete

Запускается после завершения запроса на запрос лобби.

OnPreJoinLobby

Запускается, когда локальный пользователь пытается присоединиться к лобби до получения ответа от платформы.

Когда пользователь пытается присоединиться к лобби, ответ будет либо успешным, либо неудачным. OnPreJoinLobby запускается между запросом на присоединение и ответом сервера о том, что запрос выполнен успешно.

Функции лобби

GetData

Получает данные лобби указанного ключа.

Данные состоят из пары ключ-значение. Ключ соответствует имени данных, а значение — это сами данные.

GetMemberAtIndex

Запрашивает в лобби участника по указанному индексу.

GetMemberData

Получает метаданные пользователя в лобби по имени ключа.

GetMemberLimit

Запрашивает в указанном лобби максимальное количество пользователей, которые могут в нем присутствовать.

GetNumMembers

Запрашивает в указанном лобби текущее количество населяющих его пользователей.

GetOwnerId

Запрашивает в лобби участника, которому принадлежит лобби.

Уйти

Заставляет локального пользователя покинуть указанное лобби.

SendChatMessage

Отправляет сообщение в указанное лобби.

SetData

Устанавливает данные лобби ключа в указанное значение.

SetMemberData

Устанавливает метаданные локального пользователя в лобби.

ShowInviteDialog

Показывает диалоговое окно приглашения для конкретной платформы, позволяющее пригласить друзей в текущее лобби.

События в лобби

OnChatMessage

Запускается для каждого сообщения, полученного в лобби.

OnLeave

Вызывается, когда локальный пользователь покидает лобби.

OnLobbyDataUpdate

Вызывается при обновлении данных лобби.

OnPlayerBanned

Вызывается, когда члену лобби запрещают доступ в лобби.

OnPlayerDisconnected

Вызывается, когда участник лобби теряет соединение с лобби.

OnPlayerEntered

Вызывается, когда участник входит в лобби.

OnPlayerKicked

Вызывается, когда члена лобби выгоняют из лобби.

OnPlayerLeft

Вызывается, когда участник лобби намеренно покидает лобби.

OnUserDataUpdate

Вызывается, когда участник лобби обновляет данные своего участника.

Функции регистрации событий

StartStopLobbyListener

Запускает или останавливает прослушиватели событий лобби.

Эта функция обрабатывает события запуска и остановки для определенных лобби. Пользователь может быть подключен к более чем одному лобби одновременно, поэтому необходим контроль над тем, какие лобби прослушиваются (например, когда локальный пользователь покидает лобби).

Если локальный пользователь покидает лобби, вам технически не нужно вызывать StartStopLobbyListener, поскольку все слушатели этого лобби будут отменены, когда вы покинете лобби.
