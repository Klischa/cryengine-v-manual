Основные моменты выпуска

CRYENGINE 5.3.3 включает в себя различные исправления и знаменует собой запуск нового C# Rolling Ball template. Мы также удаляем проект Sydewinder и делаем его доступным для отдельной загрузки из магазина CRYENGINE Marketplace.

C# катящийся шар template — это простая игра, которая идеально подходит для людей, не знакомых с использованием C# в CRYENGINE. Этот template демонстрирует, как вы можете использовать Entity Component для изменения поведения объектов в вашей игре, использовать физику для перемещения объектов по уровню и получать данные от игрока. Это отличный способ быстро освоить C# и CRYENGINE.

Урок по Сайдевиндеру теперь доступен для отдельной загрузки в магазине CRYENGINE. Sydewinder специализируется на разработке игр на основе программирования и представляет бесконечную игру с боковой прокруткой и счетчиком рекордов. В этом руководстве вы пройдете все необходимые шаги, чтобы начать работу с CE# Framework, а также напрямую взаимодействовать с CryEngine.Common.

Шаблоны игр

  • Новое: Добавлен RollingBall template в выбор игры C# template.
  • Рефакторинг: Удалено приложение Sydewinder — оно будет сохранено как отдельный проект и доступно для загрузки с сайта CRYENGINE Торговая площадка.
