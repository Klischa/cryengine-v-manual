Обзор

CrySpatial — это аудиоплагин функций передачи данных, связанных с головой (HRTF), который позволяет пользователям улучшать звуковые ландшафты своих игр с помощью бинаурального звука. Каждый проходящий через него монозвук CrySpatial фильтрует и вычисляет отдельную звуковую дорожку для каждого уха слушателя.

Поскольку плагин развертывается иначе, чем другие модули Engine, его настройка описана на этой странице.

Для кодера

В целом аудиоплагины должны:

  • Загружаться звуковым движком во время выполнения, чтобы его функциональные возможности стали доступны в вашей игре и в редакторе.
  • Предоставьте динамическую библиотеку для аудиодизайнера, которая будет интегрирована в инструмент разработки вашего промежуточного программного обеспечения.

Авторская работа

Чтобы запустить CrySpatial для вашего аудиодизайнера, скомпилируйте его и передайте следующие файлы на основе используемой реализации промежуточного программного обеспечения.

  • CrySpatialWwise.dll и CrySpatialWwise.xml, если используете Wwise.
  • CrySpatialFmod.dll, если используете FMOD.

Двигатель

При компиляции в виде динамической библиотеки CrySpatial загружается как часть аудиодвижка промежуточного программного обеспечения при инициализации.

  • В случае с Wwise звуковой движок ищет библиотеку плагинов CrySpatial в двоичных файлах движка, где и создан плагин. Следовательно, после компиляции CrySpatialWwise никаких дальнейших действий не требуется.
  • В случае с FMOD пользовательские плагины, такие как CrySpatial, должны располагаться вместе с другими аудиоресурсами в файле. ...\Активы\Аудио\fmod\плагин папка вашего проекта. Этот путь также можно изменить на путь к двоичным файлам вашего проекта FMOD.

Для аудиодизайнера

Чтобы иметь возможность использовать CrySpatial в инструменте разработки вашего промежуточного программного обеспечения, файлы, перечисленные в раздел выше необходимо скопировать в папку плагинов вашего промежуточного программного обеспечения.

Настройка

Wwise

Копировать CrySpatialWwise.dll и CrySpatialWwise.xml в Audiokinetic\Wwise <версия>\Authoring\x64\Release\bin\plugins папка вашей установки Wwise. Затем CrySpatial можно загрузить как MixerPlugin на шины Mix после перезапуска Wwise.

CrySpatial не будет работать в авторском программном обеспечении Wwise, если CrySpatialWwise.dll или CrySpatialWwise.xml отсутствует.

FMOD

Каталог пользовательских плагинов для проектов FMOD можно определить в разделе Предпочтение → Ресурсы → Папка плагинов опция главного меню вашего окна FMOD.

Копировать CrySpatialFmod.dll в этот каталог пользовательских плагинов и перезапустите FMOD Studio; CrySpatial теперь должен стать доступен как эффект плагина.

Использование

Основная функция CrySpatial — использовать 1-канальный монофонический вход и обеспечивать 2-канальный бинауральный выход. Это означает, что его не следует использовать с источниками, отличными от моно.

Wwise

CrySpatialWwise используется как обычный плагин Mix: он добавляется в шину микса и направляет на него моноголоса.


CrySpatialWwise

Подобно другим плагинам пространственной обработки, CrySpatial не может обрабатывать многоканальные сигналы; эти сигналы вызывают проблемы, такие как высокие звуки, похожие на обратную связь, которые появляются при маршрутизации стереофайлов в CrySpatial в Wwise v2018 и более ранних версиях.

Это также означает, что CrySpatial следует вставить в самую нижнюю шину в вашей иерархии, чтобы другие шины не могли изменить количество каналов файла перед переходом в CrySpatial.

CrySpatial, в зависимости от выходной конфигурации своей шины, будет производить либо 2-канальный бинауральный выход, либо объемный звук 5.1, либо объемный звук 7.1 для голосов, направляемых на него. Это особенно полезно для игр, которые поддерживают несколько конфигураций динамиков, поскольку вам не нужно создавать несколько настроек Mix для разных ситуаций.

FMOD

FMOD использует плагины микширования для каждого голоса. Это означает, что CrySpatial необходимо добавить в качестве эффекта плагина к голосам, которые должны быть пространственно преобразованы.


Эффект плагина

CrySpatial работает только для установок, которые обеспечивают 1-канальный моновход, создавая 2-канальный бинауральный выход без ослабления.

Чтобы иметь затухание, необходимо добавить эффект затухания FMOD после того, как CrySpatial был добавлен в качестве подключаемого эффекта.
