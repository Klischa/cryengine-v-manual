Обзор

Теперь этот раздел продолжится частью CRYENGINE, посвященной получению ваших ресурсов из конвейера 3dsMax или Maya. В этом документе мы объясним, как добавить нового персонажа в движок с помощью Character Tool.

В этом руководстве может использоваться пример проекта GameSDK. Мы рекомендуем вам скачать это с База данных активов, импортируйте его в программу запуска, запустите оттуда, а затем создайте новый уровень.

См. эта страница чтобы узнать, как импортировать проект в программу запуска. (Папка по умолчанию для образца проекта GameSDK при загрузке: C:\Program Files (x86)\Crytek\CRYENGINE Launcher\Crytek\gamesdk_<XXX>\GameSDK)

Создание персонажа

Откройте редактор Sandbox из панели запуска.

Откройте Character Tool:

  • Инструменты -> Анимация -> Character Tool

  1. На снимке экрана ниже показана левая панель, разделенная на два вертикальных макета. Она активируется с помощью значка, выделенного красной стрелкой, и предоставляет два фильтра просмотра. В ходе работы с этим руководством вы можете установить на нижней панели фильтр «Анимация».

  2. Создайте новый файл *.CDF и дайте символу CRYENGINE красивое подходящее имя:

  3. Назначьте экспортированный файл скелета *.CHR в разделе скелета. Желтые поля с предупреждениями помогут вам исправить то, чего не хватает, чтобы получить правильный символ CRYENGINE.

  4. Добавьте вложение скина в файл скелета *.CHR.

  5. По умолчанию Character Tool добавит «Объединенное вложение», измените его на «Вложение скина» и найдите файл *.CHR, который вы экспортировали ранее.

Назначение материала

  1. Это будет текущая конфигурация персонажа. Теперь назначьте экспортированный материал. На последнем шаге мы закрепим черный заштрихованный материал для головы. Это потому, что мы назначили ему шейдер dx11 в Maya, который CRYENGINE не поддерживает.

    Активируйте опцию «Программное скинирование», чтобы блендшейпы заработали!

Назначение анимации

  1. В Character Tool отсутствует местоположение анимации (и не только). Это можно сделать с помощью файла *.CHRPARAMS. Чтобы создать новый *.CHRPARAMS для этого персонажа, щелкните поле «Скелет» — это область, отмеченная красным (скриншот выше) и загружаемая с *.CHR.

  2. Добавьте «Фильтр набора анимации» и укажите каталог экспортированного файла анимации «default.i_caf»! Файл *.I_CAF представляет собой промежуточный формат перед сжатием. При желании вы можете добавить новые «Анимационные события» после этого шага, чтобы избавиться от желтого предупреждающего окна — просто выберите папку анимации *.I_CAF.

  4. Слева вы найдете связанные анимации со скелетом *.CHR.

  5. Выберите анимацию «по умолчанию» на левой панели. Теперь вам нужно добавить новый файл *.ANIMSETTINGS и сохранить его:

  6. Чтобы Character Tool обновил вашу blendshape анимацию, перейдите на левую панель — переключитесь, нажав double-щелкнув LMB на любой существующий *.CDF, а затем вернитесь к созданному вами *.CDF этого урока. (Возможно, вам придется выйти и перезапустить редактор Sandbox, а затем вернуться в Character Tool).

  7. Найдите на левой панели сохраненный персонаж (sdk_blendshape_tutorial.cdf). Выберите и double щелкните анимацию «по умолчанию» в левом нижнем углу (или нажмите пробел). Вы должны увидеть скелетную анимацию сустава головы и шеи AND, а также воспроизводимую анимацию blendshape:

    Совет: Проверьте области, отмеченные красным (скриншот выше). Указанные параметры помогут вам проверить созданную вами сцену.

  8. Вы также можете исправить материал "sdk_player_head". Откройте Material Editor в редакторе Sandbox и отредактируйте материал, сделав его более полезным:

Резюме

В заключение этого руководства приведем список файлов, которые вы создали в Maya и экспортировали в CRYENGINE: (замените имя файла, если вы решили использовать другие имена):

  • сохранил файл сцены Maya как файл Maya ASCII перед экспортом
  • экспортировал *.SKIN файл: sdk_player_head.skin содержащий модель со скелетом и данными о скинах
  • экспортировал *.CHR файл: sdk_player_head_skel.chr содержащий скелетную иерархию
  • *.CHR и *.SKIN требует от вас экспорт из кадра позы привязки/дага
  • экспортировал *.I_CAF файл: по умолчанию.i_caf содержащий данные анимации
  • экспортировал *.MTL файл: sdk_player_head.mtл содержащий информацию о материале CE


В CRYENGINE Character Tool вы отредактировали/создали следующие файлы (либо самостоятельно, либо автоматически с помощью CRYENGINE Character Tool):

  • создал *.CDF файл: sdk_player_head_blendshape_tutorial.cdf который определяет анимированный персонаж CRYENGINE
  • создал *.CHRPARAMS файл: sdk_player_head_skel.chrparams содержащий местоположение связанной анимации .i_caf/.caf файлы
  • создал *.ANIMSETTINGS файл: default.animsettings содержащий степень сжатия вашей анимации

В продолжение этого урока по blendshape мы продолжим настройку карты морщин, которая добавит больше деталей: Урок — Настройка карты морщин.

Более подробную информацию об анимации blendshape внутри CRYENGINE можно найти ниже — она в основном используется в целях отладки.

CVar двигателя

Общие переменные:
  • ca_vaBlendEnable 1/0 — общая переменная переменная для включения/отключения плавных переходов на CPU. по умолчанию: 1
  • ca_vaEnable 1/0 — общая переменная переменная для включения/выключения всей вершинной анимации на основе CPU (включая линейное оформление скинов на CPU). по умолчанию: 1
  • ca_vaScaleFactor 1 — скаляр множителя, применяемый поверх дельт. по умолчанию: 1
  • ca_vaProfile 0/1 — отображает информацию о текущих вершинах перехода. по умолчанию: 0
Смешать CVar отбраковки:
  • ca_vaBlendCullingThreshold - чем выше число, тем больше форм смешивания будет отбраковано (в зависимости от того, сколько пикселей они покрывают). по умолчанию: 1.0
  • ca_vaBlendCullingDebug 0/1 — установите значение 1, чтобы показать разницу между отсечением смешивания «с» и «без» (путем переключения функции через каждый второй кадр). по умолчанию: 0
  • ca_vaBlendPostSkinning 0/1 — выполнять смешивание вершинной анимации после скининга (вместо предварительного скининга). по умолчанию: 0

Касательные обновления

Нежесткая деформация требует обновления касательных для получения правильного затенения. Обновление геометрических касательных в реальном времени обходится дорого, поэтому, чтобы минимизировать стоимость CPU, мы используем цвета вершин для переноса окрашенной в синий цвет (0,0,255) маски внутри Maya, которая отмечает наиболее важные части лица. Бюджет XBox One составлял ~2 тыс. вершин.

Обновления Tangent работают только с 8-ми весовыми скинами и программными скинами (Flags=8) в файле *.cdf.

Чтобы включить/отключить/предварительно просмотреть треугольники, отмеченные маской в ENGINE, используйте следующие переменные CVar:

  • ca_vaUpdateTangents 0/1
  • ca_debugSWSkinning 3 (для отображения обновляемых треугольников)
