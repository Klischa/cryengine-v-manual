Обзор

Инструмент «Свойства» показывает ряд соответствующих параметров и операторов для выбранных объектов. Таким образом, при выборе нескольких объектов, которые имеют общие свойства, эти свойства будут показаны. Более того, изменение свойств приведет к изменению их для всех выбранных объектов.

Какие параметры отображаются, зависит от выбранного объекта/сущности и т. д.


Свойства, которые показаны для каждый объект:

Меню

Доступ к меню возможен через значок в правом верхнем углу панели. При нажатии открывается Помощь подменю с Перейти к документации... опция, которая направляет пользователя на страницу документации этого инструмента.

Общий

Нажав на Кнопка блокирует отображаемые в данный момент свойства и гарантирует, что содержимое панели «Свойства» не изменится даже при выборе другого объекта.

Ссылки на сущности

По умолчанию все Масштаб ценности связаны. Например, когда масштаб оси X изменяется с 1 на 2, оси Y и Z также изменятся на 2. Оси масштабирования можно отсоединить, щелкнув значок ссылки. рядом со значениями.

Группа

Несколько объектов можно добавить в группу, чтобы их можно было изменять вместе. Это делается путем выбора всех объектов, которые должны быть добавлены в группу, затем щелчка правой кнопкой мыши и выбора Создать группу вариант.

Если затем выбрать эту группу, на панели «Свойства» появятся следующие параметры:

Свойства

Остальные свойства инструмента «Свойства» могут сильно различаться в зависимости от выбранного объекта/сущности. Для объектов типа Entity здесь также появятся свойства, определенные в скрипте Lua, прикрепленном к Entity.

Добавить компонент

Добавить компонент Кнопка позволяет пользователям добавлять логические компоненты к объектам. Эта кнопка появляется на панели «Свойства» только тогда, когда объект выбран, и отображает все компоненты, доступные для создания, включая созданные пользователем. Дополнительную информацию о компонентах, которые можно добавить к сущности, см. Компоненты сущности — панель «Компоненты» страница.
