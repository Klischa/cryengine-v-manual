Обзор

Идентификаторы групп чувствительны к регистру!

Ссылка

D: Пул буферов устройства

L: Менеджер сцен перегрузки (OSM)

O: Обзор производительности рамы

P: Пулы потоков текстур

S: Элементы потоковой передачи текстур

W: Индивидуальная информация о работнике

Он содержит информацию для каждого работника, разделенную на блокирующие и неблокирующие задачи.

X: Сводная информация о работнике

Содержит сводную информацию обо всех работниках, разделенную на блокирующие и неблокирующие задачи.

Y: Индивидуальная информация о вакансии

Он содержит информацию для каждого задания, разделенную на блокирующие и неблокирующие задачи.

Z: Сводная информация о вакансии

Здесь содержится информация обо всех заданиях, разделенная на блокирующие и неблокирующие задачи.

а: Потоковое аудио

б: Диспетчер пула буферов устройств

c: Профилирование Per-CGF GPU

Статистика по вызовам отрисовки, организованная по CGF и типу рендеринга. Также охватывает рендеринг Scaleform.

г: Профилирование сети

Показывает статистику профилирования сети, разделенную по источникам трафика.

e: Обработка эффектов

f: Синхронизация кадров

г: Графика

я: GPU Время

j: CPU Тайминг

l: Расположение камеры

Эти данные не отображаются непосредственно в виде графика в Statscope, вместо этого они отображаются как часть всплывающей подсказки для графиков.

м: Использование памяти

n: сетевой трафик

o: Потоковая передача объектов

п: Частицы

r: Профилировщики кадров

Подробно описывает количество времени, затраченное на различные задачи.

с: Стриминг

т: резьба

u: определяемые пользователем маркеры

Начальный токен $ используется для категоризации маркеров.

v: Количество вершин

w: Профилирование физических объектов

Классифицируется по типу физического лица, например. static, жизнь и т. д.

x: потоковая передача текстур

z: сетевой канал

Сетевой трафик классифицируется по сетевым каналам.
