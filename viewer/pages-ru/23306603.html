SimulateExplosion

Имитация физического взрыва. Не наносит никаких повреждений от взрыва, связанных с игрой, эта функция применяет только физические силы. Параметры передаются в виде таблицы, содержащей элементы, описанные ниже. 

Physics.SimulateExplosion( explosionParams )

RegisterExplosionShape

Зарегистрируйте новую форму взрыва из геометрии static. Не наносит никаких повреждений от взрыва, связанных с игрой, эта функция применяет только физические силы. 

Physics.RegisterExplosionShape( sGeometryFile, fSize, nMaterialId, fProbability, sSplintersFile, fSplintersOffset, sSplintersCloudEffect )

RegisterExplosionCrack

Зарегистрируйте новую трещину для хрупкого объекта. 

Physics.RegisterExplosionCrack( sGeometryFile, int nMaterialId )

RayWorldIntersection

Проверьте, не пересекается ли с чем-либо сегмент луча от src до dst. 

Physics.RayWorldIntersection( vPos, vDir, nMaxHits, iEntTypes [, skipEntityId1 [, skipEntityId2]] )

RayTraceCheck

Проверьте, не пересекается ли с чем-либо сегмент луча от src до dst. 

Physics.RayTraceCheck( src, dst, skipEntityId1, skipEntityId2 )

SamplePhysEnvironment

Найдите физические объекты, которых коснулась сфера. 

Physics.SamplePhysEnvironment( pt, r [, objtypes] )
