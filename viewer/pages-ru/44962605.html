Введение

С помощью CRYENGINE V мы улучшили общее качество кода и применили новый единый стандарт кодирования для всех модулей движка. На этой странице описан наиболее удобный способ обновления предыдущей версии движка (3.8.x) до последней базы кода V CRYENGINE.

Рекомендация

CRYENGINE 5.0.0, доступная в настоящее время в программе запуска CRYENGINE, получила форматирование кода с помощью инструмента под названием Раскрутить. В настоящее время мы все еще вносим изменения в форматирование, поэтому рекомендуем подождать с обновлением кода до выхода версии 5.1. Планируется, что он будет доступен на GitHub в течение следующих нескольких недель.

Автоформатирование в Visual Studio

Интегрировав Uncrustify с Visual Studio, вы сможете автоматически форматировать свой код в соответствии с рекомендациями каждый раз, когда вы сохраняете свою работу, тем самым избавляя вас от любых усилий, связанных с соблюдением стандарта.

Обратите внимание, что настоятельно рекомендуется установить плагин «P4VS» (плагин Perforce для Visual Studio).

Шаг 1: Получите Uncrustify

Экстракт CRYENGINE_5.0.0_uncrustify.zip в предпочитаемое вами место (по умолчанию: D:\p4\Tools\uncrustify).

Вы можете поместить это где-нибудь кроме D:\p4\Tools\uncrustify, но это местоположение предполагается позже.

Шаг 2. Загрузите расширение Code Beautifier.

Загрузите и установите «Code Beautifier» со следующей страницы: Расширение Code Beautifier для Visual Studio 2015 г..

Шаг 3. Откройте параметры улучшения кода.

Шаг 4. Импортируйте настройки

Нажмите кнопку Импортировать... кнопку и перейдите к D:/p4/Tools/uncrustify, затем выберите CodeBeautifierSettings.xml.

Шаг 5: Сохранить

Все, что вам нужно сделать сейчас, это нажать Сохранить и вы готовы!

(Если только вы не сохранили Uncrustify под D:\p4\Tools\uncrustify. Тогда вам нужно будет зайти в Раскрутить -> Приложение (см. ниже) и отредактируйте пути.)
