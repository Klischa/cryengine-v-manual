Обзор

Ниже приведен список команд консоли, которые применяются к аудиосистеме в целом.

Консольные команды, относящиеся к Wwise и FMOD Studio, см. Wwise Консольные команды и FMOD Консольные команды.

CVars

s_ActivateContext

Активирует контекст.

Этот CVar также загружает метаданные и автоматически загружаемые запросы предварительной загрузки этого контекста. Принимаемый им аргумент — это имя активируемого контекста.

Использование: s_ActivateContext вступление

s_AudioObjectsDebugFilter

Позволяет фильтровать отображение аудиообъектов по строке поиска.

  • Использование: s_AudioObjectsDebugFilter космический корабль
  • По умолчанию: "" (все)

Эта CVar была удалена в версии 5.5.

s_AudioTriggersDebugFilter

Позволяет фильтровать отображение звуковых триггеров с помощью строки поиска.

  • Использование: s_AudioTriggersDebugFilter лазер («лазер» здесь является примером)

  • По умолчанию: "" (все)

    Эта CVar была удалена в версии 5.5.

s_DeactivateContext

Деактивирует контекст.

Этот CVar также выгружает метаданные и автоматически загружает запросы на предварительную загрузку этого контекста. Принимаемый им аргумент — это имя контекста, который необходимо деактивировать.

Использование: s_DeactivateContext вступление


s_DebugDistance

Ограничивает отрисовку отладочной информации аудиообъекта указанным расстоянием вокруг активных слушателей. Установка этого Cvar в 0 отключает ограничение.

  • Использование: s_DebugDistance [0/...]
  • По умолчанию: 0 м (бесконечно)

Эта CVar была добавлена в версии 5.5.

s_DebugFilter

Позволяет фильтровать отображение информации об отладке звука с помощью строки поиска.

  • Использование: s_DebugFilter космический корабль
  • По умолчанию: " " (все)

Эта CVar была добавлена в версии 5.5.

s_DrawDebug

Выводит на экран отладочные данные, связанные с аудиосистемой.

  • Использование: s_DrawDebug [0ab...] (флаги можно комбинировать)

    0: на экране нет информации об отладке звука.

    a: Нарисуйте сферы вокруг активных аудиообъектов.

    б: Нарисовать текстовые метки для активных аудиообъектов.

    c: Нарисуйте имена триггеров для активных аудиообъектов.

    d: рисовать текущие состояния для активных аудиообъектов.

    e: Отобразить значения параметров для активных аудиообъектов.

    f: Отрисовка значений среды для активных аудиообъектов.

    g: Нарисуйте расстояние до слушателя для активных аудиообъектов.

    h: рисовать метки лучей окклюзии.

    i: Нарисовать лучи окклюзии.

    j: рисовать сферы с радиусом смещения луча окклюзии вокруг активных аудиообъектов.

    k: Нарисовать плоскость окклюзии слушателя.

    l: рисовать сферы столкновения окклюзии.

    m: отобразить информацию о глобальном объекте.

    n: отображать информацию, специфичную для промежуточного программного обеспечения, для активных аудиообъектов.

    q: Скрыть информацию о памяти аудиосистемы.

    r: применить фильтр также к отладочной информации неактивного объекта.

    s: Отобразить подробную информацию об отладке пула памяти.

    u: Список контекстов.

    v: список активных событий.

    w: Список активных аудиообъектов.

    x: Отобразить отладочную информацию диспетчера FileCache.

    y: информация об отладке запроса рисования.

s_ExecuteTrigger

Выполняет звуковой триггер.

Аргументом является имя триггера, который будет выполнен для глобального объекта.

  • Использование: s_ExecuteTrigger <Имя аудиотриггера>

s_FileCacheManagerDebugFilter

Позволяет фильтровать отображение различных записей AFCM, таких как глобальные значения, характеристики уровня, игровые подсказки и т. д.

  • Использование: s_FileCacheManagerDebugFilter [0ab...] (флаги можно комбинировать)

  • Значение по умолчанию: 0 (все)

    а: глобальные значения

    б: Особенности уровня

    c: Подсказки по игре

s_FileCacheManagerSize

Устанавливает размер в KiB, который AFCM будет выделять в куче.

  • Использование: s_FileCacheManagerSize [0/...]

  • Значение по умолчанию для Xbox One: 393216 (384 MiB).

s_FileCacheManagerSize Cvar является эксклюзивом Xbox One.

s_HideInactiveObjects

При отображении имен аудиообъектов на экране эту переменную CVar можно использовать для выбора между всеми зарегистрированными аудиообъектами или только теми, которые ссылаются на активные аудиотриггеры.

  • Использование: s_HideInactiveObjects [0/1]
  • По умолчанию: 1 (только активный)

В версии Engine 5.5 имя этой CVar было изменено с s_ShowActiveAudioObjectsOnly чтобы s_HideInactiveAudioObjects.

s_ImplName

Определяет, какая реализация промежуточного программного обеспечения аудио (SDLMixer, FMOD Studio или Wwise) загружается аудиосистемой CRYENGINE.

  • Использование: s_ImplName <название библиотеки без расширения>
  • По умолчанию: CryAudioImplSDLMixer

s_IgnoreWindowFocus

Если установлено значение 1, аудиосистема не будет выполнять lose_focus и get_focus по умолчанию срабатывает при изменении фокуса окна приложения.

  • Использование: s_IgnoreWindowFocus [0/1]

  • По умолчанию: 0 (выкл.)

s_LoadRequest

Загружает запрос предварительной загрузки. Запрос предварительной загрузки не должен загружаться автоматически. Аргументом является имя запроса предварительной загрузки для загрузки.

  • Использование: s_LoadRequest VehiclePreload.

s_LoadSetting

Загружает настройку. Аргументом является имя загружаемого параметра.

  • Использование: s_LoadSetting main_menu.

s_LoggingOptions

Переключает регистрацию аудиосообщений.

  • Использование: s_AudioLoggingOptions [0ab...] (флаги можно комбинировать)
  • По умолчанию: 0 (ведение журнала отключено)
    а: ошибки
    б: Предупреждения
    в: Комментарии

s_ObjectPoolSize

Устанавливает количество предварительно выделенных аудиообъектов и соответствующих аудиопрокси.

  • Использование:s_ObjectPoolSize [0/...]
  • Значение по умолчанию: 256

В версии Engine 5.6 имя этой CVar было изменено с s_AudioObjectPoolSize чтобы s_ObjectPoolSize.

s_OcclusionAccumulate

Устанавливает, будут ли накапливаться значения окклюзии, обнаруженные при приведении лучей, или будет использоваться только самое высокое значение.

  • Использование: s_OcclusionAccumulate [0/1]
    0: Выкл.
    1: Вкл.
  • Значения по умолчанию
    PC: 1 | XboxOne: 1 | PS4: 1 | Мак: 1 | Линукс: 1 | iOS: 1 | Андроид: 1

s_OcclusionGlobalType

Может override тип луча препятствия/окклюзии аудиообъектов в глобальном масштабе. Если он установлен, он определяет, используют ли аудиообъекты нулевую, адаптивную, низкую, среднюю или высокую степень детализации для лучей.

Это тип производительности CVar, который можно использовать для глобального отключения аудио-рейкастинга или принудительного использования различных режимов аудио-рейкастинга для всех аудиообъектов.

  • Использование:s_OcclusionGlobalType [0/1/2/3/4/5]
    0: преобразование лучей для конкретного аудиообъекта.
    1: Все аудиообъекты игнорируют преобразование лучей.
    2: Все аудиообъекты используют адаптивное приведение лучей.
    3: Все аудиообъекты используют низкое приведение лучей.
    4: Все аудиообъекты используют среднее приведение лучей.
    5: Все аудиообъекты используют технологию High Ray Casting.
  • Значения по умолчанию
    PC: 0 | XboxOne: 0 | PS4: 0 | Мак: 0 | Линукс: 0 | iOS: 0 | Андроид: 0

s_OcclusionHighDistance

В пределах этого расстояния при расчете окклюзии используется наибольшее количество точек выборки для обеспечения максимальной детализации.

  • Использование: s_OcclusionHighDistance [0/...]
  • По умолчанию: 10 м

s_OcclusionInitialRayCastMode

Устанавливает режим raycast для начальной проверки окклюзии при выполнении триггера.

  • Использование: s_OcclusionInitialRayCastMode [0/1/2]
    0: нет начальной проверки окклюзии.
    1: Начальная проверка окклюзии использует 1 луч из центра плоскости окклюзии слушателя.
    2: Первоначальная проверка окклюзии использует 5 лучей. Центральный луч и по одному в каждом углу плоскости окклюзии слушателя.
  • По умолчанию: 1

s_OcclusionListenerPlaneSize

Устанавливает размер плоскости в позиции слушателя, относительно которой рассчитывается окклюзия.

  • Использование: s_OcclusionListenerPlaneSize [0/...]
  • По умолчанию: 1,0 (100 см)

s_OcclusionMaxDistance

Окклюзия не рассчитывается для звуков, расстояние до слушателя которых больше этого значения. Установка этого значения на 0 отключает расчеты препятствий/окклюзий.

  • Использование: s_OcclusionMaxDistance [0..]
  • По умолчанию: 500 м

s_OcclusionMaxSyncDistance

Лучи физики обрабатываются синхронно для звуков, находящихся ближе к слушателю, чем это значение, и асинхронно для остальных (возможна оптимизация производительности).

  • Использование: s_OcclusionMaxSyncDistance [0..]
  • По умолчанию: 10 м

s_OcclusionMediumDistance

Устанавливает среднее расстояние окклюзии. Расчет средней окклюзии выполняется между средним расстоянием окклюзии и большим расстоянием с использованием среднего количества точек выборки для средней детализации.

  • Использование: s_OcclusionMediumDistance [0/...]
  • По умолчанию: 80 м

s_OcclusionSetFullOnMaxHits

Если установлено значение 1, значение окклюзии будет установлено на 1 (макс.), когда лучевой приброс достигнет максимального предела попаданий.

  • Использование: s_OcclusionSetFullOnMaxHits [0/1]
    0: Выкл.
    1: Вкл.
  • По умолчанию: 0 (выкл.)

s_PoolAllocationMode

Определяет, как накапливаются размеры пула для элементов управления звуком.

Размеры пула определяются количеством элементов управления, существующих в контексте.

  • Использование: s_PoolAllocationMode [0/...]
    0: накапливать размеры пулов всех контекстов.
    1: суммировать размеры пула глобального контекста и наибольший размер пула для каждого элемента управления в любом другом контексте.

    Значение 1 может использоваться, если активен не более одного другого контекста, кроме глобального контекста.

  • По умолчанию: 0

s_Refresh

Обновляет аудиосистему.

  • Использование: s_Refresh

s_SetParameter

Устанавливает значение параметра аудио.

Первый аргумент — это имя устанавливаемого параметра, а второй аргумент — это устанавливаемое значение float. Параметр устанавливается в глобальном объекте.

  • Использование: s_SetParameter volume_music 1.0

Имя этой CVar было изменено в версии 5.5 с s_SetRTPC чтобы s_SetParameter.

s_SetParameterGlobally

Устанавливает значение параметра аудио.

Первый аргумент — это имя устанавливаемого параметра, а второй аргумент — это устанавливаемое значение float. Параметр задается на всех построенных объектах.

  • Использование: s_SetParameterGlobally volume_music 1.0

s_SetSwitchState

Устанавливает переключатель звука в указанное состояние.

Первый аргумент — это имя переключателя, а второй аргумент — имя устанавливаемого состояния. Состояние переключателя устанавливается на глобальном объекте.

  • Использование: s_SetSwitchState погода дождь

s_SetSwitchStateGlobally

Устанавливает переключатель звука в указанное состояние.

Первый аргумент — это имя переключателя, а второй аргумент — имя устанавливаемого состояния. Состояние переключателя устанавливается на всех построенных объектах.

  • Использование: s_SetSwitchStateGlobally погода дождь

s_StopTrigger

Останавливает звуковой триггер.

Аргументом является имя триггера, который необходимо остановить на глобальном объекте. Если аргумент не указан, все триггеры воспроизведения глобального объекта останавливаются.

  • Использование: s_StopTrigger <Имя аудиотриггера> [<Необязательный аудиообъект ID>]

s_TriggerInstancePoolSize

Устанавливает количество предварительно выделенных экземпляров триггера.

  • Использование:s_TriggerInstancePoolSize[0/...]
  • По умолчанию: 512

s_UnloadRequest

Выгружает запрос предварительной загрузки. Запрос предварительной загрузки не должен загружаться автоматически. Аргументом является имя запроса предварительной загрузки для загрузки.

  • Использование: s_UnloadRequest VehiclePreload

s_UnloadSetting

Выгружает настройку.

  • Аргументом является имя параметра, который необходимо выгрузить.
  • Использование: s_UnloadSetting main_menu.
